## 版本说明

### v4.12.1 · 冷读检验收口（v4.12.0 一致性修复·开发线）

### v4.12.0 · 温度释放与情感纵深（三方温度审计落地·开发线）

- **文笔释放**：破折号零容忍→≤3/章频率闸门（注释式纠错四型仍全禁）；
  章末核查分级「必过+★文学自评 5 问」；style 新增句法级平庸vs生动对照 5 组
- **情感纵深**：目光五层分层与四个进阶写法；安全败退阀（允许她垮一下）；
  受限的心动条件（在乎三来源+弧线升级：物理→身份→自选）；全书级情感钩子
  四条线（心愿/软肋/里程碑/器物人生）；照顾拉锯四拍；devotee 疑虑暗线
- **权重微调**：受限＝核心受众元素（素材供给最优先）；幻肢感＝次核心
  （C 档低频是有意设计，补形态学四件套质感）
- **事实修缮**：摆过步耗力、cuff 近端 1/3、对线归位、单拐拐跟患腿走、
  假肢小雨可穿行；肌电真实局限；肩部包；蹲坑与骑车双向条目
- 本版仅在 develop 分支，验证通过后推送 preview 测试通道

### v4.11.6 · 版本自检与更新提示机制

- `SKILL.md` 新增「〇、版本与更新检查」节：对话首次调用时对比本地 version
  与远端最新 tag（git ls-remote 或 GitHub API），有更新一次性提示并附拉取命令
  （git pull / checkout / clone），非阻塞不提问，提示完直接继续创作流程
- 收集流程铁则补「问题序列封闭」：更新检查不属于询问链，
  11 题逐题提问环节不混入运行时事务（双向锁定）

### v4.11.5 · 破折号闸门与注释式纠错变体家族（实测反馈修复）

实测一章结构性破折号 18 处、冷读仅报 1 条。本版修复：
- **变体家族明示**：「——不对，」「不是X——是Y」「——右腿——」插入标注、
  夹注解释——全部与「A——不，B」同族命中，各附正向替代写法
- **结构性破折号零容忍**（正文叙述层一切用法）：破折号只活在对话内
  （中断/呼喊/拟声延长白名单）；悬停式改句号断句
- **分句式对比句 ≤1/章**；同一动作链句式不得原样复用
- **冷读计数式稽查**：全章分型计数+报告强制给总数；
  判定原则「单处合法、合计超限即违规」

### v4.11.4 · 开篇推荐映射改排除式约束（防推荐收敛）

推荐映射会让生成器走零成本默认路径，同题材反复撞同一维度（新烂开篇）。
本版改为**排除式**——题材只声明禁什么：
- 删 opening.md 与四个 genre 文件的推荐映射表（末世禁 routine、
  温馨日常唯一允许 routine 且须钩子两条否定约束保留）
- historical 的古装落点素材表保留改「用法参考（素材，非推荐）」并扩充
- selfcheck 词表补「推荐开篇」防复发

### v4.11.3 · 收集流程逐题提问协议（交互重构）

创作前信息收集改为逐题提问：
- **一次一题 + 选项与效果**：每题 2–5 个选项并说明各选项对故事的影响，
  自由作答同样有效
- **答后思考再问下一题**：按回答动态分支（上肢跳过辅具题、wannabe 追问截肢过程）
- **随时可跳过**：跳过询问流程 → 默认值一行汇总 → 直接开写
- **末题固定**：是否开启独立子代理冷读稽查（唯一开启入口，跳过收集时默认不开启）

### v4.11.2 · 腾手策略阶梯与放拐合理性检测（实测反馈修复·二次）

实测续检暴露深层病因：有零成本腾手方案（前臂拐挂腕）却为轻微占手事务
（接一杯水）放拐单腿跳——角色决策非理性，创作者与冷读均漏检。本版修正：
- **腾手策略阶梯**：挂腕/夹持 → 携带重整 → 坐姿作业 → 协助 → 放拐（末端解）；
  单手可持物一律走腾手层
- **十步近距离豁免**：目标十步以内可优先考虑放拐单腿跳（合理日常非辅具弃用）
- **放拐门槛三问**：腾手可行吗 / 公共空间吗 / 距离多远——任一不过即禁放拐；
  合法放拐主要是空间受限类（如厕/沐浴/窄处）
- **冷读第二查·放拐合理性**：轻微占手放换单腿跳＝拐杖分离同族错误，命中必改

### v4.11.1 · 移动方式分层口径与拐杖分离检测（实测反馈修复）

实测暴露「单腿跳是默认」缺语境限定被读成全局默认，导致开篇拐杖与角色分离
（冷读亦未拦截）。本版修正：
- **全局默认＝辅具移动**：拐杖在手＝拄拐走、穿着假肢＝假肢走
- **单腿跳仅限三种情形**：临时无辅具 / 无辅具设定（此时才是默认）/ 辅具空白期
- **拐杖分离检测**：移动方式必须与账本辅具状态绑定，
  新增冷读维度 16 与章末核查项，开篇/出场段落优先核查

### v4.11.0 · 剧情触发制与受限层级判定

清单内容辅助剧情，剧情不为清单改造：
- **受限层级判定**：核心受限（行为方式须改变或无解——受众爱看的「能不能」）/
  弱受限（行为方式不变但有代价——累了/慢了，不占核心戏不登记）/
  点缀（纯体力感受）；弱受限撞时间窗口升格速度劣势
- **密度规则**：「每章 ≥1」→ 识别优先 + 软下限（连续 3 章内 ≥2 个核心受限）；
  招牌「每 2 章轮转」→ 反转为限频（间隔 ≥2 章）；「8 章 ≥4 类」降为冷读体检项
- **全触发制**：7 类招牌元素全部由剧情契机触发、无契机不写；
  大纲「分布计划」表 →「剧情契机标注」（只识别不分配）
- **主类重点供给**：功能丧失可重点描写＋样例级不复用；
  新增「冗余备份丧失」角度（健腿被困＝全部移动能力被困）

## v4.10.x 版本说明

辅助器具剥夺的跨章状态：剥夺后可延续数章「移动辅具全部不可用」的空白期，

- **防雷同机制（设定层）**：worldbuilding 新增「缺失解释框架」五档光谱
  （常态化/神圣化/无解释/病因学/隐秘），一书锁一个，神圣化须用户显式选定；
  回避清单新增「补偿叙事」结构级禁令；structure 新增「欲望驱动优先于归因驱动」
