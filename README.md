### v5.5.0 · 交付闸机检化 gatecheck.py（测试通道）

- 新增 `scripts/gatecheck.py`：`python scripts/gatecheck.py <小说项目目录> [--chapter N]`，
  输出 PASS 才算过闸。八项机检：账本日志完整性/模式保真（选定≠实际须降级确认）/
  调用代理必需集/产物文件存在/稽查全覆盖 22/22/审查报告维度行集合/自查覆盖计数
  自洽/交付闸判定
- 机器可验格式：自查报告末行 `自查覆盖: X/X 全查`；审查报告逐行
  `维度N｜判定｜结论` 共 22 行；账本日志增自查覆盖/降级确认字段
- 机检边界如实声明：验格式与覆盖数，不验语义真伪（引句真伪与判定质量仍靠
  冷读＋用户抽核）；无 python 环境按三卡口人工对照并注明「人工验」
- 功能实测：正例 PASS；反例（假执行+无降级确认+计数不自洽）五项绕过手段
  全部机检命中

### v5.4.0 · 执行完整性硬卡口（交付闸）（测试通道）

- 动因：流程规则已密但执行完整性无卡口——AI 可宣称 max 实跑 pro、声称已自审
  实抽查、稽查报告缺维度也照单受理；口头声明≠执行，以证据链硬卡
- 三卡口：①自查全覆盖（清单全条目逐项留痕＋「X/X 全查」报总数）②稽查全覆盖
  （冷读报告 22/22 维度逐项判定，受理前验覆盖数，缺维度退回补查）③模式执行
  保真（必需代理集＋产物文件对照，max 四角色各自独立不得合并扮演）
- 交付闸＝三卡口全过才可向用户交章；假执行章按选定模式重走流程；真降级合法
  （如实登记＋告知记录），谎报原模式才违规
- 五条铁则（四→五，新增⑤全覆盖清点）；账本新增工作流执行日志块
  （逐章证据链：选定/实际模式/调用代理/产物/覆盖/闸判定）

### v5.1.0 · 工作流三模式 flash / pro / max（测试通道）

- 三模式共享全部质量闸（大纲质量闸/章六要素/严重错误五项合一闸/章末核查清单），
  只改变写作与审查的分工方式
- **flash**＝自写自审（单代理＋章末自查，快）；**pro**＝一写一审（主代理写作＋
  独立冷读子代理逐章稽查）；**max**＝队长＋队员（队长做剧情安排与整体把控不写正文，
  写作员成文、审查员稽查、记账员唯一写账者，交接全文件化中转）
- 模式选择入口＝收集流程末题（flash 默认）；降级链 max→pro→flash
- 冷读调用方式按模式分（cold-review 五节）；账本固定属性增「工作流模式」字段

### v5.0.0 · 基调锁定＋剧情主轴重构＋情节查重＋辅具限定（推翻级，测试通道）

- **基调锁定**：收集第 2 题增「基调核心循环」（选定即锁定入大纲契约块）；
  三种漂移形态禁令（内幕转向/存在论升级/未经要求的道德困境化）；冷读维度 20

  受限叙事功能随基调走（冒险热血里受限＝她的战斗条件）

  ＝严重失败；账本 `情节事件登记`；冷读维度 21
- **辅具四类限定**：腋拐/肘拐/平台拐/假肢及组合——其他物品一律不作辅具；

- **五类严重错误分级**（SKILL「〇-补」总纲）：截肢事实偏移/生理动作违规
  （含未覆盖动作按生理事实推断）/辅具连续性偏移/基调偏移/情节重复——任一命中
  即严重失败先改后交；chapter.md 五项合一闸
- **现实/幻想向分割**：两向互斥一书锁一个；现实向超自然＝零、physio 零豁免

### v4.11.2 · 腾手策略阶梯与放拐合理性检测（实测反馈修复·二次）

实测续检暴露深层病因：有零成本腾手方案（前臂拐挂腕）却为轻微占手事务

- **腾手策略阶梯**：挂腕/夹持 → 携带重整 → 坐姿作业 → 协助 → 放拐（末端解）；
  单手可持物一律走腾手层
- **十步近距离豁免**：目标十步以内可优先考虑放拐单腿跳（合理日常非辅具弃用）
- **放拐门槛三问**：腾手可行吗 / 公共空间吗 / 距离多远——任一不过即禁放拐；

### v4.11.0 · 剧情触发制与受限层级判定

清单内容辅助剧情，剧情不为清单改造：
- **受限层级判定**：核心受限（行为方式须改变或无解——受众爱看的「能不能」）/
  弱受限（行为方式不变但有代价——累了/慢了，不占核心戏不登记）/
  点缀（纯体力感受）；弱受限撞时间窗口升格速度劣势
- **密度规则**：「每章 ≥1」→ 识别优先 + 软下限（连续 3 章内 ≥2 个核心受限）；
  招牌「每 2 章轮转」→ 反转为限频（间隔 ≥2 章）；「8 章 ≥4 类」降为冷读体检项
- **全触发制**：7 类招牌元素全部由剧情契机触发、无契机不写；
  大纲「分布计划」表 →「剧情契机标注」（只识别不分配）
- **主类重点供给**：功能丧失可重点描写＋样例级不复用；
  新增「冗余备份丧失」角度（健腿被困＝全部移动能力被困）
