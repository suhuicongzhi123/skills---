# 文本格式规范

## 1. 库文件通用格式

1. 每个库文件首行是 HTML 注释元数据，格式固定：
   `<!-- 库版本 vX.Y.Z | 最近更新 YYYY-MM-DD | 维护方式：就地修改，不留纠错注释 -->`
2. 标题层级：文件名对应一级标题 `#`，大类用二级 `##`，小项用三级 `###`，不超过四级。
3. 库文件命名：`编号_中文名.md`（如 `03_辅具/腋拐.md` 不编号亦可，目录已编号）；章节文件命名：`第NN章_草稿.md`、`第NN章_定稿.md`、`第NN章_审查报告.md`，序号两位数起。
4. 事实类断言用「事实」标注；创作约定用「风格规则」标注；有争议或未能核实的说法写「待核实」并附来源缺口，禁止伪装成定论。

## 2. 统一术语表（全库强制一致）

| 统一用词 | 禁用/慎用词 | 说明 |
|---|---|---|
| 截肢侧 | 残腿侧、坏腿 | 中性、稳定 |
| 健侧 | 好腿/好胳膊（对话除外） | 叙述语言用「健侧」，角色口语可放宽 |
| 残肢 | 断腿、断肢（对话除外） | 指截肢后留存的肢体段；髋离断、肩离断无残肢，改用「截肢侧软组织」 |
| 残端 | 伤口、疤瘌（对话除外） | 残肢的末端；关节离断术后无骨性残端，只有软组织覆盖 |
| 髋离断 | 胯部截肢、半骨盆（错误混用） | 经髋关节离断，骨盆完整 |
| 半骨盆截肢 | 与髋离断混用 | 截肢侧半侧骨盆部分或全部切除，另一术式 |
| 肩离断 | 半肩截肢 | 经肩关节离断，肩胛骨与锁骨保留 |
| 肩胛胸廓间截肢 | 与肩离断混用 | 即 forequarter，连带肩胛骨、锁骨切除 |
| 辅具 | 器械、残疾工具 | 拐杖、轮椅等统称 |
| 腋拐 / 肘拐 | 拐杖（泛称可保留） | 需要精确指代时用专名 |
| 幻肢感 / 幻肢痛 | 幻觉（含贬义，禁用） | 前者是感觉存在，后者是疼痛，分开用 |

## 3. 章节文件格式

```markdown
# 第NN章 章节名
<!-- 状态：草稿 | 适配库版本 vX.Y.Z -->

正文连续行文，自然段推进，不使用「## 场景」类二级标题分段。

* * *

时间、地点或视角切换后的正文……
```

- 正文采用正式小说排版：同一场景内靠自然段与对话衔接；场景切换用空行加独占一行的分隔线 `* * *`，无切换则不加分隔线。
- 机械脚本把分隔线之间的行文依次记为场景一、场景二……豁免标记的场景号按此顺序计数；全章无分隔线时按全文一场处理。
- 角色首次出场处用 HTML 注释标注角色卡文件名，如 `<!-- 角色：林澈_角色卡.md -->`，注释不进入定稿正文。

## 4. 豁免标记格式（双轨）

作品中角色依赖登记在案的豁免完成现实向不可能动作时，在该段落首次出现处加内联标记。豁免分两类，标记格式相同：

`【豁免：<豁免条目名>｜<本章场景号>】`

例：`【豁免：念力取物｜场景三】`、`【豁免：残端立姿美学｜场景二】`

1. 设定豁免：幻想/科幻世界观内的超常规代偿，登记规则见 `../06_题材适配/幻想向与豁免政策.md`。
2. 风格豁免：现实世界观下的美学约定（如残端立姿），登记规则见 `../06_题材适配/风格化美学模式（可选）.md`。

- 豁免条目必须已在作品设定总表登记，未登记的豁免标记视为违规（机械脚本报 EXEMPT-01）。
- 机械脚本识别该标记后跳过对应禁忌动作判定，但冷读稽查仍会审查豁免使用是否越界（代价、限制是否被遵守）。

## 5. 标点与排版

- 中文正文使用全角标点；对话统一使用中文引号。
- 不堆砌感叹号与省略号；同一章节内同类语气词分布需符合角色语言指纹。
- 破折号（书写形态为两个连续 U+2014）在正文与库文件中零容忍，替代方案与例外口径见 `../08_去AI化/AI腔特征清单.md` 第 6 条。
- 语气词落盘政策：库文件允许使用语气词（呢、吧、啊、嘛等）以保持讲解的人味，但遵守四条用量纪律：
  1. 单个自然段不超过 2 个语气词，同一个语气词不在同一文件相邻段落复读。
  2. 事实断言、数据清单、规则 ID、版本头、表格表头保持中性陈述，不带语气词。
  3. 语气词服务于讲解语气，不用于削弱规则约束力（铁律句尾不加「哦」「啦」）。
  4. 项目设定文件（设定总表、角色卡、台账）仅在对话引用与人物口语字段使用，治理字段保持书面语。
- 库文件与项目文件一律 UTF-8 编码、LF 或 CRLF 保持全项目统一。
