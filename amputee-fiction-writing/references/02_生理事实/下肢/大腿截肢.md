# 大腿截肢（TF，经股骨截肢）

## 1. 解剖边界【事实】

- 在髋关节与膝关节之间截断股骨，移除平面以下的下肢；髋关节完整保留。
- 残肢长度差异很大：高位 TF 残肢很短，低位 TF 可保留大部分大腿。残肢越长，杠杆与控制通常越好。
- 残端为股骨骨端，由肌肉成形术/肌固定术包裹缝合，愈合后是有皮肤、肌肉覆盖的圆柱或锥形残肢，不是开放伤口。

## 2. 残肢实况【事实】

- 残肢可做髋关节的屈伸、内收外展，但力量与控制弱于健侧；残肢没有膝关节，不能做出弯膝动作。
- 残端不能当「脚」用：直接承重会造成皮肤破损与骨端损伤，承重必须通过接受腔分散到残肢整体（本库风格规则下假肢不主用，叙事中不应出现残端踩地行走）。
- 残肢体积会随体重、水肿、肌肉萎缩变化，是长期管理事项；残肢袜、衬垫等属于日常用品层级，不算移动辅具。
- 幻肢感/幻肢痛常见；幻肢常被感知为仍保持「膝盖微屈」之类的姿势。

## 3. 移动与承重【事实】

- 辅具组合与 HD 类似：双腋拐、双肘拐、单拐、轮椅；单侧 TF 单腿跳能力通常优于 HD（保留大腿与髋部肌肉），但同样仅限短距离。
- 坐下时残肢自然放在椅面上或略外展，不能写「双膝并拢」对称坐姿；残肢短者久坐需要体位变换防压痛。
- 上下楼梯：无假肢设定下依赖拐杖与健侧，扶手是关键条件，逐阶侧身上下是常见方式。

## 4. 日常动作影响（摘要）

- 禁忌核心：残肢弯膝、残端承重行走、双腿跑跳、截肢侧踢蹬动作。
- 可行事项：游泳、健身（上肢与核心训练）、单腿站立（有平衡条件时）、适配后开车。
- 与 HD 的关键叙事差异：TF 角色有一截可动的残肢，情绪与动作描写可以利用残肢的存在（如残肢不自觉绷紧、幻肢发作时按住残肢），HD 角色没有这个身体部件可写。

## 5. 写作易错点

1. 把残肢写得能弯，膝关节已随小腿移除。
2. 残端直接戳地发力，会受伤，不是功夫。
3. 忽视残肢体积变化这一长期事实，把残肢写成恒定不变。
4. 与 HD 混淆：TF 有残肢、HD 没有，角色卡与正文用词必须一致。
