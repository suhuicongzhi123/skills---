# 单手日常与残端代偿

本文件是上肢截肢者日常动作的跨类型总纲，各平面的解剖边界以同目录小类文件为准。下肢健全、行动无碍，受限集中在「单手如何完成原本双手的事」。

## 1. 残端代偿的分层总纲【事实】

残端能不能当工具，先看平面，不得一刀切：

| 平面 | 残端条件 | 可做的代偿 |
|---|---|---|
| WD/PH（腕离断、手部截肢） | 前臂保留，旋前旋后功能在 | 残端夹物、末端承重（撑桌、压纸）、顶、按、撑，可转掌心配合固定 |
| ED（肘离断） | 上臂全长完整，残端膨大耐受力好 | 夹、压、撞、顶类粗操作有力，无前臂旋转与腕手动作 |
| TH（大臂截肢） | 残肢较短，力量取决于留存长度 | 稳定、推压、夹持，精细度低于 ED |
| SD/FQ（肩离断、肩胛胸廓间截肢） | 无残肢、无骨性残端 | 不存在残端代偿，只有肩部微动与躯干配合，不得套用上述任何残端动作 |

残端是仅次于健手的第二工具，但只做粗操作：固定纸张、抵住物件、配合台面施压。精细动作（系扣、穿针、拧小盖）仍归健手或工具，残端不承担。

## 2. 单手任务的四个出口

任何双手任务写不下去时，按固定物、工具、残端、求助四选一处理，不渲染无能，受限写真实（够不着、夹不住、拧不动）：

- 固定物：腿夹、身压、桌沿、重物压住。
- 工具：长柄刷、磁吸扣、松紧带、单手砧板、语音输入、单手键盘。
- 残端：按第 1 节分层，仅 ED 及以下平面可用。
- 求助：请人搭一把手，是正常社交不是失败。

## 3. 高频场景的标准处理

| 场景 | 单手方案 |
|---|---|
| 进食 | 健手执筷勺，大块预切或用叉；端碗靠桌沿或腿夹 |
| 穿脱 | 套头衫先套健臂再钻头；纽扣拉链改松紧、磁扣、套头；文胸用前置扣或先扣好再转身套穿 |
| 书写 | 健手书写，压纸靠重物、身压或下巴 |
| 拧转 | 瓶盖门把夹腿拧，或用专用工具固定后单手旋 |
| 提携 | 单手提，重物走背包、腿夹或顶靠 |
| 绑系 | 鞋带改一脚蹬或预绑松紧结 |
| 清洁 | 单手洗浴，够背用长柄刷 |
| 手机与支付 | 语音输入、单手拇指操作；扫码与开包装用残端或腿夹固定后单手做 |
| 驾车 | 方向盘旋钮（spinner knob）单手转向，改装件须在角色卡登记 |
| 婴儿护理 | 台面固定加残端按压配合，单手完成换尿布等流程 |

剪纸、绑绳、撕薄膜、剥线这类需要持续双向受力的双手任务最难，必须有固定物或工具；撑伞、抱娃本身单手可行，只有与下肢截肢拄拐语境叠加时才构成「双手占用」矛盾，归口 `../../03_辅具/占用双手时的拐杖处理.md`。

## 4. 时间成本与幻肢错位

- 单手动作比双手慢，流程更长：写她提前准备、动作熟练但有固定顺序，不写成与双手同样快，也不写成每件事都狼狈。
- 上肢近期档幻肢的高频错位：下意识伸两只手去接递来的东西，截肢侧落空，东西失手。判定程序按 `../术语与易混辨析.md` 第 4.1 节，动作未完成、真失手才成立；稳稳接住即违规。
