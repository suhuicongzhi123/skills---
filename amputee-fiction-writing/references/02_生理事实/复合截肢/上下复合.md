# 上下复合截肢

## 1. 总原则

- 约束取并集：先按各部位代码分别回读小类文件，再叠加复合限制；不存在「缺得多反而习惯了所以动作不受限」的豁免。
- 核心矛盾是辅具冲突：下肢辅具（拐、轮椅）依赖手与上肢，而上肢缺失恰好削弱的就是这个能力。每个复合角色必须在角色卡中写明移动解决方案，不能留白。

## 2. 典型组合的移动逻辑

| 组合 | 移动方案（本库风格规则下） | 关键限制 |
|---|---|---|
| 双下肢 + 单上肢缺失 | 健侧手单手驱动手动轮椅（选配单手驱动圈）或电动轮椅；双拐方案不成立 | 单手驱动速度与越障能力下降；转移只能靠单臂与核心 |
| 双下肢 + 双上肢缺失 | 电动轮椅（头部/嘴/语音控制，按时代技术水平）或陪护推行 | 独立转移几乎不可能，照护依赖是人物处境的核心 |
| 单下肢 + 双上肢缺失 | 轮椅为主；健侧腿可在地面短距离拨划辅助转向 | 拐杖无法握持，单腿跳失去摆臂平衡，风险极高 |
| 单下肢 + 单上肢（同侧/对侧） | 对侧手单拐或轮椅，按侧别关系定 | 同侧缺失（如缺右腿+缺右手）时单拐只能左手持，与患侧同侧，步态别扭；对侧缺失则持拐关系自然，侧别必须算清 |

## 3. 侧别核算义务

- 复合角色的每一处侧别描写都要过两次：下肢侧别一次、上肢侧别一次。机械自查按角色卡代码逐项比对。
- 「同侧」与「对侧」关系影响辅具选型与战斗动作设计，设定阶段就要画图或列表确认。

## 4. 写作易错点

1. 只写下肢约束忘掉上肢约束，出现轮椅角色双手端东西（没人驱动/制动）。
2. 拐杖出现在无双侧可用手的角色身上。
3. 转移动作省略发力过程，复合截肢者的转移比单一截肢更慢、更依赖布置（刹车、扶手、转移板）。
4. 照护依赖被浪漫化或被完全隐形，它是真实的时间与关系成本，应进入情节与人物关系，而不是回避。
