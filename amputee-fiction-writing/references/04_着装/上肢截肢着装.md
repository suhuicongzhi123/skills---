# 上肢截肢着装

## 1. 空袖管：允许描写【风格规则】

与下肢裤装的「不描写空裤腿」红线相反，本库允许并鼓励描写空袖管，它是上肢截肢者重要的视觉与动作语言。

## 2. 袖管处理方式

| 术式 | 袖管状态 | 常见处理 |
|---|---|---|
| SD 肩离断 | 肩部以下无肢体，袖管自肩线起扁平垂落 | 肩部缝拢固定、别针收短、内衬垫修饰肩线 |
| FQ | 肩轮廓塌陷，领口与袖山同时变形 | 肩部加垫或选落肩款，成衣改动最大 |
| TH/ED | 上臂或残肢撑起部分袖型，其下空垂 | 袖管在残肢末端附近收缝，或折叠固定 |
| TR | 肘部以下空垂 | 前臂段收缝或卷起固定 |
| WD/PH | 腕部以下为空或部分残留 | 袖口收窄、改良手套，或自然露出残端 |

- 双侧者两侧对称处理；混合平面者两侧袖型不同，是人物外形的辨识锚点。

## 3. 可写的真实细节

- 空袖管随转身、风、俯身摆动的方式与有肢体时不同（没有末端重量，摆动更飘）。
- 残肢在袖管内撑起的轮廓（TH/TR 角色）与完全扁平的袖管（SD 角色）的视觉差异。
- 固定别针松开、袖管滑进餐盘/墨水/雨水的小事故。
- 穿衣顺序：先截肢侧后健侧，脱衣反向；纽扣、拉链改用魔术贴、前置拉链、运动款。
- 文胸：前置扣、运动内衣、改装松紧款是常见方案；背后系扣需要练习或他人协助，可作关系场景。

## 4. 写作易错点

1. 把下肢的「不描写」规则错套到袖管上。
2. 扁平袖管里写出肢体轮廓或肘部顶起的形状（SD 角色）。
3. 忽略穿衣动作成本，单手角色穿衣速度与常人无异。
4. 固定方式前后不一（本章别针、下章缝合），以角色卡登记为准。
