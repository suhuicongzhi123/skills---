# 现实感细节库

本库存放现实向写作的「硬细节」：医疗康复流程、无障碍出行制度、辅具耗材生态、居家改造与照护服务。全部为【事实】口径的制度与流程知识；涉及具体品牌与价格的内容集中在第 6 节，按时效快照管理。与 `现实向.md` 的分工：那个文件管创作原则，本文件管可直接入文的细节料。

## 1. 医疗与康复流程

### 1.1 院内动线

- 典型链条：急诊/门诊确诊 → 手术评估 → 手术 → 重症或骨科病房 → 康复科/康复医院转科 → 出院评定 → 社区康复与门诊随访。
- 转科不是自动的：床位、医保结算、康复科评估意见都可能卡住，「想转转不了」是现实矛盾素材。
- 关键文书：入院记录、手术知情同意书、康复评定报告（肌力、关节活动度、日常生活活动能力评分）、出院小结。文书会被后续理赔、辅具申请、工伤认定反复调用，丢一份补一份的流程很折磨人。

### 1.2 康复训练的真实器械与叫法

- 平行杠：康复厅最基础的站立与步行训练设施，双杠夹一条步道。
- 平衡垫、Bobath 球（训练球）、功率车（上肢/下肢分体）、训练床、助行器、阶梯训练架、磨砂板（上肢推拉训练）。
- 作业治疗室（OT 室）：模拟厨房、模拟卫生间、系扣训练器、取物器、穿袜辅助器。
- 物理治疗室（PT 室）：理疗设备（电刺激、超声波、蜡疗）、牵引设备。
- 写作纪律：用器械的真实名称，不编商品名；患者对这些器械的态度变化（新鲜→厌倦→依赖→告别）是现成的心理曲线。

### 1.3 残肢管理的日常细节

- 弹性绷带包扎要重缠、会松脱；残肢套每日换洗；接受腔内衬有汗液与气味管理问题。
- 残肢体积波动直接影响适配：今天合适的接受腔明天可能磨红，需要加袜套调节层数。
- 皮肤检查靠镜子或手机拍照自查，发红 30 分钟不消退就要停训排查。
- 幻肢痛的应对在不同角色身上不同：药物、按摩残肢、镜子疗法、热敷、忍耐，写人物试错的过程，不写一种神药。

## 2. 无障碍出行制度

### 2.1 铁路（以 12306 体系为例，地方细则现查）

- 「重点旅客预约」：进站前通过 App 或电话预约，提供轮椅进站、无障碍电梯引导、站车交接服务；高峰时段运力紧张，约不上是真实情节。
- 站车交接：站台工作人员把旅客交给列车长，下车时再接一次，链条上每个环节都依赖具体工作人员的熟练度。
- 无障碍车厢与卫生间：车型不同配置不同，老车型可能没有无障碍卫生间，买票前要查车型。
- 电动轮椅的电池：锂电需提供规格参数、符合运输规定，铅酸电池限制更多，进站安检会被单独询问。

### 2.2 民航

- 国际通行的服务代码：WCHR（停机坪到客舱能自主上下台阶，仅需远机位轮椅）、WCHS（不能上下台阶，需廊桥与机上轮椅）、WCHC（完全不能移动，需机上轮椅与人员协助）。订票时申报，值机再确认。
- 自带手动轮椅一般免费托运；电动轮椅电池规定按航司与机场现行规则执行，提前 48 小时申报是常见要求。
- 客舱轮椅（aisle chair）是窄椅，用于客舱内移动，乘客自己的轮椅在登机口被收走、到达口归还，这段「装备真空期」的心理感受可入戏。

### 2.3 城市交通与建筑

- 地铁：预约服务、直梯分布、站厅到站台的垂直动线各线不同；换乘通道的长距离是真实体力考验。
- 公交：低地板车辆比例、驾驶员的停靠配合度因城市而异；预约型无障碍巴士通常要提前下单。
- 建筑入口的默认值（上锁的无障碍厕位、维修中的电梯、终点对着车流的坡道）按 `现实向.md` 第 3 节执行，本库不重复。

### 2.4 驾驶与骑行【事实】

**汽车（自动挡踏板在右）**

- 左腿截肢（右腿健全）：可原车直接驾驶，右脚踏板不受影响。
- 右腿截肢：须手控改装（手动油门刹车装置）或左脚油门改装，改装车与备案手续是角色背景的一部分。
- 手动挡车型一律走手控改装；上下车先坐车座再收腿，不写站立跨进车厢。
- 单手驾驶辅助件：方向盘旋钮（spinner knob）让单侧手可以单手打方向，上肢截肢角色出现时写明改装件。

**两轮与三轮**

- TF/TT 单脚踩踏自行车可行：坐垫承重绕开截肢侧，患侧踏板拆除或悬空随转，发力全在健腿；车座要低，保证脚能点地。
- 电动两轮车同理：双手把支撑加坐垫承重，膝下与膝上截肢均可行。
- HD 普通双踏板自行车不可行（无患侧腿控车与上下车），替代方案是三轮电动车或手摇车。

写作用法：改装件、上下车顺序、停车时的支撑习惯是人物生活动作，不要只写「她开车走了」。

## 3. 辅具与耗材生态

### 3.1 购买与维修渠道

- 医院康复科周边的器械店：贵但能现场试、能开发票走报销。
- 连锁药房与医疗器械连锁：品类标准化，拐杖、轮椅现货为主。
- 电商旗舰店：型号全、价格低，缺点是尺寸要自己量、售后靠寄修。
- 厂家直营与定制商：接受腔、定制轮椅、矫形器走这条线，周期以周计，返修要等。
- 二手社群：病友群、论坛的转卖与交换，价格友好但无售后，是低收入角色的真实选择。

### 3.2 耗材清单（长期经济账的素材）

- 拐杖橡胶脚垫、轮椅内外胎与刹车线、接受腔内衬与袜套、压疮垫、护肤与绷带、转移板、防滑垫。
- 耗材是 recurring cost：单月不显眼，年度汇总能压垮低收入家庭；报销目录覆盖范围有限，目录外的全自费。
- 写作用法：让角色对耗材价格有精确记忆（符合 `../08_去AI化/真人写作指纹.md` 第 6 节数字报数），比喊「生活艰难」有力。

### 3.3 补贴与残联流程

- 常见链条：户籍/居住地残联申请 → 资质评估 → 定点机构配置 → 验收 → 结算（限额内补贴或报销比例，各地不同）。
- 痛点素材：名额排队、指定目录里没有想要的型号、异地户籍的待遇差、发票与证明的折返跑。
- 纪律：具体比例、目录、时限全部按作品所在地现行政策现查，库内不写死数字。

## 4. 居家改造与照护服务

### 4.1 居家改造清单

- 入口：坡道或台阶处理、门槛拆除、入户门净宽。
- 卫生间：淋浴凳、扶手（L 型与一字型位置不同）、防滑砖、坐便加高器、洗手台下方留膝空间。
- 厨房：低位操作台、下拉式吊柜、侧开式冰箱。
- 卧室：床高与轮椅座面齐平、夜灯、转移空间预留。
- 智能件：语音灯控、感应门、可视门铃，经济条件分层，不家家配齐。

### 4.2 照护服务

- 护工市场：医院陪护（按天）、居家护工（按月）、钟点工（按次）三档，价格与技能差异大；会康复护理的护工稀缺且贵。
- 喘息服务：给家属照护者放假的短期托养，部分城市由政府购买服务供给，名额紧张。
- 社区资源：家庭医生签约、社区康复站、无障碍督查热线，知道规则的人才能用足资源，这本身就是人物能力的一部分。

## 5. 细节调用纪律

1. 细节为人物与冲突服务：一段流程戏至少推动一个关系变化或决策，不做百科展陈。
2. 模糊但正确优先：查不准的机构名称用类别词，不编一个像真的的名字。
3. 地域与时代分层：一线城市与县域、2026 年与 2006 年的无障碍生态完全不同，动笔前在设定总表锁定城市层级与年代。
4. 制度细节会过期：本库第 1–4 节是相对稳定的流程骨架；凡涉及具体数字、申报入口、时限的，写作时现查并在台账记录查阅日期，凭记忆写政策是会翻车的。

## 6. 品牌与价格快照（2026-11-12 核查）

本节是**时效快照**，不是稳定事实。商业品牌换代快、价格随渠道波动，使用前必须重新核查；核查后更新本节点的日期，查不到就降级为类别词。

### 6.1 使用规则

- 单章具名品牌不超过 2 处（与 `现实向.md` 第 4 节一致），其余用类别词。
- 品牌要与角色经济阶层匹配：低收入角色不随手使用高端进口型号。
- 快照只记「类别—代表性品牌—价位带」，不记精确单价；币种与价位带随核查更新。

### 6.2 快照表

| 类别 | 代表性品牌方向（核查后使用） | 价位带（相对） | 阶层适配提示 |
|---|---|---|---|
| 手动轮椅 | 国产日用型 / 进口运动型两条线 | 低—高，跨度极大 | 日常代步选中低，运动与定制向高 |
| 电动轮椅 | 国产锂电轻便型 / 进口多功能型 | 中—高 | 高价设备与补贴目录的落差是经济账素材 |
| 腋拐/肘拐 | 国产医用品牌 / 进口铝合金与碳纤维款 | 低—中 | 碳纤维轻量化对收入敏感角色是「舍不得买」的物件 |
| 接受腔与假肢装配 | 公立康复中心装配线 / 民营连锁装配机构 | 中—高，周期长 | 售后距离与返修周期比品牌更影响选择 |
| 护理耗材 | 医用敷料大厂 / 电商白牌 | 低，但复购累积 | 白牌与品牌的价差是低收入账本细节 |
| 出行服务 | 12306 重点旅客 / 航司 WCH 服务 / 城市网约车无障碍车型 | 公共服务低价或免费，预约门槛在流程不在价格 | 「会预约」本身就是技能 |
| 线上购买 | 综合电商旗舰店 / 垂直器械电商 / 病友社群二手 | 全价位 | 二手渠道承载真实社群生态 |
