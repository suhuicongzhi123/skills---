# 风格化美学模式（可选）

本文件登记一类特殊的【风格规则】：为了特定美学风格，允许作品在**项目级声明**后，有限度地呈现医学事实层面不成立或不推荐的身体表现。它和 `幻想向与豁免政策.md` 是两条并行通道：

- 幻想豁免：世界里真的存在超自然/科幻代偿，设定内自洽。
- 风格豁免：世界仍是现实世界，作者与读者达成「这是美学约定」的默契，类似武侠片里的轻功。

## 1. 总纪律（先讲死规矩）

1. **事实规则永不改写**：`../02_生理事实/禁忌动作总表.md` 的全部条目继续是事实。本文件不修改任何事实断言，只提供有限的呈现许可。
2. **默认关闭，声明启用**：未在启动框架 S1 冻结、未登记进作品设定总表的项目，一律按现实口径冷读，出现即判致命级，没有通融的余地哦。
3. **标记义务**：每次依赖风格豁免完成动作，正文段落首次出现处打 `【豁免：<条目名>｜<场景号>】`，并在配置文件的 exemptions 中登记对应规则 ID 与场景；机械脚本凭标记放行，冷读凭本文件查条件。
4. **代价可见**：风格豁免动作必须呈现身体代价（压痕、疼痛、皮肤风险、事后检查），不允许写成无成本的日常能力。
5. **不扩散**：豁免只覆盖登记的动作本身，不得顺手给角色解锁其他禁忌动作。

## 2. 模式 AM-1：残端立姿美学

### 2.1 它是什么

允许下肢截肢角色在特定场景中，以截肢侧残端/软组织覆盖处短时触地承重，完成低姿、半立或象征性直立的画面。这是向特定美学传统（慕残题材长期形成的视觉语言）开放的**风格约定**，不是康复建议，也不是现实中可行的移动方式。

### 2.2 适用平面与资格【事实前提，不可越过】

| 平面 | 资格 | 说明 |
|---|---|---|
| SYM（赛姆） | 不需要本模式 | 赛姆术式保留足跟垫、本来就设计为末端承重，属事实可行，走正常规则即可 |
| TT / KD / TF | 有条件适用 | 残肢有软组织覆盖，但无保护直接承重仍有皮肤破损、滑囊炎、骨端损伤风险，故只能短时、低频、带代价 |
| HD / 半骨盆 | 禁用本模式 | 没有残肢、没有可承重的末端结构，直立画面只能走幻想豁免（外骨骼、念力等），不允许以「残端承重」解释 |
| 上肢各平面 | 不适用 | 本模式只管下肢立姿；上肢撑扶动作按总表 ACT-ARM 系列判定 |

### 2.3 使用条件（全部满足才可登记）

1. 时间窗：术后定型完成之后（参照 `../02_生理事实/术后恢复时间线.md`，通常术后 3 个月以上、伤口完全愈合、疤痕基本成熟）。恢复期内任何阶段一律禁止，没有例外。
2. 时长：无支撑以秒计，有扶握/倚靠以分钟计；只能是仪式性、展示性瞬间，不是移动方式。
3. 频率：全书低频使用，同一角色不超过个位数次数；高频出现等于把豁免变成了日常能力，按违规处理。
4. 支撑：除 SYM 外，无辅助完全直立不成立；画面里要有墙、桌、拐、他人手臂等支撑交代。
5. 代价三件套：动作前的犹豫或准备、动作中的疼痛/吃力外化、动作后的检查（发红、压痕、舒缓处理），至少兑现两件。
6. 辅具不消失：角色的拐杖、轮椅仍在现场、仍是其日常移动手段；豁免瞬间结束后立刻回到辅具逻辑。

### 2.4 与既有规则的咬合

- 「跪」「蹲」的用词口径仍按 `../02_生理事实/术语与易混辨析.md` 第 7 节执行：写清承重部位与发力过程，不写「双膝跪地」式事实错误。
- ACT-LEG-07（残端承重站立/行走禁令）在事实层保留；启用本模式的项目，靠逐场景登记的风格豁免让机械脚本放行该规则，冷读则按本节 2.3 查条件。
- 配置登记示例（写进项目配置的 exemptions，不进库的自测配置）：

```json
{
  "name": "残端立姿美学",
  "rules": ["ACT-LEG-07"],
  "scenes": ["场景二"],
  "boundary": "TF 残端、扶桌短时半立、定型完成后",
  "cost": "事后残端发红，需冰敷与衬垫检查"
}
```

### 2.5 冷读判定

- 启用了 AM-1 但不满足 2.3 任一条件：致命级（风格豁免越界）。
- 未启用 AM-1 却出现残端承重直立：致命级（事实错误，按原 ACT-LEG-07 口径）。
- 豁免动作无代价、无标记、未登记：分别按风格违规、EXEMPT-01、配置违规上报。

## 3. 模式登记台账（项目级）

作品设定总表中增设「风格化美学模式」区，每启用一个模式登记一行：模式编号、适用角色与截肢代码、适用场景清单、代价写法承诺、冻结日期。变更走 `../01_工作流/启动框架.md` 第 6.4 节变更控制，不允许写作途中临时开启。

## 4. 边界声明

本文件不包含任何恋物语境的动作设计，不开放性场景用途；露骨内容的执行边界（见 `../09_创作注入/身体描写浓度与亲密书写.md` 与 SKILL.md 内容边界）不受本模式影响，任何模式都不能解除该边界。
