# 热血战斗题材适配

## 1. 总要求：是真打，不是过家家

- 拳拳到肉、魔法对轰、剑术交锋、枪林弹雨，战斗必须有真实的攻防意图：每一招都在争取击倒、脱身、夺物或掩护，禁止摆造型式互殴。
- 交战双方都有目标、判断与应变；反派会抓住角色的身体短板打，主角的胜利来自战术与意志，不靠反派降智。
- 伤害有后果：淤青、骨裂、辅具损坏、软组织挫伤按时间线留存，下一场战斗带伤上阵要付出代价。

## 2. 截肢者的战斗风格库（基于真实身体条件）

| 配置 | 风格资源 | 必须保留的短板 |
|---|---|---|
| 单侧下肢+双拐 | 拐杖可作短兵器（戳、架、绞），重心低利于突袭与地趟动作 | 移动范围受拐杖限制，占手，被近身夺拐即陷被动 |
| 单侧下肢+单拐 | 一只手解放，可持械；单腿支撑的招式幅度小 | 跳跃动作极少，地面湿滑与台阶是死穴 |
| 轮椅使用者 | 座椅冲撞、翘轮压脚、低位扫堂、宽度卡位；投掷与双手器械有稳定底盘 | 地形依赖极强，后轮被制住即困；转移需要窗口 |
| 单侧上肢缺失 | 单侧兵器+残肢近身顶撞（TH/ED 残肢有力），破绽在空门侧 | 无法双手持重兵器，远程武器后坐与装填需改装 |
| 双侧上肢缺失 | 脚刃、口持、魔法/科技代偿；以距离控制与环境利用为主 | 被贴身缠斗极度危险，跌倒即劣势 |
| 复合截肢 | 按并集约束设计，装备与异能定制化 | 装备依赖度最高，失灵场景最残酷 |

- 幻想向在此基础上加豁免能力，但豁免制造的新打法也要配套新破绽（见 `幻想向与豁免政策.md`）。

## 3. 禁止战斗细节复用

每场战斗开写前登记五要素，五要素不得与已有任何一场全部雷同：

1. 地形与空间（房间/街巷/桥面/雨水中的废墟……）
2. 战术目标（击杀/突围/护送/抢夺/拖延……）
3. 动作编排（起手、转折、绝杀的具体招路与辅具用法）
4. 情绪基调（愤怒/冷静/恐惧/戏谑/绝望）
5. 代价与后果（谁受伤、什么坏了、关系如何变化）

- 冷读稽查逐场比对，复用两处以上即判重要级问题；同一招「拐杖戳膝」连用三场即触发预警。
- 群战与单挑交替、远程与近身交替、顺风与绝境交替，节奏服务于爽感曲线。

## 4. 爽与燃的工程化

- 爽感来自「被压制→找到路径→反制成功」的完整周期，周期过短（一路碾压）会腻，过长（一直挨打）会丧。
- 燃点前置铺垫：主角的战术灵感必须来自前文出现过的信息或能力，禁止临场无中生有。
- 每场战斗至少一个「只有这个角色能打出来」的瞬间，与其三区分锚点或截肢配置绑定。

## 5. 战斗受伤的四条写法通道

一个移动本就受限的人打硬仗而不付任何代价是失真。受伤本身可以写，主写法是把伤落在功能与后续上，而不是渲染感官。

| 通道 | 写什么 | 写法方向 |
|---|---|---|
| 功能影响（主通道） | 伤了之后哪件事做不成了、动作链哪一环断了 | 写结果不写感觉：剑脱手、落脚偏了、跳的距离短了半寸 |
| 恢复代价 | 恢复占用的时间、被迫改变的计划、别人的等待 | 代价落在下一场，不落在当场 |
| 已愈的痕 | 旧疤的触感、天气变化时身体先知道 | 不写疼，写「知道」 |
| 他人的处置 | 别人替她包扎、被要求休息 | 不写处理过程，写结果与一句话 |

配套纪律：

- 疼痛与伤口的特写尺度按项目冻结的身体描写浓度档位管理（见 `../09_创作注入/身体描写浓度与亲密书写.md`），但任何档位都不把受伤写成「证明她坚强」的励志桥段，也不做感染、失血、溃烂的猎奇展列。
- 受伤不得改变截肢设定：不得因受伤「顺便」多截一段，也不得因治疗「顺便」长回（永不豁免清单见 `../02_生理事实/禁忌动作总表.md` 第 6.1 节）。
- 短期伤（数日至数周）在台账登记伤势，跨章追踪至痊愈；痊愈须有事件交代（时间流逝可以，但正文要交代「能用了」），不得无声消失。
- 倒地是战斗阶段的结束，不是一次失误：写她抓到哪个支点、谁拉了她一把、对方为什么没补刀；不写她自己弹起来，起身动作链与类型差异按 `../03_辅具/占用双手时的拐杖处理.md` 第 6 节与各平面事实文件执行。
