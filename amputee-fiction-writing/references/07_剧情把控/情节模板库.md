# 情节模板库

本文件是情节选型的骨架目录，每个模板给结构、场景流与伏笔位。模板与三幕节拍（`整体架构与节奏.md`）配合使用：模板决定「这是哪种故事」，节拍表决定「每章怎么排」。模板不决定人物，人物按 `../05_角色塑造/` 建档后反向校准模板，不许让情节把人写成道具。

## 1. 意外截肢—重建流（现实向主模板）

- 结构：事故/疾病 → 抢救与确诊 → 康复期 → 回归尝试 → 新平衡（不是回到过去）。
- 场景流：苏醒、第一次见残肢、拆线、第一次转移、第一次出门、返工/返校摩擦、一次重大挫败、带着缺口重建日常。
- 伏笔位：事故细节分批披露；康复期认识的人在后段回收；辅具损耗贯穿全书。
- 红线：恢复节奏走 `../02_生理事实/术后恢复时间线.md`，禁止神速康复；结局不写「变回正常人」。

## 2. 自愿改造流（BIID/伦理向）

- 结构：长期身份困扰 → 求医无门 → 获得手术的现实路径（合法或灰色）→ 术后归位感 → 与社会解释体系的冲突。
- 适配：成人角色限定；伦理与法律处境写实，不浪漫化手术风险。
- 伏笔位：早期的异常行为细节（反复测量、对特定身体的强烈注视）作为后段解释，不提前剧透。
- 红线：未成年人禁用；不与性化叙事绑定。

## 3. 扮残伪装流

- 结构：因逃避（债务/追捕/自我保护）伪装成截肢者 → 伪装带来的便利与意外代价 → 真实残障社群的进入 → 身份压力累积 → 揭穿与清算。
- 戏眼：伪装者学习「如何被看待」的过程，与真实截肢者形成镜像辩论。
- 红线：立场不能滑向「装残骗同情有理」；社群的信任被辜负后要有重量。

## 4. 渐进改造流（黑暗/幻想）

- 结构：多次手术/改造逐次推进，每次改变一次身份与关系，主角在欲望与代价间主动签字。
- 适配：科幻或犯罪向，每阶段的医疗可行性按世界观规则登记。
- 伏笔位：第一次改造时没在意的条款与副作用，在后段成为枷锁。
- 红线：自愿性要接受追问，信息不对称下的「同意」是不是真同意。

## 5. 黑市医疗流（犯罪向）

- 结构：正规系统的缺口 → 地下医疗网络 → 手术与康复的高风险 → 追查或自救 → 网络的崩塌或逃脱。
- 真实感：感染、无售后、耗材断供是最大敌人，比警察更早要命。
- 红线：不提供可操作的现实医疗指引，机构与流程写虚构化处理。

## 6. 身份真相流

- 结构：主角的截肢原因/身份被官方版本遮蔽 → 缝隙出现 → 调查 → 真相改变其社会关系 → 选择公开或沉默。
- 伏笔位：病历缺页、旧照片里的姿态、知情人的口误。
- 要点：真相揭晓后的人际连锁反应比真相本身更重要。

## 7. 日常群像流

- 结构：无单一主线事件，靠一个空间（康复医院、老小区、残联活动中心）串联多人物的四季轮转。
- 节奏：低烈度长卷，冲突以日常性为主（电梯、报销、相亲、辅具维修）。
- 纪律：每个人物至少一条完整小弧线，防止变成段子合集。

## 8. 职场流

- 结构：求职/复工 → 岗位适配谈判 → 能力证明 → 一次系统性排挤或事故 → 用规则与实绩反击。
- 素材：配 `../05_角色塑造/职业场景库.md`。
- 红线：胜利靠制度路径与专业能力，不靠老板良心发现。

## 9. 校园流

- 结构：返校适应 → 同伴关系重组 → 学业与体育的现实限制 → 一次公开事件（运动会/研学/欺凌）→ 身份立场的公开选择。
- 红线：未成年角色的身体与情感描写按执行边界从严；欺凌的解决走成人世界与制度，不写私下复仇爽文。

## 10. 纪实/论坛体

- 结构：以发帖、聊天记录、日记、访谈摘录拼贴成史，时间线靠文体自身组织。
- 真实感：按 `../08_去AI化/真人写作指纹.md` 第 3、4 节做文体细节（打码、楼歪、复读、删帖）。
- 红线：虚构作品要在作品层面声明虚构，不伪造真实档案口吻误导读者。

## 11. 康复医院群像

- 结构：入院 → 同室关系 → 训练升级与各自瓶颈 → 出院离散 → 复诊重逢。
- 戏眼：病房是天然的微缩社会，病情层级与家庭账本全部浓缩在一个走廊里。
- 伏笔位：出院时互留的联系方式，决定后段谁还留在彼此生活里。

## 12. 假肢伪装流

- 结构：追求「看起来完好」→ 伪装成功的社交红利 → 伪装成本（疼痛、维护、不敢暴露）→ 一次伪装失效的公开事故 → 与辅具身份和解。
- 立场：不嘲笑选择伪装的人，也不把展示辅助具写成唯一正确答案；两种选择都是人物的自由。
- 事实锚点：假肢的穿戴成本与适配条件按 `../02_生理事实/术语与易混辨析.md` 第 5 节写实。

## 13. 豪门资源流

- 结构：进入高资源环境 → 一切被安排妥当 → 发现自由与社会连接同时萎缩 → 资源与自主的对决 → 重定关系条款。
- 红线：保留钱解决不了的矛盾（信任、社会身份、职业自我），否则戏剧熄火。

## 14. 公开暴露与歧视反击

- 结构：一次侵权事件（偷拍传播、招聘歧视、无障碍缺失致损）→ 取证 → 维权流程的拉扯 → 代价与收益的公开化 → 结局留余波。
- 真实感：程序、时限、证据规则按现实框架写，文学加工不改变制度逻辑。
- 红线：维权过程有损耗有妥协，不写全胜童话，也不写彻底绝望。

## 15. 伴侣关系线（去性化）

- 结构：相遇 → 身体议题的披露时刻 → 照护分工的磨合 → 一次分工崩盘 → 重新立约。
- 重心：关系的成长指标是协商能力，不是牺牲额度；亲密尺度按作品冻结档位执行。
- 红线：执行边界不可由情感浓度解除。

## 16. 奇幻古风

- 结构：在已有幻想世界观中，截肢者以辅具、术法、改造器械参与世界冲突。
- 铁律：缺失部位在变身/换形后依然缺失（`幻想向与豁免政策.md` 第 4 节）；豁免三要素登记齐全。
- 风味：古风辅具要做技术自洽（机关、木质假肢、灵兽协作），不出现穿越式现代轮椅。

## 17. 科幻改造流

- 结构：义体技术普及的社会里，自然身体与改造身体的阶层分化 → 主角的改造选择或拒绝 → 技术依赖与失效危机。
- 戏眼：义体公司的商业逻辑（订阅、停更、 planned obsolescence）是最真实的反派。
- 红线：技术失效周期要建账，不许义体永远好用。

## 18. 黑暗囚禁流（非性化）

- 结构：受限空间内的生存 → 资源控制机制 → 心理依附与清醒的拉锯 → 反抗缝隙 → 逃脱或毁灭。
- 红线：聚焦权力与心理机制，不提供性暴力奇观；未成年人禁用；结局不把加害者浪漫化。

## 19. 恐怖志怪

- 结构：以截肢经验为恐怖源（幻肢的错觉、空裤管的异物感、老医院传说）→ 科学解释与超自然解释并行 → 谜底尊重医学事实或明确声明超自然。
- 红线：不把真实病理现象（幻肢痛、残肢神经痛）写成邪祟，避免对读者的现实误导。

## 20. 暂时性截肢流（科幻/特定情境）

- 结构：因伤病或特殊任务暂时失去肢体功能 → 短期辅具生活 → 恢复倒计时中的身份失重 → 恢复后的「回不去」。
- 戏眼：短暂经历残障身份后，主角看待永久残障者的目光变化。
- 红线：结尾不许写「幸好我是正常人」式优越感，临时者的故事要向永久者的现实低头。

## 模板组合纪律

1. 一部作品选 1 个主模板 + 至多 2 个副模板，副模板只提供支线结构，贪多是会打架的。
2. 模板冲突时（如纪实体撞上黑暗囚禁），以启动框架冻结的题材定位裁决，不私自缝合。
3. 源素材中的仪式化改造、家族传承美学、身体展示类模板不收录，理由同各库排除清单。
