# 章节功能与因果链

## 1. 章节功能登记

每章动笔前先声明本章主功能（只选一个主功能，可兼一个副功能）：

| 功能 | 产出 |
|---|---|
| 推进 | 主线事件向前走一步，局面发生不可逆变化 |
| 刻画 | 通过选择与冲突深化角色，至少刷新一项人物认知 |
| 揭示 | 释放关键信息，改变读者或角色对局势的理解 |
| 转折 | 推翻既有预期，建立新方向 |
| 缓冲 | 消化后果、修复关系与装备、调整节奏（须承担必要交代） |

- 声明不出任何功能的章节直接删除或合并。
- 连续三章主功能相同，检查是否在原地踏步。

## 2. 因果链规则

1. 每个事件必须能回答「因为上一章/上一场的什么，所以发生了这个」。
2. 巧合只能用来制造麻烦，不能用来解决麻烦；关键破局靠角色主动选择与已铺垫资源。
3. 场景级因果用「目标—阻碍—结果」结构：角色带着目标进场景，遇到阻碍，离开时局面与进场不同。
4. 场景结束时的「新局面」是下一场的开场条件，逐场咬合，冷读重点检查接缝。

### 2.1 场景三件套与灾难四型

- 目标必须具体、可判、场内可达成，开写前一句话写进章纲；答不出「她这场想要什么」，先补目标，不补描写。
- 阻碍逐拍升级：换人、换条件、加时间压力、暴露新代价；静态阻力（一直够不着、一直被拦）是平推。
- 场景结局落在四型之一，不给「一切照旧」：

| 型 | 结果 | 用法 |
|---|---|---|
| 是，但是 | 目标达成，同时长出更麻烦的新问题 | 最强，默认优先 |
| 不，而且 | 目标失败，处境更坏 | 次强，危机段主力 |
| 不 | 目标失败，须重试 | 可用，连续两次即停滞 |
| 是 | 顺利达成无新问题 | 慎用，会抽干张力 |

### 2.2 「因此／但是」链检

章末逐场填「因为上一场什么，因此或但是这一场什么」。连接词只能是「因此」（因果）或「但是」（转折、受阻），填不出的场是断链；连续两场只能填「然后、接着、过了一会儿」的是流水账，回炉重排节拍。同一逻辑下放段内：连续动作句群若只能靠时间先后相连，命中 AI 腔清单第 33 条等权重动作链。

### 2.3 活性链四环

立场必须产生后果，只写态度不写后果仍是装饰。每章至少跑通一次：

1. 想要：她此刻在争取什么，具体到可判。
2. 选择：两个都不划算的选项里选一个。
3. 代价：选择在当场或后文付出可指认的代价。
4. 改下一场：下一场的目标因这个选择而改变。

四环不要求同场写完，代价可跨章兑现，但须登记进伏笔与一致性台账。「选择沉默、选择忍下」同样是选择，前提是写出她放弃了什么。

## 3. 承接点与落点：章纲任务书

每章动笔前写两行章纲，把章间接缝从「凭印象连续」改为「按单据交接」，对应字段已内置在 `../../assets/章节草稿模板.md` 顶部。

### 3.1 承接点（本章从哪里接）

逐项核对上一章定稿结尾的五个维度，本章开场必须与之一致：

1. 时间：距上章过了多久，季节/时辰。
2. 地点：人物物理位置与上章结尾是否同地，位移如何完成。
3. 人物状态：伤情、疲劳度、疼痛等级、辅具穿戴情况。
4. 情绪：上章末的情绪余量，不允许无交代清零。
5. 物件：辅具、随身物、关键道具在谁手里、放在哪。

任一字段与上章对不上，要么补过渡，要么修章纲，禁止带病开写。

### 3.2 落点（本章交到哪里）

用一句话写出本章结束时的新局面，它就是下一章承接点的输入：

- 落点必须是**变化后的状态**（关系变了、信息出来了、辅具坏了、决定做了），不是「本章结束」这类空话。
- 落点与第 1 节章节功能登记互验：推进章的落点要能指出局面哪里不可逆，缓冲章的落点要能指出修复了什么、埋下了什么。
- 章尾钩子（第 6 节）挂在落点上，先有落点再设计钩子，不许钩子与落点各说各话。

### 3.3 交接纪律

- 章纲随定稿归档；下一章开写前先读上一章的落点与本章承接点，两单对得上才启动阶段 0。
- 冷读稽查把承接点五维核对作为剧情连贯维度的固定动作，发现「上章怒气冲冲、本章心情不错且无交代」类断裂按重要级上报，时间/地点/伤情硬矛盾按致命级上报。

## 4. 场景与续集（scene-sequel）

- 动作场景（外部冲突）后安排反应场景（情绪消化、分析、再决策），比例随题材调整：战斗题材动作密集但每个大战后必有余波，现实向反应场景占比更高。
- 反应场景禁止纯内心独白灌水，要落到具体动作：修轮椅、换药、与他人对话争执。
- 续篇三件套：反应（灾难后的情感余波，长度即节奏杠杆）、两难（两条都要付代价的路，只有一条可行路是假两难）、决定（由她自己作出，直接成为下一场的目标）。
- 禁止连续多章只有场景没有续篇（读者无喘息），也禁止连续多章只有续篇没有场景（拖沓）。

## 5. 截肢元素的因果纪律

- 身体条件制造的阻碍必须是真问题：台阶挡住就是挡住，不能下一段突然长出坡道。
- 解决方案从人物已展示的技能与已登记的辅具/豁免中产生，禁止临时开挂。
- 每次身体相关事件（摔倒、幻肢痛发作、辅具故障）都要有后续影响（疼痛残留、行程延误、关系变化），不允许「事件结束一切复位」。
- 伤情恢复的时间依据走 `../02_生理事实/术后恢复时间线.md`，承接点中的人物状态不得超出当前恢复阶段。

## 6. 章尾钩子

- 每章结尾留一个未闭合的张力点：新信息、新威胁、未完成的决定、关系悬念，四类轮换避免单调。
- 钩子必须由本章内容自然产生，不靠硬塞突发事件。
