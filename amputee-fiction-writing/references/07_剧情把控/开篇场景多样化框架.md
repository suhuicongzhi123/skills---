# 开篇场景多样化框架

第一章是读者的入口，也是本库反流水账的第一道闸。开篇不从「一天的开始」开始，从「一个已经失衡的瞬间」开始。

## 1. 开篇禁令（五种流水账式开局，禁用）

1. 晨起日程型：起床、洗漱、穿衣、吃早饭按时间轴播报，人物还没遇到任何事。
2. 人物小传型：旁白背诵年龄、职业、截肢经过、性格标签，像填简历。
3. 天气写景型：用季节与天色起手，三段后人物才露面且与天气无叙事关系。
4. 百科科普型：旁白突然解释什么是髋离断、拐杖分几种，事实只能在人物行动中自然显形。
5. 顺流记事型：从出院/搬家/转学第一天的清早平铺到夜里，全天均匀用力、没有重点场面。

## 2. 八种开篇模式

每种模式给出结构、截肢元素的嵌入方式与风险点。选型按第 3 节决策树，不允许连续两部作品使用同一模式。

### 模式 A：动作进行时（in medias res）

- 结构：开篇第一段人物已在某个动作中段，拄拐追人、轮椅抢行、转移到一半卡住，先给动作与压力，背景后补。
- 截肢嵌入：步态节奏、拐杖点地、重心切换直接成为开场画面，事实随动作流出。
- 风险：动作缺乏前因时读者无法建立利害关系，三百字内必须补上「他在赶什么、输了会怎样」。

### 模式 B：冲突对话开场

- 结构：用一场带火气的争执、谈判或审问开场，人物关系与立场在对话里立起来。
- 截肢嵌入：让冲突绕不开身体处境，物业拒绝修坡道、雇主的试探、家人关于照护安排的争吵。
- 风险：防止对白变成信息倾倒，冲突双方要各有立场，不安排一个人专门负责提问。

### 模式 C：环境障碍事件

- 结构：台阶、坏掉的无障碍电梯、被占用的无障碍卫生间、太窄的门，一个具体障碍当场制造选择。
- 截肢嵌入：障碍就是试金石，人物如何绕行、求助、硬闯，一次性展示性格与身体条件。
- 风险：避免写成苦难展示，重点写人物的应对策略与情绪，而不是围观者的同情。

### 模式 D：感官锚点开篇

- 结构：以一个强烈的身体感觉起手，幻肢痛的跳动、拐杖橡胶头磨地的声响、残肢袜缝线的硌压，再拉开镜头。
- 截肢嵌入：感官本身就是事实区入口，写准疼痛位置与身体反应，不写医学说明书。
- 风险：感官之后必须迅速接事件，不能沉溺在感受里超过两段。

### 模式 E：结果前置 / 倒叙悬念

- 结构：先给一个反常结果（辅具损坏在地上、人物坐在不该出现的地点、一场关系破裂后的残局），再回到「怎么走到这一步」。
- 截肢嵌入：用结果中的身体细节制造谜面，空袖管沾着泥、轮椅刹车断了一截。
- 风险：悬念必须在中篇前兑现，倒叙段落要标注时间切换，防止时间线混乱。

### 模式 F：场景切片（白描非常态瞬间）

- 结构：截取日常里一个不寻常的横截面，暴雨中收拐、深夜独自练习转移、旧货市场挑轮椅，不解释全貌，靠细节密度抓人。
- 截肢嵌入：切片天然适合展示辅具与适配流程，是受众偏好的高细节区，把动作链写完整。
- 风险：切片不能无事件，切片内部要有一个小的目标—阻碍—结果闭环。

### 模式 G：关系张力开场

- 结构：以照护协商、目光冲突、过度热情的陌生人、旧关系的尴尬重逢开场，直接把人物放进社会压力里。
- 截肢嵌入：他人的反应是镜子，但叙述立场始终贴着主角的感受与判断，不把镜头交给凝视者。
- 风险：避免配角符号化，对方要有自己的行为逻辑而非「偏见道具人」。

### 模式 H：危机倒计时 / 任务压力

- 结构：明确时限与任务，十分钟内转移到安全点、药快用完、电量只够回程，压力先行。
- 截肢嵌入：在倒计时下暴露真实移动速度与辅具限制，时间成本自然成为戏剧张力。
- 风险：倒计时设定要在后文兑现，不能开篇喊完就消失。

## 3. 选型决策树

1. 作品主打的是外部冲突（战斗/末世/冒险）→ 优先 A、H，其次 C。
2. 作品主打的是关系与社会处境（现实向/情感向）→ 优先 B、G，其次 F。
3. 作品基调偏心理与氛围 → 优先 D、E。
4. 拿不准时用 C：环境障碍事件适配全部题材，且天然强制准确的身体书写。
5. 选定后在启动采集表登记，续作不得复用同一模式。

## 4. 开篇验收标准（第一章定稿前逐条过）

- 前 300 字内：具体人物已在行动或冲突中，读者知道他此刻想要什么。
- 前 1000 字内：截肢配置通过动作与细节自然显形，无一句百科式说明。
- 第一章内：主冲突的方向露面、至少一个有记忆点的人物选择、一个未闭合的章尾钩子。
- 全章无第 1 节五类禁令的任何一种。
- 辅具在第一章的每次出现都已进入连续账，来源可追溯。
- 开篇方式与作品基调匹配：残酷题材不用轻佻切片，治愈题材不用高压倒计时（除非有明确反转设计）。

## 5. 与工作流的关系

第一章不享受豁免，同样完整走一写一审七阶段；冷读稽查对开篇禁令与验收标准单列检查项，不通过不得定稿。
