# 假肢事实

本文件是假肢的事实层权威，只回答结构、能力边界与日常使用事实。本库风格规则约定假肢不作角色主要辅具（见 `../02_生理事实/术语与易混辨析.md` 第 5 节），风格约定与事实分层标注，不得互相冒充。义手参与动作的判定与词面红线统一走 `../02_生理事实/禁忌动作总表.md` 第 7 节，本文件不另立口径。

## 1. 下肢假肢【事实】

### 1.1 分平面的组件结构

| 平面 | 组件 | 能力边界 |
|---|---|---|
| HD | 髋关节、膝关节、踝足三组件，接受腔包裹胯与腰腹 | 无股骨杠杆，不能主动驱动关节，摆动靠健侧髋伸展推送，步态机械、耗力，日常多弃用 |
| TF | 膝关节、踝足组件，接受腔包大腿残肢 | 残肢带动接受腔、由髋伸展推送摆动；常规膝关节为被动或阻尼控制，无主动屈膝 |
| TT | 踝足组件，接受腔包小腿残肢 | 最轻便，适配性最好，行走能耗最低 |
| KD | 与 TF 近似，接受腔包覆膝上软组织 | 无主动屈膝，口径同 TF |

### 1.2 部件与穿脱

- 部件：接受腔（兜住残肢或胯，决定舒适与控制）、关节（机械或气压、液压）、假脚（储能脚或静踝脚）、悬吊系统（吸盘、套筒、皮带、销锁）。
- 现代主流悬吊是硅胶衬垫加销锁：衬垫翻卷滚上皮肤，插入接受腔后锁销「咔哒」锁定；解脱按阀拔出。HD 还要套胯部接受腔、系腰带，穿脱耗时最长。
- 残肢体积一天内变化：晨起饱满、傍晚消，使用者据此加减残肢袜层数；天热衬垫打滑、冬天接受腔冰凉，都是可写的日常。
- 皮肤打理是例行事务：压痕、闷热、出汗、毛囊炎与角质化，写习惯性打理，不渲染痛苦。

### 1.3 移动边界

- 上下楼口诀：上楼健腿先上、假肢跟随；下楼假肢先下、健腿跟随。假肢无自主抬腿能力，顺序写反即事实错误。
- 常规膝关节无主动屈膝，穿假肢时深蹲极难；跑跳须特定型号支持并在角色卡登记。
- 故障形态：关节卡死、接受腔开裂、假脚断裂、悬吊松脱，写机械异响与骤失功能的瞬间；故障迫使角色转回拐杖或轮椅，是合理的情节压力源。辅具会湿、会脏、会坏，损坏更换按 `辅具连续账规范.md` 登记。

## 2. 上肢假肢（义手）【事实】

### 2.1 三类方案与平面适配

| 方案 | 原理 | 适配平面 |
|---|---|---|
| 索控假肢（body-powered） | 肩带牵引索缆实现屈肘与手开合，动作幅度大、有肩带，可靠、不需充电 | SD 唯一有实际功能的常规方案；ED 等也可用 |
| 肌电假肢 | 拾取残肢肌肉电信号驱动 | ED、TR、WD 可用；SD 无残肢肌肉，常规不可用，仅做过靶向肌肉神经重建（TMR）把残存神经转位到胸肌后才有有限可能，属少数案例，不得默认写 |
| 美容手/被动假肢 | 硅胶手壳或肩部包（shoulder cap），外观优先、无抓取功能 | 各平面均可；SD 的肩部包只补肩轮廓、不含手臂，比整条义肢更常用 |

### 2.2 肌电义手的真实局限（防「万能机械手」失真）

1. 无触觉反馈：捏软的会爆、捏滑的会掉，全靠眼睛盯着加力度猜。
2. 模式切换要停顿：同一肌肉信号切换手型（张手、捏取、旋前），每换一次顿一下。
3. 出汗会误触发：高温天信号漂移，手指可能自己动。
4. 电池一天一充，忘充电则第二天只剩装饰件。
5. 硅胶手套会染色老化，长期使用发黄、污渍难清。
6. 重量与操控成本高：多数 ED 及更高位者日常最终弃戴，留作正式场合，残端直接做事反而更快。

### 2.3 写法红线

- 义手只能做粗操作辅助（抵、压、扶），主动作在健手；双手精细协同任何题材不豁免，判定表见禁忌总表 7.1。
- 叙述层须与真手区分：写「义手把碗按住」，不写「她两手把碗按住」。
- 义手出场要有铺垫：型号、穿戴方式、操控习惯登记在角色卡，不允许需要用时凭空出现。
