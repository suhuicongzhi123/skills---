# 占用双手时的拐杖处理

核心规则：拐杖不会自己悬浮。任何「手要做事」的瞬间，拐杖都必须有明确去向，且去向符合拐的物理结构。另一类高发错误方向相反：明明有零成本腾手方案，却设计放拐单腿跳，属辅具弃用非理性。处置按下方策略阶梯选层，不是默认放拐。

## 1. 腾手策略阶梯（从顶层往下选，放拐是末端解）

**近距离豁免（优先于阶梯判断）**：目标在十步以内时，可以放拐单腿跳过去，短距离内重新撑拐的仪式成本高于跳本身。豁免的是「非理性」判定，不是交代义务：放拐动作、跳的过程、回程取拐仍要写出。

1. **腾手优先，拐不离身**：肘拐靠袖箍挂前臂是天然优势，可较久保持；腋拐不能挂肘，只能单拐夹腋、单手持双拐并拢、短时挂肘弯。杯子、手机、书本等单手可持物一律走本层。注意支撑降级：挂肘、夹腋、并拢后该拐不撑地不承重，支撑点减半，原地站立作业优先，须移动时单拐缓行或扶物挪步，不写健步如常。
2. **改变携带方式**：背包、推车、分次搬运、雨衣替代伞，物品重整后正常拄拐走。
3. **坐姿作业**：把「边移动边做」改成「移动到位坐下做」，移动段拄拐，做事段腾手。
4. **他人协助**：接、递、代拿。
5. **放拐单腿跳（末端解）**：仅当双手完全占用、物品不可分离、必须保持移动三者同时成立，如端滚烫汤移动、抱婴儿转移、双手持重物过窄处。

**放拐门槛三问**（设计放拐场景前必过，十步豁免情形除外）：

- 腾手可行吗：存在挂肘、夹持、背包等任一解即禁放拐，为一杯水或一部手机放拐是拐杖分离的同族错误。
- 是公共空间吗：他人目光有成本，要强的人设不会在人群里主动蹦跳供人观看。
- 距离多远：超过十步，体力与仪态成本陡增，长距离放拐移动失真。

## 2. 双腋拐的处理方案

| 场景 | 处理动作 | 叙事要点 |
|---|---|---|
| 临时取物（按电梯、掏钥匙） | 双拐并拢，由一只手横握或夹在腋下与手臂之间，另一只手操作 | 身体会短暂失衡，需靠墙或停稳 |
| 开门 | 先把双拐并拢靠在身侧/墙边，腾出一只手推门，人先过再取回拐；或用身体顶门 | 弹簧门、旋转门是真实麻烦 |
| 落座 | 双拐并拢，倒转手握中段，倚在桌腿、墙边或平放于桌面/腿旁可及处 | 必须在起身可及范围，写清位置 |
| 双手需要端物 | 先停稳、安置拐杖，再端；或改用背包、托盘、桌边放置替代双手端持 | 禁止「拄着双拐双手端汤」 |
| 撑伞走路 | 穿雨衣、固定伞、避雨或停步；伞与双拐无法长期共存 | 不写一手伞一手双拐 |
| 牵孩子或宠物 | 推车、绳系腰间、孩子跟着走、单拐慢速 | 边走边牵须有承载方案 |
| 推购物车 | 拐挂车边单手推、改用手提篮分次拿、请人代推或线上配送 | 超市是高频出戏场景 |
| 抱孩子转移 | 坐姿抱分段挪、他人帮、私密空间内十步豁免下放拐 | 过三问：家中私密、距离短、无替代 |
| 上下楼拿物 | 物先放下、拐夹腋下、分次搬运 | 不写一手扶栏一手拿物还持双拐 |
| 晾收衣服 | 坐矮凳作业、单拐靠墙、分次完成 | 阳台来回移动先解决拐的去向 |
| 拍照、打电话、吃喝 | 停步、挂脖、耳机、背包取水 | 都不是边走边做的事 |
| 摔倒 | 拐会脱手或压在身下，起身前先把拐收拢到可及位置 | 摔倒与起身是完整动作链 |

## 3. 双肘拐的处理方案

- 袖箍挂持是独有方案：双手松开，双拐垂挂于两前臂，可短时用手做事，但垂挂时不能行走，且前臂负重受限。
- 需要真正解放双手时，处理逻辑同腋拐：并拢、倚放、平放。
- 落座后可让拐挂在扶手或桌边（写清挂点），也可平放。

## 4. 单拐角色的处理

- 单拐本就空一只手，空手做事时拐由持拐手持稳、身体站稳。
- 持拐手也需要用时：拐夹于同侧腋下、倚靠墙/柜台、平放可及处；肘拐可挂前臂。
- 牵人、抱物等需要平衡的场景，优先安排停下再做，不要边走边完成高难度配合。

## 5. 拐杖放置动作链与闭环

拐杖不是道具，不能凭空出现或消失。放置状态枚举：在手、靠墙立、放倒、夹腋、挂肘（肘拐袖箍挂前臂）、挂肘弯（腋拐短时挂肘弯）、交他人、不在场。

- 到目的地先靠墙立稳或放倒在可及处；临时腾手用夹腋或挂肘弯。
- 起身先够到拐杖再撑起。
- 事情做完后回到放置处把拐杖拿回来，再重新撑起。
- 放拐处置的完整闭环四步：放拐、单腿跳去做、做完跳回去拿拐、重新撑起，缺一不可。
- 错误典型：写主角「放下拐杖」后下一秒又「拄着拐杖走」，中间没有拿起动作；或做完事直接走人，缺了回程取拐。

## 6. 摔倒起身五步链

单腿加双拐重心高，湿滑、绊坎、拐头打滑易摔，常向前或侧倒，拐杖脱手飞出或压在身下。起身按五步写，可写实写慢：

1. 先把拐杖收拢到身旁够得着处。
2. 翻身侧卧或仰卧。
3. 健腿屈曲蹬地，双手撑地坐起。
4. 摸到拐杖，双拐撑地，健腿蹬起站直。
5. 站稳后调整拐杖位置。

起身是体现动作智慧的场景，可写喘息、试几次、地面凉硬、判断先摸哪只拐；可有一句口语化即时反应，但不延伸为疼痛渲染。

## 7. 机械检查对应

- 脚本规则 `DEV-01`：双拐使用段落出现双手占用动词且无安置描写，报错误。
- 规则 `DEV-02`：单拐角色持拐手出现持物动作且无换手/安置描写，报警告。
- 所有安置动作必须同步登记进辅具连续账的「期间动作」列。

## 8. 适用类型与写作心法

强适用：HD、高位 TF 等双拐绝对主力的类型；低位 TF、TT 以假肢为主时弱适用；SYM/FT 基本不适用。

拐杖的拿与放是节奏器：它天然制造停顿、犹豫、小动作，能体现人物性格（麻利的人一把收拢、谨慎的人先找靠点、慌乱的人拐碰倒一地）。把处理动作写进人物，而不是写成流程说明。
