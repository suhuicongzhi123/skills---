# 辅具索引与选型

## 1. 选型矩阵（库风格规则：假肢不作主要辅具）

| 角色配置 | 主辅具 | 可选/备用 | 明确不适用 |
|---|---|---|---|
| 单侧 HD/TF/KD/TT | 双腋拐或双肘拐；熟练后单拐（健侧手） | 轮椅（长距离/户外）、短距离单腿跳 | 长期无拐奔走 |
| 单侧 SYM/FT | 通常无需移动辅具 | 情境性拄拐（伤情、地形） | 无理由的常驻拐杖 |
| 双侧下肢任意平面 | 轮椅（手动/电动） | 转运板、护身带 | 双拐长距离行走 |
| 单侧/双侧上肢 | 不需要移动辅具 | 不适用 | 拐杖（无下肢缺陷时） |
| 上下复合 | 按 `../02_生理事实/复合截肢/上下复合.md` 矩阵逐案定 | 电动轮椅、陪护推行 | 与手部能力冲突的方案 |

## 3. 通用事实【事实】

- 拐杖承重经手柄传到手与手腕，不是压在腋窝/肘弯上；腋拐长期顶压腋窝可能造成神经压迫（腋杖麻痹），正确写法是手臂撑直、手握发力。
- 任何拐杖步态都占用至少一只手；双拐占用双手，这是全库一致性检查的硬约束。
- 辅具是身体管理的一部分，会湿、会脏、会坏、会忘带，这些日常摩擦应当进入叙事，而不是把辅具写成没有物理性质的道具。

## 4. 行动音效（风格规则）

辅具会发声，声音是真实感与人物辨认的低成本素材。以下为词库，写作时按角色固定 1–2 种招牌音效、全书复用，不逐步配音。

| 声源 | 可用拟声与写法 |
|---|---|
| 腋拐/肘拐落地 | 笃、咚、嗒；胶头磨偏后发闷响，点在瓷砖上变脆 |
| 拐杖金属件 | 调节扣磕碰的叮声、两根拐相碰的轻响、拐身抵墙的刮擦 |
| 手动轮椅 | 推圈转动的咕噜声、急停锁刹的咔嗒、轮胎碾过碎石的嚓声、车架金属疲劳后的咯吱 |
| 电动轮椅 | 电机低鸣、启动与停下的电子提示音、摇杆回中的轻响 |
| 转移动作 | 椅面受力的吱呀、转移板摩擦、护身带扣合的咔哒 |
| 假肢（本库不主用，偶发出现时） | 接受腔的吸附声、关节机械音、步态节奏与肉身不同的顿挫 |

纪律：音效要随地面材质与情绪节奏变化（怒气让拐声变密变重），但同一角色的声音特征保持稳定；拟声词总量接受 `../08_去AI化/真人写作指纹.md` 第 5 节约束。
