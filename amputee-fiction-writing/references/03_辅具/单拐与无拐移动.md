# 单拐与无拐移动

## 1. 单拐（腋拐或肘拐单支）【事实】

- 持拐侧别：单拐持于健侧（未受伤/健全的一侧）手。StatPearls 明确：单拐位于健侧，拐与截肢侧同时向前迈出，重心在两者之间转移，再迈健侧腿。
- 同侧持拐不是标准用法，若角色这样设定必须给出理由（习惯、旧伤、场地），并接受平衡更差的后果。
- 单拐解放一只手，是「移动中做事」场景的合理方案：空手可提轻物、扶扶手、牵人，但负重能力有限，重物仍需停下或背包分担。
- 适用：熟练期截肢者、短距离、熟悉环境；新截肢者与复杂地形默认双拐。
- **HD 例外**：髋离断没有股骨杠杆与截肢侧支撑点，单拐仅作极短距离辅助，日常移动以双拐为主；「单拐长距离省力」只适用于有截肢侧支撑点的假肢类型，不得套到 HD 角色上。

## 2. 无拐移动：单腿跳【事实 + 风格约束】

- 事实：单腿跳是健侧腿的连续弹跳移动，能量消耗远高于正常行走，噪音大、对膝踝冲击强，跌倒风险高；现实中只用于短距离、临时情境（追几步、够个东西、拐不在手边）。
- 持续跳行的身体反应要写实：心跳加快、大腿酸胀、落地冲击、需要急停时的失衡。
- 本库风格约束：无拐单腿跳不得写成常规通勤方式；机械脚本对「无拐 + 奔跑/追逐/长距离」组合给出警告。
- 平衡辅助：跳行时双臂摆动维持平衡，若角色同时有上肢缺失，跳行可行性大幅下降，需按复合截肢矩阵处理。

### 2.1 体力节奏（在短距离边界内写实）

- 跳一段歇一下，不是跳几下就垮；随距离与时间增加，歇的频次与时长相应增加。前期停下站一会儿接着跳，后期扶物或坐下歇。
- 歇过之后回不到最佳状态，只是能继续，不是满血。
- 熟练者可以连续跳十几步，起跳、落地、起跳是一条连着的链，只在转向、选落脚点、避让障碍时略顿；不写「三步一停」式机械节拍，那把熟练度写没了。
- 较长距离按分段推进处理，分段来自距离、路况与角色取舍，不写「体力只够跳五步」式定额；连续急行或追赶之后，下一章要有恢复代价，代价走恢复时长，不走疼痛渲染。

### 2.2 无辅具角色的位移四特征【事实】

拐杖可分走两侧支撑，单腿跳没有第二支点可分。无辅具下肢角色的移动按以下四条设计：

| 特征 | 物理事实 | 写作后果 |
|---|---|---|
| 转向慢 | 转身须把整个身子带过去，不能原地换脚 | 被绕后即失位，两侧受敌时只能朝一边 |
| 不能追 | 每一跳都要重新蹬地，比常人奔跑慢得多 | 追击等于放弃，是速度劣势类受限的高发源 |
| 跨障分级 | 低矮障碍（门槛、浅沟、倒卧物）可单腿一跃而过；膝盖以上高度或落点须精准的障碍（车辕、深沟）不可跨，只能绕 | 地形对她不是背景，是算术；不写「凡需抬腿越过的都过不去」，也不写她跨越高障 |
| 站定稳、位移弱 | 站定后靠单脚加剑、墙、车补第二支点构成三角支撑；截去整条腿后重心上移并偏健侧 | 站定输出是强项，换一个点是弱项；不写「重心低」 |

反制写法不是让她更快，而是让对方多做一个动作：制造一到两拍空档（扬沙、泼油、熄灯、断绳、绊倒、贴抱），在空档里原地输出。敌方针对她的正确方式是逼她移动、逼她倒地。不写「她跳得比跑还快」「一步三尺」式超人化描写，幻想向登记在案的特殊移动除外。

### 2.3 爬行的门槛

爬行只在特殊情况下成立：健腿受伤，或地面极度受限（摩擦力极低、吸力很强的深泥浆）。不作为「累了就爬」的常规降级方式，那是把角色写弱。

## 3. 其他无拐瞬间动作

- 扶墙/扶家具侧移：室内短距离转移的常见方式，手不离支撑面。
- 坐姿转位：臀不离面的挪动（床、沙发、长椅之间）。
- 跪姿与地面移动：有膝的角色（TT 等）可跪行；HD/TF/KD 截肢侧无膝，只能靠健侧与臀部。

## 4. 写作易错点

1. 单拐持在截肢侧且毫无解释。
2. 单腿跳持续整条街、面不改色，或写成常规通勤。
3. 单拐角色提重物却不写重心与负荷代价。
4. 把「无拐」写成「无障碍」：无拐场景恰恰是风险最高的移动场景。
5. 给 HD 角色安排单拐长距离行走，忽略其无支撑点的结构事实。
