# 腋拐（腋下拐杖）

## 1. 物理特征【事实】

- 结构：单根可调立柱，顶端是托在腋下的横托（腋垫），中部是握持手柄，底端是防滑橡胶头。
- 材质多为铝合金或木材，高度通过立柱弹珠孔调节，手柄位置也可调。
- 成对使用时左右各一；正确高度下，腋垫与腋窝之间留有约两指宽余量，站立时手肘微屈约 20–30 度。
- 橡胶头磨损后会打滑，是消耗件；雨天、瓷砖、冰面抓地力下降。

## 2. 使用方法与步态【事实】

- 承重路径：手握手柄发力、手臂支撑，腋窝只负责稳定不负责承重；写「全身重量压在腋下」是错误用法。
- 常见步态：
  - 四点步态（左拐→右脚→右拐→左脚，稳但慢，适合体力弱者）；
  - 三点步态（双拐同时前伸→健侧腿跟进，截肢侧不负重，是单侧下肢截肢者的典型步态）；
  - 摆至步（swing-to）：双拐前伸→双脚/单脚摆到拐的位置；
  - 摆过步（swing-through）：双拐前伸→身体摆到拐的前方，最快但能耗最高、对上肢力量要求高。
- 单侧下肢截肢者使用双拐时，截肢侧随双拐同步前移，健侧腿负责蹬地。
- 上下楼原则：上楼先健侧后腿（拐），下楼先拐后健侧腿；扶手可用时一手扶扶手、一手持双拐并拢。

## 3. 占用状态与身体代价

- 双手均被占用：无法同时端物、开门、撑伞（可用腕挂式伞或嘴咬，需写清）、掏手机。
- 长时间使用的代价：手掌茧、腕关节痛、肩颈劳损、腋窝不适；这些可作为人物状态细节。
- 狭窄空间（门缝、电梯、拥挤人群）需要收拐或侧身，拐会勾碰杂物。

## 4. 写作清单

- 每个拄拐场景确认：拐从哪里拿起、起步前如何调位、停下后放在哪里（与连续账对应）。
- 写行走时带步态节奏（拐尖点地、身体起伏），不要只写「他走了过去」。
- 禁止出现双手持拐同时双手端物的动作，除非先写了拐杖的安置（见 `占用双手时的拐杖处理.md`）。
