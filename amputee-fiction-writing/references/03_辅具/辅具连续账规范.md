# 辅具连续账规范

## 1. 账目的地位

辅具连续账是每个作品全局唯一的台账文件（模板见 `../../assets/辅具连续账模板.md`），与正文具有同等约束力：正文与台账冲突时，以先修正一方为原则，不允许长期带病。

## 2. 记账对象

1. 移动辅具：腋拐、肘拐、单拐、轮椅（手动/电动）、转移板等。
2. 辅具的消耗件与配件可在备注中记录（橡胶头、手套、坐垫、电池），损坏更换属于期间动作。
3. 临时借用的辅具也要入账，注明借出方与归还状态。

## 3. 记账粒度

- 以「章 × 场景」为最小记录行，每个场景结束即更新，不攒章。
- 每行必须有正文依据摘录（短句即可），保证台账可回溯到具体文字。
- 期初状态必须等于上一行的期末状态；做不到就说明中间有未写的转移，退回补文。

## 4. 异常类型与处理

| 异常 | 判定 | 处理 |
|---|---|---|
| 凭空出现 | 正文使用了清单中没有的辅具 ID | 补来源登记，或改正文删除 |
| 凭空消失 | 上一场景期末在手/在坐，本场景无交代地不在 | 补期间动作，或改正文 |
| 占手冲突 | 双拐在手却双手做事、轮椅无人驱动却在移动 | 重写动作链 |
| 状态矛盾 | 已损坏/弃置的辅具被再次正常使用 | 修复/替换先入账，或改正文 |
| 转移断档 | 轮椅与座位切换无过程 | 补转移分动作 |

## 5. 主动剥离的登记

辅具不可用除了被夺、丢失、损坏三种被动情形，还有角色主动不带的一档。主动剥离必须入账，不能开局就已经处于无拐状态。

| 类型 | 典型剧情 | 必写的代价 | 常见错写 |
|---|---|---|---|
| 战术剥离（带不了） | 战斗要腾双手、变身形态带不进 | 打完怎么回去：跳、爬、等人接 | 打完拐自动回到手上 |
| 心理剥离（不愿被看见） | 出任务前把拐放回门后 | 回来那段路最狼狈 | 只写「不想拄拐」，不写代价 |
| 外部限制（场景不允许） | 潜入、被押、窄道作业 | 进去容易出来难 | 进去时忘了她是剥离态 |

登记三件套，写在台账「辅具空白期」备注中：起章、理由、回归条件。三条硬要求：

1. 剥离的那一刻要有动作（放在门后、塞进墙缝、交给谁），不能无交代地消失。
2. 剥离期间所有移动都要写代价：跳、爬、扶墙、坐地滑行，不能凭空正常走。
3. 回归要有出口：取回、捡到替代物、被人送来；出口不得晚于第 3 章，超期按设定漏洞上报。

## 6. 与机械脚本的对接

- 脚本支持 `--ledger <台账JSON>` 参数，核对场景间状态连续性（规则 `DEV-04`、`DEV-05`）。
- Markdown 台账供人读；脚本读取的是同内容的 JSON 导出版，章节定稿时由写作者同步两份，禁止只改一份。
- 脚本无法理解语义级「顺手放在旁边」，凡涉及位置变化，期间动作列必须出现明确动词（拿起、倚放、平放、换手、收起、损坏、弃置、主动剥离）。
