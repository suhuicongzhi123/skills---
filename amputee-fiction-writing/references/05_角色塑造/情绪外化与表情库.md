# 情绪外化与表情库

`../08_去AI化/AI腔特征清单.md` 第 12 条禁止情绪直告（「他感到愤怒」），本文件提供替代工艺：把情绪写成读者能看见、听见的东西。全部条目为【风格规则】，是词库与配额纪律，不是生理事实。

## 1. 四条总纲

1. **一处脸上 + 一处身体**：一个情绪节拍最多两个落点，脸上一个细节、身体一个反应，多了就是表情包堆砌。
2. **表情不逐句配**：对话不是每句都带表情。一场戏给 1–2 个情绪锚点，其余靠台词与动作承载；连续标注表情等于没有表情。
3. **招牌反应固定化**：每个角色在角色卡登记 1 个招牌情绪反应（紧张时的固定小动作、生气时的固定表情），全书复用，成为辨认该角色的指纹，与 `角色塑造模型.md` 第 8 节三锚点咬合。
4. **特写不超过两句**：面部特写连续写两句必须切走（切动作、切对话、切环境），禁止镜头在五官上巡礼。

## 2. 面部部件库

### 2.1 眼神

| 情绪 | 可用写法（选一个，勿连用） |
|---|---|
| 紧张 | 视线发飘、盯住固定点不动、眨眼变频繁、不敢抬眼 |
| 愤怒 | 视线压下去盯人、瞳孔收紧、眼皮一垂再抬、眼角绷紧 |
| 悲伤 | 眼神发空、对焦在远处、垂眼盯着自己的手、睫毛颤 |
| 害羞 | 视线一碰就弹开、偷瞄、用垂眼遮住笑意 |
| 轻蔑 | 眼皮半耷、视线从上方扫过去、看完先移开眼 |
| 惊讶 | 眼皮一跳、瞳孔张开、视线定住半拍 |
| 心虚 | 眨眼加快、视线往斜下方躲、刻意维持对视又失败 |

纪律：禁止「眼里闪过一丝 X」万能句式（与 AI 腔第 13 条套喻同病）；写视线的落点，不写眼睛的形容词。

### 2.2 眉

- 皱眉也分种类：眉心拧成结（疼/为难）、一边眉毛挑起（怀疑）、眉峰下压（怒）、眉毛往上一抬又放下（意外）。
- 一个角色的眉部反应选 1–2 种固定写法，不每次换词。

### 2.3 嘴

- 紧张：抿嘴、咬下唇内侧、舌尖顶腮、嘴角绷紧。
- 强忍情绪：嘴角抽一下、抿到发白、咬住后槽牙（可与下颌联动）。
- 假笑：只有嘴在笑、眼周不动；写「嘴角扬了一下，没到眼睛」即够，不必解释。
- 欲言又止：嘴唇张开又合上、话咽回去时喉头动一下。

### 2.4 脸色与下颌喉头

- 脸色变化写具体机制：血往上涌（发烫、耳根红）、血褪下去（发白、嘴唇失色），不写「脸色复杂」。
- 下颌：咬紧后槽牙、腮边肌肉鼓起、下颌线绷硬，用于忍怒、忍痛、忍哭。
- 喉头：吞咽一下、喉结滚动，用于紧张、哽咽、话到嘴边改口。

### 2.5 呼吸与泪

- 呼吸是最省力的情绪外化：憋气（紧张/忍痛）、呼气变重（无奈/卸力）、吸气卡在半路（吃惊/委屈）、鼻息变粗（压火）。
- 泪的分级：眼眶发热（未哭）→ 水光（忍着）→ 泪挂住没掉（临界）→ 砸下来（失控）。跳级写流泪等于廉价；硬汉角色可以全程停在第二级。
- 哭也要有身体成本：肩膀抖、呼吸乱、说话断句，不写「泪水决堤」式套话。

## 3. 身体动作外化库

情绪不只在脸上，优先用离情绪最远的身体部位传递，比脸更克制、更有质感。

1. **手**：攥紧又松开、指尖抠掌心、摩挲某个固定物件、指甲掐进虎口、手指无意识敲节奏。手部动作是本库首选外化部位。
2. **头颈肩**：偏头躲开视线、脖子发僵转动变慢、肩膀耸起来又放下、后颈绷紧。
3. **躯干**：重心从一条腿换到另一条、往后撤半步、上身前倾或后仰、肩膀缩起来。
4. **声音**：话尾发颤、清嗓子、突然压低声音、语速比平时快一截或慢半截、笑声短得像咳嗽。
5. **脚与步幅**：原地碾脚、脚尖先转向门口、步子变快或钉在原地。

## 4. 截肢角色的专属外化路径【风格规则，动作须过事实库】

这是本库相对于通用表情库的差异化素材：情绪可以借残肢与辅具外化，但每个动作必须能在 `../02_生理事实/` 与 `../03_辅具/` 找到可行性依据。

- 幻肢感发作时人物按住残肢/软组织覆盖处、动作顿一拍，疼痛与情绪共用一条通道时，先写身体再写情绪。
- 拄拐者：攥拐柄攥到指节发白、拐杖落地声变重变密（怒气进了节奏）、把拐杖往身边一收（防御姿态）。
- 轮椅者：手指在推圈上停住、突然锁刹的咔嗒声、驱动轮猛转半圈又停。
- 坐姿变化：残肢不自觉绷紧或外展、身体偏向健侧的角度改变，这些是坐着就能演的戏，不要只在脸上用力。
- 禁忌：不得为表达情绪让残肢做出总表禁止的动作（如残端承重、无膝弯膝），情绪再剧烈也不解禁生理规则。

## 5. 情绪 → 外化速查（查表选料，禁止整表堆砌）

| 情绪 | 脸上（选一） | 身体（选一） |
|---|---|---|
| 愤怒 | 下颌绷硬、视线压低盯人 | 攥紧手里的东西、步幅/拐声变重 |
| 悲伤 | 视线发空、睫毛颤 | 肩膀塌下去、动作整体变慢 |
| 紧张 | 眨眼频繁、抿嘴 | 摩挲固定物件、呼吸变浅 |
| 尴尬 | 假笑不到眼、视线弹开 | 后撤半步、手脚找不到位置 |
| 厌恶 | 眼皮半耷、上唇微动 | 身体后仰、手把物件推远 |
| 惊讶 | 眼皮一跳、吸气卡住 | 动作定住半拍、拐杖差点没跟上 |
| 委屈 | 眼圈发热、咬嘴唇内侧 | 声音发闷、肩膀缩起来 |
| 克制的平静 | 脸上不动 | 只有手部一个小动作露底 |

## 6. 冷读判定口径

- 同一场戏情绪锚点超过 4 个、或连续三句对话各带一个表情：按重要级上报。
- 情绪直告句（「他感到……」「她心里一阵……」）按 AI 腔第 12 条处理。
- 角色招牌反应前后不一致（设定紧张就摩挲袖口，后文改成咬指甲且无交代）：按人物失真上报。
- 为情绪服务的动作违反生理事实库：升级为致命级，事实错误优先于风格问题。
