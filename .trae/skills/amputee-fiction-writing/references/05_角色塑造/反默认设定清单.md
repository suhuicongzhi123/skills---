# 反默认设定清单

## 1. 头号禁令：话少、冷漠不是默认人设

- 新建角色默认值是「有正常表达欲的人」，沉默寡言必须给出成长经历层面的原因，并在角色卡写明沉默规则。
- 一部作品里沉默型角色最多一个；主角团出现两个以上冷面人，直接打回重建。
- 冷漠是一种具体行为策略（对谁、何时、为什么），不是气质滤镜。

## 2. 截肢角色的偷懒模板（禁用）

| 偷懒模板 | 问题 | 替代要求 |
|---|---|---|
| 隐忍坚强型：疼死也不说、永远懂事 | 把创伤审美化，取消人物的愤怒与自私 | 允许角色抱怨、算计、迁怒、提出不合理要求 |
| 身残志坚口号型：旁白反复强调励志 | 主题先行，人物变成宣传画 | 用具体选择呈现韧性，删掉所有励志总结句 |
| 自卑敏感型：一碰残疾话题就炸毛 | 单一应激按钮，人物只剩反应 | 设定稳定的自我认知，敏感点具体且有限 |
| 乐观天使型：永远微笑治愈他人 | 剥夺负面情绪的符号化工具人 | 给乐观设置成本与崩盘时刻 |
| 复仇执念型：截肢只为仇恨驱动 | 人物动机被术式绑架 | 截肢前就有自己的生活与欲望 |

## 3. 配角与反派的同样标准

- 配角也要填简化版角色卡（欲望、指纹、三锚点可减半，不得全空）。
- 反派的逻辑必须在其自身立场内自洽，禁止「因为坏所以坏」；禁止安排炮灰截肢者充当气氛道具。
- 路人对截肢者的反应要符合场景与身份分层：有无助的善意、有务实的冷漠、有猎奇、有制度化的歧视，不搞全员感动或全员恶意。

## 4. 关系描写禁令

- 禁止把照护关系写成天然的等级秩序（被照护者不是永久欠偿方）。
- 禁止用「他不把我当残疾人」作为爱情告白的最高规格——它暗示残疾是减分项，本库价值观不采用；好感建立在具体的人之间。
- 亲密关系推进靠共同事件与细节积累，不靠一场「吐露截肢往事」的夜谈一次性完成。

## 5. 审查口径

冷读稽查发现以上模板时，按「重要级」问题上报；主角命中头号禁令或偷懒模板，按「致命级」处理。
