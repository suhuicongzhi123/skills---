# 章节功能与因果链

## 1. 章节功能登记

每章动笔前先声明本章主功能（只选一个主功能，可兼一个副功能）：

| 功能 | 产出 |
|---|---|
| 推进 | 主线事件向前走一步，局面发生不可逆变化 |
| 刻画 | 通过选择与冲突深化角色，至少刷新一项人物认知 |
| 揭示 | 释放关键信息，改变读者或角色对局势的理解 |
| 转折 | 推翻既有预期，建立新方向 |
| 缓冲 | 消化后果、修复关系与装备、调整节奏（须承担必要交代） |

- 声明不出任何功能的章节直接删除或合并。
- 连续三章主功能相同，检查是否在原地踏步。

## 2. 因果链规则

1. 每个事件必须能回答「因为上一章/上一场的什么，所以发生了这个」。
2. 巧合只能用来制造麻烦，不能用来解决麻烦；关键破局靠角色主动选择与已铺垫资源。
3. 场景级因果用「目标—阻碍—结果」结构：角色带着目标进场景，遇到阻碍，离开时局面与进场不同。
4. 场景结束时的「新局面」是下一场的开场条件，逐场咬合，冷读重点检查接缝。

## 3. 场景与续集（scene-sequel）

- 动作场景（外部冲突）后安排反应场景（情绪消化、分析、再决策），比例随题材调整：战斗题材动作密集但每个大战后必有余波，现实向反应场景占比更高。
- 反应场景禁止纯内心独白灌水，要落到具体动作：修轮椅、换药、与他人对话争执。

## 4. 截肢元素的因果纪律

- 身体条件制造的阻碍必须是真问题：台阶挡住就是挡住，不能下一段突然长出坡道。
- 解决方案从人物已展示的技能与已登记的辅具/豁免中产生，禁止临时开挂。
- 每次身体相关事件（摔倒、幻肢痛发作、辅具故障）都要有后续影响（疼痛残留、行程延误、关系变化），不允许「事件结束一切复位」。

## 5. 章尾钩子

- 每章结尾留一个未闭合的张力点：新信息、新威胁、未完成的决定、关系悬念，四类轮换避免单调。
- 钩子必须由本章内容自然产生，不靠硬塞突发事件。
