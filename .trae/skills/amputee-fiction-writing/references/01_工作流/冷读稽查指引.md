# 冷读稽查子代理指引

冷读稽查由独立子代理承担，核心价值是「无作者偏见的 fresh eyes」。写作者通过 Task 工具启动 `general_purpose_task` 类型子代理执行，单次任务、一次性下发材料。

## 1. 下发材料白名单

只允许下发：

1. 本章草稿全文。
2. 本章出场角色的角色卡。
3. 作品设定总表中与本章相关的段落（题材、豁免登记）。
4. 出场角色对应的生理事实小类文件、本章辅具对应文件。
5. 本指引第五节点审查维度清单。

禁止下发：写作者自审记录、修改历史、写作意图说明、对剧情的解释。子代理只面对文本本身，防止被作者思路锚定。

## 2. 任务提示词要点

下发任务时明确要求子代理：

- 以陌生读者兼事实稽查员的双重身份通读，先完整读一遍记录直觉感受，再带清单复查。
- 所有问题必须定位到具体场景与原文摘录，禁止「整体感觉不好」式空泛意见。
- 每个事实类问题必须引用依据文件中的具体条目。
- 只出报告不改稿、不重写段落。
- 区分三级严重度：致命（事实错误、逻辑崩坏、自相矛盾）、重要（人物失真、节奏问题、AI腔密集）、建议（可优化项）。

## 3. 五大审查维度

1. **生理事实**：侧别/平面是否一致；动作是否在该截肢类型可行范围内；坐姿、重心、转移、残肢/软组织描写是否准确；豁免使用是否合规。
2. **辅具连续**：拐杖、轮椅等的拿取、放下、换手、携带是否有交代，是否与连续账一致；占用双手的场景与拐姿是否冲突。
3. **人物立体度**：对话能否不看署名区分说话人；角色行为是否符合角色卡；是否出现「话少冷漠」式偷懒设定；情绪是否被具体动作与细节承载而非直告。
4. **剧情与连贯**：场景间因果是否成立；时间、地点、物件、伤情状态是否与前章连续；伏笔有无遗忘或自相矛盾。
5. **文本质地**：按 `08_去AI化/AI腔特征清单.md` 标出 AI 腔具体位置；战斗章节额外检查是否存在细节复用、是否「真打」。
6. **浓度与物化（按项目冻结档位）**：对照 `09_创作注入/身体描写浓度与亲密书写.md`，检查身体描写是否越档、同部件静态描写是否超配额；逐条核对物化四特征（无主摄影机、agency 缺席、部件复读、人物缩减）与欲望凝视四条件；发现触碰执行边界的内容直接判致命级并停止该场景稽查。

## 4. 报告回收

- 报告使用 `assets/审查报告模板.md`，存为 `第NN章_审查报告.md`。
- 子代理结论与机械自查结论冲突时，写作者不得选边偷懒，回查依据文件后裁决，并在报告回执区写明裁决理由。
- 子代理若指出库文件本身的事实疑点，登记后按 `00_治理/维护规范.md` 处理库文件，不在章节里绕开。
