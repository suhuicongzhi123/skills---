# 双侧上肢截肢

## 1. 组合与定位

- 双 SD/FQ（最高位）、双 TH、双 ED、双 TR、双 WD 及混合平面。
- 行走能力不受影响，本库明确：上肢截肢者不需要使用移动辅具。叙事焦点全部在手部功能的替代方案上。
- 角色卡分别登记两侧代码；两侧平面不同的，动作能力以较低一侧为约束下限。

## 2. 功能代偿事实【事实】

- 脚代手：经长期训练可用脚趾完成写字、用餐、操作触屏、翻页等，需要赤脚/脱鞋袜条件与地面/座椅配合，不是随时随地可用。
- 口部代偿：咬持、叼物适合轻小物件，重活与卫生敏感场景受限。
- 残肢配合：TR 及更低平面可双侧残肢夹持物体；SD/FQ 连夹持条件都没有，依赖环境固定（卡扣、绑带、特制餐具）。
- 无障碍与辅具：电动/语音控制、吸附装置、改装厨具；设定时代越落后，代偿越依赖训练与他人协助。

## 3. 高风险场景【事实】

- 跌倒：无法伸手撑地，正面跌倒时面部、胸、膝直接受冲击；角色对湿滑地面、拥挤碰撞的警惕是合理的本能。
- 热饮、明火、刀具：缺少手的瞬时回避与抓握，厨房场景需要固定流程或替代工具。
- 社交动作：握手、挥手、拥抱回抱、接名片全部需要改写或由对方适应，是人物关系戏的富矿。

## 4. 写作易错点

1. 实体物件被「手」操作——任何一侧都没有手时，全文不得出现该角色的持物动作，除非写明代偿方式。
2. 脚代手无视前提：穿着鞋、站着、没有合适坐位时无法启用。
3. 把代偿写得毫无学习成本与失败率。
4. 给角色安排拐杖等移动辅具——没有医学依据。
