# 膝离断（KD）

## 1. 解剖边界【事实】

- 经膝关节离断：股骨与胫骨分开，移除小腿与足，股骨全长保留，大腿肌肉基本完整。
- 残端由股骨髁与软组织构成，没有骨性截断平面；膨大的股骨髁提供了良好的悬吊与承重条件。
- 与 TF 的本质区别：KD 保留完整大腿与髋关节力学，残端形态膨大；TF 是股骨骨干截断、残端为骨端。

## 2. 残肢实况【事实】

- 残肢长度等于大腿全长，坐姿时残肢末端大致落在对侧膝盖同一水平附近。
- 髋关节活动与大腿肌力接近常人；残端软组织愈合后耐受较好，但同样不靠残端直接行走。
- 没有膝关节与小腿，弯膝动作不存在；足部幻肢感可出现。

## 3. 移动与日常【事实】

- 辅具路径与 TF 相同：双拐/单拐/轮椅；本库风格规则下假肢不主用。
- 因大腿力量保留完整，单腿跳、转移、游泳的运动表现通常优于高位 TF 与 HD，但写作时仍受能耗与跌倒风险约束。
- 裤装修改位置在膝部附近：空裤腿从膝水平面以下裁剪缝合，或折叠塞入腰内（见 `../../04_着装/裤装.md`）。

## 4. 写作易错点

1. 与 TF 混写：KD 角色的「大腿」是完整的，不应出现「短短的残肢」这类 TF 化描写。
2. 写出残端承重走路。
3. 让残肢做出弯膝动作。

## 5. 来源

ISO 8549-4:2020 术语；康复医学通识（2026-11-12 查阅）。
