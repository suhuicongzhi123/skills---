# 肘离断（ED）

## 1. 解剖边界【事实】

- 经肘关节离断：肱骨完整保留，移除前臂与手；上臂全长与肩部力量完整。
- 残端为肱骨髁与软组织，形态膨大，没有骨性截断面。
- 与 TH 的区别：ED 保留完整上臂，肩部力学无损；TH 的肱骨被截短。

## 2. 残肢实况【事实】

- 上臂可完成有力的屈伸、外展，残肢末端可用于稳定、推压、夹持。
- 没有前臂旋转（旋前旋后）、没有腕与手；递东西、指方向只能用残肢整体示意。
- 残肢末端软组织耐受较好，但同样不做精细操作。

## 3. 日常与叙事要点

- 单手生活清单同 SD/TH；区别在于 ED 角色的上臂力量完整，夹、压、撞、顶类动作更有力，运动与搏斗题材中可利用这一差异设计动作（见 `../../06_题材适配/热血战斗.md`）。
- 衣袖：空袖管自肘部以下无内容，上臂处仍有肢体撑起袖型。

## 4. 写作易错点

1. 写出肘弯、前臂或手的任何动作。
2. 与 TH 混写：ED 上臂是完整的，不存在「短短的残肢」。

## 5. 来源

ISO 8549-4:2020；StatPearls 上肢截肢通识（2026-11-12 查阅）。
