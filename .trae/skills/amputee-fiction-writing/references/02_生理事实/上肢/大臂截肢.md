# 大臂截肢（TH，经肱骨截肢）

## 1. 解剖边界【事实】

- 在肩关节与肘关节之间截断肱骨，移除平面以下的上臂、前臂与手；肩关节保留。
- 残肢长度不等；临床建议尽量保留长度，StatPearls 指出至少保留 5–7 cm 肱骨有利于假肢适配与肩部活动。
- 残端为肱骨骨端外包软组织；肩的屈伸、外展内收可带动残肢活动，但没有肘关节。

## 2. 残肢实况【事实】

- 残肢可做肩部动作，能夹、能压、能耸肩带动，但不能弯肘、不能抓手。
- 残肢可用于稳定物体（如用残肢与躯干夹住物品），这是与 SD 的关键叙事差异：TH 角色有一个「能帮忙但不能操作」的残肢。
- 残肢短者肩部活动范围受限明显；幻肢感常表现为「前臂还在、手肘微弯」的姿势感。

## 3. 日常动作影响（摘要）

- 手部功能全部丧失，单手生活，事务清单与 SD 基本一致。
- 残肢可参与的动作：夹纸、压门、固定餐具、拥抱时施压；不可参与的动作：任何需要肘屈、腕部、手指的操作。
- 书写、用餐、洗漱全部由健侧手独立完成；背包倾向健侧或双肩包。

## 4. 写作易错点

1. 残肢弯肘——肘关节已移除。
2. 让残肢末端做出「按按钮」「勾住」等需要手或指的动作（粗抵可以，勾挂不行）。
3. 与 SD 混写：TH 有一截可活动的残肢，SD 没有。

## 5. 来源

StatPearls NBK540962；ISO 8549-4:2020（2026-11-12 查阅）。
