# 肩离断（SD）与肩胛胸廓间截肢（FQ）

## 1. 解剖边界【事实】

### 肩离断 SD

- 经盂肱关节离断，整条上肢（上臂、前臂、手）移除；肩胛骨、锁骨保留，肩峰轮廓仍在。
- 肩部外观较健侧略塌陷，但肩线大体存在；胸壁、背阔肌等躯干结构完整。
- 无残肢、无骨性残端，离断处由软组织缝合覆盖。

### 肩胛胸廓间截肢 FQ

- 在上肢移除的基础上，连带切除肩胛骨与锁骨，胸壁外侧直接为软组织覆盖。
- 肩轮廓消失、领口塌陷明显，是上肢截肢中功能与外形损失最大的术式，通常用于肿瘤或严重创伤。
- 角色设定时二选一，不得在同一角色身上摇摆。

来源：StatPearls NBK540962、PMC4317270（2026-11-12 查阅）。

## 2. 身体实况【事实】

- 截肢侧没有任何手部功能：抓、握、捧、提、撑、推、拉、指、写，全部不存在。
- 肩胛骨保留（SD）时，耸肩、肩部前后微动仍可出现，可作为情绪动作素材；FQ 连这些动作也没有。
- 躯干平衡与下肢行走不受直接影响，上肢截肢者不需要移动辅具（本库明确规则）。
- 单侧截肢者健侧手承担全部精细操作，长期可出现健侧肩颈劳损、脊柱代偿性侧弯。

## 3. 日常动作影响（摘要）

- 所有双手协同动作受影响：系围裙/背后系扣、拧大毛巾、抱大件物品、鼓掌、接抛物、用筷子端碗的配合等，需要改写为单手方案或借助环境固定。
- 穿衣先穿截肢侧、脱衣先脱健侧是常见顺序；文胸/纽扣/拉链需要改造或练习。
- 摔倒时截肢侧无法撑地缓冲，单侧者身体会向截肢侧折倒；双侧者见复合截肢文件。
- 泳游可行，上肢损失影响划水，靠下肢与躯干推进。

## 4. 写作易错点

1. 让截肢侧出现「手」「手指」「握住」——任何形式都不行，幻肢感中的手只存在于角色感觉、不能与实体物件互动。
2. SD 与 FQ 混写：肩峰轮廓在不在，前后文必须统一。
3. 给上肢截肢者安排拐杖——移动不靠下肢缺陷，逻辑不成立；复合截肢另论。
4. 忽略单手生活的时间成本：拧瓶盖、系带、扫码等动作需要固定物或技巧，写成与双手同样快是失真。
