# 幻想向题材与豁免政策

## 1. 底线：设定准确先于能力放飞

- 截肢的解剖事实不变：HD 就是没有整条下肢、SD 就是没有整条手臂，伤口、残肢、软组织、幻肢感按现实规则描写。
- 世界可以有魔法，但角色的身体账本不允许含糊：缺了什么、还剩什么、什么动作靠本体、什么动作靠能力，始终清楚。
- 豁免是「在准确身体之上的有限代偿」，不是把截肢写没。

## 2. 豁免三要素（登记进作品设定总表）

每条豁免必须写全：

1. **能力边界**：能做什么、作用范围、持续时间、作用对象限制。
2. **代价与限制**：能耗、冷却、反噬、环境条件、社会代价；没有代价的豁免不予登记。
3. **来源与成长**：能力怎么获得、能否升级、上限在哪。

例：念力取物——仅可移动单手可提重量、半径三米、持续一分钟引发头痛；登记后该角色才能用念力完成「双手持拐时开门」之类动作。

## 3. 正文使用规则

- 每次依赖豁免完成禁忌动作，按 `../00_治理/文本格式规范.md` 打 `【豁免：条目名｜场景号】` 标记。
- 未登记能力出手、登记能力越界使用（超距、超重、无代价），冷读按致命级上报。
- 豁免解决不了的问题仍然存在：魔法能取物，不能替代长期坐姿的压疮管理；能飞行，不消除人群目光与建筑障碍——现实细节保留得越多，幻想越可信。

## 4. 形态变化规则（特殊种族通用）

- 龙族变身、兽人形切换、恶魔形态等：**变身后缺失部位依然缺失**。龙形只有三条腿、兽形缺一只前爪，缺失位置与人形对应。
- 变化只改变身体的材质与尺度，不回填缺失结构；若设定例外，必须作为独立豁免登记并付代价。
- 辅具的形态适配需要交代：人形轮椅在变身时如何处理、战斗中辅具脱手后的应对，提前在设定总表写规则。

## 5. 战斗与冒险中的豁免取向

- 豁免用于扩展战斗风格（念力副手、悬浮位移、元素代偿），不用于抹平短板；短板制造的破绽与战术取舍是看点。
- 能力失效场景（禁魔领域、能量耗尽）必须周期性出现，让人物回到真实身体条件下解决问题，见 `热血战斗.md` 与 `末世生存.md`。
