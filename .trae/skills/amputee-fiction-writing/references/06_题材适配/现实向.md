# 现实向题材适配

## 1. 总原则

现实向没有豁免通道。生理事实库与辅具库的全部规则按最严格口径执行；剧情需要与事实冲突时，改剧情。

## 2. 必须进入文本的现实维度

1. **空间的政治性**：台阶、没有坡道的入口、坏掉的无障碍电梯、卫生间门宽、柜台高度——环境障碍是日常，不是背景板。
2. **经济账**：辅具与改装的价格、维修成本、保险与报销缺口、就业歧视带来的收入压力，决定人物的真实选择空间。
3. **医疗与康复**：复诊、残肢/软组织状况、幻肢痛的波动、并发症（压疮、劳损、脊柱侧弯），按时间线合理发作，不随剧情开关。
4. **社会目光的分层**：陌生人的打量与过度热情、熟人的笨拙善意、机构的例行冷漠、网络空间的猎奇；人物对目光的反应随关系亲疏变化。
5. **照护与独立的张力**：接受帮助不等于失败，拒绝帮助也不是逞强；人物在二者之间的协商是现实向的核心戏眼之一。
6. **时间成本**：转移、改装、等待、通勤都比常人慢，节奏里要留得出这些时间。

## 3. 风格要求：足够写实、社会人文气息浓厚

- 冲突以日常性、结构性为主：一场没有电梯的面试、一次辅具损坏的连锁反应、一段关系里的照护分配，胜过戏剧化的极端事件。
- 细节可核查：写到具体机构流程、辅具型号、康复动作时先查证，查不到就用模糊但正确的写法，不编具体名词。
- 情绪克制：现实向的力量在节制，禁止旁白替人物哭、替读者总结意义。

## 4. 与其他文件的关系

- 辅具与动作严格走 `../03_辅具/` 与 `../02_生理事实/`。
- 去 AI 化标准从严执行，现实向最忌「正确的空话」（见 `../08_去AI化/AI腔特征清单.md`）。
- 角色语言贴合地域、阶层与教育背景，方言与口语有真实样本意识，不凭刻板印象写。
