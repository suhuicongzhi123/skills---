# 每章剧情安排

> 类型无关。大纲阶段排布、每章开写前核对。
> 分工：`core/structure.md` 管弧线层级，`core/scene.md` 管场景内部，**本文件管章与章之间**。

## 一、章八要素（每章开写前必须填）

| 要素 | 内容 | 判据 |
|------|------|------|
| **本章 beat** | 推进所在弧线的哪一步 | 填不出 → 这章没有存在理由 |
| **本章 turn** | 章内哪个瞬间改变了什么 | 无 turn → 流水账 |
| **新信息** | 读者这章新知道了什么 | 全无新信息 → 砍或合并 |
| **stakes 变化** | 相对上一章升了，还是换了类 | 连续 3 章无变化 → 节奏 plateau |
| **章末钩子** | 停在什么上（见下） | 无钩子 → 断更风险 |
| **受限 beat** | 本章哪个受限场景（见下） | **配额制，按篇幅档取值**（单章/短篇/中篇/长篇/超长五档）；本章为 0 时须不破窗（见一-补） |
| **本章阅读承诺** | 本章开头给读者的一个可期待的问题/目标：「这一章我想看到什么」 | 填不出 → 读者进章无目标感；**章末须回应**（兑现/翻转/推进，三选一，不可无回应） |
| **主冲突线 beat** | 本章对主冲突线的状态：推进 / 蓄势 / 留白 | 烈档：连续 3 章 ≥2 非留白且留白不连 2 章；高档：5 章 ≥3；中档：5 章 ≥2；低档：只登记（口径见一-补2） |

> **章首承诺＝入口拉力，章末钩子＝出口拉力**，互不替代：承诺让读者愿意进入本章，钩子把读者推去下一章。
> 承诺由本章剧情**内生**（通常＝本章 beat 的具体化），不排班；须**具体可判**（能不能赶上末班车），❌ 不写抽象承诺（「她会面对自己」）。
> 承诺可跨章延续：本章只推进不解决时，章末钩子即该承诺的延续态。
> 与 structure.md 的关系：本章承诺＝弧线 central question 的**局部投影**。

### turn 的三条生成路径

- **信息反转**：新事实改写局面（她以为的合租室友是房东本人）
- **关系微移**：态度或距离变化（对方第一次先看她的脸再看她的拐）
- **自我认知偏移**：她对自己的看法动了（她发现自己不再数台阶了）

## 一-补、受限 beat 章级规则（★配额制——截肢是压力源，不是每章的主问题）

> 受限＝肢体缺失让某件事变难或无法完成（见 `core/audience.md#★受限清单`）。
> 与招牌元素**分开计数、互不挤占**。
> **定位**：截肢是贯穿副线与压力源，**不取代主轴**（`core/structure.md#截肢题材适配`）——
> 所以密度用配额，不用"每章一次"。

**配额（按篇幅取值——不是固定"近 3 章 ≥2"）**：

> **取值来源**：收集第 12 题 `输出长度` → 大纲 `计划章数`（`templates/outline.md#★主题材契约`）。
> **优先级：实际计划章数 > 收集时的档位选择**——选「长篇」但只定 24 章，按中篇判；
> 选「短篇」但故事长成 12 章，按中篇判。**跨档从下一弧起生效，不回改已定稿章**。
> 单章字数长期偏离 3000–5000 时，按**等效章数**（总字数 ÷ 4000）折算后再查表。

| 篇幅档 | 计划章数 N | 窗口配额（软） | 弧配额（软） | 破窗（硬） |
|---|---|---|---|---|
| **单章** | 1 | —（无窗口） | 全篇 ≥1 | 全篇 0 条 |
| **短篇** | 2–10 | 全篇 ≥2（不设滚动窗口） | 不分弧 | 全篇 0 条；N≤3 时全篇 ≥1 即可 |
| **中篇** | 11–30 | 近 3 章 ≥1 | 每弧 ≥2 | 连续 3 章 0 条 |
| **长篇** | 31–60 | 近 3 章 ≥2 | 每弧 ≥3 | 连续 3 章 0 条 |
| **长篇·超长** | ≥61 | 近 4 章 ≥2 | 每弧 ≥4 | 连续 4 章 0 条 |

- **软/硬分开判**：
  - **软（窗口/弧）未达标** → 标记提示、后续章优先补足，**不回改已定稿章、不强造**；
  - **破窗（硬）** → 该章不得交付，除非在账本 `用户指令变更.质量例外` 注明「核心受限豁免」
    并告知代价。
- **单章最多登记 1 个**（同章多个时登记最强的一个，其余并入「场景」字段）。
- **本章可以是 0**：只要不破窗。主冲突线高潮章、纯关系章、群像章都可以不带核心受限——
  这是与旧版"每章 ≥1"的关键差别。
- **篇幅越短，窗口越松、总量越硬**（短篇看全篇总量，长篇看滚动窗口）；道理是：
  三章窗口在 8 章的短篇里等于"每 3 章 2 条"，会把短篇压成受限集锦。

### 一-补1、三层供给（让路机制——"让场景，不让因果"）

> 配额只回答"这一章有没有**核心**受限"。但一章为其他剧情让路时，不该写成"什么都没有"——
> 读者要的是身体事实**在场**，不是每章都要"她做不到"。

| 层 | 定义 | 判据 | 占配额 | 例 |
|---|---|---|---|---|
| **核心受限** | 原方式**做不到** → 改变行为方式或无解；有处置 | 类型/场景/处置三要素齐；弱受限与点缀不算 | ✅ 占 1 | 拐被打飞 → 单腿跳守门 |
| **受限在场** | 身体事实**参与动作或决策**，但不构成"做不成" | 删掉这句动作仍成立；删掉后读者感觉不到身体在场 | ❌ 不占 | 起身前先看拐在哪；进门先量门宽；坐下前把拐靠好 |
| **受限余波** | 不写场景，只在**后果/他人反应/计划变更**里显形 | 至少一处**具体**后果（时间/路线/物件/别人一句话） | ❌ 不占 | 「昨天那一趟，她今天没出门」 |

**让路规则**：

- **让路**＝本章不设核心受限，用「在场 / 余波」补位，把整章让给主线（高潮章/关系章/群像章）。
- **上限**：连续让路 ≤2 章；每弧让路章 ≤**40%**（四舍五入）。
- **让路 ≠ 破窗**：让路章必须有在场或余波；**连续窗口内核心受限全 0 且无在场/余波＝破窗**，不得交付。
- **登记**：账本 `受限让路`（章 / 让给什么 / 补法 / 补偿章 / 是否破窗）——让路从"静默写 0"变"显式可审"。
- **补偿**：让路后 1–2 章内补一条核心受限（账本 `补偿章` 填章号），否则下个窗口按软不达报。

### 一-补2、主旨锚（每弧 ≥1 次「身体事实作为因果」）

> 数量守不住主旨，因果才守得住。配额可以让路，这一条不能。

- **判据一句话**：**把"截肢"这个设定删掉，这一弧的主线会不会变？**
- **会变**＝锚在（她的身体决定了某件事的走向：别人怎么待她 / 她选哪条路 / 谁留下 / 代价由谁付）。
- **不会变**＝这弧与身体无关——允许 **1 弧**（题材需要喘息），**连续 2 弧＝报「主旨漂移」**。
- 锚点不是场景，**让路也删不掉**：它可以是别人一句安排、一次路线选择、一份被拒的申请。
- 登记：账本 `本章登记.主旨锚`（有 / 无 + 一句话）；冷读维度 13 与 22 复核。
- 素材来源二选一：
  - `topics/limitation-scenes.md`（总库，含题材适配）
  - `types/{type}.md#受限清单`（本类型特有）
- 填写三要素：**类型**（功能丧失(主) / 辅助器具剥夺 / 双手占用 / 速度劣势 / 对立挑衅 / 环境与他者）/ **场景** / **她的处置**
  （用中文类名，不用编号——编号属于招牌元素清单；主源优先功能丧失类，衍生类为辅）
- **高武/高魔/神话题材另记一本**：能力受限（魔力耗尽/法器被夺/领域被破）记 `本章登记.能力受限`，
  **不计入截肢受限配额**，`是否顶替` 恒填「否」（见 `topics/combat-mechanics.md#15.4`）
- **同类受限连续深挖合法**；**事件必须新 或 视角新**——
  同事件复述/简写/改词＝严重失败（查重见 `core/audience.md#★情节查重`，
  登记账本 `情节事件登记`）
- 写法模板：**受阻 → 她的处置 → 结果**（完成 / 未成 / 妥协）；只有呈现没有处置的，砍掉

## 一-补2、主冲突线 beat 章级规则

> 主冲突线＝大纲「★主题材契约」锁定的主对抗轴（谁 vs 谁/什么、争什么）。
> 用户选定的冲突强度档＝**创作授权**：对抗/冲突场景是授权内容，写足写细，
> 不回避、不淡化、不转移；授权不豁免回避清单（`core/audience.md`）。
> 对抗场景写法素材见 `topics/conflict-scenes.md`；**战斗/追逐/围堵的打法、地形、武器与代价**
> 见 `topics/combat-mechanics.md`（类型分型/手的经济/敌方升级曲线/K01–K13 自查）。

**三态判定**：
- **推进**：主对抗双方本章正面交锋或局势实际变化（战斗开打/对峙升级/竞争结果落定/攻防换位）
- **蓄势**：未正面交锋但有明确加压（威胁逼近/约定对抗/情报到位/矛盾激化）；
  **呼吸章（节拍角色＝呼）计蓄势**——峰值后的后果与重整是冲突线的延续
- **留白**：主冲突线本章完全不在场

**四档配额（软下限，查账本 `主冲突线近五章`）**：

| 冲突强度档 | 软下限 | 适配题材 |
|---|---|---|
| 烈 | 连续 3 章 ≥2 非留白；留白不连续 2 章 | 战斗 / 末世 / 竞技 |
| 高 | 连续 5 章 ≥3 非留白 | 悬疑 / 冒险 |
| 中（默认） | 连续 5 章 ≥2 非留白 | 言情 / 职场 / 家庭等 |
| 低 | 不设下限，只登记 | 温馨日常 / 纯言情 |

- 弧线 **crisis 章必为推进**
- 窗口不足 → 标记提示、后续章优先补足，**不回改已定稿章、不强造**（同受限 beat 口径）

**与受限 beat 的划界（正交，互不挤占）**：主冲突线 beat 只管对抗线推进，与截肢无关；
受限 beat 只管截肢事实的受限（肢体缺失让某件事变难或无法完成），与主线无关。
同章可分别命中、分别登记——战斗章里拐被打飞：主冲突线记「推进」，受限 beat 记
「辅助器具剥夺」，两账分开。

## 一-补3、解法不复用（处置路径查重）

> **判据一句话：事件可以换，招法不变＝重复。**

**先分清两层——战术目标 ≠ 招法**：
- **战术目标**＝换时间 / 换高度 / 换接触 / 借他者 / 拖时间 / 让对方付接近成本。
  这是她的打法性格，**可以反复出现，不计查重**（同一个人不可能每章换目标）。
  ❌「守点」「逼对方进窄处」**已废止**——把胜负交给地形（见 `combat-mechanics#八` 禁用清单、K13）。
- **招法**＝达成目标的具体手段：扬沙 / 泼油 / 熄灯 / 断绳 / 关门 / 借台阶 / 绊倒 /
  贴抱 / 抓腕 / 借人 / 借火 / 佯退 / 示弱。**这是查重的最小单位**。

- **判据**：同一**招法**在同一**场景域**近 5 章内出现 ≥2 次 → 判「解法复用」，须换招或升级；
  **同章内**同一招法用两次也计复用（台账登记两行，场景域分别写）
- **三种升级都不算复用**：① 同目标换手段（上次推车，这次泼油）；
  ② 把对方的招学过来反用（对手拆过她的地形，下一次她先拆对方的）；
  ③ 同一招换到不同场景域的战场（同一个制造点从街口换到船头/桥面）——
  ②③ 在账本 `解法台账.备注` 注明「升级」即可
- **登记**：账本 `解法台账`（目标 / 招法 / 场景域 / 结果 / 备注），逐章累积
- **与情节查重的分工**：`情节事件登记` 管"事件层"（同场景域＋同事件结构），`解法台账` 管"方法层"；
  两层**分别查、分别判**，命中任一层都算重复
- **写作侧的执行**：每章开写前，队长（max）/主代理（pro/flash）在任务包或写作笔记里写明
  「本章禁用的招法」——从台账里挑出近 5 章用过的
- ❌ 把「换时间」当招法登记（太粗，无法查重）；❌ 把「她很聪明」当解法；
  ❌ 用窄路取胜（K13）
  （招法库与升级写法见 `topics/combat-mechanics.md#八、她的解法谱（战术目标与招法）`）

## 二、章末钩子类型库（10 类，按拉力强度分两档）

> 与 `core/style.md#章节结尾` 配合：钩子**不是升华**，停在动作/画面/情绪/悬念，不上升到感悟金句。

── 强钩 H（问题悬置型：读者必须知道下文才走得开）──
H1 悬念：下一刻会发生（手机又响了。她没看）
H2 决定：她刚做了个选择，后果未至
H3 到来：某人/某事正在路上
H4 威胁：来临之事带有明确利害（不同于「到来」——到来中性，威胁压着代价）
   例：拐杖的调节锁扣松了半圈。明天她要爬八楼。
H5 倒计时：一个明确的远期截止（距某时/某日还有 N）
   例：辞职信压在她包里。周五之前，她得决定要不要交。
H6 抉择：两条路都必须付出代价，她还没选
   例：新拐杖下周到，可旧拐的那道裂口——她今晚还得拄着它下楼。
H7 揭示：真相刚掀开一角，含义未明（升级版「新信息」——须带利害，否则降级为弱钩）
   例：体检报告最后一页，她看见了那个名字。

── 弱钩 h（余味型：留在一种状态里，不强制追问）──
h8 情绪：停在一种未消化的感受上（说不清是松了口气还是空了一块）
h9 画面：定格一个有重量的画面，余味自行发酵
h10 回声：一个意象/台词在章末回扣前文（跨章大跨度回扣由全书级钩子承担）

**强度规则（软下限，防均值化）**：
- **位置性硬规则（非软约束）**：钩子必须落在**全章最后三拍**——**拍＝一个动作或一个信息单元
  （同一动作链、同一段对话算一拍；以自然段为计数单位）**。其中 **H4/H6/H7 的兑现句须在
  最后一拍（末段）**，其后不得再接解释或日常收束；**h8–h10 可占最后三拍中的任意一拍**，
  但末拍不得另起新事件。**登记为 H 而末段停在静物描写或日常收束（"牌跟手一样温""剑尖离土半寸"），
  钩子被稀释成 h9 余味，属「钩型滑落」，须按实际钩型重判并改稿**。
  **h9 本身是合法钩型，不在本条禁止之列**：本章登记的就是 h9、且弱钩配额达标
  （不连续 3 章、近 5 章余味池 ≤2）时，末段停在画面/静物合法——本条禁的是
  「标定与正文不符」，不是「写画面」。
- 任意连续 5 章内，强钩 H 至少 3 章；弱钩 h 不得连续出现 3 章
- 弧线 crisis 章、卷末章必须用强钩 H
- 烈/高档作品：任意连续 5 章的强钩 H 中 ≥2 个源自主冲突线（威胁/倒计时/抉择的施压方来自主对抗）
- 强弱判定一句问：**这一章不看下一章，读者会不会难受？**会＝H，只是回味＝h

> 说明：素材层（招牌元素/受限）不事前排班；本节"强钩/弱钩"软下限属**结构节奏轴**（保证每几章有一次拉力），不是素材排班。**温馨日常取向**的书可按题材下调强钩下限（如连续 5 章强钩 ≥2）。

**钩子类型约束（弱钩合并计数）**：
- 每章章末钩子类型**登记进 `state-ledger.yaml` 的 `章末钩子类型`**，跨章可查
- ❌ 与上一章同类（相邻章不得同型）
- ❌ 近 5 章内同一类型至多 1 次（h8/h9/h10 合并为「余味池」，近 5 章内至多 2 次）
- ✅ **超过 5 章后**再用同一类型，须换内容载体（悬念换悬念源、决定换决定对象）
- 首章钩子类型须与全书「开篇维度」不同源（见 `core/opening.md#四-补`）
- 同类型在 5 章外复用时须换内容载体：同为「到来」，一次是人、一次是消息、一次是天气变化

**★卷末大钩（arc-level cliffhanger，与弧线五组件联动）**：
- 每段弧线的最后一章（resolution 章）章末**必须**用 H4/H6/H7 之一，且指向**下一段弧线的 central question**（呼应 structure.md「弧线 resolution 设置下一弧线的 question」）
- 卷末大钩不受「近 5 章同类型至多 1 次」约束，但同一部书内不得连续两次用同一卷末钩型
- **★全书最后一章豁免本条**：末章不是「resolution→下一弧」而是「全书收尾」，按
  `core/structure.md#一-补2、结局规则（最后三章）` 判（终局承诺兑现/不兑现的代价 ＋ 回扣第一章意象）；
  **不写指向下一卷的钩子**，也不得为凑 H 型把「新常态」写成续集预告。S10 在末章判「不适用」，
  证据列须引回扣句；冷读维度 10 同此口径（见 `core/cold-review.md` 卷末大钩例外段）

## 三、章节功能配比（全书层面，非每章）

五类功能：**主线推进 / 关系深化 / 日常样态 / 对抗危机 / 生存危机**

- **对抗危机**：有明确对抗方的正面冲突（战斗/追捕/对峙/竞技/正式口舌对决）
- **生存危机**：无对抗方的压力事件（器具故障/伤病/环境恶化/时限压力）

配比按题材取基准（软约束，允许 ±1 浮动）：

> **本表按「大类 → 细分」两级查**（题材大类/细分的权威定义见 `core/character-setup.md` 人物卡·题材大类与题材细分字段）：
> 先按大类取默认行，再按细分的偏差修正。旧表把两个层级混在一起（既有"末世"＝大类，也有"言情"＝细分），
> 导致幻想向/家庭伦理查不到基准——已按两级重排。

| 大类 | 细分 | 主线 : 关系 : 日常 : 对抗危机 : 生存危机 |
|---|---|---|
| **现实向** | 都市日常 / 言情 | 3 : 4 : 2 : 0 : 1 |
| | 校园（大学/成年） | 4 : 3 : 2 : 0 : 1 |
| | 职场 | 4 : 2 : 3 : 0 : 1 |
| | 家庭伦理 | 3 : 5 : 1 : 0 : 1 |
| | 悬疑推理 | 5 : 2 : 2 : 1 : 0 |
| | 温馨日常（偏日常向） | 2 : 3 : 4 : 0 : 1 |
| **幻想向** | 高魔奇幻 / 低魔奇幻 | 4 : 2 : 1 : 3 : 0 |
| | 都市奇幻 | 4 : 3 : 2 : 1 : 0 |
| | 科幻 / 赛博朋克 | 4 : 2 : 2 : 1 : 1 |
| **末世生存** | 末世 / 丧尸 / 废土 / 孤荒 | 4 : 2 : 1 : 2 : 1 |
| **古装向** | 架空朝代 / 真实朝代 / 低技术架空 | 4 : 3 : 1 : 1 : 1 |

- **幻想向的对抗危机默认 +1**（3 而非 1）：冒险循环的驱动是对抗，不是日常；
  若细分是"都市奇幻/言情向"，按都市日常行取。

**冲突强度档调节**：烈档 → 对抗危机 +1（自关系深化借 1，不为负）；其余档取基准。

**核查口径**：以 **每 10 章为一个窗口**统计实际配比，偏离基准 ≥2 章触发调整（该功能实际章数与基准章数之差）。

- ❌ 连续 3 章以上同一功能 → 触发中段疲劳预警
- ❌ 招牌元素分布不计入配比，须单独查 `state-ledger.yaml` 的 distribution
- 每章的 `章节功能` 与 `stakes` 登记进账本，否则配比与 stakes 变化不可查

**中段疲劳预警（升级版：三信号，任一命中即预警）**：

1. 功能失衡（原规则保留）：10 章窗口配比偏离基准 ≥2 章
2. 张力塌陷（新）：连续 4 章 张力级 ≤2 且无升级趋势 → 预警
3. 弧线联动（新）：弧线 midpoint 前后各 3 章内应出现一次张力峰值或冲突性质转变；未出现 → 预警（对应 structure「saggy middle」）

**误报豁免**：连续同功能若 stakes 或张力级**逐章递进**，不触发预警——慢热可以合法，只要坡度在升。
**窗口细分**：10 章窗口再分前/后各 5 章分别校验，避免"整体达标、局部塌陷"。

## 四、章间连接

- 上一章钩子 → 本章开场须**接住**，不另起炉灶
- **因果优先**：本章起点是上一章行为的**后果**，不是时间序列上的下一件事
- 时间跳跃须交代间隔（写入 `state-ledger.yaml` 的时间线字段）
- 视角切换须在章首标注（见 `core/character-setup.md` 的叙事视角字段）

## 五、章级质量口径优先级

四处文件都涉及「章级质量」，**以本文件的章八要素为准**（其余为补充视角，不并列）：

1. `core/chapter-planning.md` 章八要素 —— **执行口径**（beat / turn / 新信息 / stakes / 钩子 / 受限 beat / **本章阅读承诺** / **主冲突线 beat**）
2. `core/structure.md#结构五病` —— 弧线层问题诊断
3. `core/cold-review.md` 稽查维度 10 —— 事后复核口径
4. `templates/chapter.md` —— 填写与勾选项

> 判定不一致时取第 1 项；第 2–4 项只补充检查角度，不另立标准。

## 六、亲密戏的编排（B/C 档）

> 本节的 B/C 指**亲密尺度档**（B 情色半程 / C 成人全程），不是截肢时长档位。
> 尺度定义与写法见 `topics/intimacy.md#二、尺度分档` 与 `topics/intimacy-explicit.md`；
> 本节只管**全书与章级怎么排**——排得不对，写得再好也是孤岛。

### 6.1 五条硬规则

1. **不是福利章，但「受众供给」是合法功能**：每场须有剧情功能
   （关系确认 / 权力变化 / 信息交换 / 误解加深 / 和解 / **受众供给**），
   并登记账本 `亲密戏登记`。**受众供给**＝身体接纳（她让他看/碰残肢）、器具卸下（假肢/拐离身）、
   受限处置（体位改造的过程本身）——这是本类型读者的核心期待，属合约内容，
   **不得以「与主线无关」为由删掉**。
   - **删场测试（唯一删除判据）**：删掉本场，后 3 章有无台词/行动需要改？
     有＝有剧情功能；没有，且没有受众供给功能＝删。
   - 旧口径「只服务读者的场次，删」**作废**——它与 SKILL 的「受众偏好是约稿合同」自相矛盾。
2. **不得用性解决主线冲突**：和解 / 安抚之后必须有一场谈话或一次行动兑现；
   否则是假解决（下一章矛盾必须回来）。
3. **首次 C 档前须有「被看见」beat**（招牌元素⑥）：她让他看见，才让他碰。
4. **不得连续两章同档亲密戏**：两场之间章号至少差 2（第 N 章之后最早 N+2 章；
   与⑦限频同口径；用户显式上浮密度档时从其档）。
5. **章级底线不豁免**：每场亲密戏仍须有 turn / 章末钩子；**核心受限走配额，不逐场硬要**
   （见 `#一-补`）。**体位改造只能算「场景内受限」**，不得顶替章级核心受限——
   每 5 章最多顶 1 次，且须在账本 `亲密戏登记.体位与改造` 注明
   （层级判定见 `topics/limitation-scenes.md#四-补2、受限层级判定`）。

### 6.2 位置与节奏

- **首次位置按篇幅函数算**（不再用固定的 "20%＋节点间距 ≥5 章"——24 章的作品会被算到 45% 以上）：
  - **篇幅 ≤30 章**：节点间距 **3 章**，首次 C 落在全书 **25–40%**
  - **篇幅 31–60 章**：节点间距 **4 章**，首次 C 落在 **20–35%**
  - **篇幅 >60 章**：节点间距 **5 章**，首次 C 落在 **20–30%**
  - 短篇（≤5 章）：不适用百分比，见下「不能开场就上床」
  - 公式：`首次最早章 = max(节点间距约束, 全书 20% 向上取整)`；两值冲突时**以节点间距为准**（关系不能跳）
- **弧线位置**：首次 C 档常落在 midpoint 之后（改变关系性质）；第二次可在 crisis
  （安慰或错误的依靠）；末次在 resolution（新常态，不是奖励）。
- **每场之后**：下一章须写「事后变化」——关系阶段 / 信息 / stakes 至少一项；
  没有变化＝这场是孤岛。**变化须落在下一章的具体动作或台词上**，不写在旁白总结里。
- **外部后果（C9）**：首次 C 之后 **3 章内**至少落一项**外部**后果——被听见 / 被撞见 /
  避孕失败或怀孕风险 / 名声 / 社群议论 / 制度后果（宿舍查寝、门禁、军规、宫规）。
  按题材选（见 `topics/intimacy-genre.md` 各题材"风险"栏）；只写两人内部的关系变化不算。
- **张力**：C 档章通常 3–4 级；首次 / crisis 章可 5，但之后 1–2 章内安排 ≤2 呼吸章。
- **不能开场就上床**：前 3 章（新读者窗口）不排首次 C 档；**短篇（≤5 章）整体豁免本条**，
  但从第 1 章起仍须有情节钩子（短篇单章作品按"整章＝一章"处理，不受前 3 章约束）。

### 6.3 密度基准（中长篇）

> 单位＝每 N 章一场。B 情色档作品可更密（因为不写临界/高潮/后戏，单场更短）；
> C 成人档作品更疏（单场更长、后果更重）。短篇 1–2 场；单章可 1 场。
> **A 含蓄档不按"场"计**：它写的是目光/接触/回避/次日，按"里程碑"计（看见/触碰/第一次过夜），
> 密度基准＝每 4–8 章一次有效进展；A 档五拍见 `topics/intimacy.md#二-补、A 档五拍`。

| 题材 | B 情色档作品 | C 成人档作品 | 首次位置 | 常用功能 | 忌 |
|---|---|---|---|---|---|
| 都市言情 | 1/4–6 章 | 1/6–8 章 | 25–40% | 关系确认 / 误解 / 和解 | 用性解决争吵 |
| 校园（大学/成年） | 1/6–8 章 | 1/8–10 章 | 35–50% | 私密 / 被发现 / 成长 | 未成年；宿舍偷情当唯一冲突 |
| 职场 | 1/6–8 章 | 1/8–10 章 | 30–45% | 权力变化 / 秘密关系 | 性＝升职筹码的单一写法 |
| 家庭伦理 | 1/8–10 章 | 1/10–12 章 | 35–55% | 照顾者权力 / 依赖 | 把照护写成胁迫 |
| 悬疑推理 | 1/10–12 章 | 1/12–15 章或 1–3 场 | 40–60% | 信息交换 / 试探 / 伪装 | 性场景当线索倾倒口 |
| 末世生存 | 1/10–12 章 | 1/12–15 章 | 30–50% | 压力释放 / 结盟 / 风险 | 无菌棚式洁净；忽视卫生 |
| 古装 | 1/8–12 章 | 1/10–15 章 | 40–60% | 名分 / 权力 / 私通风险 | 现代性脚本；忽略无润滑/无避孕 |
| 幻想 | 1/6–10 章 | 1/8–12 章 | 30–50% | 身体规则 / 身份 / 契约 | 用魔法「修好」截肢 |
| 温馨日常 | 1/6–10 章 | 1/8–12 章 | 30–50% | 笨拙 / 幽默 / 日常 | 每章靠床戏撑 |

- 用户可在设定阶段显式改密度 → 记入账本 `角色固定属性.亲密戏密度`；未声明按上表。
- 密度是**上限管理**，不是排班：没有剧情契机就不写，不为凑数加戏。

### 6.4 与关系里程碑的接口

- 第一次看见（A 含蓄 / B 情色）→ 第一次触碰（B 情色）→ 第一次过夜（C 成人；
  B 情色档可写当夜进入，停在临界前，不写高潮/后戏）→ 第一次吵架时身体被戳（任何档）→ 和好（任何档）。
- 节点间距按篇幅（见 `#6.2`）：≤30 章＝3 章；31–60 章＝4 章；>60 章＝5 章（短篇按篇幅缩减）。
- **B 情色档作品不得为「过夜」里程碑写临界/高潮/后戏（越档）**：可写当夜的进入与抽送，
  停在「身体接管前」；用门口、次日清晨、没做完的事完成里程碑。
  **三条客观锚（缺一即判越档，见 `topics/intimacy-explicit.md#9.6 B 档停手的三条客观锚（判越档，不靠语感）`）**：
  ① 无自主收缩的节律描写；② 无「只剩一口气/脑子里一片白」式的临界失神；③ 无事后清理与相拥收尾。

### 6.5 场景数量与地点

- 每章最多 2 个场景地点；换场有动作链（见 `topics/intimacy-explicit.md#六、体位矩阵` 换位链）。
- 同一地点不连续用两次（防「每次都在卧室」）；浴室 / 沙发 / 轮椅 / 酒店 / 车里按题材选。
- 每次至少换一个新变量：地点 / 器具状态 / 关系阶段 / 权力位置 / 身体状态
  （经期、疲劳、感冒、刚吵完架）。

## 七、用户指定剧情的插入与提前

> 触发：用户明确要求「加 X 剧情」「让 X 早点发生」「把 X 改成 Y」。
> 权限：用户指令 > 大纲契约（见 `SKILL.md#★用户指令优先`）；本节只管**怎么排**。
> AI 自主新增仍走「大纲变更确认」，不适用本节。

### 7.1 五种插入法（按体量选）

| 法 | 适用 | 做法 | 代价 |
|---|---|---|---|
| **插入章** | 单场戏 / 短剧情 | 在现有章序中新增一章，后续章顺延 | 全书章数 +1；钩子链要重接 |
| **替换章** | 原计划有一章功能相近 | 用新剧情替换该章，保留其钩子功能 | 原章内容删/并入他章 |
| **压缩章** | 需要 1–2 章铺垫 | 把铺垫压成 1 章，腾出正面呈现的位置 | 铺垫密度升高；须防「赶」 |
| **前置章** | 后置弧线节点提前 | 把该节点移到当前弧线，后续节点顺延 | 弧线节奏变；midpoint 可能前移 |
| **重写弧** | 用户要求改故事方向 | 重写当前弧线编排表与后续章纲 | 影响最大；须告知代价并登记 |

### 7.2 选择判据（四问）

1. 这段剧情是**单场**还是**跨章线**？单场→插入/替换；跨章→前置/重写。
2. 需要多少**铺垫**？0 章→插入/替换；1–2 章→压缩；3 章以上→前置/重写＋用户同意。
3. 是否**撞主冲突线**？撞→改道，重写弧线；不撞→插入/替换。
4. **已写章**是否可动？不可动→只能往前排；可动→替换/重写。

### 7.3 插入后必查（七项）

- [ ] 章号连续，无空号/重号
- [ ] 钩子链不断：上章钩子被接住，新章有钩子
- [ ] 关系阶段不跳：新剧情不要求角色突然信任/突然反目
      （除非用户就是要这个转变——那须写 turn，不能白给）
- [ ] 时间线不矛盾：季节/间隔/已知信息
- [ ] 受限配额未被插章冲垮（`core/audience.md#★受限清单`：按 `篇幅档` 查表；用户明确要求豁免并在账本注明
      「质量例外」的除外）
- [ ] 亲密戏密度不被挤爆：插入的若是 B/C 档剧情，按 `#六` 的间隔与题材基准重排
- [ ] 章节功能配比与体验强度曲线未因插章失衡（10 章窗口 / 曲线规则；必要时按新章序重标
      `templates/outline.md#★体验强度曲线`）

> 改大纲后，重过 `core/workflow.md#3. 大纲` 质量闸的相关项
> （世界观/主冲突线/弧线编排/契机标注/亲密戏编排）；不得只改章序不查一致性。

### 7.4 告知与登记

- 按 `SKILL.md#★用户指令优先` 的**固定四行**告知：收到 / 呈现 / 大纲改动 / 代价。
- 登记 `templates/state-ledger.yaml#用户指令变更` ＋ 大纲 `用户指令变更记录`。
- 被替换/后移的章，在大纲里标「被替换」「后移」；**不要静默删除**。

### 7.5 与「尽快」的接口

- P0（N+1）/ P1（N+2）/ P2（N+3）；超过 3 章须用户同意。
- 用户给了章号 → **以用户章号为准**；排不下就压缩前面的铺垫，不改用户章号。
- 用户要的剧情与现有钩子链冲突 → 先接住旧钩子，再在新章里转；不得直接扔掉旧钩子。
