# 写作风格规则

> 类型无关。基于受众偏好制定。

## 基本原则
> **内容偏好与回避清单以 `core/audience.md` 为准**（受众驱动，取「读者更爱看」）；
> 本节只管风格本职。开篇从 `core/opening.md` 选维度，招牌 beat 由各章剧情契机内生供给（事后限频体检），禁止把重点内容塞进开头。

- **口语化、生动**：用语气词、短句、生活化措辞提高可读性
- **代入感优先**：让读者代入截肢者视角，感其所感

## 回避清单
> 回避清单见 `core/audience.md`。

## ★写肉不写骨（正文用部位，不用解剖名）

> 解剖定位是**规则内部的防错工具**，不是给读者看的文字。
> 正文一律写**身体部位与肉感**，不写骨骼名。

| 内部定位（**不写进正文**） | 正文写法 |
|---|---|
| 骨盆 / 髂骨 / 耻骨 | 髋侧、胯、那半边、那一侧 |
| 坐骨 / 坐骨结节 | 屁股下面坐得实的那块 |
| 髂嵴 | 腰侧到胯那道棱、裤腰卡住的地方 |
| 臀沟 | 屁股下缘 |
| 骨盆前送 / 随动 / 侧倾 | 那半边身子送出去 / 整边身子跟着动 / 这半边沉下去 |
| 骨盆软组织 | 那儿的肉、屁股和髋侧的肉 |
| 腰椎 / 躯干代偿 | 腰、上身 |

- ❌ 正文出现"骨盆""髂嵴""坐骨结节"属**医学临床化**（回避清单）
- ✅ 写她自己会怎么说、怎么看：**屁股、腰、胯、那半边、那一侧、断口那一圈**
- 例外：角色若是医护/康复从业者，其专业内心独白可破例，但叙述层仍用部位

## ★禁止注释式纠错与注释式解释

> 正文里不得出现"先说一个说法、再否定它、再给正确说法"的写法——
> 那是把**作者的说明**塞进了角色的叙述，一出现就把读者从故事里拽出来。

| 形式 | 反例（❌ 必改） | 正确写法（✅） |
|---|---|---|
| 自我更正 | 「她左腿——不，她没有左腿」 | 「她没有左腿」 |
| 概念否定 | 「不是疼——先是麻，然后是一种很奇怪的灼烧感」 | 「先是麻，然后是一种很奇怪的灼烧感」 |
| 身份注解 | 「像被电了——不是幻肢，她从来没有过幻肢，她生下来就是这样，不知道"两条腿"是什么感觉」 | 「那一侧的肉抽了一下，像过了下电」 |
| **否定式缺失描写** | ❌「战斗裤在左侧裆线处收口，缝线整整齐齐，**没有裤管**」 | ✅「战斗裤在左侧裆线处收口，缝线整整齐齐」 |

**判据**：一句话里出现「A——不 / 不对 / 不是，B」，且 B 才是事实 → **命中，必改**。

**关于第四种形式（否定式缺失描写）**：

写了「在哪里收口 / 结束」之后，❌ **不再追加「没有 X」**——
**写了收口，就已经说了那里没有**。再补一句是向读者**声明缺失**，等于此地无银三百两。

- ❌ 「在裆线收口，**没有裤管**」「**下面什么都没有**」「患侧**空空的**」「**没有那条腿**」
- ✅ 「裤子在裆线处收口，缝线整整齐齐」——到此为止，读者自己知道
- 判据：句子出现「没有 X / 无 X / 什么都不存在 / 空空的」，且 X 是**缺失的身体部位或衣物**
  → 命中，**删掉那半句**（不是改写，是删）

- ✅ 直接写正确的那一个，读者的理解交给上下文
- 例外：角色在心里纠正自己的口头禅或习惯说法（差点说"两条腿"又咽回去），
  须**一次性、有性格依据**，不得当作交代信息的手段
- 与"不解释不说明"同源：**角色不知道自己在给读者科普自己的身体**

## 语言
- 脏话限特殊痛苦场景（摔倒、受伤、关键受挫），符合自然中文口语习惯
- 不用"见鬼"等出戏词
- 语气词自然（嗯、哎、嘶、哈）增可读性

## 声口多样性
- 不同主角应有不同叙事声口，避免所有开篇都是同一种口语化热闹腔
- 声口谱：毒舌冷峭 / 克制寡言 / 絮叨热络 / 沉静内敛 / 跳脱俏皮
- 声口在人物设定阶段确定，全书统一，不中途突变
- 允许偶尔非主角 POV 或外位观察者冷开场，打破"主角自我身体凝视"的固定内视角（见 `core/opening.md`）

## 题材差异
- 现实向：器具写实、日常真实（`genre/realistic.md`）
- 幻想向：符合截肢设定事实，按需加高科技/魔法元素（`genre/fantasy.md`）
- 古装向：器具与服装按时代，见 `genre/historical.md`

## 去AI化润色
- 去总结套话：删"总而言之""综上所述""不得不说""或许这就是……"等收束语
- 去升华拔高：结尾不上升到人生感悟/励志金句/主题宣言
- 去排比堆砌：三连排比以上拆散，保留自然语气
- 去过度规整：段落长短错落，不每段都齐整三句
- 去书面腔：能口语的不书面（"于是"→"就"，"然而"→"可"），但不过度到失真
- 程度把控：只去明显AI味，不强行改写自然句子，保留作者语感

### LLM 失败模式（深化）
- **勿过早解决张力**：冲突/不便/情绪不在同场景解决，让张力跨章持续。截肢者日常的不便/错位感天然适合跨章低张力持续。例：第3章的争执不必第3章和解，可拖到第8章或永不
- **勿添加情感评论**：事件后写角色即时具体反应即可，不加"重量感X像Y"的隐喻解释和"这意味着Z"的编辑评论（与"章节结尾不升华"合并）
- **勿坍塌歧义**：动机/道德的含糊不要硬扭向一边，保留多解释。叙事拒绝对角色下判断几乎总比下了强
- **勿过度强化语言**：强情感用克制，一个强意象胜过三个 adequate；真人激烈时刻反而 understated
- **勿整洁总结结尾**：场景/章节不在结尾段总结情感意义（与"章节结尾不升华"合并）
- **勿橡皮图章手势**：勿用攥拳/倒吸凉气/移开目光/咬唇/咬牙等套路手势表情绪，找具体动作

## 章节结尾
- **不升华**：结尾停在动作/画面/情绪/悬念上，不拔高到感悟金句
- 禁止结尾句式："也许这就是……""或许生活就是……""她终于明白……""原来XXX才是XXX"
- 允许结尾类型：
  - 动作停顿（她把拐杖靠在门边，没再动）
  - 画面定格（膝上/膝下示例：窗外路灯亮了，残肢在裤管里轻轻一颤；
    髋离断示例：窗外路灯亮了，收口处的软肉轻轻一抽）
  - 情绪留白（说不清是松了口气还是空了一块）
  - 悬念未完（手机又响了。她没看）
  - 日常收束（洗完碗，她想着明天该去配把新拐杖了）
- 收尾质感贴合基调，但即便压抑沉重基调也不以金句升华收尾
