# 写作风格规则

> **目录（>100 行按需文件，勿整体加载）**：基本原则｜★三阶示范（示范节②）｜回避清单｜
> ★写肉不写骨｜★禁止注释式纠错｜★中文质感六技｜语言｜声口多样性｜★声口对照示范（示范节⑦）｜
> ★人物活性｜题材差异｜去AI化润色（含六族/伪活性/结构层指针）｜章节结尾。
> **成文层（章节因果链/叙事距离/氛围/跨章文风）权威在 core/prose-craft.md**，本文件只管词句层。

> 类型无关。基于受众偏好制定。

## 基本原则
> **内容偏好与回避清单以 `core/audience.md` 为准**（受众驱动，取「读者更爱看」）；
> 本节只管风格本职。开篇从 `core/opening.md` 选维度，招牌 beat 由各章剧情契机内生供给（事后限频体检），禁止把重点内容塞进开头。

- **声口贴角色**：语气词、短句、生活化措辞的密度**服从人物卡声口字段**（絮叨热络高密度；克制寡言低密度）——不是所有书都该热闹腔。句法级示范见本文件★三阶示范
- **代入感优先**：让读者代入截肢者视角，感其所感

## ★三阶示范（取象→句法→意象生成）
> 本节含 7 组技法示范；"三阶"指 取象层 ↔ 句法层 ↔ 意象生成层 三层正交叠加。

> ⚠ **示范句使用规则（三禁一学）**：不整句抄、不近 5 章复用同载体、不改标点；只学「公式＋变量」换情境/载体/感官通道重新生成。
> 落点意象加权判非同源，写入正文前过四道闸门——权威全文见 `core/audience.md#四道闸门`（本节不复述）。

> 取象级示范见 `core/audience.md#★平庸 vs 心动对照范例`；本节补句法/节奏/对话层。

1. **同一受限场景·平写 vs 贴身写**
   平庸：「她够不着高处的罐子，想了想，搬来椅子踩上去。」
   生动：「罐子在第二层。她看了一会儿，把椅子拖过来，先用手按了按椅面——稳的。踩上去的时候她扶着橱柜，另一只手伸过去，指尖碰到罐底，往里推了半寸才扣住。」

2. **短句节奏·匀速 vs 变速**
   匀速（平）：「她跳到门口。她开了门。她出去了。」
   变速（生动）：「门口三步。一，二——第三步她刹住了，手已经按在门把上，比脑子快。」
   （此处的破折号为时间递进的悬停，占本章配额——见下方破折号使用总闸）

3. **对话·信息单功能 vs 双功能（信息+性格）**
   单功能：「"你坐这里方便吗？"他问。"方便。"她说。」
   双功能：「"要不要换到边上那个位子？"他问的是位子，眼睛先看了一眼她的拐。/ "这儿挺好。"她把拐靠好，坐得比谁都利落——回答的是他没问出口的那半句。」

4. **悬停破折号的合法用法（紧张场景，配额内）**
   生硬：「刀划过来。她躲不开。刀刃切在左翼根部。」
   生动：「刀划过来——她躲不开。刀刃切在左翼根部。」（悬置续流：躲不开的瞬间时间还在走，句号会把它定格成陈述）

5. **插入夹注 vs 独立短句（两种时序质感，按贴脸度选）**
   贴脸（动作中分神）：「棠拔剑——她什么时候捡回来的我不知道——砍在它肩膀上。」
   回望（事后追述）：「棠拔剑砍在它肩膀上。她什么时候捡回来的，我不知道。」
   前者视角贴在她身上，后者口气退半步——高张力段落用前者，缓冲段落用后者。

6. **意象生成·反推公式（学方法，不抄句）**
   平庸：「她的拐杖旧了」
   生动：「腋托那块胶被焐得服帖，比新的时候更合她的肩」
   → 公式：**物件的「某处」+ 一个不属于它的动词/属性（先亮/记得/替/不认得）+ 不解释**
   → 变量：物件∈{拐头、袖管、接受腔、残端那圈肉、空椅面}；属性∈{先亮、发凉、记得、替谁、不认得}
   → 换载体再写一遍（示例）：接受腔的边沿先认得她的手，比眼睛快。
   ⚠ **损耗类写法禁用**（磨出光／磨得发乌／磨薄／包浆）——见
   `core/audience.md#★器具损耗与更换禁令`；本条的「旧」只能由**使用痕迹与熟悉度**承载。

7. **留白收束（心动句不得以金句收尾）**
   平庸（升华尾）：「那是她走过的所有路」
   生动（留白）：「她摸了摸手柄那截，把拐换到左手，走了」
   → 公式：**撤掉抒情尾，用一个不解释的动作落地**

## ★写肉不写骨（正文用部位，不用解剖名）

> 解剖定位是**规则内部的防错工具**，不是给读者看的文字。
> 正文一律写**身体部位与肉感**，不写骨骼名。

| 内部定位（**不写进正文**） | 正文写法 |
|---|---|
| 骨盆 / 髂骨 / 耻骨 | 髋侧、胯、那半边、那一侧 |
| 坐骨 / 坐骨结节 | 屁股下面坐得实的那块 |
| 髂嵴 | 腰侧到胯那道棱、裤腰卡住的地方 |
| 臀沟 | 屁股下缘 |
| 骨盆前送 / 随动 / 侧倾 | 那半边身子送出去 / 整边身子跟着动 / 这半边沉下去 |
| 骨盆软组织 | 那儿的肉、屁股和髋侧的肉 |
| 腰椎 / 躯干代偿 | 腰、上身 |

- ❌ 正文出现"骨盆""髂嵴""坐骨结节"属**医学临床化**（回避清单）
- ✅ 写她自己会怎么说、怎么看：**屁股、腰、胯、那半边、那一侧、断口那一圈**
- 例外：角色若是医护/康复从业者，其专业内心独白可破例，但叙述层仍用部位

## ★禁止注释式纠错与注释式解释

> 正文里不得出现"先说一个说法、再否定它、再给正确说法"的写法——
> 那是把**作者的说明**塞进了角色的叙述，一出现就把读者从故事里拽出来。

| 形式 | 反例（❌ 必改） | 正确写法（✅） |
|---|---|---|
| 自我更正 | 「她左腿——不，她没有左腿」 | 「她没有左腿」 |
| 概念否定 | 「不是疼——先是麻，然后是一种很奇怪的灼烧感」 | 「先是麻，然后是一种很奇怪的灼烧感」 |
| 身份注解 | 「像被电了——不是幻肢，她从来没有过幻肢，她生下来就是这样，不知道"两条腿"是什么感觉」 | 「那一侧的肉抽了一下，像过了下电」 |
| **否定式缺失描写** | ❌「战斗裤在左侧裆线处收口，缝线整整齐齐，**没有裤管**」 | ✅「战斗裤在左侧裆线处收口，缝线整整齐齐」 |

**判据**：一句话里出现「A——不 / 不对 / 不是，B」，且 B 才是事实 → **命中，必改**。

**变体家族**（不止「A——不，B」一种——命中判定按总闸频率闸门分档：纠错类变体全禁、对比句 ≤1/章、插入标注/夹注计入配额池；逐处单看像合法修辞，合计即文风污染）：

| 变体 | 反例（❌） | 正确写法（✅） |
|---|---|---|
| 显性纠错 | 「在跑——不对，在跳」 | 「在跳」（直接写对） |
| 对比纠错·破折号式 | 「不是飞——是掉。」 | 「是掉。」（直接写事实） |
| 对比纠错·分句式 | 「不是天界的警报。是哨站的阵在吼。」 | 「哨站的防御阵在吼，尖锐、连续」（对比删掉，信息零损失） |
| 插入标注 | 「我抬腿——右腿——膝盖顶上去」 | 「右腿膝盖顶上去」（语境已定时侧别标注多余） |
| 夹注解释 | 「棠拔剑——她什么时候捡回来的我不知道——砍过去」 | 独立短句：「她什么时候捡回来的，我不知道。」 |

**破折号使用总闸（频率闸门）**：

- **结构性破折号（正文叙述层）≤3 处/章**，且同一功能（悬停/插入/对比/夹注）
  不得连续出现 2 次——密度失控才是病（实测一章 18 处的教训），存在不是病
- **注释式纠错四型维持全禁（出现即改）**：自我更正（她左腿——不，她没有左腿）/
  概念否定/身份注解/否定式缺失描写——那是 LLM 向读者科普身体的真病
- 悬停式合法（紧张场景的利器）：「刀划过来——我躲不开」——破折号是动作的
  悬置续流（时间还在走），句号是完成定格，紧张场景慎用句号替代
- 插入标注与夹注并入配额池（≤3 共享）：贴脸的限知视角写法——
  「棠拔剑——她什么时候捡回来的我不知道——砍过去」是动作中分神，
  独立短句「她什么时候捡回来的，我不知道。」是事后追述——两种时序质感，
  按叙事贴脸度选用，配额内自由
- **「不是X。是Y。」分句式对比句维持 ≤1/章**（只留全章最锐利的单一时刻）
- **同一动作链句式不得原样复用**（日常动作的「重复中的微差」合法且鼓励——
  同一晨间例行每次写法应有微差，那是生活质感）
- 对话内的中断/呼喊/拟声延长不受限（合法白名单）

**根因提示**：这些结构是生成器的**廉价强调捷径**（最低成本制造"锐利感"），
写完一处会自我强化滚雪球——单处看着无害，一页下来满屏「——」「不是…是…」。
判定原则：**逐处单看可能合法，全章合计超限即违规**。

**关于第四种形式（否定式缺失描写）**：

写了「在哪里收口 / 结束」之后，❌ **不再追加「没有 X」**——
**写了收口，就已经说了那里没有**。再补一句是向读者**声明缺失**，等于此地无银三百两。

- ❌ 「在裆线收口，**没有裤管**」「**下面什么都没有**」「患侧**空空的**」「**没有那条腿**」
- ✅ 「裤子在裆线处收口，缝线整整齐齐」——到此为止，读者自己知道
- 判据：句子出现「没有 X / 无 X / 什么都不存在 / 空空的」，且 X 是**缺失的身体部位或衣物**
  → 命中，**删掉那半句**（不是改写，是删）

- ✅ 直接写正确的那一个，读者的理解交给上下文
- 例外：角色在心里纠正自己的口头禅或习惯说法（差点说"两条腿"又咽回去），
  须**一次性、有性格依据**，不得当作交代信息的手段
- 与"不解释不说明"同源：**角色不知道自己在给读者科普自己的身体**

## ★中文质感六技（成文美感总线）

> 六技与取象层（写什么，见 core/audience.md#★平庸 vs 心动对照范例）正交叠加。
> 每章至少命中 2 技，连续 3 章不得只用同一技（防技法疲劳）。
> 判定：删掉该技法后句子仍成立但变"平"，说明技法真在起作用。

1. **炼字**——用精准动词/名词替代形容词+程度副词。
   ❌ 平：「她很快地移到桌边」 → ✅ 炼：「她三两拐就到了桌沿」
   ❌ 平：「很吃力地把身子撑起来」 → ✅ 炼：「她把自己从椅子上支出来」

2. **通感**——把感官换一条通道写。
   ❌ 平：「地上很凉」 → ✅ 通感：「瓷砖的凉从掌心爬上来，比脚先记起路」

3. **白描**——不解释、不评价、不点题；用动作/环境承接情绪。
   ❌ 平：「她很难过，因为想到自己少了一条腿」
   → ✅ 白描：「水开了。她没去关，等它响了一会儿。」

4. **叠词与音韵**——用重复与顿挫造叙述节拍。
   ❌ 平：「她一步一步往前走」 → ✅ 节拍：「拐点一下，停；再一下，停。」

5. **以物写人**——让物承载人，不让人自己说。
   ❌ 平：「她还是在意自己的身体」
   → ✅ 以物：「给她买的那双鞋，一只穿着，一只落着灰」

6. **留白**——不说完，把后半句交给读者。
   ❌ 平：「她不想提这条腿，于是岔开了话题」
   → ✅ 留白：「他问她腿怎么了。她说，没事。水又开了。」

## 语言
- 脏话限特殊痛苦场景（摔倒、受伤、关键受挫），符合自然中文口语习惯
- 不用浮夸的出戏词（穿帮式感叹）
- 语气词自然（嗯、哎、嘶、哈）增可读性

## 声口多样性
- 不同主角应有不同叙事声口，避免所有开篇都是同一种口语化热闹腔
- 声口谱：毒舌冷峭 / 克制寡言 / 絮叨热络 / 沉静内敛 / 跳脱俏皮
- 声口在人物设定阶段确定，全书统一，不中途突变
- 允许偶尔非主角 POV 或外位观察者冷开场，打破"主角自我身体凝视"的固定内视角（见 `core/opening.md`）

## ★声口对照示范（同一情境·五种声口；学口气，不抄句子）

情境：地铁上有人给她让座。

- 毒舌冷峭：「坐。」她说，「别这么看我，我又不是站不住。」
- 克制寡言：「谢谢。」她坐下，把拐横在膝上，再没开口。
- 絮叨热络：「哎哟这敢情好——我这拐一天到晚跟人打架，腿没几条，架子倒大。」（注：此处破折号为声口表现，属对话内白名单，不计正文配额）
- 沉静内敛：她道了谢，坐下，看窗外一站一站地退。
- 跳脱俏皮：「让给我？那我可亏大了——我这半边省下的位置，您坐呗。」

（说明：本节的破折号仅作声口示范，正文引用时按 style.md 破折号总闸执行。）

## ★人物活性（去 AI 化的加法侧）

> 定位：`## 去AI化润色`、`### ★AI 高频句式家族`、`### ★伪活性判定` 全是**减法**；
> 本节补的是**立场**，不是动作。**去AI化 ≠ 去人性化，也 ≠ 去台词**：
> 呆板的根源是角色没有「此刻在为自己争取什么」，于是所有反应都写成可替换的
> 合规动作。⚠ **活性不是「加一个精巧小动作」**——那是最隐蔽的一族 AI 腔
> （判据与反例见 `### ★伪活性判定`）。
> 权威配套：`core/character-setup.md#★性格生成轴`（欲望/软肋/处置风格）、
> `core/audience.md` 的「★目光的分层」段、本节上方的「★声口对照示范」。

- **每章至少 1 处可验证的立场**（下列六项命中任一即可，不必凑齐）：
  ① **遮住名字测试**：盖住对话标签，仍认得出是谁在说——靠**句法节奏 / 用词 /
     回避方式**；❌ 不靠口头禅、俚语或固定腔（与 `## 声口多样性` 一致）；
  ② **台词在干活**：她这一句是在**得到什么 / 藏什么 / 改变两人的平衡**；
     允许答非所问、回避、说半句咽回去、反话、沉默，但不给这些动作写注解；
  ③ **立场可答**：每个给了镜头的人，此刻在为自己争取什么？答不出＝工具人；
  ④ **有代价的选择**：让她做**最违背自我形象**的那个决定，并在后文承担后果
     （不是当场圆回来，也不是让旁白替她解释）；
  ⑤ **矛盾落在行为里**：台词与动作互相顶撞即可，**动作不替台词作注解**；
  ⑥ **不替读者揭晓**：潜台词最上一层交给读者；❌ 不写「她记着」「这说明」
     「原来她是……」「这意味着」以及括号里的技法自评。
- **改写顺序（删除优先）**：先问「删掉这句，丢不丢伏笔 / 钩子 / 立场 / 后果」——
  不丢就**直接删**；要留信息，就**沿用本章已有的台词、选择、物件或后果**；
  ❌ **不另加动作**，❌ **不把套路微动作换成另一套精巧微动作**
  （替换产物反复出现，本身就成为新的模板指纹）。
- **允许直写情绪**：上下文已让情绪成立时，保留准确的直写或删掉重复说明；
  ❌ 不设「情绪词 → 身体动作」的默认转换，不为情绪词另配动作。
  口误、停顿、粗话、失误须服务人物身份与当下处境，
  ❌ 不作为「真人感」装饰批量添加。
- **本题材边界**：起身链、辅具操作、受限处置、身体细节是**必要情节动作**，
  不受「不另加动作」限制；处置风格落在动作链的效率 / 失误 / 代偿上
  （见 `core/character-setup.md#★性格生成轴`），❌ 不写成注解式小动作。
- **本节不提供示范句**：只给可自查的判据。正面范例引用既有
  `## ★声口对照示范`（引用位，不新增示范）；❌ 不得把本节判据抄成新示例句，
  也不进 `core/audience.md` 的「示范节清单」八处，❌ 不得作为心动句取象源。
- **与压缩恢复的衔接**：人物活性锚（声口 / 核心欲望 / 软肋 / 处置风格）在账本

## 去AI化润色
- 去总结套话：删"总而言之""综上所述""不得不说""或许这就是……"等收束语
- 去升华拔高：结尾不上升到人生感悟/励志金句/主题宣言
- 去排比堆砌：三连排比以上拆散，保留自然语气
- 去过度规整：段落长短错落，不每段都齐整三句
- 去书面腔：能口语的不书面（"于是"→"就"，"然而"→"可"），但不过度到失真
- **去账目隐喻格言**：❌ 禁「这是他的账，让他自己平」「这是你的账，你自己平」
  「自己的账自己平/算/还」类**句式家族及其衍生（❌ 一并全禁）**——把情感/责任/关系/身体压缩成
  「账目/债务」隐喻的格言式收束。三重禁因：①AI 高频套路（冷峻格言腔，看似深沉
  实为套话，与「去总结套话」「勿坍塌歧义」同族）；②**本题材特有危害**——把她的
  身体/受限写成「一笔要摆平的债」，暗合补偿叙事与苦难叙事（残缺≠亏欠，没有「平」
  的义务，见 `core/audience.md` 回避清单）；③格言收束替角色下了判断，替读者做了总结
- 程度把控：只去明显AI味，不强行改写自然句子，保留作者语感

### 去AI化·改写对照（每条给反例→正例；写完自查落在"正例侧"）

- 去总结套话：❌「总而言之，她还是学会了和这条腿相处」→ ✅ 删，或改具体动作：「她把拐靠在门边，顺手正了正歪掉的那道贴纸」
  （⚠ 正例不得用「新拐杖」——「换/配新的」是 `core/audience.md#★器具损耗与更换禁令` ②类触发句；贴纸属非损耗个人痕迹，合法）
- 去升华拔高：❌「或许生活就是这样——失去一些，也得到一些」→ ✅ 停在画面：「窗外路灯亮了，收口处的软肉轻轻一抽」
- 去排比堆砌：❌「拐是她的腿，是她的伴，是她与世界之间唯一的桥」→ ✅ 只留最实的一句：「拐是她的腿」
- 去过度规整：判别口径——**连续 3 段以上句长（字数）大致相等即命中**；❌ 三段皆 15–18 字 → ✅ 拆出 6 字短句夹在两段长句间
- 去书面腔：❌「于是她决定前往厨房」→ ✅「她就去了厨房」
- 去账目隐喻格言：❌「这是他的账，让他自己平。」→ ✅ 停在她的具体反应：「他把话说完就走。她把那张纸对折，塞进了抽屉最里头。」
- 去账目隐喻格言（第二人称变体）：❌「这是你的账，你自己平。」→ ✅「这话她没接。锅里的水开了，她先去关火。」
  （**合法边界**：末世/生存题材的**真实物资账目情节**不在此列——「这本账记的是全队的口粮」
  是记账场景非格言收束；禁的是人格/关系/责任/身体的账目隐喻，不是记账本身）
- 程度把控（保留）：不改自然句；改写仅针对**能指认的 AI 腔标记**（套话词、升华尾、等长段落、并列同型句、账目格言收束）

### ★AI 高频句式家族（去 AI 化的反面清单）

> 定位：与上方「去总结套话 / 去升华拔高 / 去账目隐喻格言」同族，补齐**未被点名的其他 AI 高频收束腔**。
> 统一判据：**这句是否在替角色下判断、替读者做总结**；是 → 删，或改成具体的人、物、缘由。
> ⚠ **合法边界优先**：禁的是格言式收束，不是禁这些词本身。带具体缘由的人物判断、真实对话、
> `#章节结尾` 允许的情绪留白（「说不清是松了口气还是空了一块」）与动作停顿一律不受影响。

1. **泛化顿悟／忽然懂了**（❌ 禁作收束）——反例：「她忽然懂了」「那一刻，她明白了」「她第一次意识到……」。
   与章节结尾禁句式「她终于明白……」同族，但更隐蔽（可落在段中）。
   ❌「那一刻，她忽然懂了，有些路只能一个人走。」→ ✅ **直接删**；若该处确需留下一步，沿用本章已写过的安排，❌ 不另造画面。
   合法：带具体触发物的想起（「她这才想起他把伞落在门边了」）是记忆，不是顿悟金句。
2. **时间·命运金句**（❌ 禁作收束）——反例：「时间会给出答案」「岁月终会……」「命运关上一扇门」「有些答案，要交给时间」。
   ❌「时间会给出答案的。」→ ✅ **直接删**；需要下一步就写本章已有的那个安排，❌ 不另造「意味深长」的小动作。
3. **定义式反转**（❌ 禁作收束）——反例：「不是 X，而是 Y」「不是……不是……而是……」用于**章末/段末给定性结论**。
   ❌「这不是妥协，是她给自己留的余地。」→ ✅ 删定性，或把已有台词 / 选择照写；❌ 不补「其实她是……」的解释。
   合法：人物内心带具体缘由的自问不受限；与 `templates/chapter.md` S42「不是X。是Y。」分句式配额**并行**（S42 管句式数量，本节管格言定性）。
4. **得失对仗宣言**（❌ 禁作收束）——反例：「失去的是……，长出的是……」「命运拿走了……却给了……」。
   本题材高危：把身体/受限写成换取品格的筹码，暗合补偿叙事（见 `core/audience.md` 回避清单）。
   ❌「命运拿走了她一条腿，却给了她更硬的骨头。」→ ✅ **整句删**；本题材尤其不要补「更硬的骨头」式补偿叙事，❌ 也不换成另一句身体小动作。
   合法：具体的实物得失陈述（少了半袋米、多走两公里）不在此列。
5. **空泛并列感悟**（❌ 禁作收束）——反例：「有些……有些……」「有些事，不必说破」「说不出口的，都交给……」。
   ❌「有些疼说不出口，有些路只能一个人走。」→ ✅ **直接删**；❌ 不换成另一组「具象但有深意」的物件动作。
6. **万能沉默占位**（❌ 禁作收束）——反例：「她没有说话，只是……」「她什么也没说，只是……」「沉默了很久，然后……」
   与「勿橡皮图章手势」同因：用空句式代替人物反应，是**人物呆板**的直接来源（见 `## ★人物活性`）。
   ❌「她没有说话，只是望向窗外。」→ ✅ 删「只是……」后的空转；若确为沉默就停在沉默，或写她此刻真会说出口的那句话，❌ 不加「她记着 / 她明白」的点破。
   合法：既有留白正例「他问她腿怎么了。她说，没事。水又开了。」不受影响——它有对答与物件。

> ⚠ **本节的修法以「删除优先」为准，不提供可复用的 ✅ 示范句**——
> 把删掉的套话换成另一句同样精巧的具体动作，替换产物反复出现本身就会成为
> 新的模板指纹（见 `### ★伪活性判定`）。六族字面量只进 `scripts/selfcheck.py`
> DEAD 词表的人工确认档；❌ 不进 `core/audience.md` 的「示范节清单」八处、
> 不得作为心动句取象源（R-018 非同源比对仍只按八处）。

### ★伪活性判定（最隐蔽的一族）

> 定位：六族管「格言 / 升华」，本族管**改写产物**——删掉套话后补一个
> 「看起来很具体、很有内心」的小动作，再配一句注解或括号自评。
> 这类句子**能通过所有去AI化检查**，却依然一眼 AI：它是为「显得有内心」而新造的，
> 与情节无因果，换个角色照样成立。判据：
> ① 改写应**沿用原文已有的选择、台词、物件或后果，不另加动作**；
> ② **不用同义形容词或另一套微动作轮换**——替换产物反复出现，本身成为新模板指纹；
> ③ 「The nod is enough. **Cut the gloss.**」：动作之后不解释，
>    ❌「她记着」「他其实……」「这说明」都是替读者拼因果；
> ④ 写法抽查：**用手部 / 喉部微动作代替立场**、**把算计写成一段旁白独白**＝不合格；
> ⑤ 口误、停顿、粗话、失误不作「真人感」装饰批量添加。

- ❌ **用户点名反例（不得作为正向示例）**：
  反例原句：「她把拐靠在门边，顺手把门垫踢正。他上次来踩歪过，她记着。」（记性＋小算计＋对人的态度）
  三重 AI 腔：① 在合规动作后**追加**动作层（不另加动作）；
  ② ❌「她记着」**点破**读者本可自己拼出的因果（cut the gloss）；
  ③ ❌ 括号「（记性＋小算计＋对人的态度）」是**替读者定性 / 技法自评**，属作者在场
  （去解释腔）。整句仍没有一个立场、一句台词、一个后果。
- ❌ **同族高发变体**（一律按删除优先处理）：「顺手……」「没撑，夹在……带走了」
  「把杯子挪到他够不着的那边」「把最短的那根挑出来先用了」「她没接，只是……」
  「（记性 / 小算计 / 态度 / 留白 / 克制）」类括号自评。
- **修法（严格按顺序，不得跳步）**：
  1. **先删**：删掉追加动作层与注解，看情节是否仍成立（多数情况成立）；
  2. **要留信息**：沿用本章**已有**的台词 / 选择 / 物件 / 后果，不新造动作；
  3. **要补活性**：按 `## ★人物活性` 的判据补**立场**（她此刻在争取什么、
     说了什么、要付什么代价），❌ 不是补一个小动作；
  4. **收尾自检**：删掉这句，读者会不会少一个立场或后果？不会 → 它本就不该写。
- ⚠ **库内既有 ✅ 正例的适用边界**：`### 去AI化·改写对照` 与 6.2.1 账目族的 ✅ 句
  （如「顺手正了正歪掉的那道贴纸」「她把那张纸对折，塞进了抽屉最里头」）
  只作「删掉套话后停在动作」的**方向示意**，❌ 不得当作人物活性模板复用；
  其中「顺手……」式与本族反例同构，写作时按删除优先处理。
  （贴纸一句另承担 `core/audience.md` 器具损耗禁令的合法边界说明，故保留不删。）
- **合法边界**：起身链 / 辅具操作 / 受限处置 / 有物理后果的动作是**必要情节动作**，
  「动作失败」「代价」「旁人反应」可写；判据是**它改变了后续情节，
  还是只用来显得有内心**。

### LLM 失败模式（深化）
- **勿过早解决张力**：冲突/不便/情绪不在同场景解决，让张力跨章持续。截肢者日常的不便/错位感天然适合跨章低张力持续。例：第3章的争执不必第3章和解，可延后（但须落入某章 payoff，不得永不兑现——结构层权威见 `core/structure.md`）
- **勿添加情感评论**：事件后写角色即时具体反应即可，不加"重量感X像Y"的隐喻解释和"这意味着Z"的编辑评论（与"章节结尾不升华"合并）
- **勿坍塌歧义**：动机/道德的含糊不要硬扭向一边，保留多解释。叙事拒绝对角色下判断几乎总比下了强
- **勿过度强化语言**：强情感用克制，一个强意象胜过三个 adequate；真人激烈时刻反而 understated
- **勿整洁总结结尾**：场景/章节不在结尾段总结情感意义（与"章节结尾不升华"合并）
- **勿橡皮图章手势**：勿用攥拳/倒吸凉气/移开目光/咬唇/咬牙等套路手势表情绪，找具体动作（正面示范见 `core/audience.md#★平庸 vs 心动对照范例`——「他看过来。她没抬眼，握柄的力度无声重了一档，又松开」即此条答案：把用力落在与物件的具体接触上）（此处为标准答案引用，非新增示范；全库「同一示范只立一处」的豁免情形＝引用位）

## 章节结尾
- **不升华**：结尾停在动作/画面/情绪/悬念上，不拔高到感悟金句
- 禁止结尾句式："也许这就是……""或许生活就是……""她终于明白……""原来XXX才是XXX""这是X的账，让X自己平"（账目隐喻格言，见去AI化节）；
  ❌ 禁止：「她忽然懂了」「那一刻，她明白了」「时间会给出答案」「命运关上一扇门」「有些路只能一个人走」「她没有说话，只是……」
  （六族全表与合法边界见 `## ★AI 高频句式家族`；❌ 注解式点破「她记着」「这说明」与括号技法自评
  见 `### ★伪活性判定`；⚠ 情绪留白「说不清是松了口气还是空了一块」仍合法）
  ❌ 禁止收束：氛围结论词「空气仿佛凝固了」「时间仿佛静止」「静得能听见心跳」
  ❌「五味杂陈」「说不清道不明的情绪」「仿佛整个世界都安静了」，以及场景总结尾／情绪解释尾；
  全表与删除优先修法见 `core/prose-craft.md#四、写作氛围`，❌ 不换成另一句精巧具象句
- 允许结尾类型：
  - 动作停顿（她把拐杖靠在门边，没再动）
  - 画面定格（膝上/膝下示例：窗外路灯亮了，残肢在裤管里轻轻一颤；
    髋离断示例：窗外路灯亮了，收口处的软肉轻轻一抽）
  - 情绪留白（说不清是松了口气还是空了一块）
  - 悬念未完（手机又响了。她没看）
  - 日常收束（洗完碗，她把明天要带的伞搁到了门边）
    （⚠ 不得写「想着明天该去配把新拐杖了」——「配新的」命中 `core/audience.md#★器具损耗与更换禁令` ②类，命中即改）
- 收尾质感贴合基调，但即便压抑沉重基调也不以金句升华收尾
结尾自查（写完最后一段问）：删掉这句，读者会不会"松/空/悬"？不会 → 多半是升华尾，改。
