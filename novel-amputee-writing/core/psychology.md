# 心理模式库（M1–M31 · 截肢者/devotee/wannabe 心理素材）

> 本库是"有哪些心理模式"的**素材 catalog**，按 M 编号被全库引用（亲密/SM/wannabe/人物设定）。
> **呈现技法不在本库**：怎么把心理写出来见 `core/emotion.md`（情感三层：在乎/压着/漏出）与
> `core/emotion-signal.md`（语言>身体>面部三层信号、签名动作）。
> **圆融（最高艺术标准）**：心理藏在行为里——通过动作/神态/感官带出，与身体描写揉成一体
> （她羞耻时身体如何反应、残肢如何随情绪动）；❌ "先一段心理旁白再一段身体"的割裂；
> 内心独白只偶尔出现且须有行为锚点（见 `core/style.md` ★AI 高频句式家族）。
> **红线（全书有效）**：成年（性内容角色全 ≥18）＋恢复期（术后伤口未愈禁性爱/束缚/疼痛，gatecheck [15]）；
> **截肢设定不可改变**（生理红线：不得因伤顺便多截、因治疗长回；自愿截肢是 wannabe 剧情事件，见 `topics/wannabe.md`）；
> 敏感型/黑暗取向须**人物卡授权**；A 侧即使被支配也**保留主体性**（喊得出停/有选择/事后有护理）；
> 非自愿/圈养/施虐题材**叙事不替施暴辩护，判断留给读者**（`topics/intimacy-explicit.md#十四、同意与边界`）；
> 措辞守写肉不写骨；结尾停在动作/话/画面，❌ 升华尾。
> **黑暗题材为合法内容**（物化沉迷/圈养/疼痛快感/非自愿/失禁依赖/创伤），按专项文件写，不作回避（`rules/hard-layer.md#二`）。
>
> **分组导航**：A 侧（截肢者）M1·M2·M4–M7·M12–M14·M16·M17·M19·M20·M26·M27·M31｜
> 黑暗/被支配 M3·M15·M18·M21·M24·M28·M29·M30｜D 侧（devotee）M8·M9·M25｜W 侧（wannabe）M10·M11｜特殊/幻想 M22·M23。

## M1 羞耻→习惯→骄傲→享受（经典弧线）
- 机制/弧线：怕被看到（藏残肢/长裙）→ 日常化（习惯被注视）→ 主动展示 → 享受被关注。
- 行为方向：前期回避人群、后期去人多处脱敏；从遮掩到主动撩裙摆；初期不出门 → 多年后当众穿假肢出街。
- 触发：每次出门 / 被问"你腿怎么了" / 照镜。

## M2 矛盾（讨厌残肢又要暴露取悦）
- 机制：既厌恶残缺、又忍不住用它换关注/钱/爱。
- 行为方向：展示后立刻后悔；拍完删了又拍；嘴上骂手里配合姿势。
- 触发：接单前 / 镜头前 / 被夸"好美"时。

## M3 物化沉迷与堕落（逐渐上瘾）
- 机制：自我物化 → 被支配的爽感 → 主动索求更多；残缺程度与价值挂钩的错误信念。
- 行为方向：主动要求更羞耻的展示；享受被摆布；把身体交对方管理；人偶化（M30/F23）。
- 触发：高潮后空虚 → 再次索取 / 被完全掌控的瞬间。
- ⚠ 截肢竞赛/接连主动截肢属 wannabe 黑暗弧线，须按 `topics/wannabe.md` 与人物卡；❌ 不得把"受伤顺便多截"当生理事实（截肢设定不可改变）；A 侧保留主体性。

## M4 被观看的兴奋（展演欲）
- 机制：观众的目光＝认可；羞耻与兴奋同源。
- 行为方向：知道有人在看时动作反而放慢；镜头前状态最好；被偷拍既愤怒又隐秘高兴。
- 触发：公共场所 / 直播间 / 试衣间 / 被围观。

## M5 残肢性器官化
- 机制：残肢敏感化 → 触摸/舔舐/揉捏成为性唤起来源。
- 行为方向：抚摸残肢自慰；要求对方亲吻残肢内侧；残肢夹紧/磨蹭；残肢当敏感带。
- 触发：被触碰瞬间 / 性爱中 / 独处自摸。
- ⚠ 敏感型须人物卡授权（`topics/intimacy-explicit.md#5.3`）；措辞写肉不写骨，不堆神经瘤/断骨解剖名。

## M6 幻肢痛心理（身体记忆）
- 机制：感觉腿还在（痒/疼/想动），指令下达却无回应——身心错位的钝痛。
- 行为方向：深夜蜷缩；下意识去挠不存在的脚踝；梦中还能跑。
- 触发：深夜 / 天气变化 / 看到别人走路 / 高跟鞋声。（幻肢痛合法，按档位；与 M26 互补）

## M7 高潮后空虚羞耻迷茫
- 机制：激烈性爱/展示后，看着空荡荡的下体涌起空虚、羞耻、迷茫。
- 行为方向：完事后发呆；用被子盖住残肢；沉默；眼泪无声。
- 触发：每次高潮后 / 收钱后 / 独处时。（落在动作，❌ 升华）

## M8 隐秘身份心理（D/W 侧）
- 机制：身份觉醒 → 成年后网络搜寻/混论坛 → 现实中伪装正常人；D 藏身份（怕被当变态）、残方藏残缺（怕吓到对方），双向隐瞒是张力源。
- 行为方向：加密图库；逛论坛被熟人撞见的心虚；对相关话题假装不关心；不敢在伴侣面前脱假肢；身份暴露危机。
- 触发：深夜独处 / 网上冲浪 / 现实偶遇 / 被识破瞬间。
- ⚠ 性内容角色全 ≥18（成年硬闸）；身份觉醒可作前史，性/网络内容须成年后。

## M9 看残即兴奋与占有宠爱（D 侧）
- 机制：看到截肢者＝兴奋＋保护欲＋占有欲并存；D 用"养她一辈子/科学兴趣"自我合理化。
- 行为方向：目光反复落在残肢、克制地移开又移回；主动承包护理（以此名正言顺地触碰）；对他人看她的目光不悦；被骂"变态"后自我怀疑。
- 触发：第一次见面 / 她摔倒 / 她被人议论 / 她展示残肢。（与 M25 互补）

## M10 表演快感与边界（扮残者，W 侧）
- 机制：扮残的快感（想象"我就是她们"）→ 真实感执念 → 边界（"只扮不想真截"）。
- 行为方向：调整拐杖孔位；家里练习被撞见的惊险；日记连载扮残日常。
- 触发：穿戴道具 / 独自练习 / 被识破。（见 `topics/wannabe.md`）

## M11 扮残→真截的递进（W 侧）
- 机制：先扮残 → 渴望真实 → 找医生真截（可两代传承），把截肢当人生规划；BIID 极端自主（痛恨健康腿、认定是多余附着物、截后不悔）。
- 行为方向：攒钱 / 打听医生 / 画线 / 签同意书时手抖 / 术后看着真残肢笑。
- 触发：见到真截肢者的冲击 / 被伴侣暗示 / 家族审美教育。
- ⚠ 自愿截肢属 wannabe 黑暗弧线，须按 `topics/wannabe.md` 与人物卡；手术过程/伤口为合法题材按恢复期写；❌ 不得写成"受伤顺便截"（截肢设定不可改变）。

## M12 性焦虑与感官重定位
- 机制：无感区失联 → 探索新的性感带（脖颈/耳后/残存感知带）→ 重新学习性。
- 行为方向：测试皮肤各区域反应；引导伴侣触碰新敏感区；哭诉与试验交替。
- 触发：亲密尝试 / 被触碰无感区无反应 / 康复训练。

## M13 失禁羞耻与依赖
- 机制：括约肌失控/如厕需全程代劳 → 羞耻 → 被迫接受 → 依赖中的安心；失禁/护理依赖加深绑定。
- 行为方向：把尿时躲闪眼神 → 逐渐坦然；失禁瞬间的崩溃 → 被清理时安静；用撒娇化解尴尬。
- 触发：如厕 / 失禁 / 被清理。（失禁/排泄/护理依赖合法 M13/F7；黑暗模式被支配快感见 SM B6；不作猎奇回避）

## M14 拒绝同情自证价值
- 机制："残而不废"信仰；同情＝侮辱；用能力证明自己。
- 行为方向：拒绝让座 / 坚持自理 / 超额完成工作 / 对"真可怜"皱眉 / 把歧视化为倔强。
- 触发：被让座 / 被扶 / 被问"需不需要帮助" / 面试。（主体性正写，与 M31 互补）

## M15 被救赎与被改造（双向）
- 机制：被拯救（接受残缺）或救赎对方（接受自己）；反面：被改造（渐进截肢/感官剥夺）逐步丧失自我，"最后一次手术"承诺被不断打破。
- 行为方向：感恩式依赖 vs 警惕；从抗拒手术到签字；眼神从戒备到空白。
- 触发：手术室 / 深夜长谈 / 被提出"改造建议"。
- ⚠ 被改造黑暗弧线须人物卡授权，叙事不替施暴辩护；渐进截肢是剧情事件（每次须有事件），❌ 不得违背截肢设定不可改变。

## M16 创伤闪回（事故/绑架/虐待史）
- 机制：事故/绑架/虐待的闪回；创伤后应激（特定声音/气味/光线触发）。
- 行为方向：听到特定声音发抖；对胶带味干呕；夜里惊醒；对陌生人过度戒备。
- 触发：就医 / 黑暗 / 束缚感 / 特定气味。（创伤/苦难合法，按场景写）

## M17 同类共同体认同
- 机制：同类相聚的安全感与归属（"只有你们懂"）；比较与共谋。
- 行为方向：病友会活跃；介绍医生/康复资源；自嘲式黑话；为同类出头。
- 触发：病友聚会 / 康复中心 / 论坛。

## M18 被圈养的金丝雀心态
- 机制：被养/被保护到失去自理意志 → "反正什么都做不了，不如安心被养" → 以娇气与依赖为安全壳。
- 行为方向：事事呼唤；对自由既向往又恐惧；用撒娇化解一切冲突；偷偷羡慕独立者。
- 触发：被拒绝要求时 / 看到别人自理时 / 深夜窗边。（圈养黑暗题材合法，与 M29/B7 互补；A 侧保留主体性）

## M19 身份焦虑（豪门/圈层）
- 机制：上流社会身份 vs 残缺身体的落差；怕被圈子淘汰；把残缺经营成资本或耻辱。
- 行为方向：精心维持体面（定制礼服/看护团/公关话术）；对议论敏感；宴会上强撑气场；被当众揭短。
- 触发：宴会入场 / 媒体拍摄 / 婚约谈判 / 被熟人撞见狼狈时刻。

## M20 求认可焦虑（被爱怀疑）
- 机制：反复确认"你是喜欢我还是喜欢我的残缺"；怕被嫌弃、怕连累。
- 行为方向：隐瞒 → 勇敢见面；试探性提问；穿假肢"还能稍微保留一点尊严"。
- 触发：确定关系前 / 被夸"好美"后 / 见家长前。（devotee 疑虑暗线，见 `topics/intimacy.md#十一`）

## M21 斯德哥尔摩/爱恨交织
- 机制：绑匪-人质关系中生出爱；"如果他没有犯罪就是完美男人"的幻想。
- 行为方向：爱恨绑匪；也曾幻想他的爱；被侵犯时沉默反抗。
- 触发：被囚禁期间 / 施虐后的温柔时刻。
- ⚠ 非自愿/圈养黑暗题材合法，须人物卡授权；叙事不替施暴辩护、判断留给读者；按伤害与心理写（`topics/intimacy-explicit.md#14.4`）。

## M22 变性/性别认同互证
- 机制：残缺与性别认同互证；用截肢证明变性决心（人物信念，非叙事背书）。
- 行为方向：用肢体交换成为女性；审美反转。
- 触发：身份觉醒 / 手术前夜。
- ⚠ 身份认同特殊/黑暗题材，须人物卡授权；❌ 不得写成"截肢治愈性别焦虑"的升华；截肢设定不可改变；叙事不替自伤背书。

## M23 永生/虚无（幻想向专属）
- 机制：残躯与时间的关系（永生者的残躯）；看淡生死的虚无感。
- 行为方向：长寿设定下看淡生死；慕残自我认同。
- 触发：长寿设定 / 时间跳跃 / 历史回望。（幻想向专属，见 `genre/fantasy.md`；现实向零超自然）

## M24 W 心理曲线（羞耻过载→麻木→病态安全→主动迎合）
- 机制：厌恶自己的身体 → 反复尝试又失败后的麻木 → 完全无助中反而获得病态安全 → 主动迎合；四段可整体成弧线，也可单段取材。
- 行为方向：早期挣扎自理反复失败 → 放弃抵抗；被照顾时从躲闪到坦然；主动要求更羞耻的展示；从被动接受转向主动展示取悦。
- 触发：每一次自理失败 / 被照顾的瞬间 / 被要求展示时。（W 侧/黑暗弧线，与 M3/M29/M30 互补；A 侧保留主体性，须人物卡授权）

## M25 D 双轨心理（怜惜+占有+施虐三合一）
- 机制：看到截肢者的兴奋＝怜惜＋占有欲＋施虐欲的混合快感；三者同时在场缺一不完整；"越无助越性感"。
- 行为方向：怜惜（轻吻残肢/翻身习惯）与施虐（喜欢看她挣扎绝望）并存；用"养她一辈子/科学兴趣/医者父母心"自我合理化；把她的能力当可调节的支配参数。
- 触发：第一次见面 / 她摔倒 / 她挣扎 / 她展示残肢。
- ⚠ D 侧黑暗心理，操控/支配须按 SM 与圈养工艺及人物卡，叙事不替施暴辩护；❌ 不得把"调功率让她站不起来"写成生理事实改变（截肢设定不可改变，辅具调节按器具口径）。

## M26 幻肢心理库（身心错位全谱系）
- 机制：神经记忆仍在（痒/疼/想动）而肢体已无——身心错位的钝痛，神经比身体更长情。
- 素材方向：矛盾修辞（那么疼那么真怎么可能不在）；命令失灵（命令蜷脚趾无回应）；习惯性蹬腿落空；抓空（无臂认知锚点）；幻肢新形态（不存在脚趾的蜷缩用力感）；鹅卵石触感；醉后幻觉；每次都以为还能下床。
- 对策与演变：捶腿/揉腿用真实痛压幻痛；吻残肢消幻痛；自我惩罚（黑暗，须人物卡）。
- 触发：深夜 / 天气变化 / 高跟鞋声 / 看到别人走路 / 下楼梯以为还有一级（认知摔倒）/ 摸到空荡荡的床单。
- ⚠ 幻肢痛合法按档位（与 M6 互补）；措辞写肉不写骨；吻残肢消幻痛 ❌ 不得写成"治愈截肢"（生理红线）。

## M27 "身体变小世界变大"残缺哲学
- 机制：残躯占用空间变小，世界的参照物变大；以残者视角重新测量房间高度/门槛/楼梯，日常物件被放大成山；轮椅是固定观察点，世界从低处流过。
- 行为方向：用视线代替脚步丈量距离；对"够不到"的高处反复试探；从地面视角看人；对"这么小的一件事我都做不到"产生仪式感。
- 触发：搬家 / 逛商场 / 进新环境 / 康复期第一次坐轮椅。（环境只放大难度、不构成受限来源，见 `core/worldbuilding.md`）

## M28 疼痛上瘾
- 机制：残肢/幻肢痛的疼与快感同源；疼痛成为存在感与性唤起的来源；从畏惧疼痛到索取疼痛。
- 行为方向：按摩残肢到发红发紫（用真实痛压幻痛变成享受）；要求对方加重触碰。
- 触发：疼痛发作 / 被粗暴对待 / 残肢被触碰时。
- ⚠ 疼痛＝快感合法黑暗题材（M28/B5），须人物卡授权；自残/自截换取高潮属 wannabe/极端黑暗弧线，须按 `topics/wannabe.md` 与人物卡，❌ 不得违背截肢设定不可改变与恢复期红线；SM 疼痛边界见 B5（不真伤）；措辞写肉不写骨。

## M29 被完全掌控的无助感心理
- 机制：完全无助＝极端舒爽与迷醉；被完全掌控时卸下决定权与逞强；"合理"的无助感；"愿意"和"没得选"有时候是一样的——认命即安心。

- 触发：被抱起 / 被固定 / 失禁被清理 / 被喂食 / 被要求配合姿势。（黑暗被支配心理，与 M3/M18/M24/M30/B7 互补；A 侧保留主体性，须人物卡授权）

## M30 人偶化心理（"被当人偶摆弄反而安心"）
- 机制：被当物/玩偶对待时反而安心——人偶无自理义务、无羞耻负担、只需被摆布；从"我是人"到"我当人偶更轻松"的自我降格；卸下期待与责任。
- 行为方向：接受产品说明书式描述；被固定/被穿戴/被收纳无反抗；用"被摆弄"替代"被照顾"；把身体完全交给对方管理。
- 触发：被穿戴束具 / 被拍照编号 / 被摆放姿势 / 被提起转移。（黑暗物化心理，与 M3/F23/B2/B7 互补；A 侧保留主体性，须人物卡授权；叙事不替施暴辩护）

## M31 身份认同（A 身份宣言）
- 机制：残缺只是身体属性而非身份全部——先是人，再是坐轮椅的人；把"残而不废"内化为价值感；用能力/关系证明"我还值得被爱"。
- 行为方向：拒绝同情自证价值；在关系中坚持"我不只是残疾人"；用能力对冲自卑；反向经营（"你摸的时候，我觉着自己好看"）。
- 触发：被问"你腿怎么了" / 被让座 / 被同情 / 被表白 / 照镜。（主体性正写，与 M14 互补；把截肢当唯一标签是回避清单禁区——她先是人）
