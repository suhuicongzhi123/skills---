# 场景驱动器（v9.4 新增 · 动笔前必读）

> **这一层解决什么**：机检全绿、自查全过、段落长度达标、动作密度达标，
> 读起来依然是一份**清单**——事情一件接一件发生，但没有一场是戏。
>
> 前几层管的是「**不许怎样**」（不许碎片、不许流水、不许抒情、不许点破）。
> 这一层管的是「**必须发生什么**」。少了这一层，前几层的约束加得越多，
> 稿子越像一份通过了体检的说明书。

---

## 〇、先看清楚：为什么规则越加越机械

这不是猜测，是三个可验证的机制。改稿前先认这三条，否则会继续在错的地方使劲。

### 机制一：否定式约束的省力策略是「删减」

一条规则说「不要流水账」，模型最省力的满足方式不是「制造冲突」，是**把可疑的部分删掉**。

删除永远比创造省力。于是：
- 怕抒情 → 一句内心都不写 → 人物变成动作机器
- 怕啰嗦 → 每句都砍到最短 → 全篇一个语速
- 怕假 → 什么冲突都不敢写 → 所有事顺利完成

**一堆「不要」加起来，等于「什么都不要」。** 这是最隐蔽的失效：每条规则都被遵守了。

### 机制二：可测指标会替代目标

段落长度、碎片化率、动作密度、句长方差——这些是**形状**，不是**内容**。

形状可以刷。实测样本（2800 字，日常章）：

| 指标 | 规则要求 | 实测 | 结果 |
|---|---|---|---|
| 叙述段 ≥80 字 | ≥3 段 | **7 段** | 达标 |
| 平均叙述段长 | — | **48.6 字** | 正常 |
| 以主角开头的句子占比 | — | **12.6%** | 正常 |
| 机检结论 | — | **PASS** | 全绿 |

全绿的那一章里，主角没有为任何东西使过一次劲。**她跟着人走、看着人查、数了两遍钱、照着原样抄了一遍表。**

三个动作合成一句，就能满足「段落够长」；把心理句删掉，就能满足「不要抒情」。
**形状指标全部可以靠合并与删除刷满，而内容依然是一份日程。**

> 所以：**凡是能靠删减满足的指标，都不足以保证好看。**
> 这一层要补的是"生成侧"的强制项——不是"不许短"，是"必须有戏"。

### 机制三：约束只删不加，最后没有事件

一份稿子写完，如果只问「有没有违规」，那它一定合格——因为违规的部分已经被删了。
没人问「有没有发生事」，于是删完剩下的，全是安全但空的东西。

**结论**：本层的每一条都是**正向强制**（必须有什么），不是禁止。

## 一、做事 ≠ 动手（第一个分界）

这是本层最重要的一条。混了这两个词，就会把搬东西当成戏。

| | **做事** | **动手** |
|---|---|---|
| 性质 | 流程 | 博弈 |
| 结果 | 必然完成 | 可能失败 |
| 有没有对手 | 没有 | 有（人、条件、时限、自己的身体） |
| 失败会怎样 | 不会怎样，重做一遍 | 丢掉某样东西 |
| 读者的反应 | 知道她在忙 | 想知道成不成 |
| 例 | 搬椅子、拖地、理货、开门、装饭 | 讨价、瞒住一件事、赶在某人之前、留下一个人 |

**一句话判据**：

> **这件事失败了会怎样？**
> 答「不会怎样，顶多重来」——它是**做事**。
> 答「会丢掉某个具体的东西」——它是**动手**。

**一场戏至少要一次「动手」。** 一章里可以有很多「做事」，但它们只能当背景、当节奏、当身体质感的载体，**不能当戏**。

> ⚠ 这是最容易自欺的一处：把「做事」写得又细又准，读者会觉得真实，
> 作者也会觉得「我写得很扎实」。扎实不等于有戏。
> **一个动作写得再准，只要它不可能失败，它就不产生张力。**

## 二、三个硬条件（缺一条就不算戏）

一场戏要成立，三条全要。少一条，这一场就是过场。

### 条件一：她做了一件**可能失败**的事

不是「她想」「她看」「她等」。是**做**，而且存在失败的可能。

- ❌ 她跟着经理走了一圈 → 没有失败的可能
- ✅ 她趁经理进后厨，把备货单从墙上取下来折好塞进围裙 → 被看见就完了

### 条件二：它**没有完全成功**

- 全成功 → 没有戏（读者松一口气就翻页了）
- 全失败且**没有代价** → 也没有戏（只是倒霉）
- **要的是：拿到一半，或者拿到了但不是想要的那个，或者成功了却长出更大的麻烦**

### 条件三：她**付出**了可数的一样东西

「可数」是关键。不可数的付出不算付出。

| 可数 | 不可数（不算） |
|---|---|
| 一句她本来不打算说的话 | 她的尊严 |
| 一次求助（欠了一个人） | 她的骄傲 |
| 半小时（错过了某件事） | 她的时间感 |
| 一样东西（送出去、弄坏、留在原地） | 她的心情 |
| 一个谎（以后要圆） | 她的不安 |

## 三、假戏六型（最危险，因为它们有质感）

下面六种写法**看起来在写人物**，其实她一次也没使劲。
它们能骗过自查、骗过机检、骗过作者自己，因为它们都有细节、都克制、都不抒情。

**这六型是「冷」和「空」的主要来源。**

| 型 | 长什么样 | 为什么空 | 怎么救 |
|---|---|---|---|
| **跟着走** | 她跟在他后面，看他检查每一张桌子 | 她的注意力在别人身上，自己没有目标 | 让她在跟随中**做一件怕被看见的事**（藏、改、挪、发消息） |
| **看着** | 她看着那片光从桌面移到地上 | 观察不等于参与，读者跟着她一起发呆 | 让看到的东西**改变她的判断**，或让她**必须马上做点什么** |
| **数着** | 她把零钱数了两遍 | 重复动作可以暗示焦虑，但连用就成了习惯描写 | 只留一次，且**数错了**——数错才有信息 |
| **照做** | 她拿空白表照原样抄了一遍 | 这是最像"有情感"的假戏，其实只是重复 | 让抄的过程**出了偏差**（写错一个字、少抄一个人、多留一行） |
| **等着** | 她站在那儿等他自己弄完 | 等待是被动的极致 | 让她在等的过程中**做了决定** |
| **记着** | 那一眼她记住了 | 内心动作不可观察，等于没写 | 改成**身体反应**，或**后来用上这个记忆** |

> **六型的共同点**：她的注意力落在**别人或外物**上，不在**自己想要的东西**上。
> 一个人只要不为自己想要的东西使劲，读者就不会为她使劲。

**自检**：把这一场里她的所有动作列出来，问每一行「她想拿到什么」。
答「不知道」或「没什么」的行，就是假戏。

## 四、详略差（流水账的真正机制）

这一条最反直觉，也最有效。

> **流水账不是「动作太多」，是「所有事一样重」。**

实测样本：一章 2800 字的日常流程（只记性质与篇幅，不记写了什么）。

| 事件 | 性质 | 篇幅 |
|---|---|---|
| 反复搬运重物（十四趟，含一次失败的小聪明） | 做事 | **4 段 / 约 300 字** |
| 清洁、收拾、等它自己干 | 做事 | 3 段 |
| 整理存货、把零碎归位 | 做事 | 2 段 |
| **把一件注定要变的东西，照原样又做了一遍，做得比平常认真** | **全章唯一有情感重量的动作** | **2 段 / 约 120 字** |

**最重要的那件事，写得比搬东西还短。**

读者的判断依据只有一个：**篇幅**。你把什么写长，读者就认为什么重要。
所有事件等权重，读者只能把它当清单读——这不是读者的错，是篇幅在告诉他「这些都不重要」。

### 权重表

| 事件 | 占全章篇幅 | 写法 |
|---|---|---|
| **正事件**（她动手、失败、付代价的那一次） | **≥40%**（按张力分档，见下表） | 慢下来，允许写长、写乱、写不体面 |
| 次事件（推进或转折的第二场） | 15–25% | 正常写 |
| 其余事件 | 每件 ≤10% | 压成一句概述，或直接不给过程只给结果 |

**比例不够，还要看绝对字数**（9.4 追补）：

> 只给比例会漏掉一种情况——**全章写得短，正事件的比例达标，绝对量却撑不起一场对抗**。
> 实测：一章 2700 字，正事件占 42%（看似合格），实际只有 1130 字；
> 契约上写「办公室一场 1700 字」，正文写出来 1350 字，**承诺没兑现，机检查不出来**。

| 张力 | 正事件占全章 | **正事件绝对字数下限** |
|---|---|---|
| 5（爆） | ≥50% | **≥1600** |
| 4（爆） | ≥45% | **≥1400** |
| 3（蓄/转） | ≥40% | **≥1100** |
| 2（呼） | ≥35% | **≥900** |

- 低于下限 → 这场戏**没写透**，不是"精简"，是没到位。加的不是描写，是**回合**（她又试了一次／对方又挡了一次）。
- 单场景章（全章只有一场戏）不受比例约束，但绝对字数下限照旧。
- ⚠ 这条与「字数目标」联动：如果字数目标本身低于"下限 ÷ 40%"，那**目标就定低了**，
  先改字数目标，不要靠拉长别的段落凑比例。

**判据（写完必做）**：

> 把全章事件按篇幅从大到小排一遍。**第一名必须是「她动手并失败的那一次」。**
> 如果第一名是「搬东西 / 走路 / 等人 / 收拾」，这章就是流水账，重排，不要改句子。

### 详略差同时解决「没有情感」

情感不是靠「加一段内心」实现的。**情感是篇幅的副产品**：

> 她在意的东西，作者会不自觉地多写；她不在意的东西，一句就过去了。
> 所以**篇幅的分布本身就是态度**。

一章里如果能看出「作者对哪件事格外舍不得放手」，情感就已经在纸上了。
反过来，每件事都写得一样详略，读者读到的就是**作者谁也不爱**。

⚠ 这与「一段一职」「动作要合并」不冲突：那两条管**局部**（一个段落内部不要碎），
这一条管**全局**（整章的篇幅往哪儿倾斜）。段落写得再好，权重分配错了，整章还是清单。

## 五、配角驱动器（一句话，决定他有没有嘴）

> **流水戏里所有角色都朝同一个方向划桨。**

这是最普遍的一种失效：她要开店，店员帮她开店，经理来检查店，老客人来店里坐着。
没有一个人的目标和另一个人不一样。于是没有摩擦，没有潜台词，对话只能是信息交换。

### 规则：每个配角**进场前**答一句

**「他今天本来想干什么？」**——而且这件事要跟她的目标**冲突**。

三种冲突，任选：

| 冲突类型 | 例（不写进正文，只用来定他的动作） |
|---|---|
| **要同一样东西** | 两个人都想用同一段时间/同一张台子/同一个名额 |
| **时间不同步** | 他急，她不急；或者反过来，他有一件必须马上走的事 |
| **他知道一件她不知道的事** | 他已经在别处听说了消息，但不知道怎么开口 |

**这一句永远不写进正文**，它只用来决定三件事：
1. 他进门第一眼看哪里
2. 他哪句话说得心不在焉
3. 他什么时候想走

> 有了这一句，配角自动长出嘴；没有这一句，他只能是一个"功能"。
> **一个只有功能的配角，会让整场戏变成服务流程。**

### 检验

一场戏里有几个人，就问几句「他今天想干什么」。
如果有两个人答得一样，或者有一个人答不出——这一场是假的群戏。

## 六、出状态（机械感的直接来源）

机器做事：每个动作完整、准确、有始有终。
人做事：会走神、会多此一举、会忘、会做一半改主意。

**文本里如果每个动作都被完整执行，读者读到的是机器。**

> 这一条与「手部预算」「受限让路」不冲突，反而是它们的解药。
> 预算管的是「这个动作物理上能不能做」，出状态管的是「这个人做的时候在不在状态」。

### 每章至少三处「她不在状态」

| 型 | 例 |
|---|---|
| **多余的一步** | 门已经关上了，她又推了推，看关严没有 |
| **顺序错乱** | 先伸手去拿杯子，想起来杯子还在池子里，手在半空改了个方向 |
| **做到一半停住** | 拧到一半，听见外面有人说话，手停了，听完才继续 |
| **话没说完** | 说了一半，觉得没必要，把后半句咽了（不是"欲言又止"，是真的换了个话题） |
| **做完了才发现没必要** | 擦完桌子，发现这张桌子今天不开 |

**判据**：

> 这一章里有没有一件事，她做得**不完美、没有效率、但也没有后果**？
> 没有的话，她就是机器——不管动作写得多准。

⚠ 「没有后果」很重要。不是为了塑造人物而硬塞一个失误，那样反而假。
真实的人效率本来就低，这些浪费不产生情节，只产生**人味**。

## 七、动笔前的四问（只问这四个）

不要问十个。问四个，答得出才动笔。

1. **这一章她动手几次？失败的那一次在哪？**
   一次都没有＝这一章没有戏，回去加事件，不要靠描写补。

2. **谁是她的对手，他今天想干什么？**
   答不出他的名字＝这一场没有阻力；答不出他想干什么＝这个人是功能。

3. **篇幅第一名是谁？**
   必须是「她动手并失败的那一次」。是别的东西＝重排权重。

4. **她哪三处不在状态？**
   说不出＝这一章的人是机器。

> 四问答不出，**不要动笔，也不要用形容词和细节去补**。
> 补出来的东西会很好看，然后依然是一份清单。

## 八、与其它层的关系

| 层 | 管什么 | 本层与它的分工 |
|---|---|---|
| `core/scene-engine.md` | 一场戏的五件事（结构骨架） | 五件事是**答得出**；本层管**答出来的东西是不是戏**（"试了什么"必须是可能失败的动手） |
| `core/intensity.md` | 好不好看（峰值、回合、对话博弈） | 强度是**结果**；本层管**为什么会有强度**——没有对手就没有强度 |
| `core/emotion.md` | 动不动人（在乎、压着、漏出来） | 情感是**详略差的副产品**；没有详略差，情感会被平均分配掉 |
| `core/prose-craft.md` | 句子层去 AI 化 | 句子层修不了结构层的空。**权重错了，句子越漂亮越像样张** |
| `core/cold-review.md` | 审读时点 | 冷读的「读感七问」是**验证**本层四问有没有做到 |

> **一句话记法**：
> 前三层问「有没有出错」，这一层问「**有没有发生事**」。
> 一份没有出错、也没有发生事的稿子，是说明书。
