# 短篇与单章合并口径（唯一权威页）

> **适用**：计划章数 ≤10（短篇 2–10）或单章；或用户明示「短篇／番外／试笔」。
> **权威声明**：本文件是短篇**篇幅相关缩放**的唯一事实源。配额本体在
> `core/chapter-planning.md#一-补`（本页只给短篇行，不复制全表）；中长篇的位置函数、
> 四卷规格与弧线层仍按 `core/structure.md` 与 `core/chapter-planning.md` 第六节。
> ❌ 其余文件不得再列短篇数字，只留指针；出现第二处字面量即删。短篇口径只改本页。

## 一、一处查完（短篇全口径表）

| 主冲突线 | 烈档 3 章窗口仍适用；高／中档 5 章窗口在 <5 章作品豁免，只登记三态 | 只登记 | `core/chapter-planning.md` 一-补2 节 |
| 招牌元素 | 首章 ≤2 类；常规型限频仍适用（不得连续两章） | ≤2 类 | `core/audience.md#★招牌元素密度与疲劳控制` |
| 功能配比 / 钩子近 5 章轮转 / 账本滚动窗口 / 8 章健康度 | 不适用（仅 ≥10 章作品适用） | 不适用 | `core/cold-review.md` |

- **两套配额互不套用**：受限 beat 走「篇幅档表」（短篇看全篇总量），
  主冲突线走「冲突强度档窗口」；同一章可以受限为 0、主冲突为推进，两账分判。
- **缩减只减内容项**：❌「篇幅短」不得援引为跳过机检或降级模式的理由；
  收集 13 题 → 5 题（题材／基调／类型／尺度／模式），文学自评 5 问与零发现反证轮照走。
- 账本 `篇幅档: 短篇（2–10）`、`自查档: lite`；滚动窗口字段按「不适用」登记，❌ 不填空凑数。

## 二、首次 C 位置与节点间距的仲裁（6–10 章口径真空修正）

> 把中长篇的「≤30 章＝首次 C 25–40% ＋节点间距 3 章」套到 9 章书：
> 里程碑按 3 章间距排成 看见 1 → 触碰 4 → 过夜 7（过夜 ≈78%）；
> 首次 C 若按「间距优先」落到第 6 章＝67%，远超 stated 的 25–40%。
> **百分比与等距里程碑在短篇数学上不可同时成立**，故短篇废止百分比、改按里程碑判。

- **里程碑优先**：A 含蓄档三里程碑（看见／触碰／过夜）按 `ceil(N/3)` 间距排入，
  允许落在全书 60–85%，❌ 不判「超区间」；判据改为
  「看见在首 1/3 内、过夜不在末章」，且首次 C 档前须有「被看见」beat。
  N≤4 时以「过夜不在末章」优先，允许合并里程碑（如看见与触碰同章），❌ 不硬套等距。
- **首次 C 档**：N≥6 时不排前 3 章，建议落在 `max(4, ceil(N/2))` 章前后；
  N≤5 整体豁免「不能开场就上床」，但从第 1 章起仍须有情节钩子。
- **外部后果三章律**短篇保留，可压到首次 C 之后 1–2 章内；
  末章须回扣第一章意象（结局规则见 `core/structure.md`）。
- **B/C 档越档与停手三条客观锚在短篇不降级**（`topics/intimacy-explicit.md#十五、自查表`）。
- ❌ 短篇不得援引中长篇的 25–40%／20–35%／20–30% 表，也不得用「间距优先」硬套百分比。

## 三、四节缩放与冗余字段豁免

- 四节＝起／承／转／合；**不要求**填「卷问题／卷内升级三段／卷末大钩／分卷表」四卷规格字段
  ——那是 8–15 章／卷的长篇形态（见 `templates/outline.md#★四卷规格表`）。
- 大纲契约仍须：基调核心循环、`templates/outline.md#★主题材契约`、体验强度曲线、结局三章；
  短篇可把结局三章压成末章一段。
- 单章作品的「章内四转」按 `core/pacing.md` 高低张力交替压进一章。

## 四、写法层增量（短篇特有）

- 篇幅短 → 每句权重高：开头砍日历句，从事件砸过来的瞬间切入；
  常规动作链按 `core/prose-craft.md` 1.6 节压成「一次活细节＋一个数字」。
- 温馨基调的**嬉戏节拍**（互相逗弄、记错对方的事、小比赛、马屁拍在马腿上）
  是短篇关系温度的主要来源；❌ 不把全章写成边界谈判。
  温暖来自角色给角色的具体意外，不是契约标签。
- 交付闸 bootstrap 三步（`--precheck` → 回填字段 → 正式跑）不因篇幅省略，
  见 `core/workflow.md` 第八节机检条款。
