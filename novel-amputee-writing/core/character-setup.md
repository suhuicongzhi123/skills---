# 角色设定收集

> 类型无关。创作前期向用户收集以下信息（后期按需补充字段）。

## 收集流程（逐题提问协议）

**交互铁则**：
1. **一次只问一题**——禁止一次性抛出多个问题或全部设定项清单
2. **每题给选项与效果**：2–5 个选项 + 每个选项对故事的实际影响（引导而非限制；
   用户自由作答同样有效，选项之外的回答按回答本身理解）
3. **答后思考再问下一题**：用户回答后，先想该回答对后续问题的影响
   （分支/默认值/联动），再提出下一题——下一题可根据已答内容动态调整
   （例：选了上肢截肢 → 跳过辅具题；选了 wannabe → 追问是否含截肢过程；选了古装向 → 提示器具表差异、末世向 → 追问辅具/假肢可得性）
4. **随时可跳过**：用户在任何一题表示「跳过询问流程」→ 剩余项全部按默认值
   一行汇总告知，直接进入创作（跳过不豁免生理事实类约束，只豁免询问）
5. **末题固定**：询问是否开启独立子代理冷读稽查流程（创作全程的章末稽查，
   见 `core/cold-review.md`）——这是它唯一的开启入口，见下「问题序列」
6. **问题序列封闭**：除冷读稽查（末题）外，问题序列不插入任何非设定类问题
   ——技能更新检查（见 `SKILL.md` 〇节）等运行时事务**不属于询问链**，
   已在对话首次调用时一次性处理，不得混入逐题提问环节

**问题序列**（默认顺序；逐题动态分支，非死板清单）：

── 世界观（先定"在哪个世界"——它约束后续一切设定）──
1. **故事题材**——先定世界观；它约束后续设定（古装无现代器具、末世看辅具与假肢可得性）
   （现实向：都市日常/校园/职场/家庭伦理/言情/悬疑推理｜幻想向：高魔奇幻/低魔奇幻/都市奇幻/科幻/赛博朋克｜
    末世生存：末世/丧尸/废土/孤荒生存｜古装向：架空朝代/真实朝代/低技术架空）
2. **基调**——与题材合力定故事调性
   （温馨日常｜平静克制｜暧昧暗流｜紧张悬疑｜压抑沉重｜黑色幽默｜治愈｜虐心纠结｜冒险热血｜荒诞）
3. **缺失解释框架**——世界如何解释"她为何缺一条腿"
   （常态化：人人如此无需解释，默认｜神圣化：**须你显式选定**，有形而上意义但受补偿叙事约束｜无解释：世界不回答｜
    病因学：医学前史已淡化｜隐秘：真相被遮蔽，悬疑用）——错过此题，神圣化全书不可达

── 角色生理（依赖链）──
4. **截肢部位与类型**——决定一切生理事实与注入文件
   （下肢：髋离断——受限最重、空椅面意象、双拐主力｜膝上——假肢为主、幻膝感｜膝下——受限最轻、日常最接近常人；
    上肢：肩离断/肘离断/腕离断——单手生活线；上下肢复合：两域并行，按域分工）
5. **侧别**（左｜右｜双——双＝叠加双侧文件，无健腿，轮椅可能）
6. **辅具类型**（仅下肢类型问；按已选类型给默认。腋拐：支撑强但占双手，双手占用受限高频｜
   肘拐：灵活、可挂腕腾手｜假肢为主：外观接近常人、隐藏/暴露张力｜无：单腿跳为默认移动，受限最原始）
7. **截肢时长档位**（先天：无幻肢感｜近期 B：幻肢高频+受限带生疏感，适合成长线｜
   多年 C：熟练利落、幻肢低频，受限写「熟练不消解结构」）
   ＋ **训练程度**（初学：更早歇/放弃｜熟练：默认｜长期适应：完成但代价高——只影响弱受限呈现，不影响能否蹲）
8. **人物基本**（姓名/年龄/**性别**（默认女）/职业/性格——按★性格生成轴给欲望与软肋，回答越具体人物卡越省）

── 叙事与交付 ──
9. **受众取向**（devotee：默认，截肢者生活主线｜wannabe：含求截肢前史，追问「是否含截肢过程」与跃迁设定｜
   **双取向**：按章切换）
   ＋ **视角身份定位**（仅读者视角：默认｜作为角色入戏：须标注其剧情功能）
10. **叙事视角（人称）**（第一人称：默认，代入感强｜第三人称限知｜第三人称全知）
    ——**与第 9 题强耦合**：「受众取向 × 叙事视角」决定第一人称里"我"的身体状态（wannabe+第一人称不可用身体细节/幻肢感写"我"），写错即出戏，见下「两类组合的必答项」
11. **亲密尺度档**（A 含蓄｜B 暧昧：默认｜C 成人：须显式声明）
12. **输出长度**（单章/短篇：缩减口径，无轮转机制｜中长篇：完整密度与账本机制）
13. **末题：是否开启独立子代理冷读稽查**（开启：每章完稿后独立子代理按 18 项维度稽查，多一层质量兜底、流程更慢｜不开启：仅章末自查清单，快）

**跳过时的默认值**：按「默认值原则」节执行（现实向/温馨日常/常态化/髋离断/右/腋拐/多年/熟练/女/第一人称/devotee/仅读者视角/B/中长篇/不开启冷读），一行汇总告知用户后直接开写。

## ★性格生成轴（人物卡心理区配套）

- **核心欲望**：她最想要什么（与截肢无关的人生目标也要有）
- **恐怕失去什么**：她的一条软肋
- **与截肢无关的身份标签**：她还是什么人（厨师/棋手/跑者/姐姐……至少一个）
- **幽默或待人方式**：她的说话温度
- **处置风格化提示**：同一起身链，急性子=一气呵成偶尔第四步失手重来；慢性子=每步稳但费时；要强的人=拒绝扶膝盖偏用双拐硬撑——生理事实长在性格上，角色才活

## 默认值原则
- 代入感优先 → 默认第一人称
- 截肢后生活为主 → 默认不含截肢过程
- 髋离断为主 → 默认 髋离断
- 髋离断辅具 → 默认腋拐（可肘拐、腋拐混用）
- 性别默认女 → 慕残者群体以女性截肢者为主要想象对象
- 基调默认温馨日常 → 贴合受众日常样态偏好，回避苦难沉重
- 时长默认"多年" → 幻肢感低频、安静，避免全书高频重复导致疲劳（见 `topics/timeline.md`）

## 两类组合的必答项

**其一：受众取向 × 叙事视角**（决定第一人称里"我"的身体状态，写错即出戏）

| 组合 | "我"是谁 | 可用素材 |
|------|----------|----------|
| devotee 受众取向 + 第一人称 | 截肢者本人 | `types/{type}.md` 全部素材（颤动 / 幻肢感 / 空椅面） |
| wannabe 受众取向 + 第一人称 | 健全人（向往方） | **不可**用 `types/{type}.md#身体细节`、`#幻肢感` 写"我"；那些只能写在她身上 |
| 双取向 | 按章切换，章首标注 | 两 POV 各记一次招牌元素，计入**同一本账的密度统计**，不因分视角而翻倍 |

**其二：wannabe 主角**（`是否含截肢过程: 是` 时）

- 允许"走向截肢"作为主轴（覆盖 `topics/wannabe.md` 的默认前史定位），但须满足：
  主线是**她的欲望与处境**，不是求截肢行为的流程记录
- 时长档位允许跃迁：无 → 近期。跃迁时间点写入 `state-ledger.yaml` 的 `角色固定属性.时长档位跃迁章`，
  并**分两段执行频率档位**（跃迁前按 A 档 0 次，跃迁后按 B 档）
- 跃迁后仍须过回避清单：不写手术过程、不写伤口与疼痛处理

## 受众定位（默认）
- **默认 devotee 为读者身份**（非角色），整体文风以 devotee 偏好为准
- devotee / wannabe **可作为角色入戏**，但须从属主线、不影响 central question
  详见 `core/audience.md`

## 多样性自检
- 当 性别/截肢类型/侧别/辅具/题材/基调/叙事视角 **全部取默认**时，提示"高雷同风险"，建议至少改 2 项
- 设定摇号表（灵感用，非强制）：

| 维度 | 选项 |
|------|------|
| 性别 | 女 / 男 |
| 类型 | 髋离断 / 膝上 / 膝下 / 肩离断 / 肘离断 / 腕离断 |
| 侧别 | 左 / 右 / 双 |
| 题材 | 现实向 / 幻想向 / 末世生存 / 古装向 |
| 基调 | 温馨 / 克制 / 暧昧 / 悬疑 / 压抑 / 黑色幽默 / 治愈 / 虐心 / 冒险 / 荒诞 |
| 叙事视角 | 第一人称 / 第三人称限知 / 第三人称全知 |

- 摇号用法：每维度随机取一项，至少与默认差 2 项，生成非默认组合当起点
