# 角色设定收集

> 类型无关。创作前期向用户收集以下信息（后期按需补充字段）。

## 收集流程
1. 向用户说明需要收集的设定项
2. 用户给出后，注入 `types/{type}.md` 建立生理事实基线
3. 辅具类型按截肢类型给默认（下肢：髋离断→腋拐；上肢：不适用），询问用户是否调整
4. 缺项用合理默认值，并告知用户默认
5. 设定确认后进入大纲阶段

## 设定字段


## 默认值原则
- 代入感优先 → 默认第一人称
- 截肢后生活为主 → 默认不含截肢过程
- 髋离断为主 → 默认 髋离断
- 髋离断辅具 → 默认腋拐（可肘拐、腋拐混用）
- 性别默认女 → 慕残者群体以女性截肢者为主要想象对象
- 基调默认温馨日常 → 贴合受众日常样态偏好，回避苦难沉重
- 时长默认"多年" → 幻肢感低频、安静，避免全书高频重复导致疲劳（见 `topics/timeline.md`）

## 两类组合的必答项

**其一：受众视角 × 叙事视角**（决定第一人称里"我"的身体状态，写错即出戏）

| 组合 | "我"是谁 | 可用素材 |
|------|----------|----------|
| devotee 读者视角 + 第一人称 | 截肢者本人 | `types/{type}.md` 全部素材（颤动 / 幻肢感 / 空椅面） |
| wannabe 读者视角 + 第一人称 | 健全人（向往方） | **不可**用 `types/{type}.md#身体细节`、`#幻肢感` 写"我"；那些只能写在她身上 |
| 双视角 | 按章切换，章首标注 | 两 POV 各记一次招牌元素，计入**同一本账的密度统计**，不因分视角而翻倍 |

**其二：wannabe 主角**（`是否含截肢过程: 是` 时）

- 允许"走向截肢"作为主轴（覆盖 `topics/wannabe.md` 的默认前史定位），但须满足：
  主线是**她的欲望与处境**，不是求截肢行为的流程记录
- 时长档位允许跃迁：无 → 近期。跃迁时间点写入 `state-ledger.yaml` 时间线，
  并**分两段执行频率档位**（跃迁前按 A 档 0 次，跃迁后按 B 档）
- 跃迁后仍须过回避清单：不写手术过程、不写伤口与疼痛处理

## 受众定位（默认）
- **默认 devotee 为读者身份**（非角色），整体文风以 devotee 偏好为准
- devotee / wannabe **可作为角色入戏**，但须从属主线、不影响 central question
  详见 `core/audience.md`

## 多样性自检
- 当 性别/类型/侧别/辅具/题材/基调/视角 **全部取默认**时，提示"高雷同风险"，建议至少改 2 项
- 设定摇号表（灵感用，非强制）：

| 维度 | 选项 |
|------|------|
| 性别 | 女 / 男 |
| 类型 | 髋离断 / 膝上 / 膝下 / 肩离断 / 肘离断 / 腕离断 |
| 侧别 | 左 / 右 / 双 |
| 题材 | 现实向 / 幻想向 / 末世生存 / 古装向 |
| 基调 | 温馨 / 克制 / 暧昧 / 悬疑 / 压抑 / 黑色幽默 / 治愈 / 虐心 / 冒险 / 荒诞 |
| 视角 | 第一人称 / 第三人称限知 / 第三人称全知 |

- 摇号用法：每维度随机取一项，至少与默认差 2 项，生成非默认组合当起点
