# 世界观建立

> 类型无关。**大纲阶段建立，全书锁定**，写入 `templates/outline.md` 与 `state-ledger.yaml`。
> 世界观服务于两个目的：**跨章一致性锁定** 与 **场景条件供给**。
> ⚠ **受限的来源是身体结构本身，不是环境缺陷**——无障碍水平只决定"这一处有多难走"，
>   不决定"她是不是受限"。
> ❌ 不写以改造环境 / 控诉制度为主线的冲突。

## 一、建立字段

```yaml
world:
  时代:
  地域:
  无障碍水平: 完善 | 部分 | 缺失       # 场景难度系数：影响绕路/找支撑/耗时，不决定是否存在受限
  社会态度: 排斥 | 怜悯 | 平常 | 制度性不便
  医疗与器具:                         # 器具可得性/维护/更换成本
  题材特有设定:                        # 幻想向：魔法义肢的社会位置；末世：器具是否稀缺资源
```

## 二、与截肢设定的一致性检查

- **无障碍水平 ↔ 场景难度**：无障碍缺失时绕路更多、耗时更长；完善时通行顺畅。
  ❌ 不写因无障碍缺失而"无法通行"

  | 档位 | 具体后果（写入世界观后全书一致） |
  |------|----------------------------------|
  | 完善 | 直梯可用、坡道贯通、无障碍厕位常有；代价是绕路到指定口、等梯耗时 |
  | 部分 | 主干道有坡道、支线没有；老楼无梯、新楼有；找入口要提前看，走错要折返 |
  | 缺失 | 台阶为主、无扶手、路面破损；须自己找支撑物、挑路线、预留一倍时间 |

- **时代/地域 ↔ 器具形态**：器具须符合该时代医疗与工艺水平
  - **现代**：见 `topics/crutch-spec.yaml`（该文件仅覆盖现代工业制品）
  - **非现代（古装/古代/架空低技术）**：`crutch-spec.yaml` 不适用，
    须在世界观里自建器具表（材质/形制/可得性/维护），见 `genre/historical.md`
- **社会态度 ↔ 冲突源**：态度越负面，"被看见"场景张力越大（见 `topics/clothing.md#三、视觉信号`）

  | 档位 | 路人行为模板 |
  |------|--------------|
  | 排斥 | 侧目、挪位、小声议论、被当成麻烦 |
  | 怜悯 | 让座/硬要帮忙/夸"真坚强"、被当成励志对象 |
  | 平常 | 不多看一眼、正常服务、偶有孩子直问 |
  | 制度性不便 | 流程卡在窗口、要开证明、被要求"有人陪同" |

- **题材特有设定 ↔ 生理事实**：高科技/魔法可替代器具，**不替代截肢体验本身**（见 `genre/fantasy.md`）；
  幻想/科幻向可豁免的物理条目与豁免边界见 `core/physio-audit.md#题材豁免`

## 三、硬约束

- 世界观在大纲阶段确定，**全书锁定**；中途变更须告知用户并评估下游影响
- 世界观不得与 `types/{type}.md` 的生理事实冲突
- 同一场景的无障碍条件全书一致（第 5 章地铁有直梯 → 第 11 章不得写成只有扶梯）
