# 世界观建立

> 类型无关。**大纲阶段建立，全书锁定**，写入 `templates/outline.md` 与 `state-ledger.yaml`。
> 世界观服务于两个目的：**跨章一致性锁定** 与 **场景条件供给**。
> ⚠ **受限的来源是身体结构本身，不是环境缺陷**——无障碍水平只决定"这一处有多难走"，
>   不决定"她是不是受限"。
> ❌ 不写以改造环境 / 控诉制度为主线的冲突。

## 一、建立字段

```yaml
world:
  时代:
  地域:
  无障碍水平: 完善 | 部分 | 缺失       # 场景难度系数：影响绕路/找支撑/耗时，不决定是否存在受限
  社会态度: 排斥 | 怜悯 | 平常 | 制度性不便
  医疗与器具:                         # 器具可得性/维护/更换成本
  题材特有设定:                        # 幻想向：魔法义肢的社会位置；末世：器具是否稀缺资源
  缺失解释框架: 常态化 | 神圣化 | 无解释 | 病因学 | 隐秘   # 一书锁一个；神圣化须用户显式选定，见「一-补」
```

## 一-补、缺失解释框架（防雷同锁定字段）

> 「她为什么缺失」是设定层最大的收敛点——不加约束时，生成器会反复收敛到
> 「残缺被解释为有意义的交换/馈赠」的补偿叙事（励志二元的结构变体），
> 导致多本书设定高度雷同。一书开始前从下表锁定一个，写入 outline 与账本，全书不变：

| 框架 | 含义 | 使用条件 |
|---|---|---|
| **常态化** | 人人如此/常见，无需解释，她也不觉得缺 | 默认选项；社会性受限类失效（无健全者对照系），受限写法贴常态视角（写技巧与吃力，不写缺失意识） |
| **神圣化** | 有形而上意义（神赐/使命/交换） | **须用户显式选定**，禁止生成器默认收敛；选定后写法仍受回避清单「补偿叙事」约束（见 `core/audience.md`） |
| **无解释** | 世界不回答，她也不问 | 文学/克制向；缺失是给定事实，不是待解的谜题 |
| **病因学** | 有医学/事故解释，但已淡化成前史 | 现实向常用；解释只出现在必要的回忆与手续里 |
| **隐秘** | 有解释但被权力遮蔽 | 悬疑题材用；「真相」须服务于 central question，不是默认走向 |

- 锁定时机：世界观建立时一并锁定，与世界观同权重（大纲阶段写入，全书不变）
- ❌ 未锁定时禁止自补解释——「为什么缺失」不回答就是回答（等于「无解释」框架）

### 框架→叙述措辞（框架不只管设定，还管正文用什么词）

> 框架决定世界里的人**如何认知与谈论**身体缺失——叙述措辞与框架不符＝世界观违背。
> 实测高发：常态化世界观下旁白惯性沿用「髋离断/患侧/残肢」等病理词——
> 常态化世界里无人这样认知与说话，出戏点直给。

| 框架 | 正文叙述层/对话层措辞 | 病理词可用域 |
|---|---|---|
| **常态化** | 世界内平常语言——「左边」「空的那侧」「那条腿生来就没有」；天使/特殊种族世界用该世界的身体平常语 | ❌ 零容忍（髋离断/截肢/残肢/残端/患侧/假肢学名不得出现在叙述与对话） |
| **神圣化** | 宗教/神话语言（神赐/印记/誓约） | 仅仪式/经文引述场景 |
| **无解释** | 中性身体描述，不引入任何归因词汇 | ❌ 医学与宗教词都不用 |
| **病因学** | 医学叙事合法但限场景（诊断/前史回忆/手续） | ✅ 限前史与医疗场景，不进日常叙述 |
| **隐秘** | 按遮蔽方的官方话语写（表层措辞），真相词只在内幕揭示后出现 | 揭示前禁，揭示后按真相话语 |

- **登记层不受限**：大纲/账本/章末自查/人物卡用医学术语保精确（如「左髋离断、
  无辅具」）——那是技能层语言，不进正文；正文措辞按本表
- 三个措辞层分查：旁白/内心/对话（高发位＝旁白惯性病理词；对话按说话人身份——
  常态化世界里旁人同样没有病理词汇）
- 稽查：章末核查项（`templates/chapter.md` 措辞匹配项）＋冷读维度 22

## 二、与截肢设定的一致性检查

- **无障碍水平 ↔ 场景难度**：无障碍缺失时绕路更多、耗时更长；完善时通行顺畅。
  ❌ 不写因无障碍缺失而"无法通行"

  | 档位 | 具体后果（写入世界观后全书一致） |
  |------|----------------------------------|
  | 完善 | 直梯可用、坡道贯通、无障碍厕位常有；代价是绕路到指定口、等梯耗时 |
  | 部分 | 主干道有坡道、支线没有；老楼无梯、新楼有；找入口要提前看，走错要折返 |
  | 缺失 | 台阶为主、无扶手、路面破损；须自己找支撑物、挑路线、预留一倍时间 |

- **时代/地域 ↔ 器具形态**：器具须符合该时代医疗与工艺水平
  - **现代**：见 `topics/crutch-spec.yaml`（该文件仅覆盖现代工业制品）
  - **非现代（古装/古代/架空低技术）**：`crutch-spec.yaml` 不适用，
    须在世界观里自建器具表（材质/形制/可得性/维护），见 `genre/historical.md`
- **社会态度 ↔ 冲突源**：态度越负面，"被看见"场景张力越大（见 `topics/clothing.md#三、视觉信号`）

  | 档位 | 路人行为模板 |
  |------|--------------|
  | 排斥 | 侧目、挪位、小声议论、被当成麻烦 |
  | 怜悯 | 让座/硬要帮忙/夸"真坚强"、被当成励志对象 |
  | 平常 | 不多看一眼、正常服务、偶有孩子直问 |
  | 制度性不便 | 流程卡在窗口、要开证明、被要求"有人陪同" |

- **题材特有设定 ↔ 生理事实**：高科技/魔法可替代器具，**不替代截肢体验本身**（见 `genre/fantasy.md`）；
  幻想/科幻向可豁免的物理条目与豁免边界见 `core/physio-audit.md#题材豁免`
- **战斗豁免（高武/高魔/神话）**：档位 E1–E3 与**能力 / 可豁免 / 代价 / 失效**须写进
  `题材特有设定`，未登记即不豁免（见
  `topics/combat-mechanics.md#十五、高武/高魔/神话战斗豁免（题材层，可选）`）

## 三、硬约束

- 世界观在大纲阶段确定，**AI 不得自主变更**；用户显式指令可变更
  （按 `SKILL.md#★用户指令优先` 告知影响并登记）；中途变更须评估下游影响
- 世界观不得与 `types/{type}.md` 的生理事实冲突
- 同一场景的无障碍条件全书一致（第 5 章地铁有直梯 → 第 11 章不得写成只有扶梯）
