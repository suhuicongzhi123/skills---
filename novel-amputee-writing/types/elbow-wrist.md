# 肘离断 / 腕离断（上肢低位截肢）

> 与肩离断的关键区别：**有残端**。肘离断保留上臂（肱骨），腕离断保留前臂。
> 单手日常通则见 `topics/one-handed-daily.md`，本文件只写两类各自的差异。
> 注入时机：角色设定 `截肢类型: 肘离断 | 腕离断` 时。

## 与肩离断的对照（★易写错）

| 项 | 肩离断 | 肘离断 | 腕离断 |
|---|---|---|---|
| 保留结构 | 锁骨、肩胛骨完整，无上臂 | 肱骨保留，有上臂残端 | 前臂保留，有腕以近的残端 |
| 残端长度 | 无残端 | 上臂中下段至肘上 | 前臂下段，较长 |
| 残端可否承重 | 无 | ✅ 可（常见末端承重） | ✅ 可 |
| 能否主动带动袖管 | ❌ 不能（空袖管不晃） | ✅ 能带动袖管 | ✅ 能带动袖管 |
| 前臂旋前/旋后 | 无 | 无（无前臂） | ✅ 保留（腕离断的特点） |
| 常规肌电假肢 | ❌ 不可用 | ✅ 可用 | ✅ 可用 |
| 瘢痕位置 | 肩关节周围弧形/纵向 | 肘上残端末端 | 腕横纹附近 |

❌ 常见错误：把肩离断的「空袖管完全不晃」「不可用肌电假肢」套到肘离断/腕离断上。

## 肘离断

- **形态**：上臂止于肘上或肘下；残端为圆柱状，末端有瘢痕；保留上臂全部肌肉（肱二头/三头）
- **可做什么**：屈伸残端（肱二头肌带动，幅度可观）、用残端夹物（肘弯夹持）、
  残端末端承重（撑在桌面/椅面）、带动袖管
- **不能做什么**：无手无前臂——抓、握、捏、拧、托、推、拉、提，以及屈腕、握拳
- **假肢**：常规肌电假肢可用（肱二头/三头肌电信号驱动）；索控假肢亦可用；
  上臂假肢带肘关节+假手，穿脱较肩离断简便
- **袖管**：患侧袖管有内容物、可带动；裁剪或卷起至肘上，❌ 不写空袖管飘荡

## 腕离断

- **形态**：前臂保留，残端止于腕关节附近，残端较长、末端圆钝，保留前臂旋前旋后功能
- **可做什么**：旋前/旋后（转掌心）、残端夹持（腕与前臂之间夹物）、
  残端末端承重、用残端按压/顶住物件
- **不能做什么**：无手——抓、握、捏、拧、指尖动作
- **假肢**：肌电假肢适配性好；亦常见**美容手/被动手**（外观型），
  不戴假肢时用残端直接做事更常见——这是腕离断的日常特色
- **袖管**：长袖可自然垂下（残端撑起一部分），短袖则露出残端

## 身体细节

- 残端肌肉可自主收缩颤动（肱二头肌收缩时残端抬起是本类型的看点），
  分布服从 `core/audience.md#招牌元素密度与疲劳控制`
- 残端末端瘢痕：可写纹路、触感、温度（B 档新，A 档先天无瘢痕）
- 与肩离断的区别：**这里能写"她把残端抬起来"**（有杠杆），肩离断不能

## 幻肢感

> 档位决定"真不真"，见 `topics/timeline.md` 档位总表。

- 肘离断：觉得前臂和手还在，能"握拳""屈肘"，实际没有
- 腕离断：幻手最完整（手指、掌心的感觉最清晰）
- **B 近期档（真）**：真的想用 → 残端跟着发力 → 动作未完成 → **落空**
  - 「她伸手去接，手指握了个空，杯子摔了」
- **C 多年档（不真）**：不会真想用 → 仅残端肌肉抽动 → **无后果**
- 频率服从时长档位，A 档 0 次；**须有剧情触发**

## 受限清单

> 推导方式：不可能动作 → 放进具体事件（上肢不依赖拐杖，辅具依赖轴弱）

- **无手指精细动作**：解扣子、捡小物、撕薄膜、数钱、系鞋带做不到
- **拧 / 掰 / 撕做不到**：瓶盖、罐头、包装——须台面固定或借助工具
- **双臂协同做不到**：端大盆、搬大件、撑开袋子
- **肘离断额外**：无前臂，旋前旋后做不到（转不了掌心）
- **残端承重有限**：顶住可以，长久撑住身体不行
- **假肢不是万能**：义手能做的有限，精细活仍要靠单手与工具（见上）

## 不可能动作（供 `core/physio-audit.md` 扫描）

- 患侧抓/握/捏/拧/托/推/拉/提（无手）
- 患侧屈腕、握拳、手指动作（无腕无手）
- 双臂协同持物（如双手端盆）——须给单手替代或求助
- 肘离断额外：前臂旋前/旋后、屈肘承重发力（无肘无前臂）

## 写作要点

- 单手日常的变通是主要看点，见 `topics/one-handed-daily.md`
- 残端"能做事"是这两类区别于肩离断的最大爽点：夹、撑、顶、转、按
- 回避清单同样适用：不写幻肢痛、残端溃烂、伤口处理
