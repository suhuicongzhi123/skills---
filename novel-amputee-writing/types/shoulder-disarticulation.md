# 肩离断生理事实

> ★上肢截肢。肩离断（shoulder disarticulation）：整条手臂经肩关节离断，锁骨与肩胛骨完整，无肩关节，无残肢。
> 写作总则：重受限不便、幻肢感、裸露场景残肢/剩余部分细节（重点）；日常样态为次重点；回避苦难叙事（幻肢痛、肩部劳损、伤口处理）。
> **本类型不适用下肢专项**：拐杖（`topics/crutch-*.md`）、双手占用（`topics/hands-occupied.md`）——肩离断者下肢健全，不需拐杖；"手少"而非"手被占"。

## 形态
- 整条手臂经肩关节离断，**锁骨与肩胛骨完整，无肩关节，无上臂残端**（与肘离断的关键区别）
- 患侧肩以下空，肩峰突出，锁骨可见
- 肩部肌肉（三角肌残部、胸大肌、背阔肌等）保留但止点改变，**剩余肌肉与软组织可收缩颤动**
- 瘢痕沿肩关节周围，常呈弧形或纵向，愈合后一条带状疤
- 两侧不对称：患侧肩以下空，袖管空

## 拐杖使用差异
- **不适用**：肩离断者下肢健全，不需拐杖
- 注：若合并下肢伤患才用，本类型默认不注入 `topics/crutch-*.md`

## 假肢使用差异
- 肩离断假肢：自带**肩关节+肘关节+腕手**多组件，接受腔包裹肩胸
- 又重又难控，无残肢主动驱动，靠胸背肌带动假肢摆动
- **日常多弃用**，留作正式场合/外观/拍照/特定社交
- 肌电假肢：可做开合手、屈肘，但控制粗放、耗电、需训练
- 美观假肢（被动）：硅胶手壳，外观优先，无功能
- 穿脱需他人协助或单手对镜（接受腔套肩胸，系带/扣）
- 穿久肩胸有压痕、闷热（只写日常不便，不渲染痛苦）

## 日常动作差异
> 详见 `topics/one-handed-daily.md`（跨上肢类型复用）

| 动作 | 样态 |
|------|------|
| **吃饭** | 单手执筷/勺；切大块需预切或用叉；端碗靠桌沿或双腿夹 |
| **穿衣** | 套头衫先套健臂再钻头，脱则先退头再退健臂；纽扣/拉链单手难，常穿松紧/磁扣/套头 |
| **裤/鞋** | 单手系鞋带难，常穿一脚蹬/松紧鞋；穿裤单手提拉可行 |
| **写字** | 健手写字无碍，但压纸靠重物/身体/下巴 |
| **开门** | 单手拧门把可行，推门靠身体 |
| **提物** | 单手提，重物靠腿夹/背/头顶；双手提物不可能 |
| **拧瓶盖** | 单手拧难，常夹腿间拧或用开瓶器 |
| **绑鞋带/细绳** | 单手极难，常改一脚蹬或预绑 |

| **上下车** | 单手开门，上下车无碍 |

## 身体细节
**剩余肌肉软组织收缩颤动**（慕残者关注重点，多写）：
- 患侧肩部及胸背剩余肌肉（三角肌残部、胸大肌、背阔肌、冈上肌）与软组织可**自主收缩或反射性颤动**
- 触发：用力、咳嗽、打喷嚏、体位变动、情绪波动、冷刺激
- 样态：患侧肩胸肌肉抽动/颤动/一缩一松，可见可触
- 写作：可写"那一边的肩头轻轻一抽""胸侧的肉跟着呼吸一颤一颤""他一使劲，空荡荡的那边也跟着缩了一下"

**其他细节**：
- 坐姿：患侧肩以下空，袖管扁瘪空垂
- 瘢痕：肩周带状疤，可写纹路、触感、温度
- 不对称：穿衫后患侧袖管空，走路时空袖管不晃（无残肢带动）
- 肩峰突出、锁骨可见——骨架感

## 幻肢感
> **写幻肢感，不写幻肢痛**（回避苦难叙事）

- **感觉整条手臂还在**：能"感觉"到幻肢的手指、手掌、腕、肘、肩，甚至能"动"幻肢（屈肘、握拳、张手），但实际没有
- 错位感：下意识想用两只手抓东西，伸出去却落空——"觉得手还在，想抓却抓了个空"
- 用幻肢"发力"会落空：推门、提物时下意识用幻肢，结果没有
- 慕残者代入点：幻肢感是代入截肢者体验的重要通道，可多写、写细——让读者跟着主角"感觉那条不在的手"

## 服装
- 上装患侧完全空（无残肢），裁剪至肩处
- 不写空袖管飘荡，写裁剪缝合/折叠塞肩（打结仅限刚截肢不久+公用服装）
- 视觉信号：上装已裁剪→一眼便知；详见 `topics/clothing.md`
- 下装无碍

## 不可能动作
> 患侧整条手臂无（肩以下空），以下动作患侧**实际参与**即违规（幻肢感豁免，见 `core/physio-audit.md`）：
- 双手操作（双手合十、双手夹、双手握、双手绑、双手拧）
- 患侧抓/握/捏/托/推/拉/提（无手无前臂）
- 患侧屈肘/屈腕/握拳发力（无肘无腕无手）
- 双臂并拢/双臂交叉（无手臂可并）
- 患侧搭肩/环抱（无手臂）
- 患侧撑地/扶墙（无手臂）
- 注：单手（健手）操作可行；幻肢感内容豁免
