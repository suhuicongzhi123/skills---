- **性质**：PATCH（9.5.0 → 9.5.1）。修复全库审查发现的14个问题（1个P0、3个P1、6个P2、4个优化建议），

- **触发**：系统性全库审查（62个md文件、10个Python脚本），交叉验证多专项文件间的冲突与逻辑漏洞。

### 一、P0级修复（严重问题）

**1. 双侧髋离断"空椅面"概念混淆风险**
- **问题**：`types/hip-disarticulation.md` 行136描述"那半边椅面空着"，
  与 `core/audience.md` 双侧髋离断不取"空椅面"的判据存在表述冲突，
  容易被误读为"臀部悬空"。
- **修复**：
  - `types/hip-disarticulation.md#身体细节` 改写为"臀部压住椅面，**椅面前方没有腿伸出**"，
    删除"那半边椅面空着"表述
  - `core/audience.md` 坐面对照表增加"⚠️ 关键区别"行，明确"空"指的是**椅面前方没有腿**，
    不是臀部悬空

### 二、P1级修复（重要问题）

**2. 髋离断假肢能力描述的隐性矛盾**
- **问题**：假肢"步态机械、耗力"与"日常多弃用"的关系不够清晰，
  实际使用场景（正式场合/外观/社交）与"日常移动"的分界模糊。
- **修复**：`types/hip-disarticulation.md#假肢使用差异` 新增**使用场景分层表**：
  - 日常室内/短距离/外出：双拐（省力）
  - 正式场合/社交/拍照：假肢（外观需求）
  - 需要腾手的工作：假肢+单拐（解放双手）
  - 明确口径：日常使用率远低于膝上假肢，**不是她"不够努力"，是生物力学限制**

**3. 单腿跳"连跳能力"口径与幻肢感档位的潜在冲突**
- **问题**：近期档"她真的想用"的触发机制与"连续跳十几步"存在张力。
- **修复**：`topics/mobility-modes.md#二、体力节奏` 增加**近期档特殊口径**：
  - 连续跳动中**每5-8步可能出现一次**"想用患侧支撑"的幻肢感触发，导致失衡或摔倒
  - **多年档无此限制**（身体已适应）
  - 理由：近期档"想用"的机制在连续落地时高发

**4. 自查分级与机检代判的边界不清晰**
- **问题**：机检 [18] 代判了11项，但语义半区（受限层级判定依据、标点三禁语境合法性）
  边界模糊，容易产生"假通过"。
- **修复**：
  - `scripts/gatecheck.py` [18] 增加**边界声明**：
    "本项只判枚举合法性与可算术性，不判语义正确性。语义半区仍由冷读把关。"
  - `templates/chapter.md` G11组S42增加提示：
    "⚠️ 机检已验证文本模式，**但语境合法性需人工复核**"

### 三、P2级修复（次要问题）

**5. 上下肢复合注入规则的执行优先级不明确**
- **修复**：`SKILL.md#五-补` 新增**冲突仲裁规则**表：
  - 起身/坐下：下肢为主，上肢为约束（髋离断+肩离断：健腿蹬地+**单手**撑地）
  - 假肢穿脱：下肢设备+上肢操作能力（需双手套接受腔→肩离断者需他人协助）
  - 拐杖使用：下肢需求+上肢持握能力（髋离断需双拐，但肩离断者**无法持双拐**）
  - 蹲下做事：健腿单腿蹲+一手支撑，**腾出的手数=剩余上肢数**
  - 通用原则：复合不是"优点相加"，是"**限制相乘**"

**6. 器具禁令的"个人痕迹"边界模糊**
- **修复**：`core/audience.md#★器具损耗与更换禁令` 新增**四类合法边界**：
  1. 体温/汗渍/手茧痕迹
  2. 主动改造/标记（刻字、绑布条做标记）
  3. 使用习惯痕迹（因她的步态）
  4. 情感载体/来历
  - 增加**易混淆案例表**：明确"拐杖上绑了布条"（防滑标记=✅；遮损耗=❌）等边界情况
  - **判定铁则**：是"她与器具的关系"还是"器具本身的状态"？前者可写，后者不写。

**7. 情感层"篇幅权重"判据的可操作性问题**
- **修复**：`core/emotion.md#〇` 新增**篇幅权重统计规则**：
  - 事件切分：一个明确的目标 = 一件事
  - 篇幅统计：标记所有段落→累计非空白字符→排除通用场景描写
  - 示例：3000字章节的事件A/B/C分别460/750/120字，排序B>A>C，
    判定第一名是否为她最在乎的事

**8. 强度层"峰值段位置"的百分比计算基准不明**
- **修复**：`core/intensity.md#一` 新增**峰值段位置计算方法**：
  - 分母 = 全章总字数（非空白字符，含标点）
  - 位置 = 峰值段**起点**在全章的百分比
  - 占比 = 峰值段总字数 ÷ 全章总字数
  - 示例：3000字章，峰值段从第2000字开始到2600字结束 → 位置66.7%、占比20%
  - 边界情况：单场景章/短篇/战斗章的放宽口径

**9. 冷读"独立发现"的判定标准循环依赖**
- **修复**：`core/workflow.md` 新增**冷读报告受理验收流程**完整章节：
  - 验收6步骤：覆盖数→生成指纹→输入隔离→引文实证→主语纯净→独立发现判定
  - 独立发现判定细化：
    - 机检信号（gatecheck [13]）：一致率≥95% → WARN
    - 人工复核：对比引文/论证路径/实际问题
    - 裁定：合法同判（接受）vs 伪装同源（退回重审）
  - 记录留痕：账本工作流日志记录验收结果
  - `scripts/gatecheck.py` [13] 注释删除"主代理受理时裁定"表述，改为明确引用workflow文档

**10. 账本枚举表一致性检查的提示不够明确**
- **修复**：`scripts/gatecheck.py` [25] 改进提示文案：
  - 增加**修复方法**三步：对比templates → 手动同步 → 或运行sync-enums命令
