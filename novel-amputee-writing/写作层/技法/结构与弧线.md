# 结构与弧线（全书、分卷、章节与结局）

> 类型无关。用于搭建全书骨架与承诺—兑现关系，不提供统一卷数、章数和结局模板。
> **分工**：章间见 `写作层/技法/章节规划.md`；场景见 `写作层/技法/场景构建.md`；人物与情节素材见人物库和情节模式库。

> **目录（按需读取，勿整体加载）**：一 叙事层级｜二 全书生成｜三 结局规则｜四 分卷与分段｜五 体验变化｜六 结构原则｜七 弧线组件｜八 结构常见病｜九 铺垫与兑现｜十 截肢题材适配｜十一 情节引擎｜十二 全书级钩子

## 一、叙事层级

常用五个层级，按篇幅删减而非全部堆叠：

- **全书**：一个持续的核心问题或阅读体验。
- **卷／段**：较大的自足阶段，可共享一个阶段问题。
- **弧**：围绕一个选择、目标或关系形成的连续变化。
- **章**：一次可辨识的推进、深化或收束。
- **场景**：人物在具体时空中的行动与经验。

每层都可以问：承诺了什么、推进了什么、兑现了什么、留下了什么。不是每层都必须有新危机。

## 二、全书生成

可用以下问题生成一个真正不同的故事，而不是先选模板：

1. **目标**：主角最想完成的具体事情是什么？
2. **阻力**：谁或什么系统性地使这件事困难？
3. **独特条件**：本书最不可替代的人物关系、世界规则或身份是什么？
4. **代价与选择**：主角可能在两条都有损失的路之间如何选择？
5. **情绪体验**：本书主基调与主要情绪收益是什么？轻快、温暖、幽默、看见的愉悦、身手爽感、战果畅快或压抑如何构成，而非默认伤痛深刻？上述是基调与情绪收益，不是 `写作层/素材/受众定位.md#3.1` 的主导体验类别；两者同时登记、分开验收。
6. **主导体验**：本书主导体验登记审美、受限、能力展示、成为中的哪一种？至少一场显著看点放在何处（全书或完结批次核验）？定义与验收见 `写作层/素材/受众定位.md#3.1`。
7. **终局**：读者最后会看到目标实现、失败、变形还是有意开放？

- 核心问题可以一个，也可以多条相互制约，不要求所有书只有一个总问题。
- S0 与重大转折可比较少量实质不同的因果方案，看目标、信息、选择和后果是否真正不同，不默认采用模型最先想到、只换职业或地点的答案。
- 目标可以在故事中改变，改变目标不等于换书，关键是有因果。
- 截肢可以参与目标和阻力，但不默认答案就是“接受自己”。

## 三、结局规则

- 主要承诺要兑现、明确否定或有意开放，不能因作者忘记而悬空。
- 代价在人物实际选择发生时结算，不固定倒数第三章永久失去某物。
- 关系和次要线按故事需要收束，不要求倒数第二章至少落定三条。
- 最后一章可以是新常态、余波、决战后一刻或开放问题，不强制写“之后的日子”。
- 可以回扣首章意象，也可以完全不回扣；若使用，意义必须有所变化，不能只是重复物件。
- 续作空间可以存在，但不能以续集预告替代本书结局。

## 四、分卷与分段

- 卷和段用于组织阅读，不是“长篇不分卷必塌”。章数、字数和卷数按结构需要。
- 每卷或每段可有一个阶段问题、一次升级和一个落点，不必同时满足三件套。
- 一卷可以包含多弧，也可以只有一弧；卷末不必同时是弧的解决章。
- 短作品可只有一章、几个场景或一个连续弧，不套用四卷四段。
- 首卷先建立本书的核心体验，不要求第三章前完成一次固定循环。

## 五、体验变化

可以用以下维度检查各阶段是否同构：

- **处置方式**：独力、协作、依赖、主导、放弃、反击或接受。
- **主导变量**：空间、时间、信息、关系、资源、规则或身份。
- **阶段体验面向**（弧线变量，不是验收分类）：身体在场、能力代偿、关系交托、主体选择、探索、悬疑或平静。项目主导体验只登记审美／受限／能力展示／成为之一，定义与验收见 `写作层/素材/受众定位.md#3.1`，本节不是验收分类。
- **世界面**：新人物、新地点、新规则、新过去或新未来。

这些只是分析维度，不规定“归属不能在第一卷、他者不能在第四卷”。人物可以从独立开始，也可以从依赖、共生或黑暗处境开始。

## 六、结构原则

1. **因果优先**：后果和选择比单纯时间顺序重要，但顺叙不是错误。
2. **压力与承诺变化**：可升高、换类、转向或揭示，不要求始终升级。
3. **铺垫与兑现**：重要结果需要有条件，重要铺垫需要有意图；未兑现的留白必须是有意。
4. **张力与释放**：可以连续紧张，也可以长时间平静，按阅读体验调整。
5. **用户指令**：用户指定优先于结构偏好，AI 可在确认的总纲内自主创造，不为维护模板而拒绝好点子。

## 七、弧线组件

常见组件可按需使用：

- **进入**：人物、关系或问题被推到台前。
- **复杂化**：先前选择带来新条件，不一定是更大敌人。
- **中点变化**：信息、目标、关系或冲突性质改变，可早可晚。
- **危机与选择**：人物面对价值冲突、资源极限或不可逆后果。
- **结果**：局面、关系或理解形成新状态。
- **余波**：后果被消化，下一问题自然产生或故事闭合。

有些弧没有明显 midpoint 或 crisis 也成立，尤其是日常、氛围和人物研究。

## 八、结构常见病

- **中段松**：同一障碍重复，条件和意义没有变化。
- **结尾赶**：重要后果没有足够空间被人物和读者消化。
- **注水（filler）**：精彩段落删除后不影响任何人物、关系或世界状态。
- **断链**：场景各自成立，但行动与结果缺少因果。
- **平台期**：利害长期不变且没有新的信息、关系或体验。
- **假升级**：只增加敌人数量、伤势和爆炸，而人物选择没有变难。

## 九、铺垫与兑现

- 缺铺垫的反转像作者临时救场。
- 铺垫后没有回收会消耗读者信任，除非它本来就是氛围或人物细节。
- 铺垫太显眼会提前泄露答案，但熟悉类型后的读者也可能享受预见，不必追求人人首读不可见。
- 可以在后文修改旧铺垫的含义，但要保留旧事实，不静默吃书。
- **改向钩子**：提到前史、旧伤或新组织不等于必然改向，要看作者实际准备让它承担什么。若意图是改变核心冲突、主角长期目标或主要类型体验，写入正文前先按重大改向确认；尚未证实的反派说辞不能掩盖真实改向意图。
- 只保留可能性而未决定展开时可登记候选钩子，不要求立即确认，但候选不等于后续已获授权。失腿旧案、复仇和阴谋均可写，不默认把截肢前史升级成主线谜题。

## 十、截肢题材适配

- 核心问题由人物和题材决定：真相、关系、职业、冒险、生存、欲望或自我理解均可。
- 自我接纳是合法主线之一，不是禁区，也不作默认。
- 截肢可以作为主线、副线、身体条件、社会经验或感官来源，不强制“只能副线”。
- 身体与环境共同影响行动，不把所有冲突归因于身体，也不禁止制度与环境冲突。
- 幻想世界可选择肢体能否恢复、如何恢复及其代价，不必用“任何题材都不可治愈”代替世界设计；若主题是永久截肢，须在设定中明确并保持一致。
- 人物欲望不必围绕截肢，但身体也不应成为可以被一键删除的装饰。

## 十一、情节引擎

| 引擎 | 可用骨架 | 可挖的核心问题 |
|---|---|---|
| 截肢与重建 | 事件→恢复→生活重建 | 如何在新条件下生活与选择 |
| 身份与伪装 | 隐藏→破绽→坦白或继续 | 谁有权定义一个人 |
| 渐进改造 | 决定→后果→再次选择 | 渴望、边界与自我如何变化 |
| 日常群像 | 单元事件→关系与社区积累 | 普通人如何共同生活 |
| 康复与照护 | 伤病→训练→独立或互助 | 自主与依赖如何重新定价 |
| 关系与婚恋 | 相遇→试探→选择与后果 | 爱、欲望、权力与信任如何平衡 |
| 公开身份与歧视 | 暴露→冲突→应对与后果 | 谁拥有解释身体的权力 |
| 黑暗与控制 | 控制建立→应对→逃脱、反抗或沉陷 | 自由、同意、依赖与生存 |
| 幻想与冒险 | 世界规则→探索→代价与选择 | 力量、身体和目标如何相互改变 |
| 职业与调查 | 任务→证据→判断与行动 | 专业知识、信息和正义如何碰撞 |

引擎只是起点，具体故事应由独特人物和因果生成，而不是照表换皮。

## 十二、全书级钩子

可以建立以下持续线，数量按作品需要：

- **主冲突**：真相、威胁或目标如何持续变化。
- **人物心愿**：一个具体愿望如何被接近、改变或放弃。
- **软肋**：人物最害怕失去的东西如何影响选择。
- **关系里程碑**：关系如何在行动中改变，不必固定五个节点。
- **物件与装备**：来历、私人意义、借用、剥夺、维护、替换和归还如何参与故事。

持续线必须有后续，但不要求每条都在每弧出现。器物正常维护、维修、替换和淘汰都可以成为人生事件，不必只保留夺走与取回。
