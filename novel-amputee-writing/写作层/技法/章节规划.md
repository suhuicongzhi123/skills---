# 章节规划（章与章之间的编排＋开篇切入）

> 类型无关。`写作层/技法/结构与弧线.md` 管全书骨架，`写作层/技法/场景构建.md` 管场景，本文件管章间承接、主导体验的章级编排、开篇和亲密位置。
> **使用原则**：规划记录必须足以支撑写作，但章级结构不是配额表。除事实、安全和用户明确指定外，可按故事自然形态调整。

> **目录（按需读取，勿整体加载）**：一 章级要素｜二 主导体验的章级编排｜三 主冲突线｜四 解法与变奏｜五 章末落点｜六 场景与后续｜七 章间连接｜八 章节功能｜九 开篇切入｜十 亲密戏位置｜十一 用户指定剧情

## 一、章级要素

规划时建议回答以下问题，不要求每项都成为显眼事件：

| 问题 | 用途 |
|---|---|
| 本章推进或深化哪条线？ | 判断存在价值 |
| 谁想做什么，为什么是现在？ | 建立行动与时机 |
| 哪个信息、关系、位置或选择发生变化？ | 判断落点 |
| 读者会期待什么？ | 建立阅读承诺 |
| 身体事实如何参与？ | 防止截肢只成标签，也防止硬塞 |
| 主冲突是推进、蓄势还是有意留白？ | 检查主线是否失控 |
| 章末如何收？ | 形成闭合、余味或拉力 |
| 下一章承接什么？ | 保证连续性 |

- 呼吸章可以只有关系、感受或世界细节的变化，不必制造 turn。
- 阅读承诺可以在本章兑现、推进、翻转或有意留到后文，不要求所有问题立即回答。
- 若一章只是必要过渡，也要确保它提供新的条件，而不是重复起点。
- 章纲是章级任务单，不必预写全部镜头与台词。关键对话只另记各方意图／需要、顾忌或不可退让处、可交出的信息／行动及回应后的策略／关系／行动变化；谈判与对抗再明确要价和交换。迅速理解和合作可以成立，不把“接纳、原谅、站队”预设成唯一正确答案。

## 二、主导体验的章级编排

> 先按已登记的主导体验安排显著看点，再决定本章是否需要核心受限。四种体验都不是每章配额。定义与验收见 `写作层/素材/受众定位.md#3.1`。

### 2.1 触发、层级与显著看点

- 层级测试与全类型非受限基线见 `写作层/素材/受众定位.md#六`，本章不复制定义。穿搭与亲密默认不算受限，升级条件回指该节；受限桥段合理性（辅具离手须有客观原因、先排除简单解、匹配角色熟练度、不隐形没收健侧能力）见 `写作层/素材/受限场景库.md#1.2`。
- 显著看点只验收已登记的主导体验：审美看情境、态度和感官结果，困难不是必要条件；受限看常用办法不可用之后的取舍与下一步改变；能力展示看难事如何做成，不能填补受限缺口；成为看向往与选择如何改变关系、计划或身体图式，凝视不能代替。吸引力分级与详略标尺见 `写作层/素材/受众定位.md#3.2`、`写作层/素材/受众定位.md#5.4`。
- 一章可以没有核心受限，也可以有多处，只要它们确实属于同一事件链。审美、能力展示或成为主导时，不要为凑受限另造功能缺口。
- 不因为“最终办成了”就否定受限，也不因为“有身体细节”就算核心受限。
- 审美主导不因缺少功能取舍判缺席。受限主导才写缺口、取舍和结果。章纲不要预写理由台词，正文也不写选择理由；取舍用动作和后续状态呈现。成本比较留在规划与审查。普通上下楼、行走、起身、解形取拐及各类型熟练日常基线动作不计入受限。

### 2.2 戏剧宿主与主线咬合

先立人物已经在乎的目标，再让身体条件影响路径。不要为补身体镜头凭空制造跌倒、故障或围观，更不要把章节写成“前半章演毫无身体特征的健全人剧本＋后半章硬切一段孤立看点戏”的两张皮。

- **主线咬合设计**：规划核心重场时，优先让角色的截肢平面、装备特性或代偿习惯直接成为**破局手段、冲突导火索、身份辨认线索或关系拉扯支点**（让身体姿态、装备状态或按 `写作层/素材/受限场景库.md#1.5` 选型的四类自然窗口直接改变当前谈判、调查、追逃或人际互动的走向，❌ 跨书套用固定桥段）。相邻章的受限／代偿窗口须变换触发轴向（时间抢拍／空间挤压／动态对抗／双任务并发），防止跨章桥段同构。
- 成功代偿、器具变通、载具、协作与求助都可以是有效解法；有完整健腿即禁轮椅。
- 长期熟练的日常不需要每章困难化；新环境、不同任务和状态变化更容易产生自然素材。
- 连续多章没有核心受限不是错误，检查是否主线确实以关系、悬疑、职业或其他冲突为主。

### 2.3 主旨参与

每隔一段故事，检查截肢是否至少以某种方式影响了人物的选择、关系、代价或世界，而不是只在开头贴标签。

- 可以连续多章以其他剧情为主，不必每弧都强设“主旨锚”。
- 若删除截肢后全书基本不变，说明身体设定没有真正进入故事，而不是需要增加更多身体特写。

### 2.4 主基调与情绪收益

- 章纲记录本章主基调与实际情绪收益，轻快、温暖、幽默、看见的愉悦、身手爽感、战果畅快或压抑均可按项目选择。上列是基调与情绪收益，不是主导体验类别；两者同时登记、分开验收。须点名温度或活气落在哪一场、哪句对话或哪处关系。
- 若项目约定轻快或爽燃，检查连续伤痛、压抑独白、透支和新危机是否挤占体验；高潮战果须保留，不刚赢就全部抵消。
- 正向体验不是只被允许，按承诺实际设计；功能受限与轻松主动可以并存。用户未指定情感色彩时默认带一笔温暖或活泼；明示阴沉或压抑时遵守契约，苦难不能成为唯一质地。高压章也要有活气，不为“不够阳光”判失败。见 `写作层/技法/强度与情感.md#2.7`。

## 三、主冲突线

- **推进**：对抗、竞争、调查或目标发生实质变化。
- **蓄势**：威胁、信息、关系或条件正在形成压力。
- **留白**：本章有意转向其他线，能够产生节奏、对照或铺垫。
- 强对抗题材不宜长期只有留白，温馨和单元剧则可更大弹性。
- 危机章应兑现此前承诺，不靠突然新增敌人抬强度。
- 截肢受限与主线冲突分开记录，同一事件可同时属于两者，但不必互相凑数。

## 四、解法与变奏

- 人物可以形成稳定的打法、习惯和偏好，这些是个性，不是重复。
- 查重看“同一条件＋同一动作＋同一结果＋同一意义”是否反复，而不是同一招在第几章出现几次。
- 同义信息、同镜头与身体事实的复读另按 `写作层/素材/受众定位.md#4.5` 判断；场景用途不同不自动豁免，有效复现也不需每次证明新意。
- 敌人可以重复使用有效策略，主角可以改变信息、位置、装备、协作或目标来应对。
- 变奏可来自新条件、新视角、新后果、新代价或新理解，不能只换道具和同义词。

## 五、章末落点

### 5.1 常见类型

- 悬念：即将发生什么。
- 决定：选择已做，后果未至。
- 到来：人或事正在接近。
- 威胁：明确的损失正在形成。
- 倒计时：截止期限推动下一步。
- 抉择：两条路都有代价。
- 揭示：真相出现一角。
- 心动或越界：关系与身体边界变化。
- 情绪：未消化的感受。
- 画面：有重量的视觉或感官落点。
- 回声：与前文物件、台词或动作形成呼应。
- 闭合：本章问题得到回答，不需要再抛出新问题。

### 5.2 使用原则

- 落点由本章内容决定，不设强钩比例和类型轮转。
- 卷末、弧末和全书末章可以强钩，也可以闭合，不必指向下一卷。
- 末章不必回扣第一章意象；若使用，须因意义自然形成，而不是为“读完感”硬凑。
- 章末可以停在解释、感受或决定，不强制只能落在动作与器物上。

## 六、场景与后续

- 场景以目标、条件、行动和结果连接，后续可以消化反应、作出决定或直接进入下一场。
- 场景之间优先有因果，但时间顺序和空间移动也可成立，不禁止“然后”。
- 视角人物知道什么、读者知道什么、其他角色知道什么要分清，避免信息无来源。
- 新信息按读者理解需要投放，不一次性倾倒，也不靠人物复述彼此都知道的事。
- 视角切换要有明确标记和理由，不能为解释另一方动机随时跳脑。

## 七、章间连接

- 上一章的落点要在本章被接住、转化或有意留白，不能无声遗忘。
- 时间跳跃交代跨度以及人物、装备、关系和伤病的变化。
- 视角切换在章首或场景边界标清。
- 上一章强钩可以在本章立即兑现，也可以继续持有，取决于承诺是否值得等待，不设“第二章不得兑现”。

## 八、章节功能

常见功能包括主线推进、关系深化、日常经验、对抗危机、生存压力、氛围与过渡。

- 不按题材给固定比例，真实章节可以一章多功能。
- 连续同类章节可以形成深耕，也可以是疲劳，判断依据是是否有新的条件、信息和体验。
- 若中段开始重复，优先改变问题的性质、人物目标或代价，而不是只换敌人和地点。
- 高潮后可有呼吸，也可连续推进，节奏以读者理解为准。

## 九、开篇切入

### 9.1 切入维度

- 动作进行中：任务、追逐、转移、工作、争吵或选择。
- 感官与身体：幻肢、温度、触感、衣物或身体认知。
- 他人目光与误判：被看见、被误解、被提问或被忽略。
- 器具与物件：有来历或当前状态的物品。
- 关系瞬间：相遇、重逢、告别、亲密或冲突。
- 日常反常：与人物习惯不同的具体变化。
- 对话起笔：由声音、信息和关系直接进入。
- 回忆与前史：只在能塑造当前问题时使用。
- 环境与空间：让地点规则直接影响人物。
- W 视角：向往、模拟、身份冲突或身体愿望。

### 9.2 多样性硬约束的边界

- 开篇维度按本书最独特的经验选择，不强制前三章类型不同，也不强制跨书避开同一有效入口。
- 若多次创作同设定，先比较核心目标、关系、信息和冲突是否不同，不必只换开篇标签。
- 首章需要有能支撑后续阅读的承诺，但不一定是对抗或悬念。
- 身体与受众细节按事件进入，不设黄金橱窗数量。

### 9.3 烂开篇反例清单的使用

- 晨间、苏醒、镜子、恢复期和器具清点只有在没有人物目标和事件时才优先返工，不把这些题材当禁题。
- 避免“意识回笼→身体逐件报到→最后发现残缺”的机械序列，但苏醒和恢复本身可以写得有效。
- 大段家世、医学和世界说明若没有影响当前选择，应移到真正需要的位置。
- 不要为了反套路而选择不适合本书的动作开场。

### 9.4 题材开篇约束

- 末世和生存题通常适合从事态中进入，但安全期的晨间和日常也能建立世界，不作绝对禁止。
- 现实温馨日常可以使用 routine，只要其中有独特人物、关系或问题。
- 古装和幻想可以从身体、关系、世界规则或职业进入，不要求先展示战斗。
- 每本书只选一个主要入口，也可组合，不必按题材分配固定维度。

### 9.5 与章末落点的联动

- 首章落点与开篇可以同源，形成完整闭环，也可以不同源，打开第二条线。
- 若首章已经以身体细节吸引读者，章末不必再换一个身体钩子来防重复。
- 检查首章的核心承诺是否在后续得到回应，而不是只比较钩型。

### 9.6 开篇拉力坡度

- 前三章可递增、回落或保持，关键是核心体验是否建立并被持续兑现。
- 首章钩子可以在第二章立即兑现，只要此后仍有新的问题和后果。
- 前置爆发型开篇之后可用后果和人物维持拉力，不必强行再升级敌人。
- 低冲突作品不必把前三章都改成强钩，日常吸引力也能支撑继续阅读。

## 十、亲密戏位置与间隔

- 亲密戏应有关系、人物、世界或受众价值，不必同时证明对主线有功能。
- 不用“发生关系后三章是否有台词变化”作为唯一删除判据，身体接纳和欲望本身就可以是正事件。
- 不用亲密戏机械解决外部冲突，但也不要求“下一章矛盾必须回来”。
- 首次亲密前的信任与同意按人物关系，不固定“被看见才能碰”。
- 首次直写可以早、晚或不发生，取决于故事和人物，不按全书百分比。
- 高浓度作品可以连续亲密，慢热作品也可长时间不发生；变奏看人物与意义，不机械更换体位、地点和道具。
- 亲密后的后果可以是关系、生活、情绪、信息或没有明显外部事件，不强制名声、怀孕或被撞见。

### 10.1 A 档非露骨亲密执行

- 看见：具体注意到人、动作、物件或身体，不把观看者设为必需。
- 接近：由双方意图明确的靠近、邀请或试探。
- 触碰：可撤回、可拒绝、可调整的非性行为接触。
- 收束：停下、继续、留白、转场或直接进入下一天。
- 后果：关系、称呼、行动、生活或情绪发生变化；没有外部变化时，亲密体验本身也可成立。

A 档可以直写想要、主动和拒绝，不把“没有拒绝”当同意；不读取成人目录，具体性爱与性器官内容不进入注入。**防过度自我阉割**：A 档禁的是性行为过程，**不禁止细腻的身体审美与非性行为触觉特写**（残肢／空处轮廓反差、卸具后的皮肤温差与压痕、手掌覆触或托举残端／腰胯时的软硬回弹与重量交托、拥抱时的呼吸与重心贴靠均完全合法，见 `写作层/素材/受众定位.md#3.1`、`写作层/素材/受众定位.md#5.4`）。

## 十一、用户指定剧情

- 用户明确指定的内容直接登记并落实，说明章位、影响和需要改动的承接，不额外夹带剧情。
- 模糊偏好转成可感知方向，如更多关系互动、更强对抗或更高身体浓度，不必伪精确到公式。
- 全自动模式下，AI 可在用户确认的总纲和边界内自主补全人物、场景与伏笔，不再逐项请求确认。
- 若新增内容会改变主线、既有结局或用户明确禁区，先暂停并说明，而不是一面全自动一面把所有创意都列为待确认。
- 与已写正文冲突时，列出改设定、修订旧章、保留矛盾为人物误判或另开平行线的实际代价，不静默改写。
- 用户指定章号优先尊重；若严重破坏因果，说明问题并提供最接近的实现方式，不机械压缩到失真。
