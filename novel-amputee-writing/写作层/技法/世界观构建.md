# 世界观构建

> **目录（按需读取，勿整体加载）**：一 建立字段｜二 缺失解释框架（全库权威）｜三 无障碍水平｜四 社会态度｜五 器具可得性与器具表自建原则｜六 题材特有设定｜七 硬约束
>
> **定位**：写作层技法。世界观在大纲阶段（S0/S1）建立，**全书锁定**，随设定与总纲落盘。世界观服务两个目的：**跨章一致性锁定**与**场景条件供给**。第二节是**全库权威**：缺失解释框架的定义、五框架表、锁定时机、框架→叙述措辞表只立于此，`基础层/身体细节与幻肢.md` 等文件一律指针引用，❌ 复述。铁则：**受限的来源是身体结构本身，不是环境缺陷**——无障碍水平只决定「这一处有多难走」，不决定「她是不是受限」；❌ 写以改造环境／控诉制度为主线的冲突。

## 一、建立字段

```yaml
世界观:
  时代:
  地域:
  无障碍水平: 完善 | 部分 | 缺失      # 场景难度系数：影响绕路、找支撑、耗时，不决定是否存在受限
  社会态度: 排斥 | 怜悯 | 平常 | 制度性不便
  医疗与器具:                        # 器具可得性与获取成本；损耗与更换情节禁写（回避清单见 写作层/素材/受众定位.md）
  题材特有设定:                       # 幻想向：魔法义肢的社会位置；末世：器具是否稀缺资源
  缺失解释框架: 常态化 | 神圣化 | 无解释 | 病因学 | 隐秘   # 一书锁一个；神圣化须用户显式选定，见二
```

## 二、缺失解释框架（全库权威）

「她为什么缺失」是设定层最大的收敛点——不加约束时，写作会反复收敛到同一套解释（如「残缺被解释为有意义的交换／馈赠」），导致多本书设定高度雷同。一书开始前从下表锁定一个，随世界观落盘，全书不变。锁定是为防雷同，补偿信念本身合法。

| 框架 | 含义 | 使用条件 |
|---|---|---|
| 常态化 | 人人如此／常见，无需解释，她也不觉得缺 | 默认选项；社会性受限类失效（无健全者对照系），受限写法贴常态视角（写技巧与吃力，不写缺失意识） |
| 神圣化 | 有形而上意义（神赐／使命／交换） | 须用户显式选定，❌ 默认收敛；补偿信念可写，❌ 格言式收束（判据见 `写作层/文风/反AI写作.md`） |
| 无解释 | 世界不回答，她也不问 | 文学／克制向；缺失是给定事实，不是待解的谜题 |
| 病因学 | 有医学／事故解释，但已淡化成前史 | 现实向常用；解释只出现在必要的回忆与手续里 |
| 隐秘 | 有解释但被权力遮蔽 | 悬疑题材用；「真相」须服务于核心问题，不是默认走向 |

- 锁定时机：与世界观同步，大纲阶段落盘，全书不变。
- ❌ 未锁定时自补解释——「为什么缺失」不回答就是回答（等于「无解释」框架）。

### 2.1 框架→叙述措辞

框架决定世界里的人**如何认知与谈论**身体缺失——叙述措辞与框架不符＝世界观违背。高发失误：常态化世界观下旁白惯性沿用「髋离断／患侧／残肢」等病理词——常态化世界里无人这样认知与说话，出戏点直给。

| 框架 | 叙述层／对话层措辞 | 病理词可用域 |
|---|---|---|
| 常态化 | 世界内平常语言——「左边」「空的那侧」「那条腿生来就没有」；天使／特殊种族世界用该世界的身体平常语 | ❌ 零容忍（髋离断／截肢／残肢／残端／患侧／假肢学名不得出现在叙述与对话） |
| 神圣化 | 宗教／神话语言（神赐／印记／誓约） | 仅仪式、经文引述场景 |
| 无解释 | 中性身体描述，不引入任何归因词汇 | ❌ 医学与宗教词都不用 |
| 病因学 | 医学叙事合法但限场景 | 限诊断、前史回忆、手续，不进日常叙述 |
| 隐秘 | 按遮蔽方的官方话语写（表层措辞），真相词只在内幕揭示后出现 | 揭示前禁，揭示后按真相话语 |

- **登记层不受限**：库内文件、大纲、角色卡用医学术语保精确（如「左髋离断、无辅具」）——那是技能层语言，不进正文；正文措辞按本表。
- 三个措辞层分查：旁白／内心／对话。高发位＝旁白惯性病理词；对话按说话人身份取词——常态化世界里旁人同样没有病理词汇。
- 身体细节与幻肢落笔时的两条措辞边界（观测点不越框架、医学场景窗口）见 `基础层/身体细节与幻肢.md#四、缺失解释与措辞边界`。

## 三、无障碍水平

档位定场景难度系数，全书一致：

| 档位 | 具体后果 |
|---|---|
| 完善 | 直梯可用、坡道贯通、无障碍厕位常有；代价是绕路到指定口、等梯耗时 |
| 部分 | 主干道有坡道、支线没有；老楼无梯、新楼有；找入口要提前看，走错要折返 |
| 缺失 | 台阶为主、无扶手、路面破损；须自己找支撑物、挑路线、预留一倍时间 |

- **现实向默认档＝缺失或部分**：现实中新建场所才有坡道、直梯、无障碍厕位，老楼老店多台阶；无障碍厕位常上锁（钥匙在保洁手里）、被占、当杂物间，设备坏了没人修；预约类服务要提前、到了仍要等——**多数时候她等的是人，不是电梯**。遇上一处好设施当「运气」写（这家商场居然有无障碍卫生间）；题材侧细则见 `题材层/现实向.md`。❌ 写「一路畅通、处处有坡道电梯、人人让道」的幻想式无障碍。
- 受阻的**表现**是绕路、等、求人、换地方、预留时间；❌ 写成因无障碍缺失而「无法通行」，❌ 写成环境控诉。哪些「被占」情形算合法受限素材，判定见 `写作层/素材/受限场景库.md`。

## 四、社会态度

态度越负面，「被看见」场景的张力越大；态度档决定冲突从哪来，不决定受限有无：

| 档位 | 路人行为模板 |
|---|---|
| 排斥 | 侧目、挪位、小声议论、被当成麻烦 |
| 怜悯 | 让座、硬要帮忙、夸「真坚强」、被当成励志对象 |
| 平常 | 不多看一眼、正常服务、偶有孩子直问 |
| 制度性不便 | 流程卡在窗口、要开证明、被要求「有人陪同」 |

## 五、器具可得性与器具表自建原则

器具须符合该时代的医疗与工艺水平——时代与地域决定「她能用上什么」：

- **现代**：拐杖规格与使用、假肢穿脱与使用按 `基础层/辅具-拐杖.md`、`基础层/辅具-假肢.md`（只覆盖现代工业制品）。
- **非现代（古装／古代／架空低技术）**：❌ 直接套用现代辅具文件，须按「器具表自建原则」在世界观里自建器具表，至少定四项：
  1. **材质与工艺**：该时代做得出什么（金属加工、皮革、木作的上限）；
  2. **形制**：与该类型身体和步态如何配合，支撑结构靠什么承力；
  3. **可得性**：谁能提供、要什么代价、普通人家用不用得起；
  4. **维护方式**：由谁料理（写进设定即可，❌ 展开成损耗与更换情节）。
  古装向的题材侧器具口径与时代豁免见 `题材层/古装向.md`。
- 获取成本与渠道写进「医疗与器具」字段；❌ 损耗与维修更换情节（回避清单见 `写作层/素材/受众定位.md`）。

## 六、题材特有设定

- 高科技／魔法可替代器具，❌ 替代截肢体验本身——魔法义肢的社会位置、叙事层豁免见 `题材层/幻想向.md`。
- **战斗豁免（高武／高魔／神话）**：可豁免的物理条目、能力名与来源、代价与失效条件须写进「题材特有设定」，未登记即不豁免；档位与边界的唯一权威见 `题材层/幻想向.md`。现实向恒零豁免。
- 末世：器具是否稀缺资源写进本字段——稀缺抬高的是获取难度，不改受限本身。

## 七、硬约束

- 世界观在大纲阶段确定，❌ 自主变更；用户显式指令可变更（按 `SKILL.md`「用户指令优先」口径告知影响并登记），中途变更须评估下游影响。
- 世界观不得与所选类型文件的生理事实冲突（`基础层/类型-*.md`）。
- 同一场景的无障碍条件全书一致：第 5 章地铁有直梯，第 11 章不得写成只有扶梯。
- 缺失解释框架全书不变，正文措辞按 2.1 表执行。
