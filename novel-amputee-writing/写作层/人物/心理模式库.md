# 心理模式库

> **目录（按需读取，勿整体加载）**：一 使用方法｜二 截肢者主体心理（M1–M15）｜三 黑暗与被支配（M16–M23）｜四 D 侧心理（M24–M26）｜五 W 侧心理（M27–M28）｜六 特殊与幻想（M29–M30）｜七 通用心理维度
>
> **定位**：M 编号是可能的心理机制，不是诊断，也不是角色必须完成的弧线。每个角色可以有与截肢无关的价值、欲望、偏见和人生问题。
> **使用纪律**：把机制落成具体情境中的选择，不把“羞耻→接纳→享受”“被照顾→依赖→沉沦”当默认时间轴。

## 一、使用方法

- 主导模式可取一个，也可没有明显模式；其余只作单场可能反应。
- 同一人可以同时自信、羞耻、享受、拒绝和反复，不必按阶段逐格升级。
- 黑暗与被支配条目须单独授权，明确自愿、非自愿和叙事立场，不用甜宠包装。
- 疼痛、幻肢、失禁和医疗问题必须有身体依据，不能由心理偏好反向制造生理事实。

## 二、截肢者主体心理（M1–M15）

| 编号 | 可用机制 | 使用边界 |
|---|---|---|
| M1 身体目光变化 | 从回避到习惯、展示或享受目光 | 可停在任何阶段，也可反复，不必以展示证明接纳 |
| M2 厌恶与利用并存 | 不喜欢身体某面，却借它获得资源、关系或表达 | 不把身体当唯一本钱，允许矛盾长期存在 |
| M3 幻肢体验 | 位置、感觉、运动和疼痛与身体现实错位 | 幻肢不等于不接纳，频率与病程按个体 |
| M4 空间参照变化 | 身体、装备和视角改变对空间的感知 | 不把每件小事都仪式化，具体环境与行动优先 |
| M5 性与感官重定位 | 探索新的敏感区、亲密方式和欲望表达 | 不假设性功能障碍，也不默认残端敏感 |
| M6 被观看的兴奋 | 目光、展演、认可与曝光带来兴奋 | 可与愤怒、隐私和反感并存，偷拍不自动暗爽 |
| M7 残肢情色化 | 特定人或关系把残肢纳入欲望 | 身体感受按角色，情色化与接触须授权；敏感不是必需条件，不把残端统一当性器官 |
| M8 亲密后的复杂感 | 亲密后空虚、羞耻、平静或满足 | 不把高潮后空虚当必经阶段 |
| M9 失禁与护理依赖 | 身体功能、羞耻、帮助和信任纠缠 | 必须有独立身体设定，不由截肢直接推导 |
| M10 拒绝同情与自证 | 不愿被怜悯，靠行动争取评价 | 不必事事自证，也可接受善意与帮助 |
| M11 身份认同 | 身体、职业、关系、残障和自我定义协商 | 不把“先是人再是残障者”当唯一正确答案 |
| M12 同类共同体 | 同经验者提供理解、资源与归属 | 同群体内部也有差异、竞争和冲突 |
| M13 创伤闪回 | 特定感官、地点或关系唤起创伤体验 | 需具体病史与表现，不随意当紧张特效 |
| M14 圈层身份焦虑 | 公众身份、面子与身体现实冲突 | 不只豪门，任何社会评价与职业都可使用 |
| M15 被爱怀疑 | 不确定对方爱人、身体、照顾还是控制 | 可通过长期行为回答，不能靠一次性爱解决 |

## 三、黑暗与被支配（M16–M23）

| 编号 | 可用机制 | 使用边界 |
|---|---|---|
| M16 物化沉迷 | 自愿把物化当游戏、身份或欲望出口 | 须明确同意，和非自愿剥夺分开 |
| M17 救赎与改造 | 被支持、被改变或被迫改变中的自我协商 | 不把更多截除当自然升级，须有独立决定与后果 |
| M18 圈养依赖 | 安全、安逸、自由与离开能力冲突 | 自愿包养与非法囚禁分开，不把依赖当浪漫证明 |
| M19 囚禁中的依恋 | 恐惧、生存、恨、依赖和幻想混合 | 不简化成“斯德哥尔摩”，不把依恋当同意 |
| M20 过载到迎合 | 反复失控后出现麻木、病态安全或主动迎合 | 可中断、反抗、反复，不当作唯一终局 |
| M21 疼痛偏好 | 特定疼痛带来强度、存在或性唤起 | 不将真实重伤、神经瘤痛和自残当普通玩法 |
| M22 完全掌控的无助感 | 交出决定权带来放松、欲望或恐惧 | 自愿与“没得选”必须区分，不能混成一句 |
| M23 人偶化心理 | 以物件角色卸下责任、羞耻或选择负担 | 角色 play 与真实失主体性分开，须可撤回 |

## 四、D 侧心理（M24–M26）

| 编号 | 可用机制 | 使用边界 |
|---|---|---|
| M24 隐秘身份 | 对取向、身体或关系的隐瞒与自我理解 | 不必从少年觉醒写到论坛，表现形式多样 |
| M25 吸引与宠爱 | 身体吸引、怜惜、保护和占有混合 | 不保证“无施虐欲”，也不能把占有包装成纯爱 |
| M26 怜惜与施虐双轨 | 爱慕、照顾、控制与伤害欲并存 | 可用于复杂角色，须面对行为和后果，不浪漫化操控辅具 |

## 五、W 侧心理（M27–M28）

| 编号 | 可用机制 | 使用边界 |
|---|---|---|
| M27 模拟与边界 | 通过扮演接近理想自我，同时保留现实边界 | 可永远停留在模拟，不必递进真截 |
| M28 求截与实现 | 模拟、确认、决定、手术与术后生活 | 重视长期动机、评估、代价与恢复，不写成冲动流程 |

## 六、特殊与幻想（M29–M30）

| 编号 | 可用机制 | 使用边界 |
|---|---|---|
| M29 身体与性别认同 | 身体部位、性别表达和自我认同互相影响 | 不把截肢写成性别焦虑的通用治疗，也不替自伤背书 |
| M30 永生与残躯 | 长时间改变对身体、损失和身份的理解 | 长寿不等于虚无或毫不在意，可有不同价值观 |

## 七、通用心理维度

避免所有人物都围绕身体转，可从以下方向补充：

- 好奇、厌倦、野心、嫉妒、愧疚、幽默、信仰与审美。
- 职业荣誉、金钱压力、家庭责任、友谊、竞争和权力。
- 对真相、正义、自由、秩序、亲密和独处的不同排序。
- 面对失败时学习、否认、推责、求助、复盘或放弃。
- 对他人误判、善意、自私和前后矛盾，而非永远正确或永远降智。
- 与截肢完全无关的人生目标、关系问题和道德选择。
