# 性格库

> **目录（按需读取，勿整体加载）**：一 使用方法｜二 主体性格方向（P1–P8）｜三 掌控与守护（P9–P10）｜四 处境与复合方向（P11–P24）｜五 恋人位与依赖自立（P25–P31）｜六 用于补充差异的维度
>
> **定位**：P 编号是灵感索引，不是完整人格，也不是固定台词包。每个角色另写目标、价值、知识、关系、决策方式和变化条件。
> **使用纪律**：可以只取一个侧面，也可以不取。允许多种性格共存于同一人，允许随场景变化，不追求每人都有“外表×内心”的固定反差。

## 一、使用方法

- 先问这个角色在故事里做什么，再选是否有可借用的性格方向。
- 不把“软糯＝喊哥哥”“泼辣＝骂变态”“独立＝拒绝辅具”“敏感＝反复确认”当公式。
- 相邻条目可以重叠，不必强行区分 P2、P5、P20、P24 等近义标签；使用时合并成真实人物。
- 黑暗、占有、疼痛与物化条目只提供人物可能性，需单独授权，不与普通甜宠混写。
- 心理健康、BIID、创伤和身份认同不用于替代完整人物，也不随意当诊断。

## 二、主体性格方向（P1–P8）

| 编号 | 可借用的方向 | 可避免的单一套路 |
|---|---|---|
| P1 清纯乖巧 | 体贴、怕麻烦别人、用懂事维持关系 | 不默认叠词、撒娇、讨好和身体顺从 |
| P2 泼辣嘴硬 | 直接、敢冲突、用攻击保护边界 | 不必夜里崩溃，不必每句毒舌 |
| P3 优雅从容 | 重视体面、审美、秩序和自控 | 不必眼底藏伤，不必永远得体 |
| P4 要强独立 | 喜欢自主、证明能力、重视选择 | 不等于拒绝辅具和一切帮助；轮椅只属于没有完整健腿的设定 |
| P5 严厉负责 | 高标准、职业化、愿意承担 | 不必用辱骂表达关心 |
| P6 敏感不安 | 善于观察评价、需要确认与安全 | 不必反复问“你嫌不嫌我” |
| P7 乐观豁达 | 能发现幽默、恢复力、带动气氛 | 不必创伤史，不必永远想得开 |
| P8 温柔依赖 | 喜欢稳定关系、愿意接受照顾 | 不等于没有主见或喜欢被控制 |

## 三、掌控与守护（P9–P10）

| 编号 | 可借用的方向 | 可避免的单一套路 |
|---|---|---|
| P9 冷峻掌控 | 重规则、观察、资源与决定权 | 不自动物化、收藏品化，须查授权与后果 |
| P10 温柔守护 | 用行动提供稳定、尊重选择、长期一致 | 不等于沉默无欲、包办一切或永远正确 |

## 四、处境与复合方向（P11–P24）

| 编号 | 可借用的方向 | 可避免的单一套路 |
|---|---|---|
| P11 偏执防备 | 警觉、猜疑、反复核查、难信任 | 不把精神疾病当戏剧装饰，须给经历与信息 |
| P12 幽默转移 | 用玩笑处理压力、活跃气氛 | 不必伪装坚强，也可只是天生幽默 |
| P13 羞涩被动 | 慢热、谨慎、表达含蓄、需要主动空间 | 不把不回答当默许，不把被动当同意 |
| P14 职业化抽离 | 重流程、价格、边界和情绪管理 | 不必唯利是图或隐藏创伤 |
| P15 倔强追梦 | 目标驱动、能长期坚持、愿意付代价 | 不必把自伤和截肢当爱的证明 |
| P16 娇气任性 | 会索取、会试探、喜欢被重视 | 不必生活无能，不必用假疼骗抱 |
| P17 从容主导 | 能控场、下决定、享受主导权 | 不等于冷酷或把亲密关系全当命令 |
| P18 破碎脆弱 | 易受伤、低自我评价、需要支持 | 不把静默、眼泪和自贬当唯一美点 |
| P19 身体自主 | 对身体形态有强烈而持久的认同诉求 | 不把 BIID 简化成“恨健康肢体”，须重视决定过程 |
| P20 傲娇多变 | 口是心非、戏谑、用闹腾测试关系 | 不把“嘴上说不要身体很诚实”当同意 |
| P21 D 方谱系 | 研究、合理化、忠犬、腹黑、冷幽默、施虐等 | 每种都须独立动机，不按慕残身份统一心理 |
| P22 心理反转 | 处境改变带来价值与行为重构 | 转变须有与事件强度相称的依据和后果；一章可发生决断或认知反转，不直接写成彻底治愈或人格无代价重置 |
| P23 自我欣赏 | 喜欢身体、愿意展示、享受审美与目光 | 不必镜前自恋，也不必以暴露证明接纳 |
| P24 口嫌体正直 | 口头矜持、行动表达需要、容易害羞 | 不把口头拒绝当实际同意，谨慎处理边界 |

## 五、恋人位与依赖自立（P25–P31）

| 编号 | 可借用的方向 | 可避免的单一套路 |
|---|---|---|
| P25 病娇占有 | 强烈怕被抛弃、独占、控制与极端化 | 不把囚禁和威胁当普通浪漫，须单列黑暗授权 |
| P26 掌控恋人 | 安排生活、重秩序、用照顾维持确定感 | 区分协商规则与以“为你好”剥夺选择 |
| P27 温柔照料 | 耐心、可靠、尊重、提前考虑需要 | 被拒绝后应能调整，不是“下次照旧” |
| P28 被宠依赖 | 会索取、享受宠爱、用撒娇换资源 | 不等于无能、颐指气使或全靠伴侣 |
| P29 倔强自立 | 自证、好胜、愿意独立完成任务 | 不以过用和自伤证明独立，可选择合适辅具 |
| P30 接受自洽 | 能谈身体、接受帮助、主动定义自我 | 不要求永远和解、永远积极或替别人解开心结 |
| P31 疼痛偏好 | 对特定疼痛、强度或控制感有偏好 | 须明确自愿与安全，不把真实伤病和神经病理痛当玩法 |

## 六、用于补充差异的维度

若所有角色仍像同一个人，优先改变以下维度，而不是继续加近义标签：

- 价值观：结果、规则、关系、自由、责任、公平、信仰哪个优先。
- 认知方式：证据、直觉、经验、权威、利益还是情绪先行。
- 社交方式：合作、支配、回避、讨好、独立、游戏化或公事公办。
- 情绪处理：直说、压抑、转移、幽默、爆发、分析或寻求支持。
- 生活态度：好奇、无聊、保守、冒险、实用、审美、怀疑或乐观。
- 道德灰度：愿意为什么事破例，撒谎、伤害和牺牲到哪条线。
- 日常质感：工作、饮食、消费、爱好、习惯、厌倦感和普通偏好。
