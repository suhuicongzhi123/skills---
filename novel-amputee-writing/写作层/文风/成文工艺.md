# 成文工艺

> **目录（按需读取，勿整体加载）**：一 叙事距离｜二 自由间接引语与叙述声口｜三 动作链压缩｜四 氛围｜五 长篇一致性｜六 编辑顺序｜七 局部编辑
>
> **定位**：处理叙事距离、动作省略、氛围、跨章变化和局部修订。物理连续不等于每一步都写出，文风一致不等于每章相同。

## 一、叙事距离

### 1.1 可选距离

| 档 | 位置与用途 |
|---|---|
| 远 | 时代、全景、概述和叙述者评论 |
| 中远 | 外部观察、群像和动作白描 |
| 中 | 常规第三人称限知或稳定叙述者 |
| 近 | 感官、判断和注意力贴近视角人物 |
| 贴脸 | 自由间接引语、未成形念头和即时感受 |

- 默认距离按作品需要，可在章内和全书变化，不要求锁定一档。
- 距离通过语气、词汇、信息和内心可入程度调整，不只靠换人称。

### 1.2 跳档与视角

- 跳档可由冲击、回忆、抽离、时间变化或叙述者选择驱动。
- 同一视角内不要无提示读取他人内心；全知叙述者则按其既定权限。
- 高张力可以贴脸也可以远观，呼吸章可以贴近也可以全景，不固定映射。无论远近，步骤清楚之后都要留下当场气氛与人物感觉，不要写成局外人的步骤清单；见 `写作层/技法/强度与情感.md#2.7`。

## 二、自由间接引语与叙述声口

### 2.1 自由间接引语

- 用第三人称语法保留人物的词汇、偏见、疑问和未完成念头。
- 不是删除所有“她想／她觉得”，必要时的标签反而更清楚。
- 贴脸不等于每句都短、都口语、都不完整。

### 2.2 叙述声口

- 叙述者可以有自己的立场和风格，不必每章刻意插入一句“人物判断词”。
- 环境经过谁的注意力选择，决定了读者看到什么；全知叙述者也可选择不同重点。
- 直接情绪、医学词汇和作者插话是否合适取决于既定叙述者，不按题材统一禁止。

### 2.3 注意力过滤

- 谨慎的人可能先看出口，冲动的人可能先看机会，疲惫的人可能什么都没注意。
- 不列视觉、听觉、嗅觉全通道清单，也不为了“过滤”删掉必要世界信息。
- 人物可以注意到不符合作者主题的东西，这种偏差能形成真实感。

## 三、动作链压缩

- **物理连续**：装备、支点、参与肢体和物品位置要能对上。
- **叙述省略**：常规动作根据读者已知程度压缩，不必每次完整分帧。
- 需要展开的情形：首次建立、方式改变、出现异常、影响目标或关系。拄拐与替代移动的分寸见 `基础层/行动库.md#8.1`，详略见 `写作层/素材/受众定位.md#5.4`。
- 可以压缩为一句结果、一个活细节或一段概述，不要求必须带数字。压缩后仍须留下气氛或人物感觉，不要只剩步骤清单；多余精确数字的取舍见 `写作层/文风/反AI写作.md#2.23`。
- 修改时先检查删掉的是否是后文依赖的支点或引子。

## 四、氛围

### 4.1 来源

- 氛围来自光线、声音、空间、物件、人物注意力、社会规则和事件，不只来自景物描写。
- 可以直接命名“压抑、温馨、暧昧、安静”，也可以让读者从细节形成判断。但不能只靠命名或一盏灯兑现温度契约；温度主要靠对话、小动作和注意力，不宣布“她感到温暖”。见 `写作层/技法/强度与情感.md#2.7`。
- 场景只取真正相关的感官，不必五感齐上，也不必每条都有身体后果。

### 4.2 细节选择

- 雨、咖啡、凌晨、旧物和空镜都可以有氛围价值，不强制每个细节改变行动。
- 删除的是可任意替换、重复和陈词滥调，不是“无因果的环境”。
- 反声写静、规律被打破和以物承情只是工具，不是固定答案。

### 4.3 意象与变奏

- 可以建立少量意象母题，让它们随关系、时间和视角改变意义。
- 重复是作品设计的一部分，不必每次换载体，更不必末章强制回扣首章。
- 意象若每次都被解释为象征，容易变成作者盖章，需给读者留白。

## 五、长篇一致性

### 5.1 文风契约

- 记录默认叙述者、视角权限、主要语域和是否使用母题即可，不锁死每章距离与句式。
- 契约可以随作品发展改变，重大改变要同步设定与章纲。
- 不另建复杂的外部记忆系统，使用项目内可读、可更新的记录。

### 5.2 跨章变化与重复

- 逐章独立审查难以发现跨章同腔，需要批次和全书回读。
- 检查同一收尾、同一动作、同一对白策略和同一身体镜头是否机械重复。
- 有意的风格一致和人物习惯不是漂移，不要为了去重破坏作品识别度。

### 5.3 具体与毛边

- 每本书需要不可替代的具体经验，可以是人名、规则、职业、地点、关系或一次后果，不要求每章都有硬数字。
- 人物可以有偏见、口误和选择性观察，但不要故意保留事实穿帮来模拟真人。
- 参数在需要时保持连续，允许人物改口、记错和被纠正。

## 六、编辑顺序

1. **结构与事件**：先查目标、因果、详略、重复和承诺，再修句子。
2. **人物与声音**：查知识、声口、视角、距离、关系和跨章变化。
3. **行级表达**：查动词、句长、标点、解释、身体事实和阅读节奏。
4. **回读**：至少连读修改处上下文及本批章节，必要时读全卷和全书。

不要为了执行顺序而重复做无效检查；若结构已稳定，可直接处理明显语言问题。

## 七、局部编辑

- 改前读足够上下文，至少明确这句话依赖什么、后文谁依赖它。
- 改后检查引子、承接、问答、物品、身体状态和新产生的重复。
- 一次修改多处时按语义分组，每组后回读，不机械追求一次只改一处。
- 检查四种联动：前文铺垫是否兑现、后文回答是否悬空、对话是否配对、物品与身体是否连续。
- 修改不是越少越好，若事件骨架有问题，应重写场景而不是保留漂亮句子。
