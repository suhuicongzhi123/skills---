# 表情库

> **目录（按需读取，勿整体加载）**：一 总纲｜二 外化方向｜三 情绪对照｜四 亲密反应｜五 使用纪律｜六 身体动作
>
> **定位**：提供情绪外化的选项，不要求所有情绪都写成“脸＋身体”，也不要求每个人拥有固定招牌表情。
> **原则**：表情、动作、语言、内心和他人反应都可以表达情绪。直述不是错误，重复和不合人物才是问题。

## 一、表情总纲

- 眼神、眉、嘴、脸色、呼吸、声音和动作按场景选择，不需要一次配齐。
- 近距视角可直写感受，远距视角可借外部表现；不要把“内脏感受读者看不见”当理由禁用。表情与小动作可以带出温度，但不要用“她感到温暖”这类宣布收束；活气见 `写作层/技法/强度与情感.md#2.7`。
- 同一种表情可以对应不同情绪，同一种情绪也可以没有外部表现。
- 习惯与招牌可以存在，但不必每人只有一个，也不必全书反复使用。

## 二、外化方向

### 2.1 眼神与视线

- 躲闪、直视、停留、失焦、抬眼、别开、寻找和无视。
- 先确定看谁、看什么、为什么看或为什么不看，不拿“眼神复杂”代替情境。
- 目光可以是审美、判断、欲望、无聊、习惯和认错，不总是深刻。

### 2.2 眉与面部肌肉

- 皱、松、挑、僵和轻微变化，注意不同人的基线不同。
- 不必把挑眉当嘲讽，也不必把舒展当释然。

### 2.3 嘴与声音

- 抿、咬、张合、笑、嘴角动作、发不出声和话到一半。
- 冷哼、嗤笑、叹气可以使用，但意义由语境决定。

### 2.4 脸色与皮肤

- 红、白、汗、热、冷、僵和松弛，可用于情绪、疼痛、环境和疾病，不能一概心理化。
- 脸红不必等于害羞，脸白不必等于恐惧。

### 2.5 下颌与喉部

- 绷紧、吞咽、抬头、低头、哽住和声音变化。
- 喉头滚动不是欲望专用，也不必每个紧张的人都出现。

### 2.6 呼吸与生理

- 屏息、急促、缓慢、倒吸、心跳、手心出汗和发冷，近距视角均可直写。
- 这些感觉可以真实可靠，不要因为“读者看不见内脏”而排除。

### 2.7 泪

- 打转、滚下、哭出声、无声、干涩、忍住和哭不出来。
- 眼泪可以来自悲伤、疼痛、愤怒、释放、疲劳和生理反应，不默认“崩溃”。

## 三、情绪对照

| 情绪 | 可选表现，任选而非组合 |
|---|---|
| 羞耻／尴尬 | 回避、解释、直视、玩笑、脸红、藏物、继续做事 |
| 紧张 | 话变多或变少、动作变化、呼吸、注意力过度集中或涣散 |
| 难过 | 哭、沉默、直说、做旧事、找人、独处、没有外显 |
| 惊喜／心动 | 靠近、笑、愣住、追问、分享、直接表白 |
| 愤怒 | 质问、冷处理、提高音量、离开、动作变轻或变重 |
| 疼痛 | 描述感受、保护部位、改变动作、停、寻求帮助 |
| 恐惧／支配 | 后退、观察出口、服从、反抗、冻结、谈判 |
| 憋笑／隐忍 | 转移话题、咳嗽、低头、直接承认想笑 |

## 四、亲密反应

> 仅在相应亲密尺度与授权范围内使用，不与普通照护混写。

- 亲密中的面部、呼吸、声音和身体反应由个人体验决定，不设统一“高潮脸”。
- 残肢反应可有、可无、可强、可弱，敏感程度按角色身体设定，触碰与亲密使用另核授权，不把抽动当通用证明。
- 羞耻、放松、快乐、疲劳、疼痛、尴尬和沉默都可能出现，不把每场都写成失控与泪水。
- 继续、调整、暂停和拒绝都是有效反应，不能只把承受当美。

## 五、使用纪律

- 同一表情是否重复主要看功能和语境，不设全书次数上限。
- 避免把皱眉、抿嘴、垂眼、叹气、脸白机械打包成“五连拍”。
- 招牌表情可以重复形成人物辨识度，也可以随关系变化。
- 不需要为了去套话而写“脸上一丝表情也没有，眼睛盯着某处”这种更冗长的替代。
- 亲密与恋物不必每次脸部和残肢同帧，视角与当下事件优先。

## 六、身体动作

### 6.1 手与手指

- 攥、绞、抠、抖、摸空、藏、捂、扯、松和继续完成当前动作。
- 这些动作并不天然比“紧张”更具体，要交代物件、目的和变化。

### 6.2 头颈与肩

- 低头、仰头、别脸、梗颈、缩颈、肩抖、塌肩和主动迎上去。
- 低头不一定是服从，仰头不一定是承受。

### 6.3 躯干与姿态

- 弓身、僵住、后缩、前倾、软下、坐不住、站直和主动改变位置。
- 可以把“软下来”写成脱力，也可以写成放松，避免自动色情化。

### 6.4 残肢与缺失侧

- 髋、肩离断软组织可随肌肉和躯干反应变化，但不能独立抬甩蹬。
- 有骨残肢可在保留关节控制下抬放、夹持或回撤，幅度按个人与情境。
- 双侧类型逐侧判断，不把“想并却并不上”设成固定高潮反应。
- 羞耻不必藏，快乐不必颤，截肢部位不是所有情绪的必经出口。

### 6.5 脚与假肢

- 脚趾蜷、点地、改变支撑、停步、假肢发出实际机械声或没有声音。
- 假肢悬空与晃动只在姿势成立时使用，不作为“无力”的通用象征。

### 6.6 声音

- 气音、呜咽、倒吸气、叹气、笑声、喊叫和沉默。
- 声音可以真实表达，也可以被人物刻意控制，不必每次解释为“情绪漏出来”。
- 说话方式随疲劳、伤势与情绪的变化见 `写作层/文风/台词库.md#1.15`；本节仍管气音、呜咽等非语言声音。
