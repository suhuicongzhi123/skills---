# 冲突与战斗

> **目录（按需读取，勿整体加载）**：一 读法｜二 对抗节拍｜三 霸凌与黑暗边界｜四 底层事实｜五 类型分型｜六 手的经济｜七 武器与器具｜八 重点类型打法｜九 地形｜十 对手｜十一 解法与变奏｜十二 敌方学习｜十三 失败、代价与撤离｜十四 群战｜十五 战后｜十六 防复读｜十七 辅具被夺与失去
>
> **定位**：现实与超自然共用的对抗决策库。超自然增量见 `题材层/幻想向.md`，生理事实见基础层。
> **核心**：胜负由目标、信息、资源、能力、训练和现场选择共同决定。截肢只是条件之一，不自动推出固定打法、固定站位和固定代价。

## 一、读法

1. 先定双方目标，再定类型、装备和战场，最后设计动作。
2. 先问“赢意味着什么”：击杀、逃生、救人、拖延、夺物、立威、隐藏还是完成任务。
3. 每个关键结果都要能在规划与审查中复盘：为什么此人此时这样做，为什么有效，对方为什么这样回应。正文用可见动作、条件与后果呈现，不写选择理由或替代方案说明。
4. 身体被看见和截肢在场是可选素材，不必每场都安排目光或残端特写。
5. 战斗可以很短、可以非致命、可以无伤，也可以惨烈。爽感来自有效行动与结果兑现，不是动作数量。
6. 燃点来自“已建立或当场可理解的能力、资源、地形与选择在关键时刻奏效”：压迫成立 → 主角主动选择 → 关键行动有效 → 可见战果 → 战果被确认并改变后续。指定爽燃场景还须给读者保留胜利、能力释放、认可或轻松余韵，不能刚赢就用见底、透支或新危机立即抵消；代价可有但不默认。不是每场都需完整展开，即兴选择也须能被现场条件复盘。
7. 战果确认不必靠旁人惊叹，可以是敌方退却、目标完成、战术成立、队友信任或地位变化。不要每次成功都立刻用新危机抵消。

## 二、对抗节拍

- 常见结构：条件形成 → 行动与反应 → 结果 → 新条件。可以跨场景，也可一招结束。行动与反应可以重叠、可以打断，不是轮流举手。不要写成你一招我一招、一方做完对方才动、对白切在回合边界上；群战与多名对手须有同一拍里的重叠动作，不要排队上场。
- 口角不必固定“试探—定性—撕破”，可直接冲突、冷处理、协商、误解或合作失败。
- 需要升级时，让信息、利益、关系或风险改变，不只是声音变大。
- 短句、长句、心理和对话都可以进入战斗，不按每百字动作数计算。

## 三、霸凌与黑暗边界

- 单次嘲讽与持续权力压制分开，后者需要资源、关系和后果。
- 被霸凌者可以反击、求助、取证、结盟、离开或暂时忍耐，不必每次都正面赢。
- 黑暗暴力、非自愿和圈养按专项授权写，明确叙事立场，不用“她不反抗”默认同意。
- 主角施暴需要动机与后果，不能只靠“他很厉害”免除逻辑。
- 敌方或偏见者可以用残障蔑称，作为立场与权力表现；叙述不认同，也不当嘲讽词库反复使用；被骂者可回骂、无视或反击。见 `写作层/文风/台词库.md#1.16`。

## 四、底层事实

### 4.1 支撑与移动

- 支撑点、支撑面、重心、摩擦、装备和外力共同决定稳定，不用“单脚＋一点＝三角”简化。
- 单侧下肢在某些动作中冗余更少，但假肢、拐杖、武器和训练能改变条件。
- 动作设计先点名实际使用哪条腿、哪只手。缺失侧不能完成不等于角色整体不能完成；健腿可在支撑允许时蹬、踢、屈膝与转身。
- 倒地后能否起身和能否继续战斗取决于技术、支点、对手距离和装备，不必然只能挨打，也不保证地面战拉平差距。
- 换位成本可高可低，先写具体动作再决定是否“位置战”，不把所有单侧角色锁成站桩。

### 4.2 上肢与复合类型

- 单侧上肢缺真手，但残端、武器支架、躯干和下肢可参与；双手兵器和攀爬按具体方式。
- 双侧上肢缺失不等于只能借人，下肢、嘴、设备和训练可提供多种战法。
- 复合类型逐项检查任务必要条件，较好侧和装备可以形成代偿，不用“最弱侧决定一切”。

### 4.3 幻肢

- 幻肢意图可在战斗中造成注意与动作错位，也可完全不出现，频率按人物而非“近期必摔”。
- 多年截肢者也可以出现幻肢感，是否影响结果看当时动作。
- 实际缺失肢体不能完成抓握、蹬地或踢击，不能靠战斗紧张获得豁免。

## 五、类型分型总表

> 下表是设计起点，不是能力上限。每一行都要再叠加装备、训练、年龄、健康和对手。

| 类型 | 可能优势 | 可能短板与针对方向 |
|---|---|---|
| 髋离断·无假肢（未持拐） | 可借墙面、长杖、坐位或单腿跳形成输出，短距动作可突然 | 长距与持续换位需规划，持拐时见下行 |
| 髋离断·双拐 | 拐可作支撑与钝器，双手与步态组合多 | 移动中持其他武器受占手限制，拐落点可被针对 |
| 髋离断·假肢 | 可腾手并使用更多武器，适配者可训练复杂动作 | 普通系统能耗、侧向稳定和控制成本较高 |
| 膝上·假肢 | 有髋部控制，双手可用，部分型号动作潜力大 | 普通机械膝侧向、扭转和低姿受限，具体看型号 |
| 膝下·假肢 | 有真膝，可跑跳、低姿和多类动作 | 假脚踝足、接受腔、湿滑和扭转会影响表现 |
| 单侧下肢·无辅具 | 双手可持械；单腿跳的距离按会、稳、敢、值和路面决定，不设短距上限 | 持续速度赶不上健全人奔跑，例外见 `基础层/行动库.md#4.2` |
| 肩离断 | 下肢机动，单手兵器和工具可用 | 真手抓握与双手协同缺失，摆臂与保护不同 |
| 肘离断 | 上臂与肩带可参与，可顶按和支架辅助 | 无前臂与真手，旋转和抓握不存在 |
| 腕离断 | 前臂与肘可参与，顶按夹持方便 | 无手指抓握，旋前旋后幅度按手术 |
| 双膝下 | 真膝与假肢可提供站立、行走和低姿 | 双手是否自由取决于支撑，装备和地形影响大 |
| 双膝上 | 可用轮椅、假肢、臂力和低位攻击 | 裸残端站立须谨慎，转移与台阶需要规划 |
| 双髋离断 | 轮椅平台、臂力、低位与坐位控制 | 无站立，轮椅失效后须挪移或替代 |
| 上下肢复合 | 可通过装备、位置和协作形成独特打法 | 移动、控制和转移分别判断，不能只按最重项；仍有一条完整健腿时禁配轮椅，除非明示虚构豁免 |

无辅具单腿跳的窗口与验收见 `写作层/素材/受众定位.md#3.1`：可选素材不为过审补跳。

## 六、手的经济

- 双拐移动时双手主要支撑，停稳后可按条件使用武器；单拐与武器组合按稳定，不限“一两步”。
- 假肢无拐时双手通常可用，双手兵器能否使用还要看步法与支撑。
- 已配置轮椅者（限无完整健腿者）停稳刹车后可用双手，推轮时可用单手、改装控制器或协作，不是“停手就必挨打”。
- 单侧上肢可用健手、残端支架和躯干配合，盾与兵器不是简单二选一。
- 双侧上肢可用下肢、嘴、支架和设备，不把“0 手”写成“0 战法”。
- 放武器、放拐，或已配置轮椅者弃轮椅，以及其他取舍，要有去向与后果，不必每次三句写完。未合法配置轮椅的角色不在此列补出或弃用轮椅。

## 七、武器与器具可用性

- **单手刀剑短兵**：单侧下肢与上肢角色可按支撑使用；持双拐者须停稳腾出一手；没有完整健腿、已配置轮椅的角色停轮后同样可用。
- **盾与支架**：可绑在残臂、前臂或躯干，须考虑固定、重量与解脱，不默认义手只能粗操作。
- **弓弩**：通常需要双手或特殊上弦与支撑，坐姿、脚踏、绞盘和协作可改变；具体型号优先。
- **长柄与长杖**：可兼作支撑和武器，但杆尾离地、挥动惯性和转身会改变稳定，不是天然第三腿。
- **枪械**：后坐力、重量、姿势和训练决定效果。换弹可用双手、残端、腿部、台面或改装，不统一“必须两只手”。
- **徒手与踢击**：有支撑时健腿可踢，地面战可用各种杠杆，但需技术与空间，不能由“健腿代偿”推出必然力量超群。踢出前须写清踢出后的支撑；双拐横拦、拐夹在腋下或持拐在手不自动等于已建立支撑。若双拐均用于拦击且无其他支点，先落拐、靠物或改用不腾空的动作。
- **拐杖**：战斗中可戳、挡、勾、别和扫，主要是钝器与杠杆，不写成刀剑；勾、别等战斗杠杆不证明拐杖能完成精细日常操作，非战斗使用另核接触、受力、精度与支撑。
- **假肢**：可支撑、格挡或摆动踢击，具体取决于关节和固定，不统一可或不可。
- **轮椅**（仅限没有完整健腿的已配置角色）：可撞、卡、挡和作为射击平台，也可被针对；不是囚笼，也不是绝对盾牌。
- **改装**：可加固、包布、加箍、改善握持和适应任务，涉及刃器、机关和武器化须考虑现实法规与后果。

## 八、重点类型打法

### 8.1 髋离断与单侧无假肢

- 可借双拐、墙面、家具和长杖形成不同打法，站定与移动都可设计。
- 目标可以是迫使对方多走一步、改变视线、失去武器或暴露位置，不必只追求原地输出。
- 被绕后时可小步转、跳、借支点、后退或换目标，不必然失位。
- 倒地后可借支点起身、滚入掩体、脱离或拖入地面战，按训练和对手。

### 8.2 双拐与单拐

- 拐本身就是武器和支撑，可一拐撑一拐打，也可暂放、换单拐或改换其他已铺垫方案。
- 被夺拐时可保护剩余支点、贴身、撤退、夺回或换装备，偷拐者不必因“不会站三角”自动摔倒。
- 台阶上端和下端各有利弊，重点是撤退路线和落点，不是固定守门。

### 8.3 膝上与膝下假肢

- 普通机械膝侧向和低姿可成为针对点，但具体反击按型号和训练。
- 假肢受损后可弃具、换拐或继续用假肢；有完整健腿即禁轮椅；没有完整健腿的设定可按既有装备切换。弃具不是每场固定高光。
- 可利用对方对假肢能力的误判，但不能每次都靠“对方以为她不能”获胜。

### 8.4 无完整健腿与轮椅

- 本节轮椅方案只用于没有完整健腿、并已配置轮椅的角色。轮椅可提供速度、平台和武器支撑，手刹、地形和控制器决定动作。
- 被掀翻后可挪移、抓握、使用短兵、呼叫或撤离，不保证地面反杀，也不等于完全失能。
- 台阶与门槛需要提前解决，战斗中遇到时可换路线、借物、协助或防守，不只“死路”。

### 8.5 可形成的战斗风格

- 以器代肢：长杖、刀鞘、拐和假肢与步法协同。
- 双拐锁控：用拐作钝击、格挡和杠杆，不写成刀枪两用万能器。
- 战损转换：装备失效后转入另一套已铺垫的方案，而不是突然爆发。
- 上肢代偿：独臂、残端、下肢和工具共同完成拔刀、换握和射击。
- 低位与已配置的轮椅（限无完整健腿者）：利用高度、速度和近距离杠杆，但不把地面战写成必然优势。

## 九、地形矩阵

- **窄道与门框**：可限制双方角度，也限制退路。敌人可绕、烧、烟、远程或拆，不能只排队。
- **开阔地**：利于观察和远程，移动和接近路线决定风险，不自动对阵地型不利。
- **楼梯与高差**：影响接近、落点和撤离，谁能利用取决于装备，不只“上端必胜”。
- **湿滑泥雪冰**：改变摩擦和转向，对所有人都危险，程度按装备。
- **水面与船**：晃动、空间和转移是关键；已配置轮椅时（限无完整健腿者）须固定，不等于所有人不能上船。
- **马背与载具**：骑乘需要与鞍具、训练和身体条件匹配，不默认高位截肢一定不能骑。
- **夜间**：声音、视野和感知装备改变信息，不把拐声当唯一暴露源。
- **室内与人群**：家具可提供支撑和障碍，人群可掩护也会推挤，双方都可利用。

## 十、对手矩阵

- **单兵**：比较技术、信息、目标和准备，不强制有来有回。
- **多人**：人数增加会改变角度和资源，但可以通过撤退、隔断、协作、谈判和地形处理，不设几人必败。
- **远程**：掩体、推进、压制、烟雾、交涉和反击都可，机动型也不能无脑冲。
- **重甲**：按真实护甲和武器，攻击关节、缝隙、移动和体力，不写一刀破甲。
- **骑乘**：高度、速度和马具重要，可用障碍、远程、车辆和地形，不默认徒手拽马。
- **兽与无智群**：依据感知、动机和习性，不会因“不懂针对拐”就失去危险，也不禁止倒地反击。
- **火烟水**：优先考虑出口、呼吸、视线和装备，撤离慢者需要提前规划。
- **陷阱与暴民**：信息、预警、人群情绪和出口比“是否一眼看穿”重要。

敌人可以轻敌、抢功、怕死、犯错和重复有效策略，但错误要有其信息与动机。

## 十一、解法谱与变奏

- **换时间**：遮光、声响、假动作、落物、关门和打断。
- **换高度**：占高、拉倒、逼对方改变姿势和利用落差。
- **换接触**：贴身、抓腕、抱距、拐别、地面转换和脱离。
- **借他者**：队友、第三方、规则、环境、动物和公众。
- **拖时间**：谈判、示弱、抛物、等待援军和改变目标。
- **提高接近成本**：投掷、障碍、湿滑、远程和路线控制。

变奏看条件、结果和意义是否不同，不按近五章同招次数机械查重。窄道不是禁用，排队送死和敌人忘记其他手段才是问题。

## 十二、敌方学习

- 敌方可以轻敌、识别、针对和学习，也可因信息不足、骄傲或时间压力重复错误。
- 同一敌人再次交手是否更针对，取决于他是否获得情报和愿意改变，不强制每次升阶。
- 学习需要载体：亲眼所见、同伴情报、旧伤、录像、传闻或内部人。
- 不要为了让主角赢而让对方忘记已知有效策略；应让主角改变其有效性。

## 十三、失败、代价与撤离

- 失败可为失位、倒地、装备损失、受伤、被俘、暴露、任务失败和关系破裂。
- 赢也可以付代价，也可以无伤且达成目标，代价不是战斗真实性门票。
- 受伤写功能、恢复、资源和后续，不以疼痛长度代替后果。
- 撤离可以快、慢、借助载具、队友、障碍和谈判，不只“退到下一个点”。
- 输也可以输得清楚、输得有原因，不需要每次都转为高光反杀。

## 十四、群战与队形

- 角色可做定点、机动、远程、支援、侦查、驾驶、后勤和指挥，不按截肢统一分配。
- 需要换位时可由队友、载具、装备和路线共同解决，不强制安排一个“搬她的人”。
- 击杀数不是唯一贡献，信息、救援、拖延、资源和目标完成都可成为高光。
- 队伍成员各有目标与能力，避免全队只负责照顾主角或等主角救场。

## 十五、战后与跨章

- 装备损坏和维护状态要连续，可修、可换、可租、可失去，不要求下一场仍破。
- 战后余波可为疲劳、疼痛、检查、清洁、情绪、护理、庆祝、争执和关系变化，不固定残端照护。
- 伤势影响功能、计划和资源，恢复有过程，也可有旧伤长期影响。
- 敌方情报、声望和资源随结果流动，下一场要有来源。
- 连续战斗后的恢复按个人，不固定必须一章残端发热或被人抱走。

## 十六、战斗过程防复读

检查开局、双方目标、关键条件、胜负手、结果和意义是否同构，不机械禁止同一部位、同一武器和同一有效策略。

- 同一辅具可连续成为目标，因为敌人有理由针对；通过不同处理方式与后果避免复读。
- 战斗章可以是对峙、协商、伏击、追逐、救援和撤退，不必全部有死有伤。
- 真正的复读是只换名字和地点，过程、结果和意义完全不变。相邻战斗章还要查招式排序与收束套话，不只查用词；只换一层陷阱皮、同一套组合技和同一句“我记住了”，也算过程复读。

## 十七、辅具被夺、破坏、偷窃与失去后的应对

### 17.1 来源与过程

| 来源 | 需要写清 | 可选结果 |
|---|---|---|
| 抢夺 | 谁抓、怎样争夺、双方力量与支点 | 即时夺回、失去、贴身反击、撤退 |
| 破坏 | 什么外力、哪个部件、功能影响 | 降级、弃具、维修、替换 |
| 偷窃 | 何时何地被拿、如何发现、线索 | 追查、找回、交易、替代 |
| 扣押 | 依据什么规则、谁有权、流程 | 交涉、申请、换通道、法律与救济 |

### 17.2 应对阶梯

1. 瞬间判断：装备在哪、对方还有几人、当前支撑与目标。
2. 即时选择：夺回、保护、撤离、求助、换装备或改目标；身体移动求助门槛见 `基础层/日常动作.md#3.7`。
3. 当场后果：位置、动作、资源和伤势是否变化。
4. 后续出口：取回、维修、替代、租借、购买、转入其他方式，按剧情而非固定章数。

### 17.3 类型判断

- 失去一支拐不等于只能跳，可单拐、扶物、长杖或协助。拐还在手但来不及架时，紧急可拎拐跳逃，见 `基础层/行动库.md#8.1`。
- 失去假肢不等于残端不能动，可换拐、单腿跳、爬行或其他装备；有完整健腿即禁轮椅。独立跳窗口见 `写作层/素材/受众定位.md#3.1`。
- 已配置的轮椅被夺不等于完全失能，可挪移、呼叫、爬行、备用设备或协助；未合法配置轮椅的角色不在此列补出轮椅。
- 上肢武器被夺可换武器、支架、下肢、工具或撤退，不写“只能认输”。

### 17.4 处置选项

- 夺回需要距离、对方控制和风险，不写主角一喊对方就松手。
- 借物替代要有实际支撑和适配，长杖、台面、墙、车、同伴都可。
- 对方误用装备只能提供机会，不保证其自动失衡。
- 放弃和撤退可以是聪明选择，不必为了证明独立强行夺回。
- 维修与替换是正常生活结果，不把“破损后只能永久无辅具”当真实。

### 17.5 独立跳窗口

- 明确承诺，或已有拿不到拐、来不及取拐、必须腾手、追逃窗口，才按无拐无扶物独立跳写。可选素材不为过审补跳。正文不写选择理由。细则见 `写作层/素材/受众定位.md#3.1`。事后见到熟人时的吐槽方向见 `写作层/文风/台词库.md#1.16`。

### 17.6 禁写

- 辅具无因消失、复原或跨场瞬移。
- 把自然磨损与外力破坏混为一谈，只为重复危机。
- 对方夺走关键装备后主角毫无判断，或对方因“不会用”立刻降智。
- 把失去辅具后的所有移动都写成同一种单腿跳，忽略载具、扶物、工具和协助；轮椅只作为没有完整健腿之角色的既有装备，有一条完整健腿不在此列。
