# 受限场景库

> **分工**：本文件负责把身体事实转化为具体事件。动作物理见 `基础层/行动库.md`、`基础层/日常动作.md`；受众与层级见 `写作层/素材/受众定位.md`。
> **原则**：身体结构、装备、环境、社会规则和他人行为共同决定任务难度。先问这件事为什么变难，再选择人物如何处理。

> **目录（按需读取，勿整体加载）**：一 来源与判定（含 1.2 四条铁律、1.5 四类自然窗口原型）｜二 强度与归因｜三 受限类型与素材｜四 人物的处置｜五 心动条件｜六 受限弧线

## 一、来源与判定

### 1.1 生成轴

| 轴 | 机制 | 例子 |
|---|---|---|
| 身体结构 | 缺失或保留功能影响动作 | 无真膝、无手抓握、假脚踝非生物踝 |
| 辅具依赖 | 装备改变能力，装备失效或占用影响任务 | 拐杖被夺、假肢故障；已配置轮椅者（限无完整健腿者）推轮椅占手 |
| 环境与制度 | 空间、设施、流程和社会规则改变可达性 | 被要求不合理陪护、场所禁入辅具、施工封路改道 |
| 他人与关系 | 帮助、阻碍、误解、控制和协作改变选择 | 过度帮助、藏拐、协作转移、伴侣分工 |

### 1.2 判定四问与受限桥段合理性

1. 如果按该人物常用的方式，任务为什么变难或需要改变？
2. 变化是否来自身体、装备、环境或他人的具体条件，而非空泛“她残疾”？
3. 是否影响她当前在乎的目标、时间、资源、关系或结果？
4. 她做了什么，结果如何？

核心受限不必以失败告终。漂亮完成、协作和绕行，只要常用办法不可用、人物做了取舍、下一步因此改变，就按 `写作层/素材/受众定位.md#六` 归为核心受限。身体出现在句子里而功能路径没变，记为身体在场。

**受限桥段合理性四条铁律（防硬造、防降智，单一来源）**：

1. **辅具不在手须有故事内原因（禁人为降智丢拐）**：拐杖、假肢或环境辅助物（搭板、坡板）不在手边，常见来源有 **① 突发事件**（突发异响、突遭袭击、抢几秒窗口来不及拿拐或穿假肢）；**② 外力剥夺**（被抢、被踢远、损坏、有前因的耗材老化（见 `基础层/辅具-假肢.md#六`）、车门／缝隙卡住、按场所规则寄存）；**③ 合理的日常置放距离**（洗浴、睡眠或久坐休憩时辅具按常理置放在数步之外，此时遭遇外部突发急事需立即响应）；**④ 必须腾手，或比较拿拐、占手、体力与时间成本后主动放拐短距单腿跳**（窗口见 `写作层/素材/受众定位.md#3.1`，成本比较见 `基础层/行动库.md#1.7`）。❌ 让角色在已知危险或需要连续移动时，无缘无故把拐丢在远处自己跳走。
2. **必须先排除简单常识解（禁放着简单办法不用去硬吃苦）**：若小物件能揣进衣兜、塞进随身包、挂腕勾指（`基础层/日常动作.md#3.2`），或能先把手上东西放桌沿再去拿拐、坐定操作，简单办法可行时不写成弃拐硬跳或开口求助（放拐短跳本身更省事时属第 1 条④；求助门槛见 `基础层/日常动作.md#3.7`）。只有**简单办法在当场确实走不通**（物品过大／过烫／易碎、时间来不及回身取拐、无处借放、地面确有阻碍）时，受限取舍才合理。简单办法可以由人物当场的对白、动作或看得见的障碍排除，这本身是事件；叙述者替人物解释为什么不选别的，才按零解释删。
3. **受限强度须匹配角色熟练度与体能（禁平地莫名降级）**：熟练角色在平整干燥地面的单腿跳连续流畅（`基础层/行动库.md#8.1`），受限应来自**距离耐力消耗、追逃绝对速度差距（`基础层/行动库.md#4.2`）、湿滑／高差／窄道地形、外力干扰或手脚被占**，❌ 在自家平地上跳两步就无故写得东倒西歪；也不把熟练者早已掌握的日常操作（上下车、放拐、上下楼）写成不会做的知识缺口，换一辆车、换一栋楼只影响放在哪、走哪条路，不影响会不会。
4. **完好健侧与保留关节能力不得被隐形没收**：单侧下肢有一条完整健腿和双手，单侧上肢有一只完好健手和双腿，肘腕／膝上／膝下各有保留关节。受限点只能落在**“仅靠健侧＋当前支点确实无法覆盖的功能缺口”**上，❌ 把单侧上肢写成普通虚掩门都推不开、把穿合适假肢者写成过普通门槛也受阻。

### 1.3 地面与环境

- 冰、油、明水、沙、泥、坡、台阶、窄门、拥挤、光线和噪声都可能改变动作；改变动作不等于构成受限，归级与楼梯、台阶的默认处理见 `写作层/素材/受众定位.md#六`。
- 同一环境对拐杖、假肢和不同训练者影响不同；已配置轮椅者（限无完整健腿者）另按轮椅通过性判断。不能统一判“只是点缀”。
- 环境可以直接造成无法通行，也可以只是增加一点麻烦，按真实空间，不为避免“环境控诉”而扭曲事实。

### 1.4 层级

层级测试只以 `写作层/素材/受众定位.md#六` 为准，这里不另立标准。核心受限要同时有常用办法不可用、真实成本之间的取舍，以及下一步改变。路径变了但目标从未悬置，记为受限在场或弱受限。身体只是可见，记为身体在场。社会面是否核心受限，也按这同一测试，不预先排除，也不预先算上。

### 1.5 四类高张力自然受限／代偿窗口原型（S1 桥段生成器）

在严守 1.2 四条铁律（不降智丢拐、不拿普通台阶充数）的前提下，规划受限主导或动态代偿重场时，优先从以下四类客观自然窗口中选型，并与本章主线冲突深度咬合（相邻章变换窗口轴向，避免跨章同构）：

1. **时间抢拍窗口（启动成本差）**：外部突发事件陡然压缩响应时间（如器物临近失控、通道即将封闭、关键目标即将脱离接触、突发袭击或环境骤变）。此时回身取拐、解锁或穿戴假肢的“几秒启动耗时”直接构成战术劣势，迫使角色当场决断——单侧下肢（及双臂＋单腿）直接离拐／弃拐连续流畅单腿跳或紧急拎拐跳（`基础层/行动库.md#8.1`）；上肢角色不戴假手直接以健手配合残端／嘴／下肢极限抢做；双侧无完整健腿角色直接从地面／床榻以臂力撑移抢位。
2. **空间与介质挤压窗口（器械物理边界）**：辅具或常规步态在特定物理环境中受阻——如极窄通道／密集货架卡住双拐展幅或轮椅宽度（轮椅仅限无完整健腿者）；泥泞、积雪、格栅、软沙导致拐头深陷或打滑；颠簸车船甲板、狭窄车厢或高差榻台使辅具难以支稳。角色被迫收拢或暂置辅具，切换为贴墙／扶物单腿跳、坐姿平移、（保留真膝者）膝行或借同伴支点通过。
3. **动态对抗与速度／支点差窗口（物理博弈落差）**：在追逃、抢夺、近身缠斗或熟人玩闹拉扯中，触发客观物理边界——单侧下肢单腿跳爆发启动快，但持续速度被全力奔跑的健全人拉开、绕前截住或并行戏弄（3.4 与 `基础层/行动库.md#4.2`）；单侧支撑或双拐占手时遭遇侧向冲撞、逼退或夺拐；湿滑急转下拐未撑住引发期望性幻肢蹬空与真摔（`基础层/行动库.md#2.2`）；上肢角色在对抗中单手被制，依靠残端（仅肘腕／经肱有骨残端）顶撞、肩躯发力或下肢反制。
4. **双任务并发窗口（突发支撑与操作冲突）**：非因角色忘背跨包等低级降智，而是现场突发“必须同时稳住高风险目标＋完成位移／对抗”的并发强制条件——如同伴突发晕厥／受伤需一把扶住（扶持力学见 `基础层/行动库.md#3.15`）、双手必须同时护住易碎／滚烫／关键证物撤离、在无掩体处既要维持单腿／坐姿平衡又要双手操作器械或施法。

- **隔离纪律**：选型时严格核对截肢类型（有完整健腿绝不派生轮椅窗口；髋、肩离断绝不派生残端杠杆夹顶窗口；上肢截肢绝不派生下肢拐杖／单腿跳窗口）、题材科技树（古装／末世／现实／幻想器物与环境严格分界）及特殊种族设定（已登记 `题材层/幻想向.md#1.5` 族群常态者按其高于人类伤残基线的机动上限设计窗口；已整合尾翼按协调资源算，不无故写成失衡累赘）。

## 二、强度与归因

### 2.1 熟练度

- 熟练者常规动作可稳定，初学、恢复、疼痛、疲劳和新任务会改变表现。
- 不按截肢年限分配能力，健腿、残肢、假肢和训练分别判断；轮椅能力只评估没有完整健腿、并已配置轮椅的角色。
- 可以长期存在幻肢与偶发失误，不能用“多年绝不想用”解释一切。

### 2.2 归因

- 不要只用“力气不够／力气用完了”解释所有困难，也不要反向假定健腿一定比常人强。
- 可检查支撑面、支点、力矩、合力、摩擦、长度、装备、信息、时间和资源。
- 疲劳与体力可以是核心原因，不必永远降为弱受限。
- 环境不是“纯环境问题”的免责标签，残障者面对的环境问题往往与身体条件直接相关。

## 三、受限类型与素材

### 3.1 功能丧失与保留功能

- 无真膝、无脚、无手或相应关节缺失会改变动作，但假肢、工具和其他肢体可代偿。
- 驾驶、蹲跪、夹物、上下楼、骑车、取物和水中活动分别按装备与训练。
- 驾驶、运动与游戏先拆所需动作、输入、规则和装备，再判断能否参与。手动挡要分别核对离合、制动、油门与换挡的操作侧；不能参与要有具体功能依据，不能由“截肢”一词代替。
- “没有冗余”会影响某个动作，但不等于健腿被控后一定全身失能，仍有手、装备和环境。

### 3.2 辅助器具剥夺

- 抢夺、破坏、偷窃、扣押、遗失、维修和主动放弃都可成为来源。
- 写清谁、如何、结果和后续状态，不能下一场自动恢复。
- 取回、替代、维修、租借、购买、转入其他装备都是出口，按剧情时间，不设五章上限。
- 剥夺后的移动不只有单腿跳，可载具、扶物、滑板、爬行或协助；有完整健腿即禁轮椅。独立跳窗口见 `写作层/素材/受众定位.md#3.1`。

### 3.3 双手占用

- 双拐摆步、抱物、操作和抓握分别判断手是否可用；已配置轮椅者（限无完整健腿者）另核推轮占手。
- 解决顺序不必固定：可背包、推车、坐定、调整装备、分次、协助或改变路线。身体移动求助须过 `基础层/日常动作.md#3.7` 门槛；随身背负包袋与小件携物不构成双手占满。
- 不把抱婴儿跳跃和湿滑端热汤当“末端解”，危险物优先稳定转移。
- 上肢截肢者可借残端、嘴、腿、工具和协作，不把所有双手任务判为不可能。

### 3.4 速度劣势

- 时间窗口可来自追赶、末班车、关门、抢救、逃离和排队。
- 比较双方装备、路线、体能和目标；速度基线见 `基础层/行动库.md#4.2`：对全力奔跑的健全人默认追不上、甩不掉，例外要有具体条件，也不为展示能力预设总能追上。
- **速度受限**（受众有吸引力的受限类型之一）：只在故事里真有追逃窗口时写，不为凑看点硬造追逐，跳窗口仍以 `写作层/素材/受众定位.md#3.1` 为准。物理机制：单侧下肢无辅具单腿跳的启动爆发可很利落，但持续位移速度低于全力奔跑的健全人——被追或被戏弄时，可体现为对方借速度优势提前封堵路线、从容并行施压、迫使她变向折返或随体能消耗而步幅渐短；追赶目标时，可体现为距离被逐步拉开、全力扑抓后因缺乏第二支点缓冲而连人带物真摔，或耗尽余力仍未能截住目标。跳的动态须流畅合理，速度劣势写在距离变化、步幅衰减与双方节奏反差里，不写成平地笨拙跌撞，见 `基础层/行动库.md#8.1`；扑抓或力竭后的真摔按 `基础层/行动库.md#2.2`。拉扯、戏弄分熟人玩闹与恶意挑衅（3.5），涉性另走成人或黑暗授权。❌ 跨书复刻同一套绕前转身或拐角跟丢分镜。
- 被夺拐后比较追赶与等待的后续成本：追回的可能、对方距离、援助到达时间、备用装备位置、购买与适配费用。立即跳追可以比原地等待更值得，但仍可能失败。
- 逃离另按更高紧迫度判断：威胁正在接近时，比较取拐时间与立即跳逃的启动差、出口与隐蔽路线、持续体力、被看见或被抓的后果，以及逃脱后藏身和取得替代装备的成本。跳逃可争取先机，但不保证安全抵达。
- 角色可追人、追物、放弃、换路、提前布局、用车或请他人协助。全力跳追或跳逃后的真摔须由力竭、落点、外力或地面等具体条件产生，不把普通踉跄冒充摔倒；该真摔时也不写成踉跄站稳，见 `基础层/行动库.md#2.2`。

### 3.5 对立挑衅

- 对方用身体完整性、能力、身份或社会规则施压，可以是一句话、一个动作或制度安排。
- 回应可无视、反问、直说、离开、取证、协商、行动反制或正式对抗，不固定四层。
- 不必围观哄笑，也不必每次都赢；更不必每次都付“尊严成本”。
- 对方为何这样说得通，比嘲讽词够不够狠更重要。

### 3.6 社会面与环境

- 无障碍被占、流程歧视、过度帮助、忽略、错误帮助和公共服务都可成为主线。
- 她可以接受、拒绝、协商、教育、投诉、换路径、联合他人或改变制度。
- 不把制度批评当“环境控诉”禁止，也不要求每次最后都只靠个人适应。

### 3.7 题材适配

| 题材 | 可用主轴 |
|---|---|
| 都市与校园 | 工作、学习、装备、占手、公共交通、关系与制度 |
| 言情与家庭 | 照护、权力、亲密、独立、信任与家庭分工 |
| 战斗与冒险 | 装备、支撑、信息、地形、时间与双方决策 |
| 末世与生存 | 资源、撤离、路线、装备、协作与群体规则 |
| 古装 | 礼法、身份、器具工艺、交通、婚配与权力 |

### 3.8 审美与关系场景

穿搭与亲密默认不算受限，定义与升级条件以 `写作层/素材/受众定位.md#六` 为单一来源。以下只保留例子：默认是审美或关系素材；只有常用办法不可用、人物做了取舍、下一步因此改变时，才升为受限。

- 亲密与照护：具体需要产生接触、协商和关系变化，不把每次帮助都写成调情。
- 穿搭与审美：成衣、鞋履、丝袜和定制反映人物审美与装备逻辑。
- 强者私密面：公开能力与私下疲惫、习惯和普通需求并存，不固定为“私下更无助”。
- 亲水与特殊地形：岸边、入水、转移和水中推进分别处理，不只写脱具和抱入水。

### 3.9 健康维护

- 皮肤休息、减压、消肿、复查、康复和装备调整会改变当天计划。
- 可以让角色主动安排，不必每次都被迫取消重要事件。
- 伤病和护理要影响具体行动，不写医学科普。

### 3.10 器具规则

- 安检、医疗、比赛、工作和场所规则可要求出示、调整、寄存或替换装备。
- 先核对真实规则，不能把“安检必卸假肢”当普遍事实。
- 合理便利、申请、替代检查和申诉都可以成为解决方式。

## 四、人物的处置

### 4.1 骨架

常见为受阻 → 判断 → 选择 → 结果 → 余波。人物可以第一轮就放弃或求助（身体移动求助须过 `基础层/日常动作.md#3.7` 门槛），不强制尝试两种策略。

- 成功、失败、妥协和换目标都可行。
- 选择要符合其性格、信息和资源，不为了展示技巧放弃最稳妥的方案。
- 事后可以有疲惫、松弛、幽默、反思或没有特别感受。

### 4.2 性格化

- 急性子可能先行动，慢性子可能先检查，合作者可能先分工，独立者可能选装备。
- 要强不等于拒绝一切帮助，独立不等于偏爱更难的方式。
- 同一人在不同关系中可采用不同方法，这才是人物活性。

### 4.3 边界

- 不把窘迫和疼痛当唯一看点，也不把“必须体面”当另一种束缚。
- 可写真实受伤、恢复和照护，但要有后果和人物经验。
- 受限可以服务爽感、温馨、悬疑、恐怖、幽默或悲剧，不自动把基调拖向压抑。

## 五、心动条件

- **时间**：是否来得及。
- **尊严与关系**：谁在看、谁在乎、谁被承诺。
- **为他人**：角色为什么愿意多付一步。
- **兴趣与欲望**：身体、装备或审美可以让读者在乎这场戏。这只说明它可能是审美看点，不自动升为受限。
- **信息与选择**：读者能否从行动与后果感到这条路的利害，而不是读到一段解释。规划与审查须能复盘理由；正文不写选择理由或替代方案说明。

心动不等于时间压力和失败，熟练、默契和成功也能成立。

## 六、受限弧线

- 早期可偏身体学习和外部条件，中期可偏身份、制度与关系，后期可偏主动选择与价值，但不固定顺序。
- 自选更难、选择放弃、选择求助和选择改变环境都可能是主体性。选择轮椅只适用于没有完整健腿的设定；有一条完整健腿即不把轮椅当主体性方案。
- 不必把“自选受限”当终点，也不把“终于不再为自己证明”当唯一成熟。
- 时长、熟练度、心理状态和剧情阶段分别变化，不能用一个档位锁住全书。
