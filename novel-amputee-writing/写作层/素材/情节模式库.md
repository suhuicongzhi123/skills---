# 情节模式库

> **目录（按需读取，勿整体加载）**：一 使用方法｜二 截肢与恢复（L1–L5）｜三 身份与日常（L6–L11）｜四 处境与群像（L12–L17）｜五 类型场域（L18–L21）｜六 仪式与觉醒（L22–L27）｜七 黑暗与幻想（L28–L30）｜八 成人向模式（L31–L33）｜九 防同构
>
> **定位**：L 编号只提供故事发动机，不提供必须照演的场景流。每条都要由独特人物、目标、阻力和世界条件重新生成。
> **使用纪律**：主引擎取一个，副线可另取；不把同一“画线→手术→恢复→照护→亲密”流程套给所有书。

## 一、使用方法

- 先问“谁想要什么、为什么难、哪里独特”，再选模式；不从恋物节点倒推人生。
- 黑暗、自愿改造、非自愿与成人向须分别授权，不能以含蓄档绕过专项边界。
- 不把具体地点、台词、手术操作、价格和真实机构当可复用模板。
- 故事可以没有明显的起承转合，也可以从一个静态处境逐渐积累。

## 二、截肢与恢复（L1–L5）

| 编号 | 可用发动机 | 必须改变的条件 |
|---|---|---|
| L1 自愿截肢 | 长期身体认同与外部生活之间的选择 | 评估、动机、代价、恢复与后果，不写自伤教程 |
| L2 意外截肢与重建 | 事故或疾病改变既有生活 | 伤病、职业、关系、资源和不同恢复选择 |
| L3 扮残与身份 | 模拟、隐藏、被发现与自我定义 | 可永远停在模拟，不必然真截 |
| L4 渐进改造 | 多次身体选择与不断变化的边界 | 每次都有独立动机与后果，不写成自然升级 |
| L5 黑市医疗 | 非法服务、信息差、剥削与追责 | 风险、法律、健康、权力与调查，不提供真实渠道 |

## 三、身份与日常（L6–L11）

| 编号 | 可用发动机 | 可拓展方向 |
|---|---|---|
| L6 身份真相 | 秘密暴露、信任与重新定义关系 | 不必双向欺骗，关注知情权和选择 |
| L7 日常群像 | 工作、家庭、社区中的连续小事 | 单元目标、人物积累、关系与非身体冲突 |
| L8 生计展示 | 直播、付费服务、劳动与消费 | 平台、收入、边界和公众形象，不默认每次都进入性爱 |
| L9 职场 | 入职、项目、合作、权力与职业发展 | 以专业任务为主，歧视只是可选冲突 |
| L10 校园 | 学习、友谊、住宿、社团与成长 | 成年角色亲密与未成年校园生活分开 |
| L11 论坛与纪实 | 帖子、采访、回忆、不同叙述者 | 视角可靠性、信息差与叙述形式 |

## 四、处境与群像（L12–L17）

| 编号 | 可用发动机 | 使用边界 |
|---|---|---|
| L12 绑架与改造 | 控制、剥削、求生、反抗与后果 | 非自愿黑暗专项，不将施虐当甜宠，不提供教程 |
| L13 康复医院 | 训练、病友、专业关系与出院 | 不同恢复路径、职业与友谊，不只有照护恋物 |
| L14 假肢与伪装 | 技术、外表、身份和暴露风险 | 装备真实、信息与社会反应，不强行每章脱卸 |
| L15 家族与传承 | 家庭价值、审美、期待与个体选择 | 不要求子女复制父母的身体或愿望 |
| L16 豪门与上流 | 资源、继承、公众形象与权力 | 以权力劳动为主，不只被围观和婚配 |
| L17 疗养与病床 | 治疗、探望、恢复、关系与重返生活 | 医疗现实、恢复节奏和职业选择 |

| 编号 | 可用发动机 | 可拓展方向 |

| L18 奇幻与古风 | 世界规则、身份、力量、权力与冒险 | 截肢是否可逆由世界规则决定，避免“断肢必换神力” |

| L21 科幻与游戏 | 技术、虚拟身份、身体与真实 | 技术规则、虚拟与现实的代价和社会影响 |

## 六、仪式与觉醒（L22–L27）

| 编号 | 可用发动机 | 使用边界 |
|---|---|---|
| L22 身体标记与选择 | 标记、协商、身体计划与决定 | 只写心理与关系，不提供截断位置操作教程 |
| L23 术前仪式 | 检查、告别、犹豫、签字与最后确认 | 可反悔，不把仪式写成不可撤回承诺 |
| L24 术后初视 | 敷料、换药、身体认知与关系变化 | 恢复、安全和个体差异优先，不固定“纱布球”反应 |
| L25 双方向往与共同生活 | 双方共同讨论身体、生活和边界 | 不把渐进改造当幸福义务，须重新评估每次选择 |
| L26 截肢后的觉醒 | 对身体变化的认识、接受或重新定义 | 可震惊、平静、释然、混乱或反复，不用固定三板斧 |
| L27 馈赠与献祭 | 身体、爱、信仰、权力与交换 | 区分自愿与胁迫，不把献出身体当最高爱情证明 |

## 七、黑暗与幻想（L28–L30）

| 编号 | 可用发动机 | 使用边界 |
|---|---|---|
| L28 圈养日常 | 控制、依赖、自由、日常与离开可能 | 自愿与非自愿分轨，关注信息和资源，不浪漫化囚禁 |
| L29 恐怖志怪 | 异常身体、传说、调查与规则 | 线索、恐惧和真相优先，不只堆残肢意象 |
| L30 暂时性截肢 | 可逆技术、身份切换、代价与不可逆后果 | 规则一致，恢复必须有条件，不能随剧情随意开关 |

## 八、成人向模式（L31–L33）

> 只在相应露骨程度、同意模式与专项授权下使用；每条都须有成年人的知情、边界与后果。

| 编号 | 可用方向 | 质量与边界 |
|---|---|---|
| L31 量残与鞋履 | 身体、物件、审美、比较和亲密互动 | 不把残端承重和展示当通用动作，避免重复同一量尺仪式 |
| L32 出借与共享 | 多方关系、许可、观看与权力 | 每个参与者都须独立同意，支配者不能替别人给许可 |
| L33 丝袜与玩法 | 衣物、触感、声音和权力游戏 | 敏感与安全按个人，不把袜口弹伤当通用高潮触发 |

## 九、防同构

出现以下情况时，应回到故事核心重想，而不是换皮：

- 主角仍只有“接受自己”或“被伴侣看见后接纳”的人生问题。
- 每个职业都只用于体面与残缺反差。
- 每段关系都靠照护、占有和依赖维持。
- 每个重要转折都是暴露、被看见、被抱、被照顾。
- 每个战斗都靠夺拐、毁假肢和弃具反杀。
- 每本书都要画线、手术、纱布球、第一次摸、第一次亲密。

真正的新意来自不同的目标、价值、信息、资源、人物关系和世界规则，不是同一流程换名字。
