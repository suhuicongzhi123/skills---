# 命名库（N 库）

> 全库唯一命名权威（N）：书名与章节名的命名方法、风格池、候选流程与常见错误。原则：**简短、有辨识度、贴合题材、不露骨直白**——书名是给人点进去的钩子，章节名是给读者定位的坐标。反AI味同样适用：不堆套话、不模板化（判据＝`写作层/文风/反AI写作.md`）。
> **候选流程一行（与 `SKILL.md` 六段调度链 S0 一致）**：用户已指定书名则直接用；未指定给 3 个候选让用户选。章节名在 S1 章纲定题、S3 成章时按本章核心事件校核。

> **目录（按需读取，勿整体加载）**：一 取书名｜二 取章节名｜三 风格池｜四 反套话与不剧透（正反对照）

## 一、取书名（S0）

### 1.1 规则

1. **2-4 字为主**（1 字太玄，5 字以上易啰嗦），网络小说习惯单字/双字/四字最易记。
2. **有画面感或情绪感**，让人一眼联想到题材内核——但❌ 明说「截肢」「残废」这类直白词（俗气且暴露题材，读者自己点进来才懂）。
3. **贴合主角人设与核心梗**：是名媛/主播/学生/大小姐，书名里可以有身份词或意象。
4. **不剧透关键转折**：「自愿截肢」这类后面才揭示的设定，书名❌ 提前戳破。
5. **候选流程**：用户已指定书名则直接用；未指定则给 **3 个候选**交用户选——三条从风格池（三）不同向里取、风格错开，❌ 只给一条，❌ 绕过用户自作主张定名。

### 1.2 常见错误

- ✗ 直白暴露：`我的双腿截肢女友`、`残疾人的生活`——题材感太浓，像科普不像小说。
- ✗ 套话模板：`霸道总裁的残腿小娇妻`——人设撞车、读起来像量产网文。
- ✗ 过长的解释性书名：`重生之我的双腿被截肢后嫁给总裁`——一句话剧透完。
- ✗ 与内容无关的文艺腔：`山海`、`浮生`——放任何题材都行，等于没起。

## 二、取章节名（S1/S3）

### 2.1 规则

1. **每章一个标题**，落在正文文件 `第XXXX章-标题.md` 里。
2. **2-6 字为主**，可以是词、短语或短句；❌ 「第X章」纯数字无标题。
3. **抓本章核心事件或情绪**，不剧透未来、不总结全文；开放式落点的章节标题可以悬一点。
4. **风格全书统一**：要么全部四字（`轮椅到床`）、要么全部人设向（`她站不起来`）、要么全部意象向（`够不着的水杯`）——混搭显乱。
5. **可呼应人物/场景**：残肢、丝袜、高跟、轮椅、床、浴室、楼梯——带一个这类锚点词，读者会心一笑。
6. **反AI**：❌ `风云再起`、`暗流涌动`、`真相大白` 这类万能标题；❌ `第一章 初见` 这种流水账。

## 三、风格池（书名与篇章命名手法）

原则：**点破给圈内人、留给圈外人猜**——残障不直接入题，靠意象/双关/反讽/留白说话。各条给「命名要点＋示例句式」；示例句式是方法演示不是成品书名，❌ 直接照抄当书名。直白向（3.2）也不得过 1.1 第 2、4 条（不明说、不剧透）。

### 3.1 意象向（含蓄，靠画面与双关，不写「截肢/轮椅」）

- **身体空缺＝领地/疆域**：用「领地/疆域/地盘」等空间意象框住缺失，把被锯空的身体与被圈出的空间做双关——空缺即领土，残障不出现却处处在场。示例句式：「空出的领地」「无人的疆域」。
- **等待＝含混期待**：以等待/期盼动作点题，等待对象刻意含混（等腿/等人/等认命），悬念留给读者补全。示例句式：「等一阵风」「等一场雪」。
- **时间留白＋怀旧**：只给一段旧时光的时间词做底色，不点破残障种类，靠怀旧情绪托住全篇。示例句式：「那些年」「旧时光」。
- **「前缀」式留白**：直白残障词＋「前传/后记」等后缀，用「正传会更残」的反差制造悬念。示例句式：「断肢·前传」「残足·后记」。
- **物象替代**：用一件贴身物象（踵/鞋跟/空袖/空裤管）替代被截去的部位，极克制，无一个医学词。示例句式：「断裂的踵」「掉落的鞋跟」「空垂的袖管」。
- **对仗/对照**：两组意象或两个人名并置，制造关系的镜照（一乐一悲/一健全一残缺/一冷一暖）。示例句式：「明与暗」「晴与雪」「动与静」。
- **成语/熟语化用**：取成语熟语外壳，让残缺在旧词新义里化蝶（蜕变/重生/逆流/无阻）。示例句式：「蝶变新生」「花再开时」「残爱无阻」。
- **梦/境/月/风系**：场景＋情绪的组合词，必须粘住一个人物与一段关系——❌ 放任何题材都成立的空洞词。示例句式：「浮生一梦」「月下轻舞」「风里重逢」。

### 3.2 事件/题材自报家门向（直白但克制）

- **身份＋事件＋分卷词**：身份词（律政佳人/警花/名媛）与残障词的反差即钩子，可加分卷词区分篇章。示例句式：「断足·律政佳人篇」「残肢·警花篇」。
- **题材集子直白**：集子名可以从简，但单篇名必须讲究。示例句式：「截肢短篇集」「残障合集」。
- **世界观事件向**：奇观世界观下用「游戏/酒店/国度/联邦」等容器词，把残障写成设定而非伤痛。示例句式：「残障者的游戏」「断腿者之家」「无腿之国」「慕残联邦」。

### 3.3 人物/关系/叙事向

- **人名入题**：单名/全名作题，全篇即这个人的残史，最适合第一/第三人称聚焦。示例句式：「阿X」「小X」（人名代命运）。
- **关系自指**：私人化口吻＋圈内黑话（少一条腿/dw/quad），制造「懂的都懂」的默契。示例句式：「我的轮椅生活」「妹妹少一条腿」。
- **反差宣言向**：把 wannabe／扮残的愿望、反讽、觉醒藏进题目，读题看不出、读完才明白（W 视角素材＝`写作层/素材/W视角.md`）。示例句式：「化身维纳斯」「完美的伪装」「愿望成真」。

### 3.4 论坛生态向（仿帖体参考，一般不直接用作书名）

- **连载体用日期/楼层做章节号**：日期/楼层/集数做章节标题，是真人连载的元信息痕迹；写「论坛帖体/连载体」仿写时参照，正式作品不采用。示例句式：「1月8日在46楼更新」「第一百一十四章（大结局）」。
- **求文/转帖类标题**：题目即仓库索引（求文/接帖/更新楼层），是真人生态指纹，同为「仿帖体」参考而非命名范本。示例句式：「求文」「更新第十二章在33楼」。

## 四、反套话与不剧透（正反对照）

- ✗ 套话/剧透反例句式：「截肢女上司的幸福生活」（一句话剧透完）、「重生之轮椅千金逆袭」（撞车＋剧透）、「她自愿截掉双腿的内幕」（把高潮写进书名）、「残疾总裁爱上我」（量产模板）。
- ✓ 反套话要点：用一个「缺了半句」的词（领地/风/前传/那些年/良缘/踵/重开日）让读者自己补全「缺的那半句」——这本身就是题材的镜像。
