### 剧情契机标注（素材由剧情内生供给）
> 大纲阶段**只识别不分配**——标注各章剧情天然携带的素材契机；
> 写作阶段按契机写，事后以限频/健康度体检（见 `core/audience.md#招牌元素密度与疲劳控制`）。
> 剧情不为了清单内容而改造；清单内容是剧情的内生产物。

| 章 | 天然契机（剧情自带） | 对应元素 | 备注 |
|----|---------------------|---------|------|
| 1 | | | |
| 2 | | | |

- 契机识别：从各章场景/事件反推天然素材（如「本章有更衣戏→①④契机」「本章进城社交→⑥契机」）；
  七类触发契机清单见 `core/audience.md` 两档供给
- **限频（非排班）**：常规型（③④⑤⑥⑦）同一元素出现间隔 ≥2 章（体检项，防过密）；
  触发型（①②）契机出现时写足、无契机整章不出现是正常状态
- **健康度预检（冷读体检项）**：连续 8 章常规型覆盖 <4 类时提示检查契机标注是否遗漏
- 元素命名须与 `core/audience.md` 招牌元素清单一致，**登记一律用全称**（否则账本无法比对）：
  残肢/剩余部分细节 · 颤动 · 幻肢感 · 空 · 辅助器具特写 · 被看见 · 亲密中的身体
