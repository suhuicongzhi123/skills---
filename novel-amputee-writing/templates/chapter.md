## 章末核查清单（必过）
- [ ] **开篇雷同检查（仅首章）**：对比本项目/往期首章，是否又走 wake→shower→dress→crutch 老路；无题材理由则重开（见 `core/opening.md` 烂开篇反例清单）
- [ ] 截肢侧别与设定一致
- [ ] 截肢部位与设定一致
- [ ] 生理事实兜底审查（无截肢部位参与不可能动作，见 `core/physio-audit.md`）
- [ ] 拐杖状态连续（放下/起有动作）
- [ ] 物品位置连续（转移有动作）
- [ ] 双手+移动场景已查 `topics/hands-occupied.md`
- [ ] 回避幻肢痛/劳损/伤口
- [ ] 不渲染苦难/猎奇/励志二元
- [ ] 幻肢感未误写为幻肢痛
- [ ] **幻肢感频率符合截肢时长档位**（先天档不得写、多年档须低频，见 `topics/timeline.md`）
- [ ] **招牌元素未连续重复**：本章 beat 类型与上一章不同，且未在清单里只盯 2–3 个元素
      （见 `core/audience.md#招牌元素密度与疲劳控制` 与 state-ledger 的近三章 beat）
- [ ] **devotee/wannabe 角色**（若有）未喧宾夺主、未改变 central question（见 `core/audience.md`）
- [ ] 服装处理符合 `topics/clothing.md`（含患侧裁剪位置是否正确）
- [ ] 代入感与日常真实
- [ ] 风格统一（口语化、生动）
- [ ] 去AI化（无套话/升华/排比堆砌/书面腔）
- [ ] 章节结尾不升华（停在动作/画面/情绪/悬念）
- [ ] setup/payoff 状态更新（`state-ledger.yaml` 的 open_setups）
- [ ] 已更新 `state-ledger.yaml`
- [ ] 冷读子代理稽查（可选，`core/cold-review.md`）
