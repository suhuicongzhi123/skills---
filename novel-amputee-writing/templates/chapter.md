## 章末核查清单（必过 + 文学自评）

> **执行规范（防自查偷懒，四条铁则）**：
> ① **留痕三件套**：逐项输出「项名｜判定｜证据」——证据＝正文引句 / 实际计数 / 账本字段值；
>    **无证据的 ✓ 视为未查**，须补查后重报。反例：`破折号 ✓`；正例：`破折号 ✓｜正文共 2 处（引原句）`
> ② **★深查项附检查过程**：标 ★ 的项（历史漏检高发）在判定+证据外，须写明查了哪几段（引正文）；
>    速通式 ✓ 无效。
> ③ **计数项强制报数**：破折号 ≤3 / 对比句 ≤1 / 首章 beat ≤2 类 / 限频 ≥2 章 / 近 5 章载体不重复 /
>    主冲突线窗口非留白章数
>    ——凡可数项必须给实际数字；**不报数＝未查**。
> ④ **零发现警戒（反证轮）**：一轮自查若全部 ✓ 且零修改——不许直接过：自选 3 处最可能出错的段落
>    （优先出场段 / 动作密集段 / 对话密集段）引原文逐段重查并说明为何确实无问题。
>    查不出问题是正常的，但必须证明「查过」——不硬造问题，也不空口说无问题。

**剧情结构**（见 `core/chapter-planning.md`，口径以该文件为准）
- [ ] **本章 beat 存在**：能说出推进了哪段弧线的哪一步；填不出 → 这章没有存在理由
- [ ] **本章有 turn**：章内有瞬间改变了什么；无 turn → 流水账
- [ ] **有新信息**：读者这章新知道了什么；全无 → 砍或合并
- [ ] **stakes 有变化**：相对上一章升了或换了类（连续 3 章无变化 → plateau）
- [ ] **章末钩子类型**：已选且已登记账本；与上一章不同类；近 5 章内同类型至多 1 次；复用须换载体
- [ ] **章节功能已登记**（主线推进/关系深化/日常样态/对抗危机/生存危机）
- [ ] **主冲突线 beat 已判三态**：推进/蓄势/留白已登记账本；冲突强度档配额窗口达标
      （烈＝连续 3 章 ≥2 非留白且留白不连 2 章；高＝5 章 ≥3；中＝5 章 ≥2；低＝只登记；
      窗口不足 → 标记提示后续补足，不回改不强造）；判「推进/蓄势」能引正文对抗线原句
- [ ] **阅读承诺已回应**：本章首承诺被兑现/翻转/推进（三选一，不可无回应）
- [ ] **章末钩子强度**：已标 H（强钩）或 h（弱钩）；连续 5 章内强钩 ≥3
- [ ] **卷末大钩**：弧线 resolution 章章末用 H4/H6/H7 之一，并指向下一弧线 central question
- [ ] **弱钩不连续**：h 未连续出现 3 章
- [ ] **张力级已登记**：落在体验曲线设计值 ±1 内（见 templates/outline.md#★体验强度曲线）
- [ ] **接住上章钩子**：本章开场接住上一章章末钩子（未接住须注明是否故意延迟）

**受限与不便**（见 `core/audience.md#★受限清单`，与招牌元素分开计数）
- [ ] ★**每章 ≥1 核心受限（设计优先）**：大纲每章戏剧主问题牵动截肢事实；弱受限/点缀不计入
      （层级判定见 `topics/limitation-scenes.md` 四-补2）。
      类型（一主五衍：功能丧失(主) / 辅助器具剥夺 / 双手占用 / 速度劣势 / 对立挑衅 / 环境与他者；无辅具时不选辅具依赖轴两类）+ 场景 + 处置三要素齐全；
      同类深挖合法，同事件改词重演＝严重失败
- [ ] **处置动作已写出**：不是只呈现困境（只有呈现没处置＝为受限而受限，砍掉）
- [ ] **受限成立**：是"事情变难/做不了"（行为方式须改变或无解），不是拐杖卡住、拐头打滑之类的小毛病，
      也不是「累了/慢了」的弱受限充当核心受限
- [ ] **未滑向苦难**：无疼痛 / 劳损 / 伤口 / 诉苦 / 被同情——
      **安全败退不属苦难**（三判据满足的自选放弃合法，见 `core/audience.md#★安全败退阀`）

**严重错误五项（合一闸——任一命中即严重失败，先改后交，见 `SKILL.md#〇-补`）**
- [ ] ★**截肢事实无偏移**：部位/侧别/时长档/训练程度与账本固定属性逐项一致
- [ ] ★**生理动作无违规（含未覆盖动作）**：`types/{type}.md` 未列的动作同样按生理事实推断
      （该动作需要哪些肢体参与？缺失肢体在参与列表内即违规）——不得以「技能没写」放过
      （判定见 `core/physio-audit.md#未覆盖动作兜底`）
- [ ] ★**辅具连续性无偏移**：拐杖/假肢无凭空出现消失、状态连续；正文辅具均在限定枚举内
      （腋拐/肘拐/平台拐/假肢及组合；其他物品充当辅具＝违规）
- [ ] ★**基调无漂移**：本章剧情在大纲锁定的基调核心循环内（对照 `templates/outline.md#★主题材契约`）；
      内幕转向/存在论升级/未经要求的道德困境化＝命中即改
- [ ] ★**情节无重复**：本章事件与账本 `情节事件登记` 近 5 章比对——同场景域+同事件结构复现、
      复述/简写/改词重演（「又一次」「像上次」）＝严重失败（判定见 `core/audience.md#★情节查重`）

**一致性**
- [ ] **开篇雷同检查（仅首章）**：对比本项目/往期首章，是否又走 wake→shower→dress→crutch 老路；无题材理由则重开（见 `core/opening.md` 烂开篇反例清单）
- [ ] 截肢侧别与设定一致
- [ ] 截肢部位与设定一致
- [ ] ★**生理事实兜底审查**（无截肢部位参与不可能动作，见 `core/physio-audit.md`）
- [ ] ★**动作可行性（动作链逐段核对）**：本章每个动作密集段，逐动作链核对——支撑点是否存在 /
      拐·假肢是否不离身（交出辅具后的无支撑位移＝违规，"拐塞掌心"事故教训）/
      双手是否被占 / 腾手后支撑是否降级（挂肘·夹腋后该拐不承重，见 `topics/hands-occupied.md` 一-补）
- [ ] ★**移动-辅具一致（拐杖分离检测）**：正文移动方式与账本辅具状态绑定——
      拄拐走 ⇒ 拐杖在手且有步态动作；单腿跳 ⇒ 拐不在手且未穿假肢且有原因
      （分层口径见 `topics/crutch-usage.md#四-补、移动方式分层与无辅具时的单腿跳`）；
      **放拐合理性**：双手占用场景按 `topics/hands-occupied.md` 腾手策略阶梯选层
      ——轻微占手放拐＝辅具弃用非理性（放拐仅限末端解条件或十步以内豁免）；
      出场段落尤其核查（先交代辅具在场与状态）；拐杖状态连续（放下/拿起有动作）
- [ ] 物品位置连续（转移有动作）
- [ ] 双手+移动场景已查 `topics/hands-occupied.md`
- [ ] 回避幻肢痛/劳损/伤口
- [ ] 不渲染苦难/猎奇/励志二元
- [ ] 幻肢感未误写为幻肢痛
- [ ] **幻肢感频率符合截肢时长档位**（先天档不得写、多年档须低频，见 `topics/timeline.md`）
- [ ] ★**幻肢档位真实度**（B 档真用真摔/C 档仅肌肉反应无后果，见 `topics/timeline.md#幻肢档位总表`）
- [ ] ★**招牌元素限频**：对照 `state-ledger.yaml` 的 `distribution.元素上次出现章`，
      本章所用常规型元素距上次出现 ≥2 章（限频非排班）
      （触发型①②不受此限，但无契机不硬写——见 `core/audience.md` 两档供给；
      「连续 8 章常规型覆盖 ≥4 类」为冷读体检项，不在章末核查，命中时提示检查契机标注）
- [ ] **首章 beat 数 ≤2 类**（仅首章，查账本 `首章beat数`）
- [ ] **devotee/wannabe 角色**（若有）未喧宾夺主、未改变 central question（见 `core/audience.md`）
- [ ] 服装处理符合 `topics/clothing.md`（含患侧裁剪位置是否正确）
- [ ] 去AI化（无套话/升华/排比堆砌/书面腔）
- [ ] **无注释式纠错 / 注释式解释 + 破折号闸门**：正文无「A——不，B」式自我更正、
      概念否定、身份注解（变体家族见 `core/style.md#★禁止注释式纠错与注释式解释`）；
      **结构性破折号 ≤3/章（同一功能不连续出现2次）；注释式纠错四型＝0**，
      对话内的中断/呼喊/拟声延长不受限（合法白名单）；「不是X。是Y。」分句式对比句 ≤1；
      同一动作链句式不复用——**单处合法、合计超限即改**
- [ ] 章节结尾不升华（停在动作/画面/情绪/悬念）
- [ ] setup/payoff 状态更新（`state-ledger.yaml` 的 open_setups）
- [ ] 已更新 `state-ledger.yaml`
- [ ] ★**心动句非同源**：本章若有心动/招牌 beat 句，与五处示范节（core/audience.md★平庸 vs 心动、core/style.md★三阶示范、topics/limitation-scenes.md 四-补3、topics/wannabe.md 向往的具象素材、topics/intimacy.md 亲密场景库）逐句比对——**载体/动作/落点意象 ≥2 项相同即判照抄**，命中即改写；并查账本 examples_used（近 5 章不得同载体）
- [ ] 冷读子代理稽查（可选，`core/cold-review.md`）

**★文学自评（每章章末必答；答案写入 templates/state-ledger.yaml#本章自评，供冷读抽查）**

> 不是勾选，是填空；无合格锚的答案是无效答案（等于没答）。

1. **代入感主通道**（选 core/audience.md#★代入感通道库 一条）+ **最"跟着她"的一段（引 1 句正文原句）**
   合格锚：引的必须是本章正文原句，且是某通道的落点句。
2. **声口是否贴人物卡声口字段** + **本章最生动的一句**（引原句 + 标命中了 ★中文质感六技 的哪一技）
   合格锚：该句必须能标出技法名（炼字/通感/白描/叠词音韵/以物写人/留白）。
3. **本章受限 beat 她在乎什么**（时间压力/尊严/为他人——选一）
   合格锚：与该章受限 beat 的处置能对上。
4. **本章最高张力场景用了哪档句式**（短句/长累积句/片段，见 core/pacing.md）+ 引 1 句佐证。
5. **对话是否承担双功能**（信息+性格/信息+关系）+ 引 1 句。
