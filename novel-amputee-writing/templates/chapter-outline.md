# 章纲表（Chapter Outline）

> **用途**：大纲阶段逐章填写，是"第 17 章发生什么"的唯一载体。
> `templates/outline.md` 的「章节划分」节只做全书总览（4 列），本表做**章级十四项**（一句话剧情／章节功能／beat／turn／新信息／stakes／钩子／受限／主冲突／承诺／张力／节拍／敌方阶／视角）——两组章号与章节功能必须一致。
> **没有这一行，不许开写该章**（开写前的 `templates/chapter.md` 是执行记录，不是设计文件）。
> 章级规则权威源：`core/chapter-planning.md#一、章八要素`；本表只是它的载体，不另立标准。

## 一、填写口径

| 列 | 填什么 | 不合法 |
|---|---|---|
| **一句话剧情** | 本章发生了什么（主谓宾，一个事件） | 「她成长了」「气氛紧张」——无事件 |
| **章节功能** | 主线推进 / 关系深化 / 日常样态 / 对抗危机 / 生存危机（须与 `templates/outline.md` 章节划分一致） | 空；或与大纲总览不一致 |
| **beat** | 推进所在弧线的哪一步（Hook / Rising / Midpoint / Crisis / Resolution） | 只写弧线号，不写步 |
| **turn** | 章内哪个瞬间改变了什么（信息反转／关系微移／自我认知偏移） | 「没有明显 turn」——那这章是流水账 |
| **新信息** | 读者这章新知道了什么 | 「无」——砍或合并 |
| **stakes** | 相对上一章升了还是换了类（升／换类／平） | 连续 3 章「平」＝节奏 plateau |
| **钩子** | H1–H7 / h8–h10（见 `core/chapter-planning.md#二`） | 「有悬念」——须给类型 |
| **受限** | 本章核心受限类型；本章为 0 填「—」（配额制，见 `#一-补`） | 弱受限/点缀填进来 |
| **主冲突** | 推进／蓄势／留白（呼吸章计蓄势；crisis 必推进） | 空 |
| **承诺** | 章首给读者的可期待问题（具体可判） | 「她会面对自己」——抽象 |
| **张力** | 1–5；同一弧内须有坡度 | 全弧同值 |
| **节拍** | 蓄／爆／呼／转 | 空 |
| **敌方阶** | 1 轻敌／2 识别／3 针对／4 学习；非战斗章填「—」 | 战斗章空 |
| **视角** | 主视角人物；切换章须标注 | 频繁切换不标 |

## 三、填完必查（大纲质量闸）

- [ ] **章号连续**，无空号/重号；总章数与 `templates/outline.md` 的「章节划分」节一致
- [ ] **每章都有「一句话剧情」**——有一行空着就是大纲没做完
- [ ] **受限配额**：按 `计划章数` 定档后查表（单章全篇≥1／短篇全篇≥2／中篇 近3章≥1・每弧≥2／
      长篇 近3章≥2・每弧≥3／超长≥61 近4章≥2・每弧≥4）；**不是每章都有**，破窗才是硬错
- [ ] **主冲突配额**：按冲突强度档（烈/高/中/低）过窗口；crisis 章＝推进
- [ ] **钩子**：相邻章不同型；近 5 章同型 ≤1；每 5 章强钩 H ≥3；卷末章 H4/H6/H7
- [ ] **张力曲线**：按强度档过下限；无连续 3 章 ≥4；5 级章后 1–2 章内有 ≤2 呼吸章
- [ ] **弧线覆盖**：每段弧线的 Hook/Midpoint/Crisis/Resolution 都能在表里找到对应章
- [ ] **五条全书钩子**：主冲突线**每弧**至少推一层/阶/段（对照 `templates/outline.md#★全书钩子锚点表`）；
  心愿线/软肋/关系/器物在该表里有章号落点
- [ ] **敌方阶只升不降**：同一敌人跨章若降阶，须在备注写明"换了更强的执行者"
- [ ] **亲密戏**：章号与 `templates/outline.md` 的「亲密戏编排表」一致；首次 C 位置符合篇幅函数
- [ ] **结局三章**：倒数第三/第二/最后一章已在 `templates/outline.md#★结局三章` 填定（代价结算/关系落定/新常态）

## 四、维护规则

- 用户指令插入/提前/替换章 → 先改本表，再改 `templates/outline.md` 总览，最后改账本
  （顺序反了会出现"账本有、纲里没有"的幽灵章）
- 写作阶段允许 ±1 张力级浮动，**但「一句话剧情」与「钩子类型」不得擅自改**——
  改了就是大纲变更，须过确认（`SKILL.md#★用户指令优先` 的例外③）
- 定稿后回填实际值：`钩子` 列改成"实际写成的形态"（与 `templates/outline.md` 的「★事实对齐表」互为校验）
- 本表随大纲一起落盘，登记账本 `工作流执行日志.产物`（文件名如 `章纲.md`）
