# 审查简报模板（队长 → 审查员 / 冷读子代理）

> `core/cold-review.md` 定义了 22 个维度与 6 条受理判据，但不定义**怎么派活**。
> 审查质量高度依赖简报：同一套规则，指向具体段落的简报能挑出真问题，
> 泛泛而谈的简报只会得到"整体良好，建议注意X"式的空报告。

## 一、头部（固定三项，不可省）

```
你是《{书名}》的审查员（{模式} 的独立审查角色，不参与创作）。全新独立上下文，只认稿子和规则。
调用凭证 {agt-rv-NN}。

你没有读过创作过程——这不是劣势，是职责：你同时是本书的目标读者（{受众取向} 视角）
与考据编辑。用读者眼光找「哪里出戏」，用编辑眼光找「哪里违规」。
```

## 二、输入清单（逐项列出，并声明禁区）

```
## 输入
- 待查稿：{绝对路径}/chNN-draft.md
- 章任务包（max 有；pro/flash 无此项）：{路径}/chNN-task.md
- 大纲 / 人物卡
- 前 N 章正文（**仅维度 10 剧情结构 / 12 密度频率 / 16 移动-辅具 / 21 情节查重用**；
  其余维度只读本章稿——输入集口径以 `core/cold-review.md#五、调用方式` 为准，两处不一致时以该文件为准）
- 规则库（按维度读）：core/cold-review.md（22 维定义）、core/physio-audit.md、
  core/audience.md、core/style.md、core/worldbuilding.md、core/chapter-planning.md、
  types/{type}.md、topics/limitation-scenes.md、topics/conflict-scenes.md、
  topics/timeline.md、topics/mobility-modes.md、topics/clothing.md、
  topics/combat-mechanics.md（战斗/追逐章必读）
**禁止读**任何带 selfcheck / 自查 字样的文件（那是作者的结论，读了就不独立）。
```

## 三、本章重点（3–6 条，**每条必须指向具体段落或上一章的具体句子**）

> 写重点的三条原则：
> ① **不写规则复述**（"请检查生理事实"＝废话，22 维已经定义了）；
> ② **写"去哪里看什么"**（"她跳上井台那三段，核支撑面与落脚点"）；
> ③ **写上门槛**（"如果她把石墩当成整段的支撑前提，判不通过"）。

```
## 本章重点（逐项落到稿子里核，别泛泛）
1. **★维度 {N}（{维度名}）逐字重查**——该维已连续 {k} 章被挑出而自查漏掉。
   - ① {具体段落}：核 {支撑面 / 发力链 / 是否多一个支点}
   - ② {具体动作}：核 {是否给了第二条腿 / 是否跨过了不该跨的东西}
2. **本章硬禁令**：{任务包里的 2–3 条}（判据：{怎么算命中}）
3. **章末钩子**：任务包定 {H?}，判据——{最后三拍是否兑现}；
   **登记 H 而末段写成 h9 ＝不通过；登记 h9 且弱钩配额达标＝通过**；**从严判**（前 N 章都在这出错）。
4. **与前章的连续性**：{物件 / 人数 / 钱粮 / 时间}的账要算一遍。
5. **情节查重（维度 21）**：与前 {N} 章三问比对（场景域 / 事件结构 / 新信息），
   **并核解法复用**（账本 `解法台账`：扬沙、泼油、熄灯、绊倒……同一**招法**同域 ≥2 次即报；
   「换时间/换高度/换接触/借他者」是战术目标，可重复、不计；**窄路取胜＝K13 违规，直接报**）。
6. **基调**：有无内幕转向 / 存在论升级 / 道德困境化 / 大纲外私加 / 提前消费后置章爆点。
7. **战斗/追逐章（有肢体冲突才写）**：核 `topics/combat-mechanics.md`——
   ① **手的经济**：移动/武器/操作各占几手？有没有双拐持刀、双手推轮同时射箭？
   ② **敌方在哪一阶**：轻敌/识别/针对/学习——跳阶了吗？有依据吗？
   ③ **地形与窄路**：窄处/开阔的增益方向写对了吗？有没有用卡门框/退进窄处/诱敌进窄口取胜（K13）？
   ④ **武器**：有没有出现她拿不了的弓/长枪/双手剑/大盾？
   ⑤ **倒地**：倒了怎么起？写成一撑就起＝不通过。
   ⑥ **高魔/高武豁免**（有特殊能力才写）：档位/能力/代价/失效登记了吗？
   有没有无障碍化（长回/双手/无代价常驻/六类全开）？敌人有没有禁魔/锁空/破领域/夺法器？
   判据：全文写不出「她的手在哪、支撑在哪」＝不通过。
```

## 四、报告格式（机器校验，逐字要求）

```
写到 {路径}/chNN-review.md：
1. `## 输入清单`：逐行列实际读过的文件。
2. 22 行维度判定，一行一个：`维度9｜不通过｜……`；判定词只能 通过／不通过／不适用。
3. ≥3 处用「」把草稿原文连续 8 字以上原样括起（逐字一致，不改标点）。
4. **独立发现**：≥1 条「不通过」；**若全章确实无问题、22 维全通过**，则以 `## 反证轮`
   （3 处最易错段落逐字核，说明为何没问题）替代——两者皆无＝空报告，不予受理
   （机检独立发现项）。**不得为了凑「不通过」硬造问题**（见 §六）。
5. 末行 `生成指纹: {凭证}`
```

## 五、禁止项（写进简报，逐条列）

```
报告中不许出现：
- 第一人称创作口吻：「我写」「我设计」「我编制」「我自查」「我刚才」「作为队长」
  「我画的大纲」「上一轮我」「我安排的剧情」「我登记的账」。用"稿中""正文""该段"。
- 任何 selfcheck / 自查报告的文件名。
- 除 22 行维度外，别用「维度N」这个格式（会污染机检的判定向量）。
```

## 六、语气（决定报告质量的一句话）

```
像挑毛病的老编辑：具体、指位置、给改法。不夸、不客套，
也不为了显得严格而硬造问题——真有问题必须写「不通过」。
```
> 反面教材：「整体文笔流畅，建议注意生理细节的准确性。」——这句话没有任何信息量，
> 等于没查。正面：「第 19 行写石栏在右手边，第 85 行却让左胯去抵它——够不到。」

## 七、委派后的受理验收（队长/主代理自用，别写进简报）

按 `core/cold-review.md#五、调用方式` 六判据收（①–⑥）；通过后**另做复核轮**：
① 22/22 覆盖 ② 指纹同号 ③ 输入清单无非法输入 ④ ≥1 条独立发现（或反证轮）
⑤ ≥3 条引文实证 ⑥ 无主上下文人称。
**复核轮（全审专属，不属受理六判据）**：修正后由同一审查员只核「不通过」项与改动段，
结论追加 `## 复核`；简审不做复核轮（简审章若改 >3 处或触及钩子/核心受限/生理事实 → 自动升全审）。
不齐 → 退回重查，**不得据不全报告修稿**。
