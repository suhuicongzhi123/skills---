# 章纲模板

> 规划员落盘 `大纲/章纲-第XXXX章.md`。章纲详实度＝并行写作质量：写章人只看章纲即可独立成章。批量任务时每章一份，批内章与章首尾相连（第 X 章落点＝第 X+1 章承接点）。

```markdown
# 章纲：第XXXX章 《章节标题》

- 承接点：（紧接上一章结尾与「章末状态快照」的一句话——位置、辅具、衣饰、悬而未决的事）
- 落点：（本章收尾的钩子 H1–H8 或 h9–h11——下一章从哪里接）
- 本章末状态快照：（一句话锁死本章结束时的：角色位置／辅具在手或放置状态／衣饰状态／体力或伤势余波，供下一章并行写作精准对接）
- 时间与地点：____
- 当前阶段：健全期 / 截肢事件 / 恢复期 / 残障期
- 目标字数：____（默认 7000–9000，生计展示流 3000–8000）

## 核心事件与冲突
（本章核心重头戏是什么 + 交锋/波折是什么 + 场景落点五型取哪一型；核心受限与十大招牌看点的变奏切入点）

## 场景流（3–5 个，写明各场目标→波折→落点及预估字数）
1. ____（含在场人物、空间位置与动作支点）
2. ____

## 人物
| 人物 | 本场欲望/立场 | 关系变化 |
|---|---|---|

## 伏笔与回收
- 埋：____（构成后续期待的元素，须已在大纲内）
- 收：____（回收此前哪一章的哪一处）

## 题材要点与精准取节导航（供写作员靶向轻注入）
- 精准取节清单：____（写明「文件路径#小节号」，如 `基础层/行动库.md#1.7 单腿跳`、`基础层/日常动作.md#三 双手占用、#六 服装`，❌ 只写笼统文件名）
- 本章适用的类型物理/着装流派/题材规则要点（一两行）

## 待确认事项
（无则写「无」）
```

## 落盘纪律

- 承接点与落点缺一项＝章纲不完整，不得交付写作。
- 标题按 `写作层/素材/命名库.md`：反套话、不剧透、风格与全书一致。
- 落盘章纲文字保持干练、清晰、直奔主题，❌ 夹带「呢／啦／呀／嘛」等口语软尾。
