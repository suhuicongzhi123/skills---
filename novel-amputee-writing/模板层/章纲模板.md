# 章纲模板

> 规划员落盘 `大纲/章纲-第XXXX章.md`。章纲详实度＝并行写作质量：写章人只看章纲即可独立成章。批量任务时每章一份，批内章与章首尾相连（第 X 章落点＝第 X+1 章承接点）。

```markdown
# 章纲：第XXXX章 《章节标题》

- 承接点：（紧接上一章结尾与「章末状态快照」的一句话——位置、辅具、衣饰、悬而未决的事）
- 落点：（本章收尾的钩子 H1–H8 或 h9–h11——下一章从哪里接）
- 本章末状态快照：（一句话锁死本章结束时的：角色位置／辅具在手或放置状态／衣饰状态／体力或伤势余波，供下一章并行写作精准对接）
- 时间与地点：____
- 当前阶段：健全期 / 截肢事件 / 恢复期 / 残障期
- 开篇维度（仅第0001章填写，其余章填「不适用」）：____（A–J，见 `写作层/技法/章节规划.md#九`）
- 目标字数：____（默认 7000–9000，生计展示流 3000–8000）

## 核心事件与冲突
（本章核心重头戏是什么〔篇幅第一名〕 + 阅读承诺 + 交锋/波折/turn 是什么 + 场景落点五型取哪一型 + 峰值段位置〔65–85%〕或养护恋物章的感官波次节点；核心受限/在场余波与十大招牌看点的变奏切入点）

## 场景流（3–5 个，写明各场目标→波折→落点、连接词〔因此/但是〕及预估字数）
1. ____（含在场人物、空间位置与动作支点）
2. ____

## 人物
| 人物 | 本场欲望/立场 | 关系变化 |
|---|---|---|

## 伏笔与回收
- 埋：____（构成后续期待的元素，须已在大纲内）
- 收：____（回收此前哪一章的哪一处）

## 题材要点与路由标签（供写作员靶向轻注入）
- 场景标签：____（从移动、拐杖、假肢、日常、受限、战斗、辅具剥夺、亲密、恢复期、照护、恋物中勾选本章涉及项）
- 例外读取（创作包索引之外需临时读取的库小节，未写即不读）：____（写明「文件路径#小节号」，如 `基础层/行动库.md#1.7`、`写作层/素材/冲突与战斗.md#十七`，无则写「无」）
- 本章适用的类型物理/着装流派/题材规则要点（末世题材另含本章资源收支，一两行）

## 预检与待确认事项
- 预检：通过 / 需修（核对八要素、阅读承诺可判性、篇幅第一名、峰值/感官波次、受限在场、与前章快照衔接）
- 待确认事项：（无则写「无」）
```

## 落盘纪律

- 承接点与落点缺一项＝章纲不完整，不得交付写作。
- 标题按 `写作层/素材/命名库.md`：反套话、不剧透、风格与全书一致。
- 落盘章纲文字保持干练、清晰、直奔主题，❌ 夹带「呢／啦／呀／嘛」等口语软尾。
