# 设定模板

> S0 初始化落盘为项目根 `设定.md`。设定已存在时跳过重建，只增补。字段留空＝未定，开写前必须补齐。

```markdown
# 设定：《书名》

## 基本信息
- 题材：现实向 / 幻想向 / 末世生存 / 古装向（四选一，全书锁定）
- 亲密尺度档：A 含蓄（默认）/ B 情色 / C 成人（B/C 须用户显式确认）
- 视角：第三人称限知（默认）/ 第一人称 / 其他（注明）
- 目标总字数 / 是否分卷：____
- 参考文本：无 / 指定篇目与路径

## 主角物理基准（类型决定，最高优先不可违背）
- 类型文件：基础层/类型-____.md（髋离断/膝上/膝下/肩离断/肘腕/双侧叠加）
- 残肢长度与侧别：____
- 阶段：健全期 / 截肢事件 / 恢复期 / 残障期（物理红线见 基础层/身体细节与幻肢.md#恢复期时间线）
- 辅具：腋拐 / 肘拐 / 平台拐 / 假肢 / 无（单腿跳）/ 组合（注明）

## 人物表
主要人物逐人登记：姓名｜组合（类型＋O＋P＋R＋M＋L，可加 F/S/B）｜一句话定位
配角只写姓名与一句话定位。

## 基调契约
- 基调核心循环：____（本书反复发生的情绪体验，如「受限—应对—小胜」）
- 主冲突线：____
- 文风契约：叙事距离档 ____／声口指纹三条 ____／意象母题 1–3 个 ____

## 用户指定剧情
（用户显式指令登记处；无则写「无」）
```

## 落盘纪律

- 书名未定时以任务核心词临时命名，文件夹与文件名随之，定稿后统一改名。
- 本模板之外的字段 ❌ 自行扩表；项目特有需求写进「用户指定剧情」或角色卡。
