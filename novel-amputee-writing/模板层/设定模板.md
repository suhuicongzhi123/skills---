# 设定模板

> S0 初始化落盘为项目根 `设定.md`。只填本项目需要的内容；设定已存在则增补，不覆盖。

```markdown
# 设定：《书名》

## 故事核心
- 主角目标与行动时机：____
- 核心阻力／冲突：____
- 本书最独特的关系、规则或身份：____
- 核心看点与主线因果锚定（前因危机／阻力→身体代偿或互动破局→对后续主线或关系的实质改变，防主线与看点两张皮，见 `写作层/人物/人物塑造.md#1.2`）：____
- 结局方向：兑现／失败／变形／开放（可后定）

## 题材与呈现
- 题材组合：主舞台____＋规则增量____＋场景增量____（现实／幻想／末世／古装按需组合，不重复通用规则）
- 叙事视角与距离：____
- 基调与主要阅读体验：____
- 语言基调：普通话为主／带地域口音（何地）；粗口上限：____（未指定按 `写作层/文风/台词库.md#1.16`，全年龄最高中度）
- 主基调与情绪收益：轻快／温暖／幽默／看见的愉悦／身手爽感／战果畅快／压抑／混合（上列是情绪收益，不是主导体验类别）；苦难是否允许及其作用：____。用户未指定情感色彩时，默认要有活气，并带一笔温暖或活泼；用户明示阴沉、冷静、苦难或压抑时遵守契约，苦难不能成为唯一质地。活气与温度见 `写作层/技法/强度与情感.md#2.7`。
- 受众类型：一般截肢题材 / 慕残向 / W 向 / 混合
- 看点浓度：背景 / 均衡 / 高浓度
- 主导受众体验：审美／受限／能力展示／成为（登记一个主导，其余标辅助）。幻肢、装备、亲密、日常等是素材，须归入已登记的那一类，不另设验收标准。穿搭与亲密无功能分叉时默认审美或关系，不因身体出现或卸具就记核心受限，见 `写作层/素材/受众定位.md#六`。验收与看点分级、详略标尺见 `写作层/素材/受众定位.md#3.1`、`写作层/素材/受众定位.md#3.2`、`写作层/素材/受众定位.md#5.4`。
- 可选用的素材举例（须归入上条已登记类型，不单独验收）：身体形态、动态代偿、装备、幻肢、被看见、照护、亲密、能力反差、燃向等
- 条件触发素材：空管、空鞋、幻肢、残端反应等按衣物、病史与准入场景（`基础层/身体细节与幻肢.md#3.7`）调用，不自动成为每章重点
- 目标总字数／计划章数／是否分卷：____
- 推进模式：逐章交互 / 按批≤3章 / 全自动完本

## 主角身体与装备
- 类型文件：基础层/类型-____.md
- 截肢平面、侧别与保留关节：____
- 先天／幼年截肢／成年后天截肢等经历、病因与手术／皮瓣史：____。当前年龄与受伤／受造年限分开写，勿写成“29 岁时（三年前）”这类自相矛盾。
- 瘢痕来源与当前状态（先天缺如不自动有手术瘢痕）：____
- 当前恢复阶段与熟练度（分开）：____
- 无辅具站立／跳跃等既有能力与习惯（相关时记录，不设类型常数）：____
- 无辅具独立移动（单侧下肢慕残项目）：可选素材／明确承诺。不得填“不需要”，未登记视为待规划。可选素材不要求正文补跳；明确承诺才记录所需动作。非单侧下肢项目标不适用。判定见 `写作层/素材/受众定位.md#3.1`。
- 幻肢体验（个人化，可变化）：____
- 常用辅具与其他可选装备：____（有完整健腿即禁轮椅，不得由 AI 自行推导加入；交叉组合若仍要配轮椅须明示虚构豁免）
- 着装、鞋袜与审美：____
- 空裤管处理（不穿假肢的膝上、髋离断必填，登记剪掉缝合或折叠塞进裤腰固定之一，另有理由才改其他方式；其余类型标“不适用”。见 `基础层/日常动作.md#6.2`）：____
- 空袖管处理（不戴假手的肘腕、肩离断必填，登记揣兜、翻折别住、裁短收口或自然空垂之一，另有理由才改；其余类型标“不适用”。见 `基础层/日常动作.md#6.2`）：____
- 个人动作质感与身体互动基调（选填，锚定主角移动／代偿的动态气质及与核心关系的互动光谱，见 `写作层/素材/受众定位.md#5.4`、`写作层/人物/关系库.md#九`）：____

## 人物表
主要人物逐人登记：姓名｜年龄｜目标｜关系｜一句话定位｜角色卡路径
常驻配角登记轻量卡，不只写名字。

## 世界与题材规则
- 时代、地点、制度与公共服务：____
- 制度执行差异与公共信息传播（若影响主线）：____
- 医疗、器具与维护条件：____
- 虚构豁免（用户明示或经授权登记，含超自然能力）：来源／触发与控制／目标与范围／效果与精度／反馈／持续与终止／代价与失效／跨形态表现；无对应机制记不适用。生效后直接呈现，正文不加医学免责声明；未豁免处仍须内部一致，不为填表强造代价
- 截肢是否永久、能否恢复及其原因：____
- 若有多形态：形态机制（同源／独立构型／投影／附身等）、各形态解剖与部位映射（含无同源、一对多／多对一）：____
- 多形态状态迁移：伤病、治疗、恢复、瘢痕、疼痛、幻肢、疲劳的方向与时间点；动作经验、装备衣物、随身物与解除后空间／支撑：____

## 内容边界
- 亲密尺度：A 含蓄 / B 情色 / C 成人（B/C 已获用户确认）
- 同意模式：自愿 / 自愿角色 play / 非自愿黑暗叙事
- 专项授权：支配、疼痛、羞辱、公开、多人、出借、圈养、自伤与非法医疗，逐项确认，预设不替代授权
- 项目承诺看点与交付要求：____（逐项注明用户明示／AI 经授权登记及兑现方式＝持续推进／阶段推进／单次兑现；素材触发条件另记，普通候选不列入）
- 其他禁区：____

## 用户指定剧情与默认推导
- 用户显式指令：____
- AI 推导但非用户明示的默认值：须单列主角性格与声口。用户未指定时，不得把“冷静、干练、高效、句句正确”作为未标记的默认；从情绪温度、话量、判断方式、社交策略、能力分布中另选并记录。用户明示要冷静干练时可以写，但须登记一处盲点或代价。其余推导：____
- 待确认事项：____
```

## 预设使用原则

- `设定.md` 与角色卡是项目权威源；默认不生成二手创作包，长项目确需薄底稿时也不能反向覆盖本文件。
- 预设只提供起点，不锁死故事。可根据用户方向生成 2–3 个不同核心，而不是只改身体类型。
- B/C 与专项内容必须逐项确认，预设不替代授权。
- 技术字段可由 AI 推导，但须标明哪些是用户选择、哪些是推导。
- 后续允许增加项目必要字段，不为维持模板短小而删掉故事、年龄、同意和动态连续性。
