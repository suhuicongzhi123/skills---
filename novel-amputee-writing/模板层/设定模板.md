# 设定模板

> S0 初始化落盘为项目根 `设定.md`。设定已存在时跳过重建，只增补。字段留空＝未定，开写前必须补齐。

```markdown
# 设定：《书名》

## 基本信息
- 题材：现实向 / 幻想向 / 末世生存 / 古装向（四选一，全书锁定）
- 亲密尺度档：A 含蓄（默认）/ B 情色 / C 成人（B/C 须用户显式确认）
- 视角：第一人称 / 第三人称限知（默认）
- 目标总字数 / 计划章数 / 是否分卷：____
- 推进模式：一次性完成整本书（全自动完本，每批并行≤3章）/ 逐章交互创作 / 按批确认（每批≤3章）
- 四卷体验弧模板：A 独立破冰弧 / B 共生养护弧 / C 渐进蜕变弧（短篇按四节缩放）
- 参考文本：无 / 指定篇目与路径

## 主角物理基准（类型决定，最高优先不可违背）
- 类型文件：基础层/类型-____.md（髋离断/膝上/膝下/肩离断/肘腕/双侧叠加；特殊种族另标翼/尾三档/逆足/断尾/快拆接口）
- 残肢长度与侧别：____
- 阶段与时长档：健全期 / 截肢事件 / 恢复期 / 残障期（先天档 / 近期档 / 多年档熟练态）
- 辅具：腋拐 / 肘拐 / 平台拐 / 假肢 / 无（单腿跳＋掌跟交替旋移）/ 组合（注明）
- 日常着装流派与鞋袜偏好：____（①翻折塞腰·塞兜 / ②挽结束起 / ③裁短封口 / ④自然空垂；短裤/长裙/丝袜高跟偏好）

## 人物表
主要人物逐人登记：姓名｜组合（类型＋O＋P＋R＋M＋L，可加 F/S/B）｜一句话定位
配角只写姓名与一句话定位。

## 基调契约
- 基调核心循环：____（本书反复发生的情绪体验，如「受限—应对—小胜」）
- 主冲突线：____
- 文风契约：叙事距离档 ____／声口指纹三条 ____／意象母题 1–3 个 ____

## 用户指定剧情
（用户显式指令登记处；无则写「无」）
```

## 预设组合（S0 快速选用）

用户选定一套预设后，题材、类型、推进模式与亲密档一并锁定，其余参数由 AI 按预设推导，不再逐题询问。

| 预设 | 题材 | 推进模式 | 亲密档 | 适用 |
|---|---|---|---|---|
| P1 | 现实向 | 逐章交互 | A | 日常、职场、校园、言情（不含亲密细写） |
| P2 | 现实向 | 一次性完成整本书 | A | 同 P1，篇幅较长、希望一次交付 |
| P3 | 幻想向 | 逐章交互 | A | 高魔、高武、都市奇幻、修仙 |
| P4 | 末世生存 | 按批确认（每批≤3章） | A | 废土、丧尸、灾变 |

- 类型与侧别仍须在「主角物理基准」中填写；预设只决定题材与推进方式。
- B/C 档亲密须用户另行显式确认，预设不替代确认。

## 落盘纪律

- 书名未定时以任务核心词临时命名，文件夹与文件名随之，定稿后统一改名。
- 本模板之外的字段 ❌ 自行扩表；项目特有需求写进「用户指定剧情」或角色卡。
