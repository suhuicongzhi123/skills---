# 角色卡模板

> 每个主要人物一卡，落盘 `角色/角色卡-姓名.md`。S0 为任务给定主要人物建卡，规划员为新增主要角色补卡。**已存在的卡只增补不覆盖**；正文中人设变化（阶段进阶/装备变化/关系变化）须回写卡内——角色卡是全书人物连续性的唯一权威。

```markdown
# 角色卡：姓名

## 基本信息
- 组合：类型文件名＋O＋P＋R＋M＋L（可加 F/S/B，含义见 SKILL.md 组合语法）
- 阶段：健全期 / 截肢事件 / 恢复期 / 残障期
- 首次出场：第XXXX章

## 物理基准（最高优先，不可违背）
- 残肢长度与侧别 / 行动方式 / 辅具 / 姿态细节
- 依据：基础层/类型-____.md（❌ 凭想象补物理）

## 身份（O）
职业与生计：现状 / 前后职业流 / 场景锚点（素材见 写作层/人物/职业库.md）

## 性格（P）
核心词 / 外在表现 / 内心底色（素材见 写作层/人物/性格库.md）

## 关系（R）
关系结构 / 互动方式 / 张力点（素材见 写作层/人物/关系库.md）

## 心理（M）
主导模式 / 触发点 / 行为表现（素材见 写作层/人物/心理模式库.md）

## 声音
- 语气基准：____（一句话）
- 口头禅与禁语：____
- 素张弛度：叙述冷静 ↔ 台词外放（1–5 档）

## 情节模式（L）
主导模式与当前节拍（素材见 写作层/素材/情节模式库.md）

## 边界与红线
- 残端接触边界：____（亲密戏用；A 档可留空）
- 阶段红线：当前阶段禁什么（对齐 基础层/身体细节与幻肢.md#恢复期时间线）

## 术语与特殊细节
本人物专用的叫法/习惯/物品（写作与审查都以此核对）
```

## 使用纪律

- 写作员写该人物前必读其卡；审查员按卡核对一致性，不符＝高严重度并提示回写。
- ❌ 在卡里写剧情预告或与本书无关的设定。
