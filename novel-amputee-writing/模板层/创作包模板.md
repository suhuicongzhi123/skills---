# 创作包模板

> 书级创作包＝项目内的**派生摘要**，由规划员在 S1 生成一次，写作员与主对话在整本书的写作过程中只读它，不再逐章加载全库。落盘于 `书名/创作包/创作包.md`。
> 创作包是库的派生物：每条摘要必须注明来源（文件＋小节号），内容只摘不改义。库版本变化（SKILL frontmatter `version` 与创作包头部记录不符）时须重新生成，❌ 沿用旧包。
> 创作包上限 **12 KB**，超限时拆为 `创作包/类型摘要.md`、`创作包/题材与文风.md` 两份，入口仍是 `创作包.md`。

## 生成规则（规划员执行）

1. 读取 `设定.md` 的题材、类型、辅具、着装流派、基调契约，确定本书需要的摘要范围。
2. 按下列各节逐一摘录；每条写「规则 ＋ 来源（如 `基础层/类型-髋离断.md#十一`）」。
3. 摘录只取本书用得上的条目，❌ 把整文件搬进来。
4. 生成后自检：字节数 ≤ 12 KB；每条都有来源；与 SKILL 常驻铁则不冲突。

## 包的结构

```markdown
# 创作包：《书名》

> 生成于 novel-amputee-writing v{版本}｜派生自：{来源文件清单}｜库版本不符时重生成

## 一、通用红线
- 熟练者单腿跳与日常动作（来源：SKILL 常驻 4；行动库 1.7、1.10）
- 距离分水岭与手拐协调（来源：行动库 1.10；日常动作 3.3、3.6）
- 写作时点三问（来源：SKILL 常驻 6）
- 文风硬底线（来源：反AI写作 〇节）

## 二、本书类型物理摘要（主角与在场截肢角色各一段）
- 形态与承重要点（来源：类型文件 形态节）
- 不可能动作清单（来源：类型文件 不可能动作节）
- 受限清单与占手速查（来源：类型文件 受限清单节；日常动作 3.6）
- 幻肢档位与恢复期时间线快照（来源：身体细节与幻肢 二、一）

## 三、题材摘要与禁忌
- 题材定位与零豁免／豁免登记（来源：所选题材文件 一节）
- 本书登记的超自然或特殊移动、辅具替代（来源：世界观题材特有设定）
- 题材禁忌清单（来源：题材文件 禁忌节）

## 四、辅具与物品基线
- 主角辅具类型与当前在手状态（来源：设定；上一章末状态快照）
- 替代器具与备用物（来源：设定；章纲）
- 进行中的辅具剥夺或空白期（若有；来源：章纲伏笔登记）

## 五、文风与声口
- 叙事距离档与声口指纹（来源：设定 基调契约）
- 身体镜头预算档：常规剧情档（1 个特写＋单句在场） / 感官主菜档（每章 2–3 处成段动态特写，适用于高浓度恋物/养护/B·C 档；来源：写作技法卡 九）
- 招牌元素分配规则（来源：受众定位 四、十大核心看点）
- 对白与表情的本书偏好（来源：台词库、表情库，仅摘本书用到的条目）

## 六、例外读取索引
- 写作员在本书常需的库小节（仅列路径与小节号，正文写作时按章纲点名读取）
- 例：`基础层/行动库.md#1.7`、`写作层/素材/冲突与战斗.md#八`
```

## 与其他文件的关系

- 写作员：每章必读本包全文；章纲与本包冲突时停止并返回主对话，❌ 自行取舍。
- 审查员：C 档审查时读本包；B 档只读与命中维度相关的节。
- 规划员：每次章纲变更涉及辅具状态或物理设定时，同步更新本包第四节（辅具基线）。
- 主对话：S0 与 S1 之间确认本包已生成且版本匹配，再进入写作。
