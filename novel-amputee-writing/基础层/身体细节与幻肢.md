# 身体细节与幻肢

> 跨类型通用层：恢复过程、幻肢体验、身体细节与措辞。各类型形态以对应类型文件为准；移动见 `基础层/行动库.md`，辅具见对应文件。
> **分开记录五件事**：术后时间与伤口、动作熟练度、幻肢体验、心理与生活适应、叙事描写密度。它们相关但不等价，不能再用一个“近期／多年档”锁死全书。
> **事实与审美分开**：长期幻肢、个体差异和不同康复路径是事实；每几章出现一次只是写作选择，不是生理频率。长期熟悉自身构造的尾巴、翅膀等部位，默认已整合进动作经验，详见 `基础层/行动库.md` 使用原则，不在本文件复写。

> **目录（按需读取，勿整体加载）**：一 恢复期时间线｜二 幻肢体验｜三 残肢与身体细节｜四 缺失解释与措辞边界

## 一、恢复期时间线

> 下列是常见组织顺序，不是统一医嘱。手术方式、病因、年龄、营养、循环、合并症、感染和康复条件都会改变时长。早期临时假肢与正式假肢也存在不同路径。

| 阶段 | 可关注的变化 | 写作与行动判断 |
|---|---|---|
| 术后早期 | 麻醉与止痛、肿胀、敷料、引流、伤口监测、体位与并发症风险 | 以休息、基础护理和逐步活动为主，不直接写成熟移动与高强度动作 |
| 伤口愈合期 | 拆线或愈合评估、疼痛与感觉变化、皮肤脆弱、瘢痕形成、幻肢体验 | 按愈合与医嘱逐步坐起、转移、用拐或其他合适装备；未愈合处不承重、不浸泡、不作性接触或束缚 |
| 康复与塑形期 | 消肿、体积变化、脱敏、力量、平衡、转移和日常生活训练 | 可独立或协助完成越来越多任务，熟练度逐项发展，不必全身同时“毕业” |
| 假肢适配期 | 取模、试腔、悬吊、对线、试穿、渐进佩戴与调整 | 时间可从较早临时适配到数月不等，按具体方案；不能一律禁止两周试用，也不能直接写到长跑 |
| 长期适应期 | 体积与瘢痕继续变化、装备调整、生活与职业重建 | 行动和亲密能力按当前状态，不把“满六个月”当统一解禁点 |

### 1.1 必须守住的安全边界

- 未愈合伤口、感染、明显肿胀疼痛、皮肤破损或医疗禁忌存在时，不安排相关承重、束缚、疼痛玩法和性接触。
- 亲密活动不必统一推迟到所谓稳定期。伤口与整体状态允许时，可按医嘱、舒适、同意和体位条件恢复，不以日历代替判断。
- 不把早期临时适配写成必然不存在，也不把正式假肢写成一到固定月份就自然适合。
- 任何高强度动作都要有相应训练、装备和恢复过程，不能因人物意志直接越过。
- 医疗条件差的时代与世界会改变风险和康复路径，但不能把愈合写成随题材任意加速。

### 1.2 恢复期剧情节点

按人物选择与主线取舍，不要求每个节点都展示：

- 术前沟通、标记、签字、告别或等待，适合自愿或计划手术。
- 术后第一次看到敷料、换药、拆线、第一次直视与触碰，适合身体认知和关系变化。
- 第一次坐起、转移、用拐、回家，适合生活重建；没有完整健腿的设定另可按实际装备写轮椅出行，交叉组合若仍有健腿而要配轮椅，须明示虚构豁免。
- 取模、试腔、第一次站立、第一次走出家门，适合装备与身份线。
- 并发症、怀疑、反复、疲惫、短暂后退和重新选择，避免恢复被写成单向升级。

恢复不是空白等待期，但也不强制“拆线、第一次看、第一次摸”逐项打卡。节点须改变人物、关系、计划或读者理解。

### 1.3 恢复期的幻肢表现

- 早期可更明显，也可能暂时没有；感觉、痒、痛、位置和运动感不必同时出现。
- 触碰、压力、穿戴、疲劳、注意力和情绪可影响体验，但不存在统一触发清单。
- 可以随时间减弱、波动或长期存在，不把“多年后”写成消失，也不把频率当章节配额。

## 二、幻肢体验

### 2.1 先分病因与经历

- **后天截肢**：幻肢感与幻肢痛常见，表现形式和持续时间差异很大。
- **幼年截肢**：与成年截肢的身体图式和经验不同，不能简单并入先天档。
- **先天肢体缺如**：也可出现幻肢体验；形成机制、身体图景和体验可能与后天截肢不同，也可能有相似的位置感或感觉。不默认有，也不绝对排除感觉或疼痛，不由研究比例替单个角色抽签。
- **wannabe 手术前**：不能凭空拥有真实截肢后的幻肢感；手术后按实际神经与身体变化写。

### 2.2 体验维度

| 维度 | 可用方向 |
|---|---|
| 位置 | 脚、手、膝、指或整段肢体的位置感，可与实际残端不一致 |
| 姿势与运动 | 觉得蜷缩、伸直、想抓握、想迈步或想蹬地；真实缺失部分不能完成。失稳时想蹬地救场见 2.5 |
| 感觉 | 痒、麻、温度、压力、触碰、轻重与存在感 |
| 疼痛 | 灼、刺、抽、痉挛样或其他神经病理性体验，强度和频率因人而异 |
| 变化 | 可持续、波动、减弱或长期存在；有人出现缩影等变化，有人没有 |
| 装备互动 | 穿戴假肢可改变部分人的位置感或体感，也可能没有影响 |

### 2.3 长期幻肢的形态学质感

- 幻肢可以随时间保持原样、改变位置或出现缩影，但不是人人都会发生。
- 长期幻肢可以包括静息姿势、温度、痒痛和存在感，不能只剩“肌肉抽一下”。
- 身体熟练与幻肢长期存在可以同时成立，不能用熟练度否定体验。
- 天气、疲劳与个体差异只作可能条件，不写统一因果。

### 2.4 幻肢受限来源与出现边界

- 多年后的限制可来自解剖、装备、环境和任务，不能只归结为“技能生疏”，也不能把所有困难都推给幻肢。
- 频率由人物病史、当前事件和作品节奏决定，不设每章或每几章一次的硬配额；重复分寸见 3.7，频率仲裁见 `写作层/素材/受众定位.md#4.6`。
- 可在高压、安静、亲密、康复和普通日常中自然出现，3.7 的五类准入是常见触发而非穷举；禁止的只是没有触发、也不承担功能的插播（如普通走路、谈正事时刷存在感的“残端抽动了一下”）。
- 连续出现时须改变触发条件、感受、应对或阶段反应，不只换同义词。
- 若角色长期没有幻肢体验，不为受众期待强行补写。

### 2.5 运动意图与功能落空

- 幻肢运动意图不等于真实动作完成。判定始终看实际参与肢体与结果。
- 失衡可发生在幻肢意图、注意分配和当时动作共同作用下，但不把每次失误都归因于幻肢。
- 长期截肢者也可能出现运动意图和错位感；熟练代偿与幻肢可以并存，但熟练者连续单腿跳或常规拄拐时，不写成“每一步都幻想缺失腿还在迈步”。
- 写“多年只做肌肉反应、绝不想用”是一种人物选择，不是生理规则。
- 上肢与下肢同理：幻手不能真的接住物品，幻脚不能真的支撑身体。
- 救不回的失稳里，期望性幻肢可作可选看点：想用不在的腿蹬地救场，保留关节或残存肌肉跟着动了一下，底下却没有肢体可用，随后按受力方向真摔。优先用在救不回的这一刻，同一场通常一次就够，不设配额，不写成真的蹬到地面，也不为凑这一看点插入打滑。救回与真摔见 `基础层/行动库.md#2.2`。

### 2.6 假肢与幻肢的互动

- 穿戴假肢可改变部分人的位置感、体感或注意分配，也可能没有影响；不合脚与不适可改变体验，但不写成必然。
- 幻肢是感觉与神经体验，不等于角色不愿接受现实。
- 熟练生活、接受身体和持续幻肢可以并存，不能用幻痛证明“尚未接纳自己”。
- 触摸、按摩、镜像、分散注意或亲密可能让某些人暂时缓解，但不写成治疗保证或情感治愈。
- 天气、疲劳与情绪是否与体验相关按个体，不写普遍因果。

## 三、残肢与身体细节

### 3.1 形态判据

- 有骨性残肢的外观是皮肤、脂肪、肌肉与骨共同构成，不能整体写成“硬柱”。
- 髋、肩离断的无骨性软组织可随躯干、压力和外力变形，但不独立完成杠杆动作。
- 手术皮瓣、瘢痕位置、肌肉保留、脂肪分布与年龄决定外形，不统一为圆润、嫩白或对称肉球。
- 先天肢体缺如不自动带有截肢手术瘢痕，其他伤病或生活瘢痕另设；类型文件中的术后形态与瘢痕描述只在相应病史下适用，不得覆盖先天设定。
- 坐姿、侧卧和承重是否稳定按保留骨骼、支撑与训练，不从外形直接推断功能。

### 3.2 坐卧与衣物

- 骨盆和坐骨保留时可坐实；无大腿前伸配重者前后和侧向稳定可能不同。
- 侧卧是否垫枕取决于舒适、瘢痕和习惯，不是每种类型都必须。
- 空裤管、空袖管、空鞋与空椅面是可选意象，不是每章必须出现的身体标签。
- 衣物驱动源要分清：有骨残肢可带动；若空垂，髋肩离断软组织主要随躯干、风或外力变化。不穿假肢的膝上、髋离断首选处理与只交代一次见 `基础层/日常动作.md#6.2`、`基础层/日常动作.md#6.3`。

### 3.3 臀部与骨盆形态

- 髋离断通常保留骨盆与坐骨，半盆切除另写，不能把两者外观和坐位能力混同。
- 骨盆完整不等于外形两侧完全一致，软组织和皮瓣会随手术与个体改变。
- 坐骨存在时可承担坐位压力，但是否需要靠背、座垫或固定带按稳定与舒适。

### 3.4 类型差异速查

| 类型 | 身体细节核查重点 |
|---|---|
| 髋离断 | 无骨性杠杆，软组织随躯干和外力，坐位与半盆切除区分 |
| 膝上 | 有股骨与髋部控制，无真膝，残肢长度不直接等于能力 |
| 膝下 | 有真膝与部分小腿，假脚踝足与真膝分开 |
| 肩离断 | 无上臂残端，肩带与胸背活动保留 |
| 肘腕 | 有上臂或前臂残端，腕旋转按手术 |
| 双侧／复合 | 逐侧判断，不能把较好侧一并删掉 |

### 3.5 取象与基调

- 残端可以敏感、普通、回避、减退或随位置不同而不同，默认不设置“一碰就软”。
- 神经瘤、皮肤破损、压疮、水肿、骨赘和毛囊炎可影响接触与装备，但不能作为固定卖点。
- 残端不是全身神经最密集的统一部位，也不必然疼痛加倍或成为性器官。
- 健康侧可以过用和疲劳，但不自动“也快废了”；合理代价不必回避。

### 3.6 常见并发症与写法

- 并发症可以影响具体行动、计划、关系或资源，也可以只提供真实体感、氛围或受众经验；是否展开看人物与场景需要。
- 皮肤问题可导致停穿、换装备、调整行程或就医，但不自动等于残肢彻底失去用途。
- 治疗和康复是过程，可以用细节体现专业与人物选择，不写成恐吓或医学讲义。
- 维护、维修、更换耗材与调整装备属于真实生活，可用于剧情而非一律禁写。

### 3.7 幻肢与残肢肌肉活动的场景、方式与分寸

本节是身体细节、幻肢与残肢／残存肌肉活动何时出现、如何呈现及何时可重复的单一来源（频率仲裁见 `写作层/素材/受众定位.md#4.6`，详略篇幅见 `写作层/素材/受众定位.md#5.4`）。

- **五类准入场景（常见触发，不是穷举；有具体触发与功能即可自然切入）**：
  1. **突发失衡与本能救场**：脚滑救不回真摔、被猛推、踏空或物品突然滑落时，本能想用缺失肢体蹬地或抓握，引发残存肌肉或有骨残肢瞬间动作并落空（期望性幻肢，见 2.5 与 `基础层/行动库.md#2.2`）。
  2. **高强度发力与有骨残肢主动代偿（严禁把“腰胯／残端软肉一绷一松”当常规发力伴生挂件）**：有骨残肢（膝上／膝下／肘腕）主动抬摆、夹物、顶按、换位时的保留关节带动；**髋、肩离断无骨性杠杆（L2 软组织不承担支撑或位移做功），常规代偿发力（单腿跳落地、撑台沿站立、挪物、直起身、日常干活）的着力点在健侧腿、手臂、掌跟与躯干，一律只写健侧、手掌、肩背与呼吸的受力，严禁顺带附写“腰胯那侧的（软）肉／残端跟着绷紧（一绷）又慢慢松开”！**
  3. **直接触碰、照护与亲密互动**：洗浴、换药、按摩、穿脱假肢／丝袜、量体适配、伴侣抚摸／亲吻／托举，或外物直接重磕在患侧时，受温度、压力、撞击或情动刺激产生的软组织回弹、肌肉收缩或幻肢感变化。
  4. **装备切换与生理／环境刺激**：刚卸下假肢（接受腔压力骤失后的压痕、轻松感与幻肢位置感变化）、久跳或久站后的疲劳酸胀、恢复期牵拉、明显冷热骤刺激、剧烈咳嗽／打喷嚏，或安静独处时的清晰幻肢存在感与痒痛。
  5. **术后初期与 W 视角探索**：新近截肢或 W 术后初期身体图式尚未更新时的习惯性运动意图，以及主动试探残余肌肉收缩控制。
- **五类禁入场景（不应出现，防无效打断与换壳打卡）**：
  1. **普通日常过场与纯信息对话**：常规拄拐走路、正常坐着谈事、吃饭办公时，❌ 无故插播“残端抽动了一下”“幻肢麻了一下”刷存在感。
  2. **充当通用情绪或发力收尾标点（禁作“第二张脸”与“发力伴生挂件”）**：人物只是普通疑惑、犹豫、冷笑、听见一句话，或**只是完成了单腿跳落地、撑台沿、挪物、直起身、拿笔干活等常规健侧发力动作**，❌ 动辄用“残肢一缩／断口绷紧／腰胯那侧的（软）肉跟着绷紧又慢慢松开”当动作收尾标点（除非当场发生直接触碰、外物重磕患侧或突发失衡运动意图落空）。
  3. **隔着日常外衣的旁观者纯视觉**：角色穿着普通外裤／外套（尤其已剪掉缝合或折叠塞腰的长裤）且未发生接触时，❌ 从旁观者视角写“看见空裤管／袖管里的软肉或残端抽动”（有骨残肢较大幅度主动抬摆带动衣管除外）。
  4. **熟练代偿稳态的每一步**：长期熟练者在连续单腿跳、撑物作业或常规拄拐移动中，❌ 写成“每跳一步都觉得缺失腿还在迈步”或“每发一次力腰胯那侧的肉就绷一下又松开”。
  5. **wannabe 手术前**：❌ 出现真实截肢后的幻肢感与残端肌肉收缩反应。
- **三类呈现机制（解绑使用，不绑成“幻肢一想→残端必抽”或“一发力→腰胯必绷松”的固定连招）**：
  1. **纯感觉型幻肢（错位知觉，不绑肌肉抽动）**：只写视角人物感知到的缺失部位位置感、姿势感或温度／痒／麻／刺痛等具体质地（严格按角色实际缺失的是下肢还是上肢对应部位写，❌ 跨类型串位或全书只复读同一种脚趾蜷缩／发痒），可配一个自然的姿态微调或按压缓解，不必每次配残端抽动。
  2. **纯残肢／残存肌肉物理活动（解剖发力与触感，不绑幻肢，严控 L2 触发）**：髋、肩离断无骨性杠杆，日常发力与平衡只写腰胯／肩带随躯干的整体倾斜（L1）及健侧／手臂受力；**臀侧／髋侧／肩胸软组织的局部绷紧、微隆、放松或轻颤（L2）仅在直接触碰、外物磕碰患侧、冷热骤刺激、卸具瞬间或亲密护理时才准写出**，❌ 在普通单腿跳、撑物、起身、挪物后例行打卡“腰胯那侧的软肉绷了一下又松开”，更❌ 写独立抬起、甩动、夹物或顶起空管；膝上、膝下、肘腕有骨残肢，可写保留关节（髋、真膝、肩、真肘）控制残肢主动抬放、摆动、回撤、夹持、顶按，发力时肌肉绷紧、放松时柔软，以及从内部带动衣管。动残肢不必每次解释“因为幻肢想动”。
  3. **运动意图→残余动作→功能落空（仅在突发本能反应或试探时三拍合一）**：大脑本能发出指令（想蹬地、想迈步、想抓握）→ 保留关节或残存肌肉跟着动了一下（髋离断软组织一绷／膝上大腿残肢前送／肩肘残端一抬）→ 远端无肢体可用，动作在半途落空并带来具体后果（真摔、失手或靠其他真实支点救回）。
- **视角与衣物遮挡匹配**：只写视角人物能感知、触到或合理看见的内容；细微肌肉收缩与轻颤只能由**本人体感、他人手掌触觉，或裸露／贴身薄衣下的近距视觉**呈现。
- **何时可重复、何时不应重复（含 L2 残端／腰胯软组织绷松的单章与跨章硬冷却闸）**：
  - **单场与单章内**：同一场战斗、追逃或行动戏里，“运动意图落空／期望性幻肢”留给最关键的真摔或失手瞬间；非亲密、非直接护理场次中，**残端或患侧腰胯软组织的局部肌肉收缩／轻颤／“一绷一松”必须有直接触碰、外物磕碰患侧或突发失衡触发（普通发力干活、跳跃、起身 0 触发），且单章最多出现 1 处（无直接触发则全章 0 处），严禁同章出现两次“腰胯／残端……绷……松”**！前一场已写过某类幻肢或肌肉绷松，同章后一场不再重复。**亲密抚摸／性爱、医疗换药／按摩、假肢试腔调校**专场中，残肢触感与肌肉反应可随互动阶段递进出现，每次须有新的反馈（如接触初期的局部微绷→适应后的放松软化→深按或情动高点时的收紧轻颤），不原样复读同一词。
  - **跨章硬冷却（防连续章打卡）**：**相邻两章严禁连续出现“残端／腰胯那侧的（软）肉绷紧（一绷）又松开”或同类幻肢桥段**！一旦本章使用了残端／腰胯软组织局部绷松或抽动，必须记入章末「④ 本章已用看点与窗口指纹」，**下一章强制进入冷却期（禁用 L2 软组织／残端绷松，除非下一章是专门的亲密抚摸或医疗护理核心重场）**，把身体在场感切换到不对称空间余量、健侧足底／掌心受力、器物交互或人物姿态态度上。角色已在角色卡登记的个人化代偿或小动作习惯可跨章复现作辨识度（❌ 跨书照搬未登记的固定习惯模板），后文复现简写带过；恢复期与病程线跨章出现须体现状态变化或新后果。

## 四、缺失解释与措辞边界

- 角色是否解释病因、何时解释、对谁解释，由人物和主线决定，不强制全书锁一个叙事框架。
- “髋离断、患侧、健侧、坐骨”等词在医疗、康复、专业或熟悉这些说法的人物语境中可以使用；日常对话按人物知识，不统一清零。
- 常态化不等于角色不知道自己的医学情况，也不等于旁白只能说“软肉”“小肉球”。
- 解剖与临床词应准确、必要、符合说话者，不为展示专业知识而科普。
- 身体描述可用普通部位名、残肢、残端、左右侧和具体动作，亲密昵称只留给合适关系与语境。
- 病因可以是前史、悬疑、现实问题或不解释的事实，但不能强迫所有作品回避“为什么”。
