# 辅具-拐杖

> 现代腋拐、肘拐、平台拐与手杖的结构、量裁、使用和疲劳。古装与低技术器具另建材质和工艺表。
> 动作与移动见 `基础层/行动库.md`；日常腾手见 `基础层/日常动作.md`；类型差异见各类型文件。
> **原则**：拐杖首先是支撑工具，也可成为私物、审美载体和识别特征；象征与情感不能覆盖当前任务、安全和人物知识。有完整健腿即禁轮椅。其他类型可与助行器等设备按任务共存。

> **目录（按需读取，勿整体加载）**：一 辅具选择与组合｜二 腋拐｜三 肘拐（前臂拐）｜四 平台拐｜五 承重口径与身体代价｜六 步型定义与移拐节奏｜七 上下楼｜八 摔倒与起身｜九 持拐日常与双手占用｜十 单拐与双拐｜十一 拐杖与假肢并用｜十二 写作纪律

## 一、辅具选择与组合

- 腋拐、肘拐、平台拐、手杖、助行器和假肢各有适用条件，可组合使用。轮椅只与没有完整健腿的设定组合；有一条完整健腿即不因本条改用轮椅。
- 选择依据是支撑、握力、肩腕状态、距离、地面、腾手需求和个人习惯，不只按截肢平面。
- 腋拐可以作为受众偏好的视觉选择，但不能因此忽略更合适的器械。
- 量裁目标是拐头完整接触地面、手柄便于承重、姿态稳定，具体由使用者与适配人员调整。

## 二、腋拐

| 部件 | 功能 |
|---|---|
| 腋托 | 定位与保持杖身，避免长期压迫腋窝 |
| 手柄 | 主要握持与承重位置 |
| 双立杆与横梁 | 传力与保持结构 |
| 拐头 | 防滑、缓冲与适应地面 |

- 材质可为木、铝、碳纤维等，重量按具体产品，不给统一区间。
- 常见量裁为腋托与腋窝保留数指空间、手柄使肘部适度屈曲，不能把“减五厘米”当所有身材和拐型的统一公式。
- 腋托接触造成的压痕或不适可以出现，但不应把承重主要写到腋窝。

## 三、肘拐（前臂拐）

- 由前臂套、手柄、单立杆和拐头组成，前臂套提供稳定与挂臂可能。从坐处站起时，臂环在站直后才套上，见 `基础层/行动库.md#3.2`。
- 前臂套位置须兼顾支撑和手部活动，具体开口与位置按产品，不只写“近端三分之一”。
- 挂臂时该拐通常不再承担地面支撑，可在原地或合适步态中腾手，但必须重新判断稳定。

## 四、平台拐

- 以前臂平台承托并传力，适合手部握力不足、腕指疼痛或关节受限者。
- 平台、绑带和立杆承受主要负荷，不能写成手柄完全不参与一切控制。

## 五、承重口径与身体代价

- 腋拐以手柄承重为主，腋托用于定位，避免持续压迫臂丛等神经血管。
- 手掌、虎口、前臂、肩背和健侧下肢都可能疲劳，先后顺序随人、任务与装备变化。
- 薄茧、握力疲劳、肩腕酸胀和需要休息可以写；日常轻扶墙或撑桌不应自动磨破手，真实过用和伤病也不必禁写。
- 维护拐头、调整高度、替换磨损件和清洁是正常行为，可以在剧情中使用。

## 六、步型定义与移拐节奏

> 定义供工程核对；正文平写，见 `基础层/行动库.md#8.1`。

- **摆至步**：双拐先出，健腿摆至拐附近，常较稳。
- **摆过步**：双拐先出，健腿摆过拐，步幅与耗力可更大。
- **三点步态**：名称不等于患足必须部分负重，也可用于非负重或单腿情境，不能一律禁写。
- 单拐、交替、跳跃和混合节奏均可存在，按训练与地面选择。
- 健腿离地时双拐承担主要支撑；站定后在支撑允许时可腾一只手，不能简单说移动中两手永远做完全相同的动作。

## 七、上下楼

- 常见原则为“健腿上、拐下”：上楼健腿先、拐随后；下楼拐先、健腿随后。腾手须先站定：健腿离地时双拐承担主要支撑，不得把双拐并到一只手去扶人；扶持与护送见 `基础层/行动库.md#3.15`。
- 有扶手时可一手扶栏、另一手管理拐杖；无扶手时保证拐头完整落在台阶上。
- 熟练者可以流畅上下，不必每次费劲；台阶确实挡住目标时只写改变本身，归级见 `写作层/素材/受众定位.md#六`。工程上核清顺序，正文不必报出第几级、停几秒；见 `写作层/文风/反AI写作.md#2.23`。正文写法见 `基础层/行动库.md#8.1`。
- 穿假肢时另按关节和训练，常见“健腿上、假肢下”，不是所有型号都一样。

## 八、摔倒与起身

- 摔倒方向与受力、地面、注意力和装备有关；救回与真摔、按方向保护哪里、拐杖是否脱手，见 `基础层/行动库.md#2.2`。
- 起身时先确认伤情，再处理拐杖和支点。可翻身、收健膝、手撑、借家具或他人协助。
- 从坐处、地面或蹲姿起来，都是先把拐拿到手里，借手、健腿或家具站起，站直后再把腋托收到腋下，或把前臂套进肘拐臂环。站起前腋托够不到腋窝，不能先夹腋再蹬直。详见 `基础层/行动库.md#3.2`。
- 熟练者可以把这三步写短，顺序不能反。重摔、初学或环境复杂时再展开调整。
- 不以固定秒数决定对方是否来得及补刀，战斗中按双方距离和动作计算。

## 九、持拐日常与双手占用

| 场景 | 判断与可选做法 |
|---|---|
| 开门 | 停稳后夹拐、挂臂、单手拢拐、用拐抵门或先放稳 |
| 扶人／护送 | 先站定再腾手；健腿离地时两手承重，不得并双拐去接人。见 `基础层/行动库.md#3.15` |
| 拿物 | 小件可挂腕或勾指，较大物品用背包、推车、停步或协助；身体移动求助门槛见 `基础层/日常动作.md#3.7` |
| 坐与起 | 先把拐拿到手里、拐头支稳，支撑在手和健腿或家具上，再借座沿或台面站起；站直后再夹腋托或套臂环。重心升高前要有支点。顺序见 `基础层/行动库.md#3.2` |
| 过门槛 | 按高度和落点跨、绕、移拐或换设备 |
| 湿滑地 | 减小动作、检查拐头、选支撑与替代路线，不把单脚端热汤当通用解 |
| 提物 | 背包、轻袋挂腕、推车或分次；重量和摆动不能破坏支撑 |

- 拐杖靠放是否稳定取决于角度、接触面、拐头和地面，不写“平靠光滑墙必滑”。
- 携带腋拐与肘拐须考虑长度、能否折叠或拆卸、包容量、重量和当前使用者；不要无说明地把长拐塞进普通包中。
- 上下车与车内放拐见 `基础层/行动库.md#3.11`。
- 旧拐、新拐和备用拐可以同时存在，但同时出门需有切换、退货、备用风险或不同使用场景等任务依据。
- 新旧不构成价值排序。选择时看型号与量裁、手柄与拐头、重量、维护、熟悉度、当前任务和个人偏好；旧拐可能更合身，也可能已有安全风险，新拐可能需适应，也可能更合适。
- 备用拐须记录来源、存放位置和可用性；是否已预先调妥、当前是否适用按实际状态，不因“备用”就自动完美适配，也不因“新”就自动难用。
- 若以隐瞒、识别或他人反应为换拐理由，须核对观察者实际见过什么、已经知道什么；对方已经见过并讨论新装备时，不能再用“怕对方发现新装备”作理由。
- 放拐后需要取回或另有去向，但不必每次写完整闭环。
- 非战斗操作不能由“能勾、能拨”直接推出：先核对拐头或杖身的实际接触点、推拉方向、目标重量与阻力、所需精度和当下支撑。需要精细捏持、复杂角度或双手协同时换用手、工具或坐定操作，不把拐杖写成万能手臂。

## 十、单拐与双拐

- 双拐提供更多支撑组合，单拐更便于腾手，选择取决于任务和稳定需求。
- 单拐常与假肢侧形成对侧协调，但具体持手与节奏按个人训练。
- 不穿假肢的单侧截肢者也可用单拐完成某些动作，不能限定为“只能极短辅助”。
- 单拐、双拐和假肢可以随任务切换，不把角色锁死在一种配置。轮椅只进入没有完整健腿之角色的切换；有完整健腿即禁轮椅。

## 十一、拐杖与假肢并用

- 单拐可辅助平衡、起步、长距和复杂地形，是否省力按个体。
- 出拐与假肢的节奏要相互协调，不把所有假肢类型都套成同一“拐跟患腿走”的固定画面。
- 髋离断假肢也可用拐，不存在“单拐只适用其他类型”的生理禁令。

## 十二、写作纪律

- 工程核对时写清拐杖、身体和地面的接触，比堆器械术语更重要；正文默认称“拐杖”，部位名只在该部位起作用时用。
- 常规拄拐平写；移动方式改变、失稳或影响目标时，才展开变化本身。见 `基础层/行动库.md#8.1`。
- 器具维护、磨损和更换可用于现实质感与剧情，但不应反复以同一故障制造危机。
- 不用拐杖把人物固定成孱弱、励志或恋物符号；它首先是角色选择使用的工具。
