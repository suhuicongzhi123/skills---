# 类型-双侧叠加（叠加层）

> 触发条件：双侧上肢或双侧下肢截肢，以及上下肢复合。必须与相应单侧类型文件合用；本层处理“没有健侧可用”的差异。
> **核心原则**：先分别确定每侧的截肢平面与保留功能，再处理共同任务。双膝下、双膝上、双髋离断、不同平面组合和上下肢复合不能共用一套行动模板。
> 动作、转移和环境见 `基础层/行动库.md`；假肢按人物实际设定。有一条完整可站立的健腿即禁配或使用轮椅；没有完整可站立的健腿才可配轮椅。交叉组合若仍有一条完整可站立的健腿，要配轮椅必须明示虚构豁免。

> **目录（按需读取，勿整体加载）**：一 适用范围与叠加路由｜二 双腿类型物理基准｜三 双髋离断物理基准｜四 四肢叠加、无臂与双臂＋单腿｜五 身体细节与幻肢感｜六 不可能动作｜七 受限清单｜八 与单侧类型的口径差异速查｜九 占手与移动选择

## 一、适用范围与叠加路由

### 1.1 适用范围

- 双侧下肢：双膝下、双膝上、双髋离断、膝离断及不同平面组合。
- 双侧上肢：双肩离断、双肘／腕平面或不同平面组合。
- 上下肢复合：任意两侧或四肢组合，不使用“quad”替代具体解剖设定；作为圈内简称时必须同时写明实际平面。
- 先天肢体缺如与后天截肢的瘢痕、软组织和幻肢表现分别设定。

### 1.2 叠加路由

| 设定 | 注入组合 | 判定重点 |
|---|---|---|
| 双侧下肢 | 本文件＋两侧对应类型文件＋行动库双侧节 | 保留关节、左右差异、假肢与轮椅 |
| 双侧上肢 | 本文件＋肩离断／肘腕对应文件 | 剩余手、残端、脚嘴与设备代偿 |
| 四肢复合 | 本文件＋所有涉及类型文件 | 无完整健腿时才涉及轮椅；移动、操作、转移和照护分别判断 |
| 双臂＋单腿 | 本文件 4.3＋对应下肢类型＋`基础层/行动库.md#3.14` | 移动完全采用单腿跳，不以拐或轮椅为默认；操作按嘴、肩、残臂或解放后的脚；因仍有一条完整健腿，禁配轮椅，除非明示虚构豁免 |
| 单臂＋双腿 | 本文件上肢叠加＋对应下肢类型 | 无完整健腿时可配轮椅；移动、持物、轮椅与假肢控制分别判断 |

- 判定顺序：逐侧列保留结构 → 列当前可用装备 → 判断任务需要的支撑、发力和协同 → 选择动作。
- “限制相乘”只用于检查必要条件，不把角色总能力简单等同于最弱一侧，也不忽略器械与训练带来的代偿。

## 二、双腿类型物理基准

### 2.1 残肢长度与功能

- 残肢长度必须相对原肢体和截肢平面描述，不能脱离膝上、膝下或膝离断单用“10／20／25 cm”推出能力。
- 长残肢通常提供更多杠杆和控制，但短残肢并不自动排除假肢；特殊接受腔、悬吊和手术情况会改变适配。
- 左右可以等长，也可以不同平面、不同长度和不同装备。差异会影响姿势、步态和衣物，但不必然造成每次移动都偏斜。
- 训练能改变力量、技巧、平衡和耐力；身份、职业和性格不改变解剖结构，但会改变角色选择的代偿方式。

### 2.2 承重、站立与起身

- 双膝下保留真膝，穿合适假肢后可能独立站立、行走、跪和上下楼；不穿假肢时可膝行或使用轮椅。
- 双膝上无真膝，裸残端直接站立承重需要谨慎评估皮肤、骨端覆盖、长度、平衡和支撑，不把“残端顶地”写成常规行走。
- 双髋离断没有股骨杠杆，不能以残端站立，但可坐位转移、轮椅移动、爬行和使用其他设备。
- 起身可独立臂力转移、扶物、滑板、升降设备或他人协助，不统一规定步骤和耗时。
- 假肢和轮椅可以组合使用，脚踏板与腿托不是禁项。

### 2.3 装备

- 残肢袜、硅胶衬垫、护套和弹力绷带按皮肤、塑形和悬吊需要使用，穿法和材料以实际系统为准。
- 假肢可有不同接受腔、关节、脚板、快拆与用途，是否适合长距或运动由具体配置决定。
- 轮椅可选手动、电动、定制座垫、腿托、脚踏、倾仰和不同控制方式。无手或手功能受限者可用手、前臂、下巴、口棍、头控或其他开关。
- 低位家具、扶手、滑板、坡道、升降设备、浴凳等按角色需求配置，不把“未改造只能爬”写成通则。

### 2.4 变体

- 不同平面与长短不对称型。
- 双膝离断型，末端承重可能性依手术和皮肤而定。
- 假肢日常型、轮椅日常型、运动型、多副装备切换型。
- 上下肢复合、单侧上下肢交叉组合，以及幻想种族的多足或额外器官变体。交叉组合若仍有一条完整健腿，禁配轮椅，除非明示虚构豁免。

## 三、双髋离断物理基准

### 3.1 形态与承重

- 双侧髋离断通常保留骨盆与坐骨，无股骨及髋关节，不能把半盆切除的形态混入。
- 无骨性残肢用于站立或蹬地，但坐位可承重；前后和侧向稳定受躯干、座垫、靠背与个人控制影响。
- 不能写“跪＝残端顶地”，也不能由此推出“坐不稳、只能躺”。
- 站立、跪姿和独立转移不能靠不存在的双腿完成，但独立臂力转移、坐位挪行和轮椅活动可以成立。

### 3.2 装备与护理

- 轮椅、座垫、靠背、腰带、扶手、滑板和升降设备按稳定与舒适选用，不是人人都需要固定带。
- 专用髋离断假肢适配复杂、能耗较高，使用频率因个体而异，不绝对排除日常或特定活动使用。
- 普通马桶、浴凳、坐便椅和改造坐圈按平衡与转移能力选择，不把儿童马桶、尿片或导尿当默认。
- 失禁、导尿和灌肠必须有独立伤病或神经功能设定，不能由髋离断直接推导。

### 3.3 变体

- 一侧髋离断＋另一侧膝上／膝下：分别判断两侧，不能用“按较差一侧”抹掉较好侧的功能。
- 半盆切除与髋离断分开，坐骨和骨盆形态变化会影响坐位与接受腔。
- 双髋离断合并上肢缺如时，重点评估轮椅控制、转移、口控或头控设备与照护需求。

## 四、四肢叠加、无臂与双臂＋单腿

### 4.1 四肢复合

- 本节默认针对没有完整健腿的四肢复合。仍有一条完整健腿的双臂＋单腿见 4.3，不要把下列轮椅与载具控制方案当成所有上下肢复合的默认移动。
- 先逐肢写明平面和剩余功能，再判断坐、卧、移动、翻身、操作和照护，不使用“标准残肢长度配置”替代人物。
- 有残臂者可利用残臂、肩、嘴、下巴和设备；无残臂者也可通过口、下巴、环境和已合法配置的控制设备完成大量任务。
- 在没有完整健腿的前提下，电动轮椅、口控、头控、眼控、语音和定制开关可以显著扩大自主行动半径。这些方案不适用于仍有一条完整健腿的组合。
- 无站立能力不等于无翻身、坐位挪移或操作能力；需要支撑时应写真实支点。
- 搬运和转移优先考虑安全、尊严和当事人配合，不写“抱婴式单手可抱所有人”或按体重推导毫不费力。
- 护理依赖程度与神经功能、认知和情绪分开，肢体缺失不损伤智力与主体性。

### 4.2 无臂（双上肢缺如、下肢健全）

- 下肢可以走、跑、跳，但摆臂、跌倒保护和部分平衡任务可能改变。
- 脚代手与嘴代手可高度熟练，包括取物、翻页、打字、触控、穿衣和创作，具体程度按训练。
- 语音输入、读屏、开关控制、脚控和口控设备可以组合，不必把每个动作写成艰难挑战。
- 摔倒时无法用手撑地不等于一定脸朝下重伤；可转头、侧身、屈膝、借物或经训练形成保护动作。
- 私密自理可用脚、工具、改造衣物与他人协助，具体按人物选择和边界。
- 本节省两条健全的支撑腿，站着时仍可用一只脚代手。不要与 4.3 混用。

### 4.3 双臂＋单腿

- 定义：缺失双臂和一条腿，还剩一条完整健腿。因此禁配或使用轮椅，除非明示虚构豁免。本组合与 4.1、4.2 不是同一套动作。
- 移动完全采用单腿跳，不以拐或轮椅为默认移动；追逃速度基线同单侧，见 `基础层/行动库.md#4.2`。除非项目明示使用下肢假肢，并且由他人或脚／嘴完成穿脱，否则不改走假肢步态。
- 其他动作：腿没有用于支撑、也没被占用时，可选脚、脚趾、嘴、肩膀或残臂完成，但必须按各部位实际能做的事写。嘴可咬、拉拉链、衣角、带子，不能当真手那样抓握。肩可抵、顶、挂；无残臂时不能抓。有残臂时按残臂长度与保留关节写，不要把肩离断写成能抓。脚趾可夹、钩、拨细件，不能当成有手的灵巧。
- 腿正在用于支撑时（站着、单腿跳过程中），这条腿和脚不能再参与其他动作。要用脚，必须先坐下、倚稳或以其他真实支点把脚解放出来，再操作，再回到站立或单腿跳。
- 可执行动作链见 `基础层/行动库.md#3.14`：下车与离座、开门、持续移动、起坐。不要套用持拐上下车链，不要临时补出轮椅，也不要写成不知道怎么站起来。

## 五、身体细节与幻肢感

### 5.1 双腿类型

- 残肢外观由平面、长度、皮肤、脂肪肌肉、手术和年龄决定，不统一为“嫩白、圆润、肥大”。
- 有骨残肢可在相应关节控制下移动，肌肉收缩和幻肢感与髋、肩离断软组织分别写；准入／禁入场景、三类机制分写、衣物遮挡可见性与重复分寸见 `基础层/身体细节与幻肢.md#3.7`。
- 瘢痕位置、颜色、敏感度和末端承重能力存在个体差异，不能把“高度敏感、疼痛、阴雨天必痛”设为通用。
- 长期轮椅使用不必然造成残肢肥胖或角色羞耻；体形与自我态度由人物决定。

### 5.2 双髋离断与四肢复合

- 软组织形态与瘢痕依手术和个体写，不把“深红蜈蚣疤”当成熟稳定态通用外观；先天肢体缺如不自动带有截肢手术瘢痕。
- 无骨性残肢可保留感觉和肌肉反应，但不能独立完成杠杆动作。
- 额外神经、盆腔或脊髓伤病才影响相关功能，不由截肢平面自动附带。

### 5.3 幻肢感

- 两侧可以都有、只有一侧有或没有，频率和表现按个人与时间变化。
- 幻肢感可以长期存在，不能用“多年后绝不会再想使用”作为生理定律。
- 先天肢体缺如与幼年截肢者也可能有幻肢体验，是否使用由角色卡决定。
- 动作失误可来自幻肢、注意、环境或疲劳，不把每次失衡都归因于幻肢。

### 5.4 坐面与取象

- 单侧和双侧都可能坐实，双侧并非不能使用“空椅面”这个词；关键是对比与视角是否自然。
- “空裤管”“空座面前缘”等意象可以出现，但不要求每章重复，也不以“无对称另一边”禁止用词。
- 服装、轮椅和坐姿按当场状态写，不把取象规则变成生理事实。

### 5.5 恢复期

- 伤口、肿胀、承重、假肢适配和亲密活动分别判断，不给所有人统一六个月成熟期。
- 未愈合、感染或存在医疗禁忌时不安排承重、束缚和性接触；其他情况按医嘱、舒适和同意。
- 恢复过程可详写或时间跳跃，但不能无理由从手术直接跳到熟练行动。

### 5.6 服装与当件结构

- 每侧残肢、假肢、轮椅姿势与当件衣物共同决定穿法；处理前读 `基础层/日常动作.md#六`，不从“双侧”标签直接复制造型。
- 同一件衣物的折塞、封口、空管与穿着状态须连续；换衣不等于状态错误，章级实际状态以审后记录为准。

## 六、不可能动作

- 缺失肢体不能实际参与其抓握、蹬踏、屈伸、承重或精细协同；器具代偿时写明是器具而非真肢。
- 双膝上无真膝，不写真膝屈伸或膝盖直接着地；不穿假肢时不能写双腿交替跑，穿戴合适假肢后的步态与跑法按组件、训练和地面判断。
- 双髋离断无股骨，不写残端站立、蹬地和杠杆发力。
- 无手者不能真手抓握，但有残臂、嘴、脚和工具不等于什么都不能做。
- 穿假肢后的动作按具体关节和控制能力，不把“假肢有膝”自动等同于可以稳定跪坐。
- 不把“脚踏板、轮椅、站立、转移”列为所有双侧角色的禁词。

## 七、受限清单

- 辅具依赖：轮椅、假肢或其他装备失效会影响行动，但可保留爬行、挪移、呼叫、备用设备或协助等路径。
- 环境可达性：台阶、窄门、坡度和车辆会影响具体路线，身体与环境共同决定结果。
- 双手占用：手动推轮椅时手部工作受限，停轮、背包装备、电动轮椅和协作可改变条件。
- 转移成本：不同高度、狭窄空间和疲劳会增加难度，但熟练转移可以简洁可靠。
- 速度与耐力：与装备、地形、训练和任务比较，不统一判定“绝对追不上”。
- 高处与低处：可用工具、改造、设备和协助，不把每次取物都写成失败。
- 水中：浮力、密度、姿势和划水方式因人而异，不写“无腿必然垂直下沉”。

## 八、与单侧类型的口径差异速查

| 维度 | 单侧 | 双侧／复合 |
|---|---|---|
| 健侧 | 可用于主要支撑和代偿 | 无健侧或不同侧能力不一，须分别判断 |
| 常见移动 | 拐、假肢、跳、扶物挪步与载具 | 无完整健腿时：轮椅、假肢、膝行、爬行、滑板、载具与组合；交叉组合仍有健腿时禁轮椅，除非明示虚构豁免 |
| 拐杖 | 按装备与训练 | 双膝下穿假肢等条件可用，不能一概排除 |
| 起身 | 健腿与支点可组合 | 臂力、设备、扶物或协助，不只靠被抱 |
| 脚踏板 | 按装备 | 同样按配置，不是禁词 |
| 行动连续性 | 当前装备改变会影响动作 | 还需同步左右与上下肢的状态 |
| 幻肢 | 按个人与病史 | 可双侧、单侧或无，不按年份一刀切 |

## 九、占手与移动选择

- 双膝下穿假肢：可按能力独立行走或用拐、扶物，双手是否自由取决于当前支撑，不统一写成双手自由或双手被占。
- 双膝下不穿假肢：轮椅、直立或低姿膝行、爬行、滑板等；膝行能否腾手按姿势与平衡判断，爬行和需要双手支撑的低姿挪移另行判断。
- 双膝上：轮椅、爬行、假肢或组合，裸残端站立须谨慎，不把短站当日常。
- 双髋离断：轮椅、爬行、滑板、设备或协助，手动推轮椅占手，电动轮椅按控制方式。
- 四肢复合（无完整健腿）：分别判断下肢移动与上肢操作，可通过口控、头控、残臂和他人协助组合；轮椅只在这一范围内使用。
- 双臂＋单腿：移动默认单腿跳，不以拐或轮椅为默认；脚只有在不承担站立或跳跃支撑、并已解放后才能操作。详见 4.3。
- 禁止：把双侧写成统一无能力，把轮椅失效写成必然完全失能，把被协助写成唯一日常出口。禁止把 4.1 的电动轮椅、口控或头控方案写给仍有健腿的双臂＋单腿。
