# 日常动作

> 日常动作物理的单一事实源：坐立转移、拾物家务、双手占用、单手日常、高频场景、服装穿脱与选择。
> 移动/位移类（行走与步态、转身、上下楼、骑车、下肢驾车、长距离、公共交通乘行）不在此文件，见 `基础层/行动库.md`；持拐原则与拐杖放置规格见 `基础层/辅具-拐杖.md`，假肢穿脱见 `基础层/辅具-假肢.md`。
> 内容按「动作→类型差异」组织：同一动作先写动作本身，再写类型差异——单侧髋离断差异写最详，膝上/膝下与上肢随后，双侧一律见 `基础层/类型-双侧叠加.md`。类型生理事实以各类型文件为准，本文件不另立生理定义。

> **目录（按需读取，勿整体加载）**：一 坐立与转移动作｜二 拾物与家务｜三 双手占用矩阵｜四 单手日常通用｜五 高频场景物理｜六 服装穿脱与选择｜七 书写纪律

## 一、坐立与转移动作

### 1.1 坐

- 动作链：走到椅前→拐杖移开（靠墙/放倒/夹腋，处置见 三）→健腿屈膝坐。
- 单侧髋离断：坐下后**那半边椅面在身前是空的**——坐得实、骨盆落座，只是那半边往前没有腿，**不是**臀下悬空；重心偏向健侧，落座头几秒在找平衡。久坐患侧软组织受压发酸：随身坐垫、定时换重心。双侧髋离断不取此象（写法对照见 `写作层/素材/受众定位.md`），细目见 `基础层/类型-双侧叠加.md`。
- 膝上：残肢在接受腔里的活塞感与伸展需求，久坐后起身前先理残肢。
- 膝下：残端与衬垫摩擦发热，起身脱腔散热（穿脱见 `基础层/辅具-假肢.md`）。
- 上肢截肢：坐姿与常人无异，患侧空袖管口径见 六。
- 裤装落座视觉：未处理裤装时那半边裤管空垂；髋离断常服在裆线收口，无空管（判据见 6.3）。

### 1.2 起身

- 动作链：手撑扶手或膝→健腿蹬起→够拐→撑起；起身前先确认拐杖位置（闭环见 3.5）。
- 单侧髋离断：第一下把重心送到健腿正上方再够拐，写「送重心」这一拍。
- 膝上/膝下：起身前的理残肢/脱腔散热见 1.1。
- 上肢截肢：起身不能双手撑地，须就手借物（桌沿、椅背、他人手臂）。
- 双侧：见 `基础层/类型-双侧叠加.md`。

### 1.3 床上起卧与床边转移

- 床高：过低起不来、过高坐不上；与常坐椅面等高最省事，这是可写的居家布置细节。
- 起卧动作链：侧身→手撑床面抬上身→健腿下床落地→坐稳→够拐站起。
- 床边转移（床↔坐处）：坐于床沿→手撑→站起够拐／挪移到坐处。
- 单侧髋离断：侧身起身带动**整边身子**；床垫只塌半边、光脚落地那一下的凉，都是现成锚点。
- 双侧：床上挪移、翻身、转移全链见 `基础层/类型-双侧叠加.md`。
- 晨起与就寝的场景细节见 5.3。

### 1.4 上下车与载具转移

- 动作链：先坐上车座→健腿收入→那半边车座往前空；下车反向，先健腿落地再撑起。或单腿跳近车、扶门框作支撑。
- 写车门当支撑、收腿顺序；拐杖折叠入后备箱或放副驾脚下，放与取各写一笔。
- 网约车/出租：后备箱放拐/取拐是固定两笔；无障碍车型多数约不到（预约类服务的口径见 5.5）。
- 双侧轮椅的上下车（斜坡板/他人协助）见 `基础层/类型-双侧叠加.md`。
- 骑行、电动车、下肢驾车改装属位移类：见 `基础层/行动库.md`；上肢驾车见 4.4。

### 1.5 他力转移（被抱与被背）

- 抱法：一手托臀/残肢根、一手环背，整身横躺臂弯；残肢垂在臂弯外随动作晃、贴向对方身体。
- 背法：高位截肢背部无着力点，须顶住臀部才背得稳；残肢软软贴背。
- 上下车分镜：拦腰抱起→放进副驾→系安全带→折叠轮椅入后备箱。
- 写「一提一落的重量」、她的配合（搂颈/扶肩）与落座那一下。
- 日常场景按转移动作写，不默认暧昧；亲密用法见 `成人内容/亲密总纲.md`（条件注入）。

## 二、拾物与家务

### 2.1 蹲（全类型速查）

> 验尸、捡东西、看孩子这类场景不会触发类型文件注入。任何场景写到蹲，先查本节；单侧下肢的健腿单腿蹲是正式豁免，写「蹲不了」就是错。

| 类型 | 能不能蹲 | 条件 | ❌ 常见错写 |
|---|---|---|---|
| 单侧髋离断/膝上/膝下 | 能，健腿单腿蹲 | 须一手支撑（扶拐/扶墙/扶健侧膝/撑地）；蹲下后一手掌拐或扶物，另一只手只能做轻活 | 写「蹲不了」「只能跪」——除非要腾双手做细活 |
| 双侧 | 不能（或须双手撑物、短时） | 见 `基础层/类型-双侧叠加.md` | 「一蹲就起来」 |
| 上肢截肢 | 能，起身要借物 | 不能双手撑地起 | 「双手一撑就起」 |

- 蹲**不是**受限点，**蹲着做事**才是：要腾双手（翻、量、掰、绑）时改为跪或坐——写「她蹲着没法用两只手」，❌ 写「她蹲不了」。
- 蹲下与起身是两件事：蹲下容易，起身须扶；无扶手深蹲（蹲坑、蹲式便器）＝蹲得下、起不来。
- 起身三种写法：扶拐撑起／撑健侧膝／就手扶旁边的东西（顺手扶，不是必须扶）。

### 2.2 弯腰取物与高处取物

- 单腿站弯腰平衡难：常扶物、坐地拾取、或用拐杖勾（拐杖当钩用是现成细节）。髋离断弯腰时上半身前倾、健腿后撤配重。
- 高处取物：踩矮凳（须扶稳）、长柄夹、改变物品摆放高度、求助；❌ 踩不稳的椅子。
- 双侧有残肢者的撑起试够、双髋离断的替代路径，见 `基础层/类型-双侧叠加.md`。
- 够高与够低是同一类受限；**处置顺序**（扶什么/踩什么/叫谁）比结果更有戏。

### 2.3 家务速查

| 场景 | 处置 |
|---|---|
| 端热锅/热汤 | 不端走——托盘放灶台旁分次，或坐下后再取 |
| 洗碗 | 坐矮凳；❌ 不写久站 |
| 切菜 | 坐高凳操作台面；固定食材用叉或压板（上肢单手切法见 四） |
| 开罐头/拧瓶盖 | 台面固定+单手拧、开瓶器夹台边、求助 |
| 扫地拖地 | 长柄工具；湿拖地面对拐头是打滑源 |
| 晾收衣服 | 坐矮凳（到位坐下做）、单拐靠墙、分次（双手占用处置见 三） |
| 倒垃圾 | 分次提、或用背包 |

### 2.4 静态照护小孩

- 换尿布在地面/矮台进行（坐位操作）；久站哄抱不可行→坐姿抱；携娃出行＝推婴儿车+单拐或让孩子跟着走。
- 上肢的婴儿护理（台面固定+残端按压）见 4.4；抱孩子移动的双手占用判定见 三。

## 三、双手占用矩阵（拄拐时能腾几只手）

### 3.1 适用面与核心矛盾

- 行走需双拐→双手被占；常人无感的「边走边用手」场景，截肢者无法直接做到。必须写出变通，否则出戏；但变通≠放拐——有拐不用（腾手方案存在时）同样是出戏。
- 适用面：髋离断强适用（双拐绝对主力）；膝上高位强适用（假肢非优先时）；膝上低位/假肢优先弱适用；膝下基本不适用（假肢为主）。上肢截肢无此矛盾——撑伞、抱娃单手可行，仅下肢拄拐语境才构成本节矛盾。
- 受限「双手占用」类的完整定义与处置链见 `写作层/素材/受限场景库.md`。

### 3.2 腾出几只手（速查矩阵）

| 状态 | 腾出 | 支撑变化 | 能做／不能做 |
|---|---|---|---|
| 双拐各在一只手 | 0 | 正常 | 只能走与站；❌ 写边走边用手做事 |
| 腋拐单拐夹腋 | 1 | 夹腋那支不承重，支撑降级 | 原地站立作业优先；移动须单拐支撑缓行 |
| 单手持双拐并拢 | 1 | 支撑点合并 | 提轻物短距移动 |
| 腋拐挂肘弯 | 1（短时） | 该拐不撑地 | 掏钥匙、开门一类短动作 |
| 前臂拐 cuff 挂前臂 | 1（可较久） | 支撑降级 | 较久持物；仅前臂拐适用 |
| 拐靠墙/放倒/交他人 | 2 | 无支撑 | 须坐或扶物；失去移动能力 |
| 坐姿作业（拐在手边） | 2 | 不需支撑 | 移动段拄拐，做事段腾手 |

- 髋离断默认腋拐：腾手一律走夹腋/并拢/挂肘弯口径，❌ 写 cuff 挂肘（那是前臂拐的物理前提）。拐具规格与持拐原则见 `基础层/辅具-拐杖.md`。
- 支撑降级后该拐不撑地不承重：支撑点减半，原地作业优先；须移动则单拐缓行或扶物挪步，❌ 写健步如常。

### 3.3 腾手策略阶梯

> 「双手+移动」矛盾的处置从顶层往下选，放拐是**末端解**。

1. **近距离豁免（优先于阶梯）**：目标十步以内，可优先考虑放拐单腿跳——短距离内重新撑拐的仪式成本高于跳本身，属合理日常而非辅具弃用。豁免的是「非理性」判定，不是「交代」义务——放拐动作与跳的过程仍须写出。
2. **腾手优先（拐不离身）**：杯子、手机、书本等单手可持物一律走 3.2 的腾手格；注意支撑降级，原地作业优先。
3. **改变携带**：背包、推车、分次搬运、雨衣替代伞——物品重整后正常拄拐走。背包优于提袋，双手要留给拐。
4. **坐姿作业**：把「边移动边做」改成「移动到位坐下做」。
5. **他人协助**：接、递、代拿。
6. **放拐单腿跳（末端解）**：仅当双手完全占用＋物品不可分离＋必须保持移动（端滚烫汤移动、抱婴儿转移、双手持重物过窄处级别）。

- 放拐门槛三问（设计放拐场景前必过；十步豁免除外）：腾手可行吗——存在挂肘/夹持/背包等任一解即禁放拐（为一杯水/一部手机放拐＝拐杖分离的同族错误）；公共空间吗——他人目光成本，嘴硬要强者不会在人群里主动蹦跳；距离多远——超过十步体力与仪态成本陡增，长距离放拐移动＝失真。

### 3.4 高发错误场景清单

> 多解并存时优先靠阶梯上层；标注「十步内」的放拐解法仅在近距离豁免内合法。

| 场景 | ❌ 错误写法 | 处置（按阶梯层） |
|---|---|---|
| 端碗/盘走到桌边 | 端着碗走向餐桌 | 挂肘夹持端、背包装、分次；十步内放拐跳 |
| 开门通过 | 开门走进去随手关上 | 拐杖撑门/身体顶门，过门取拐；或先过再回身 |
| 撑伞走路 | 撑伞走在雨里 | 穿雨衣、固定伞、避雨、停 |
| 牵孩子/宠物 | 牵着孩子走 | 推车、绳系腰、单拐、让孩子跟着 |
| 边走边打电话/喝/吃/挥手/拍照 | 边走边打电话 | 停下、耳机、挂脖持杯；十步内放拐跳 |
| 推购物车 | 推车逛超市 | 拐挂车边单手推、手提篮、分次、请人代推、线上配送 |
| 拿钥匙开门 | 拿钥匙走到门口开门 | 钥匙挂脖、挂肘持钥；十步内靠墙放拐再掏 |
| 抱孩子走 | 抱起孩子往卧室走 | 末端解场景：坐姿抱分段挪、他人帮；家中私密+距离近可放拐（过三问） |
| 提物走路 | 提着袋子走 | 背包、单手持双拐并拢提轻物、推车 |
| 上下楼拿物 | 一手扶栏一手拿物下楼 | 物先放下、夹腋、分次（楼梯位移见 `基础层/行动库.md`） |
| 晾收衣服 | 在阳台来回晾衣服 | 坐矮凳、单拐靠墙、分次 |
| 倒水端杯走/边走边递物 | 端杯走到桌边 | 挂肘持杯、分次、停下递；十步内放拐跳 |

### 3.5 拐杖放置闭环

- 拐杖不是可凭空出现/消失的道具，必须有放置动作链：靠墙立／放倒在地或靠椅边／夹腋／挂肘弯／交给他人或靠物体。
- 起身先够到拐杖再撑起；事情做完**回到放置处把拐杖拿回来**，再重新撑起。
- 放拐单腿跳的闭环四步缺一不可：放拐→单腿跳去做→跳回去拿拐→重新撑起。
- ❌ 写「放下拐杖」后下一秒「拄着拐杖走」却无拿起动作；❌ 做完直接走人、缺闭环末两步。
- 连续性自查按同一套状态枚举核对：在手／靠墙／放倒／夹腋／挂肘弯／交他人／不在场。

## 四、单手日常通用（上肢类型共用）

> 适用：肩离断/肘离断/腕离断。下肢健全、行动无碍，重点在单手完成双手任务的样态与受限。类型特有差异见 `基础层/类型-肩离断.md`、`基础层/类型-肘腕.md`。

### 4.1 总则

- 写「单手如何完成原本双手的事」，不渲染无能。
- 受限写真实（够不着、夹不住、拧不动），❌ 不写劳损/疼痛。
- 常用替代：腿夹、身压、嘴咬、桌沿、重物压、长柄工具、一脚蹬/松紧。
- 一切写法回到「固定物/工具/残端/求助」四选一。

### 4.2 残端代偿（按类型分，勿一刀切）

- 肘离断/腕离断：残端是仅次于健手的第二「工具」——残端夹物（与身体侧/台面配合固定）、末端承重（撑桌/压纸）、顶、按、撑；腕离断还可旋前旋后转掌心。独门细目（残端当压纸石、拧瓶盖两端式）见 `基础层/类型-肘腕.md`。这是这两类区别于肩离断的最大差异点。
- 肩离断：无残端，❌ 套用上述任何残端动作（见 `基础层/类型-肩离断.md`）。

### 4.3 分类速查

- 进食：单手执筷/勺，切大块预切或用叉，端碗靠桌沿或腿夹。
- 穿脱：套头衫先套健臂钻头；纽扣/拉链单手难，改松紧/磁扣/套头（服装细目见 六）。
- 书写：健手无碍，压纸靠重物/身/下巴。
- 拧转：瓶盖/门把夹腿拧或用工具。
- 提携：单手提，重物腿夹/背/顶。
- 绑系：鞋带/细绳改一脚蹬或预绑。
- 清洁：洗澡单手，够背用长柄刷。
- 双手任务（最难）：剪纸/绑绳/撕薄膜/剥线——须固定物/工具/求助。❌ 把撑伞、抱娃列进此类（单手可行；仅下肢拄拐语境才构成双手占用，见 三）。

### 4.4 现代高频

- 手机/键盘：语音输入或单手拇指。
- 扫码/支付、开包装/外卖盒：残端或腿夹固定后单手操作。
- 背扣内衣/胸罩：前置扣，或先扣好再转身套穿（贴身层见 6.8）。
- 剃须/化妆/扎头发：台面镜前固定。
- 驾车：方向盘旋钮（spinner knob）单手转向；下肢截肢者的驾车口径见 `基础层/行动库.md`，两处不互套。
- 婴儿护理/换尿布：台面固定+残端按压。

### 4.5 幻肢错位（上肢特有）

- 近期档示例：下意识伸**两只手**去接递来的东西，患侧落空→动作未完成，真失手——代入感通道。
- 档位判定与触发机制见 `基础层/身体细节与幻肢.md`；类型细目见各类型文件幻肢节。

## 五、高频场景物理

> 高频私密与公共场景既是出戏高发区，也是受众关注区。跨类型通用；类型差异叠加各类型文件；古装变体见 `题材层/古装向.md`。

### 5.1 沐浴

- 单腿站洗难：坐浴凳+防滑垫+扶手是标准配置。
- 洗低位与患侧够不着（重心全在健腿，弯腰受限）：坐姿、长柄刷或扶手。
- 水路：水顺着患侧滑下去的路径与健全侧不同——髋离断的水沿收口缝合线分岔，膝上的水在残端上缘改道。这是把裸露细节与身体事实焊在一起的黄金细节。
- 浴室积水+单腿+无处扶＝事情办不成，成立受限 beat；防滑/水汽本身不作受限 beat（真受限与点缀的判定见 `写作层/素材/受限场景库.md`）。
- 沐浴底色轮转——同一素材在不同底色下是不同的戏，第 8 次沐浴场景若还是「水路+收口+不对称」的排列组合就该换底色：

| 底色 | 同一条「水路」怎么变 |
|---|---|
| 例行日 | 水从健侧流到患侧，她顺手擦完——身体是身体，不是话题 |
| 疲惫日 | 热水多冲了半分钟——那半分钟不是洗，是站着的许可 |
| 有约日 | 擦到收口处她停了一下——今晚有人会看到这里 |
| 低落日 | 跳过了镜子；毛巾裹得比平时高 |
| 和解日 | 多看一眼镜子里不对称的轮廓——不是检查，就是看 |
| 亲密余温日 | 昨晚被碰过的地方，今天水流过时她会想起来 |

- 底色用一两处行为差异侧写（跳过镜子/毛巾裹高/多冲半分钟），❌ 写「她今天心情不好」式直陈。表中破折号属对话打断，叙述层标点纪律见 `写作层/文风/词句工艺.md`。

### 5.2 如厕

- 马桶动作链：移到马桶前→拐靠墙/并到一手→转身背对→健腿屈膝坐→手撑扶手或水箱稳住；起身：手撑膝或扶手→健腿蹬起→够拐。
- 扶手与水箱瓷面的凉是现成触感锚点；「门要开着还是关着」这类真实取舍可写。
- 狭小空间：转身难，拐杖常须先递出或立在门外。
- 蹲式便器：单腿蹲撑不久（蹲姿全靠一条腿），须坐便器或加坐便椅；膝下穿假肢者可短时蹲，仍费力。
- 公共厕所蹲坑（隐形考点）：单侧下肢可蹲但起不来——健腿单腿蹲可行（正式豁免，见 2.1），但蹲式便器无承重扶手、且需保持时长，起身须一手支撑（扶隔板/扶手/他人拉），不写支撑＝失真；❌ 不写无扶手悬臀深蹲还久蹲。处置三选：有隔板/扶手可扶时单腿浅蹲（短时可忍，须交代扶的是什么）／找无障碍坐厕位／换地方。膝下可行但形态特别：假脚踝背屈有限，蹲姿是健腿深蹲+患侧脚跟翘起的半蹲。
- 日常决策视角：「这家的厕所她来过，知道有坐位」是熟练生活者的知识质感；「又是一个蹲坑」的叹气+出门找第二家，是受阻→处置→结果的最小完整链。
- 经期与卫生用品：坐位更换；久坐与器具压迫叠加的不便；❌ 不写血污细节。
- 失禁/排泄/护理依赖为合法题材（心理模式库、恋物素材库 F7），按场景与人物卡写，不作猎奇回避。

### 5.3 就寝与晨起

- 睡姿：患侧朝上需枕垫空处；仰卧无碍，俯卧不适；髋离断翻身要带动整边身子。
- 睡前卸具仪式（3–4 拍）：解悬吊的声音→假肢拿在手里的沉→放床边哪个位置→患侧翻身时那半边格外轻。假肢穿脱细目见 `基础层/辅具-假肢.md`。
- 睡姿的「轻」：患侧在上时，身子朝床面那侧沉；「半边身子轻得像不是自己的」是体感写法方向。
- 晨起与床边转移的动作链见 1.3。
- ❌ 不写「醒来—巡视身体—起身」套路（见 `写作层/技法/章节规划.md`）。

### 5.4 更衣（裸露场景）

- 单腿平衡脱裤的序列：坐姿→健腿先出→（收口/空管/假肢的）视觉一瞬——更衣过程的「空」是动态的，比静态更抓人。
- 更衣全过程：内衣坐位穿、先从健侧脚套入；裙子侧拉链（单手够背难，上肢口径见 四）；外套先患侧后健侧。
- 试衣间：空间窄、转身难、无扶手。
- 更衣室镜前：镜子里的不对称全景——「被看见」的自愿版，她自己看自己。自我目光素材：她看自己的眼光就是她此刻与世界的关系——例行日不细看，期待日挑角度，和解日敢看正面的全貌。
- 裸露场景的身体细节以本节与 5.1 为准；露骨度与 B/C 档截断线见 `成人内容/性爱模式.md`（条件注入）。

### 5.5 公共空间

- 购物：货架间过道窄、收银台高够不到要人帮；超市代步车只有大超市有且常借不到；「把要买的挂轮椅扶手上，结账时收银员把找零递到手心」是现成细节。推购物车的双手占用处置见 三。
- 被困：停电困电梯＝密闭+无处坐；楼梯间被困＝坐台阶等待、手机求助。
- 安检（假肢旅客）：假肢须取下过检；被要求当众卸假肢、双手撑地爬过安检门是真实发生的羞辱场景素材（合法题材，按档位写，受众口径见 `写作层/素材/受众定位.md`）。
- 预约类服务「约了也要等」：高铁重点旅客预约、民航轮椅服务真实存在，但要提前申请、接站接机的人可能迟到、服务只覆盖站内或机场内一段；网约车无障碍车型多数约不到，普通车常装不下轮椅——要她开口求司机搭把手，默认司机不主动，「约到了」是运气不是常态。
- 环境与无障碍：❌ 不写因无障碍缺失而「无法通行」，写绕路、耗时、挑路线；「无障碍被占→等/绕/开口请让」是合法受限素材（判定见 `写作层/素材/受限场景库.md`）。无障碍水平属世界设定，见 `写作层/技法/世界观构建.md`。
- 就医与康复（恢复期高频公共场景）：门诊流程＝挂号（APP 挂号、专家号难挂）→就诊→检查排队→住院押金登记→术前检查与谈话签字→手术→术后监护→换药拆线→出院复查约号；康复科序列＝卧床防褥疮→体位性低血压（起立床逐步升角度）→轮椅坐位→转移→站立→行走，理疗/作业治疗/镜像盒/平行杠按需点名。写流程与不便（排队、反复试穿、尺寸不合、家属陪床），❌ 不写成医疗科普，❌ 不把流程写成苦难展览；恢复期阶段与时长见 `基础层/身体细节与幻肢.md`。用具名可点名（导尿包/集尿袋/弹力绷带/硅胶衬套/防褥疮坐垫/浴凳/床边便盆），品牌与型号按 `题材层/现实向.md` 限量。
- 乘行与位移（地铁/公交/长途/楼梯/长距离/雨雪路面/摔倒起身）：见 `基础层/行动库.md` 与 `基础层/辅具-拐杖.md`。

### 5.6 其他高频

- 游泳：膝下穿假肢者可游泳（防水套/专用肢）；髋离断水中靠浮力活动，更衣与进出泳池是难点；无腿者没有打腿推进（入水易垂直下沉），多靠划手+残肢摆动漂浮，深水须有人陪或辅助具。水中位移细目见 `基础层/行动库.md`。
- 职场：工位过道宽度、会议久坐、通勤、出差、团建活动的地形。
- 校园：宿舍上下铺（爬梯不可行→换下铺）、教学楼台阶、体育课见习、集体活动地点。

### 5.7 照护操作（转移/翻身/清洁/排泄）

> 照护是高频私密场景，也是护理依赖题材的落地处。写步骤与用具名，❌ 医学解说段。

- 翻身防褥疮：托肩托臀平移→垫翻身枕/体位垫→左右侧卧交替；卧床期每 2–3 小时一次（阶段与时长见 `基础层/身体细节与幻肢.md`）。
- 床上擦洗：温水（约 37℃）→湿毛巾从上到下、从干净到脏→擦完扑爽身粉或涂润肤乳；残肢套/绷带处理见 `基础层/辅具-假肢.md`。
- 换纸尿裤：轻揉小腹助排尿→解魔术扣→褪下→温热湿巾擦拭→托起后腰→换新拉紧魔术扣。
- 导尿与集尿袋：留置导尿接集尿袋（挂床沿/轮椅下）、定时倾倒记量、尿道口每日清洁；间歇导尿按定时自主进行；髋离断/无腿者用特制小孔马桶圈或便盆。
- 防血栓与塑形：医用弹力袜/残肢弹力绷带（消肿+规整轮廓）；气压治疗仪、踝泵动作属病床边常规。
- 护理动作写得越具体越不色情也不猎奇——顺序、用具、谁动手、她的配合与不配合；❌ 不写「像照顾婴儿」式贬抑旁白；主体性与边界口径见 `成人内容/亲密总纲.md`（条件注入）。

## 六、服装穿脱与选择（物理部分）

> 丝袜/高跟/连裤袜的恋物视角（袜口纪律、空袜管造型、叠穿）归 `写作层/素材/恋物素材库.md`；本文件只管穿脱动作物理与服装选择逻辑。类型特有裁剪差异以各类型文件服装节为准。

### 6.1 先判裙裤

- 判定问句：它是分开的两条裤腿（裤装），还是一片下摆（裙装）？按形态判，❌ 按名字判——裙裤、罩裙、长袍、里裤外裙先拆层再判。
- 判错则全错：裙装上不存在「裆线收口」「缝合封口」——收口是裤腿末端的处理，裙装没有裤腿。把裤装收口套到裙装上是最常见也最出戏的错误。

### 6.2 裤装处理

| 处理方式 | 裁剪位置 | 做法 | 适用 |
|---|---|---|---|
| 折叠塞裤腰 | 不裁剪 | 患侧裤腿折叠塞进裤腰 | 假肢为常用辅具时默认；公用服装不便裁剪时 |
| 裁剪缝合 | 髋离断→大腿根部（裆线/腹股沟）；膝上/膝下→残端下缘（略放长 1–2cm 容纳残肢袜/接受腔上缘） | 患侧裤腿裁短至该位置缝合封口 | 假肢非常用辅具（日常用拐）；日常常服、长期 |
| 打结 | 不裁剪 | 患侧裤腿打结束起 | 刚截肢初期未掌握塞裤腰技巧的临时做法 |

- 假肢为常用辅具时默认折叠塞裤腰，不裁剪——裁剪后裤腿封死，假肢无法穿进；需穿假肢者保留裤腿完整，不穿时折叠塞裤腰。
- ❌ 髋离断写「裁剪到胯骨那儿」（裁剪基准是大腿根部/裆线）；❌ 膝上裁剪位置写成裆线（膝上有残肢，裤管要留到残端）。

### 6.3 空裤管与空袖管判据

> 判据：空管只在「未处理」时存在。一旦裁剪缝合（封口）或折叠塞裤腰/打结（裤管不再垂下），就没有空管，❌ 再写。

| 情形 | 有无空管 | 写法 |
|---|---|---|
| 髋离断·常服已裁剪 | 无——裤子在裆线处结束 | ❌ 不写空裤管；视觉信号是「裆线以下无裤管」 |
| 髋离断·未裁剪公用服装 | 有垂下一截，空瘪 | 空瘪、空垂、随动作晃、被风吹起；❌ 「被残肢带动」（无骨性残肢，软组织撑不动裤管） |
| 膝上/膝下·未处理 | 有——残端下缘以下垂着空管 | 变瘪、飘荡、可写残肢带动（有残端） |
| 膝上/膝下·已裁剪/已折叠/已打结 | 无 | ❌ 不写空裤管 |
| 肩离断·上装已裁剪（肩峰下缘/肩缝处） | 无——袖子在肩缝处结束 | ❌ 不写空袖管；宽松上衣易向患侧滑落，需合肩 |
| 肩离断·未裁剪公用上装 | 有，空瘪 | 空瘪、空垂、随动作晃、被风吹起；❌ 「被残端带动」（无残端） |
| 肘离断/腕离断·未处理 | 有 | 空袖管+残端带动 |

- 空管晃动通用判据：空管会动——随身体动作晃、被风吹起，任何类型都有，不是残肢的专利；唯一不写的是「被残端主动带动」——当残端不存在时（髋离断无骨性残肢、肩离断无残端）。❌ 写「像里面有条腿/有只手臂那样有规律的摆动」。
- 髋离断裆线以上由那儿的肉撑起，外观接近一段很短的大腿根；正面看裆线封口、侧面看患侧臀下空。

### 6.4 裙装与外裙里裤

- 裙装不裁剪、不收口、不封边，裙摆自然垂落；视觉信号由裙长决定。
- 外裙里裤两层分别判定、分别处理：内层裤仍按裤装规则收口/折叠，外层裙不处理。❌ 以为外面套了裙子内层就不用管——内层裤仍在身上，有穿着体感（收口处缝线、折叠塞起的厚度、坐下时的压感）；视觉信号看外层，穿着体验看内层。
- 裙摆被掀起/坐下时上移/风吹起时，内层收口短暂露出——天然戏剧瞬间，❌ 写成刻意展示。

### 6.5 视觉信号与遮蔽选择

- 总前提：未用假肢时截肢事实一眼便知；唯一例外是长裙（及小腿/及踝）+静止——**静止可藏，移动必露**（单腿跳/摆至步/摆过步都没有交替步态）。
- 长裙+拐杖的静止误判（被当成受伤/骨折/崴脚）是戏剧素材；移动即暴露是更强的素材——她藏得住衣服，藏不住步态。
- 穿假肢按类型分：膝上/膝下假肢撑起裤管裙摆且恢复交替步态，不易察觉；髋离断假肢步态机械耗力，静止难辨但移动仍会暴露（假肢使用差异见 `基础层/类型-髋离断.md`）。
- 想藏的手段：长裙/长袍/宽大下摆、避免短裙与空管外露、坐着时患侧收好；真正有效的隐藏是尽量少动（坐着不起身、让别人过来她这边、提前到位再等人）。
- 隐藏是剧情驱动的反向操作：先问这段剧情里她有必须隐藏的理由吗（末世暴露＝被针对的风险；剧情需要隐瞒身份、求职、不想被特殊对待），没有❌ 不写隐藏；隐藏失败→按题材升级后果（末世＝抢夺/抛弃，日常＝被凝视/被议论）。
- 标签锁定：无假肢者截肢事实是最明显的标签，先于名字被记住（「那个拄拐的女孩」「那个只有一条腿的」）；用假肢者标签降级为步态标签（「走路不方便」），暴露后才换代。称呼强度落差本身是素材；标签是旁人口语称呼（对话/印象层），正文叙述层仍守否定式缺失禁令。

### 6.6 袜与鞋（按辅具分档）

- 穿假肢（膝上/膝下）：假脚要穿鞋——通常买一双、一只穿真脚一只套假脚；袜子只需健侧一只（假脚有装饰袜/袜套）。
- 不穿假肢（髋离断弃用假肢、或暂时卸下）：只穿健侧一只，患侧空着。
- 双侧：按各自是否穿假肢分别算（见 `基础层/类型-双侧叠加.md`）；轮椅使用者的推进方式露在手上（掌侧用力位置、推圈节奏）；❌ 不写鞋底/轮胎磨平一类器具损耗（口径见 `写作层/素材/受众定位.md`）。
- 系鞋带：坐地弯腰或长柄工具；假脚一侧多为魔术贴/松紧带，不必系。
- 残肢侧的袜子改法：整双剪短、断口缝合收边套在残肢上；连裤袜空袜腿折塞腰后/裙内；单腿者两袜腿一长一短——改法本身是熟练生活者的自我照顾质感（恋物镜头归 `写作层/素材/恋物素材库.md`）。

### 6.7 穿脱动作物理

- 单腿/无腿穿裤的躺下滚翻法：坐位先把患侧裤腿套上→躺下、残肢（或双腿）向后滚翻带动腰部抬起→把裤腰拉到位；脱裤反向。写顺序与腰腹发力，❌「一下穿好」。
- 外套：先患侧后健侧（患侧不能配合要先安置）；脱时反向先出健侧。
- 上肢单手穿衣：套头衫先套健臂钻头；纽扣/拉链改松紧/磁扣/套头；背扣内衣用前置扣或先扣好再转身套穿。
- 穿脱是日常细节，可写单手操作；髋离断常服无空裤管（裤子在裆线处结束），空管飘荡仅限未处理的裤管/袖管（判据见 6.3）。

### 6.8 贴身层与特定场景衣物

> 贴身层管的是穿脱、遮蔽、单手操作、与身体的接触，不是「旁人一眼看穿」；裸露场景的身体细节归 5.1/5.4，两处不重复。浴袍/毛巾等遮蔽物同归本节。

- 内衣（上下装）：内裤患侧按类型贴合（承托面差异见各类型文件服装节）；上肢背扣/前扣/无扣的选择见 4.4；钢圈/肩带与残端、假肢悬吊带的错位（不勒在瘢痕/接受腔边缘）。
- 泳装/温泉/沐浴后：单件 vs 分体对患侧的遮蔽与暴露差别；防水假肢或不戴假肢入水的移动方式见 `基础层/行动库.md`；更衣室↔浴池↔水中的转移与扶物（够不着、湿滑＝真实受限，不写成苦难）；浴袍/大毛巾当临时遮蔽物——移动即露的天花板仍成立（见 6.5）。
- 睡衣/晨间：睡前卸具后穿什么、起夜时够不够得到（衔接 5.3）；晨间更衣顺序、坐姿穿衣（脱裤序列见 5.4）；睡衣层数少，患侧收口/空管口径同 6.3。
- 旗袍与改良款（中华语境）：高开衩/齐臀短款让残肢整段露出、开衩处可露残肢根部；侧襟、包臀、收腰把骨盆线推到台前；传统长款在轮椅坐姿下裙摆铺开、残肢轮廓透过缎面若隐若现。立领/盘扣/滚边与面料（真丝、香云纱、丝绒）是身份与时代的锚点，按人设与场合取，❌ 堆品牌。

### 6.9 服装写作要点

- 裤装写处理方式（裁剪/折叠/打结）；空管只在未处理时写；髋离断已裁剪收口时任何情况都不写空管，未裁剪公用服装/临时借来的裤子仍可写空瘪空垂。
- ❌ 禁止否定式缺失描写：写了「在 X 处收口」后不追加「没有裤管/没有袖管/下面什么都没有/空空的」——写了收口就等于说了那里没有，追加即此地无银三百两。
- 打结限刚截肢不久+公用服装。
- 贴身层多在私密场景：写动作与物件的具体接触（怎么解、怎么够、放哪、换哪只手），❌「她凝视自己的残缺」式升华自怜（回避清单见 `写作层/素材/受众定位.md`）。
- 触发型裸露/器具穿脱元素的取用契机见 `写作层/素材/受众定位.md`（招牌元素密度与疲劳控制），有契机才写、无契机不硬写。
- 成年闸与恢复期红线同样适用于贴身层场景（泳装/内衣/沐浴是高发场景）；未成年设防，术后伤口未愈禁性爱/束缚/疼痛玩法——判定与前置见 `成人内容/亲密总纲.md`（条件注入）。

## 七、书写纪律

- 组织方式：按「动作→类型差异」写。同一动作先写动作本身，再写类型差异——单侧髋离断写最详，膝上/膝下与上肢随后，双侧一律见 `基础层/类型-双侧叠加.md`；类型生理事实以各类型文件为准，❌ 用主类型物理套写其他类型。
- 移动/位移类一律不收，见 `基础层/行动库.md`：行走与步态、原地转身与窄空间转向、上下楼、骑车与电动车、下肢驾车改装、长距离行走、公共交通乘行、雨雪路面、摔倒与起身（摔倒起身亦见 `基础层/辅具-拐杖.md`）。
- 触发路由：写到蹲先查 2.1；写到「双手+移动」先问拐杖在哪（→三）；写到单手任务先问怎么固定（→四）；写到卫浴/如厕/就寝/更衣/照护先查 五。
- 受限通则：受限是生活样态非苦难，写好反增代入感；主角是处置者，写受限与她的处置顺序，❌ 不写求助为常态、❌ 不写窘态为看点；真受限（功能丧失类）与弱受限/点缀的判定见 `写作层/素材/受限场景库.md`。
- 高发错写汇总（全部 ❌）：边走边用手做事未处置；放拐后无拿起动作或缺闭环；腾手方案存在却设计放拐（为一杯水放拐）；「一下穿好」；「她蹲不了」；已处理服装仍写空管；无残端类型写「被残端带动」；「醒来—巡视身体—起身」套路；否定式缺失追加；护理与就医写成医学解说或苦难展览；「无法通行」；器具损耗（鞋底/轮胎磨平）。
- 示例纪律：本文件所有示例句（底色表、场景句）是方向参考非模板，❌ 照抄成文；加细节优先加判据不加句子。
- 场景句中的破折号属对话打断示例，正文叙述层标点纪律见 `写作层/文风/词句工艺.md`。
- 古装题材的坐具/如厕/更衣变体见 `题材层/古装向.md`；现实向的品牌与型号限量见 `题材层/现实向.md`。
