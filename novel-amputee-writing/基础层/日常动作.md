# 日常动作

> 日常动作物理的事实源：坐立转移、家务、占手、单手操作、高频场景与服装。移动与载具见 `基础层/行动库.md`，器械见对应辅具文件，类型解剖见各类型文件。
> **先判断任务，再选择动作**：目标、物品、距离、支撑、双手、环境和人物习惯共同决定做法。库中方法是选项，不是角色必须依次尝试的流程。有完整健腿即禁轮椅。下述轮椅方法只用于已按此条合法配置的角色。

> **目录（按需读取，勿整体加载）**：一 坐立与转移动作｜二 拾物与家务｜三 双手占用矩阵｜四 单手日常通用｜五 高频场景物理｜六 服装穿脱与选择｜七 书写纪律

## 一、坐立与转移动作

### 1.1 坐

- 常见动作为到椅前、处理辅具、稳住身体、屈健腿或调整假肢落座；熟练者可以一句完成。
- 骨盆与坐骨保留时可坐实，单侧前方无腿不等于臀下悬空。双侧是否使用靠背、座垫和固定带按稳定需要。
- 久坐后的压痕、闷热、疲劳和换姿势按个人与装备，不要求每次起身都理残肢或脱腔。

### 1.2 起身

- 用腋拐或肘拐站起时，先把拐拿到手里，再借座沿、台面或健腿站起，站直后才夹腋托或套前臂环。站起前夹不到腋下。顺序见 `基础层/行动库.md#3.2`。
- 单侧熟练者可简洁完成，初学、疼痛、湿滑或外力干扰时再展开调整。
- 上肢截肢而下肢健全者可借腿、躯干、椅背、墙或他人起身，不统一要求双手撑地，也不统一要求必须扶物。双侧上肢、两条健腿时，站着也可用一只脚代手，因另一条腿仍可支撑。
- 双臂＋单腿只有一条完整健腿：无手从坐到站，用健腿踩地，以肩或残臂顶推座沿／墙面，或倚物借力，站稳后进入单腿跳，见 `基础层/行动库.md#3.14`。不要与上一则混用，也不要因此补出拐或轮椅。
- 没有完整健腿的双侧与复合类型可独立臂力转移、滑板、设备或协助，见 `基础层/行动库.md#3.7`。不要把 3.7 的轮椅转移写给仍有健腿的双臂＋单腿。

### 1.3 床上起卧与床边转移

- 床高、床垫软硬、扶手，以及已配置轮椅时（限无完整健腿者）的轮椅位置，都会影响难度，不是“床低必起不来”。
- 常见顺序为翻身、手撑坐起、床边坐稳、处理辅具、站起或转移。
- 幻肢、注意、疼痛和光线可影响动作，但不把每次翻身都写成卡住。

### 1.4 上下车与载具转移

- 可先坐入车座再收腿和处理辅具，也可借车门、滑板、升降设备或协助。
- 持拐上下车（单侧下肢＋双拐等）的顺序与车内放拐见 `基础层/行动库.md#3.11`。
- 双臂＋单腿无手、不默认用拐：先用肩、嘴、躯干或残臂开门，转身先让健腿落地，以车门框、座沿为支点站起，再单腿跳离开。见 `基础层/行动库.md#3.14`。不要套用持拐链，也不要临时补出轮椅。
- 已配置轮椅者（限无完整健腿者）不统一采用抱式转移，独立臂力转移与滑板很常见。本条不包括仍有一条完整健腿的双臂＋单腿。
- 拐杖、随身物，以及已配置时的折叠轮椅，放在哪里、何时取回按场景交代，不必每次展开固定两笔。未合法配置轮椅的角色不在此列补出折叠轮椅。
- 多件同功能辅具同时出门须有任务依据，写清谁使用、谁携带、尺寸重量、包装与目的地。旧拐取回后不再默认携带新拐与备用拐；需要途中退货或切换时才携带，普通腋拐不因“塞进包里”就自动成立。

### 1.5 他力转移

- 被抱、被背、吊带或搬运设备都要考虑双方体重、臂力、稳定、同意和当事人配合。
- 被抱者可以指挥、抓握、调整重心或拒绝，不自动等于暧昧、照护或失主体性。
- 不写“体重轻所以单手不费力”，也不以体长和体重作为高位截肢者的统一设定。

## 二、拾物与家务

### 2.1 蹲与低处取物

- 单侧下肢角色可尝试健腿单腿蹲，是否需要扶持、能否起身和能否双手操作按训练与环境。
- 无膝者不能写真屈膝；穿假肢者按关节和支撑，不把“穿假肢蹲极难”当所有型号通则。
- 长时或双手任务优先坐位、侧卧、长柄工具和协助，不鼓励以单腿深蹲硬撑。

### 2.2 弯腰与高处取物

- 单腿站立弯腰时可用家具、拐杖、长柄夹或坐下，稳定性按重心和支点。
- 高处可用稳固踏凳、长柄工具、下移物品或协助；已配置轮椅者（限无完整健腿者）也可用座高，不鼓励踩不稳椅子。
- 够高与够低都可以有多解，不要求先试到失败才允许求助。

### 2.3 家务速查

| 场景 | 可选做法 |
|---|---|
| 端热锅热汤 | 推车、带盖容器、分次、台面接力或协助；已配置轮椅者（限无完整健腿者）也可用轮椅；不推荐跳跃或湿滑单脚搬运 |
| 洗碗切菜 | 坐高凳或合适台面，防滑、固定食材、适配刀具 |
| 开罐拧盖 | 台面固定、防滑垫、开瓶器、残端或腿夹、单手工具 |
| 扫地拖地 | 长柄工具、拐的组合，或已配置轮椅者（限无完整健腿者）的轮椅组合，处理积水后再移动 |
| 晾收衣服 | 坐位、分次、降低衣架、推车或他人协助 |
| 倒垃圾购物 | 背包、小推车、分次或配送；已配置轮椅者（限无完整健腿者）也可用轮椅 |

### 2.4 照护小孩

- 换尿布和喂养可在稳定台面与坐位完成，抱娃移动优先婴儿车、背带、推车或协助；已配置轮椅者（限无完整健腿者）也可用轮椅。
- 不把“抱婴儿单腿跳”列为推荐技巧；婴儿安全与照护者平衡优先。
- 上肢截肢者可借残端、工具、台面和他人配合，具体按保留结构。

## 三、双手占用矩阵（各类型能腾几只手）

### 3.1 底层判断

- 双拐摆步且健腿离地时，双手主要承担支撑；此时松开一只手可能破坏稳定。
- 站定后支撑重新分配，可在条件合适时腾一只手或两只手。
- 假肢、单拐、肘拐挂臂和坐定操作的占手不同；已配置轮椅者（限无完整健腿者）另按轮椅控制方式判断。不能统一写成“截肢者双手总被占”。
- 上肢截肢者没有第二只真手，但残端、嘴、腿、工具和他人可参与，不能简单把双手任务全部判为不可能。

### 3.2 腾手方式

| 状态 | 可用方式与限制 |
|---|---|
| 双拐移动 | 小件可挂腕、勾指或放包，不能因持物破坏支撑 |
| 原地停稳 | 夹腋、挂臂、单手拢拐、靠物或坐位，可腾一手或双手 |
| 单拐或假肢 | 按当时支撑，可持物、开门或操作 |
| 已配置的轮椅（限无完整健腿者） | 停轮、刹车后可操作；推轮时的持物按控制方式 |
| 单侧上肢 | 健手＋残端／工具／腿嘴／固定面，按任务组合 |
| 双侧上肢 | 脚、嘴、残臂、设备和协助，不等于只能旁观 |

### 3.3 携带与任务选择

1. 先改携带方式：背包、带盖杯、推车、分次、容器改造。
2. 再改工作地点：坐定、台面、浴凳、站定靠物；已配置轮椅者（限无完整健腿者）也可用轮椅座。
3. 需要移动时选合适装备：假肢、拐杖或载具；轮椅限无完整健腿者。
4. 需要协助时明确谁做什么，不写成被动接管；出于身体移动原因的求助先过 3.7。
5. 单腿跳只是可选方式之一；健康熟练者无扶物连续跳数米或更远也可成立，不设置“超过五米必须拿拐”的全库规则。

### 3.4 高发场景

- 开门（有手、拄拐）：停稳后挂臂、夹拐、抵门或先放稳。
- 开门（双侧上肢、两条健腿）：站着也可用一只脚代手拨门把或旋钮，因另一条腿仍可支撑。
- 开门（双臂＋单腿）：站着或跳跃中不能用脚；用嘴、肩、残臂、躯干推靠，或先坐下／倚稳把脚解放后再操作。见 `基础层/行动库.md#3.14`。
- 撑伞：雨衣、固定伞、背包、单拐，或已配置轮椅者（限无完整健腿者）的轮椅方案，按装备与天气。
- 打电话：耳机、语音、停步操作或小件携行，不要求边摆步边触屏。
- 购物车：推车、拐与车的组合、手提篮或配送；已配置轮椅者（限无完整健腿者）也可用轮椅。注意拐杖不被车带跑。
- 抱娃：婴儿车、背带、坐位和协助，不推荐抱娃跳跃。
- 热饮热汤：带盖、推车、分次和稳定转移，不在湿滑地面单脚端汤。
- 轮椅推行中端拿（限已配置者）：物件挂椅侧钩、放椅后兜或夹在腰侧与扶手之间；热的、满的停轮刹住后再接递；有人推行时可以端在手上；放在大腿上看残肢长度能否托稳。
- 单侧上肢搬运：双耳锅、水桶、纸箱、撑袋口、压纸等，用残端、钩手或前臂托压配合健手；两手都占满时请人开门或先放下。

### 3.5 拐杖放置与取放空窗期连续

- 放置可平放、挂臂、夹持、靠物或交人，稳定取决于角度与接触面。
- **取拐前与放拐后的空窗期位移（防“无拐写走”高频穿帮）**：
  - 若拐杖靠在门边／墙边，而人坐在几步外的桌边／床边：去门边拿拐这一段**拐尚不在手**，单侧下肢（未穿假肢）必须写**“一下一下跳到门边（或扶着桌沿／墙挪到门边）拿起拐”**，❌ 写“她走到门边伸手拿拐”；
  - 若人在门边把拐靠放好，要回屋里的椅子／沙发：既然拐已离手留在门边，回座位这一段必须写**“单腿跳回（或扶物挪回）椅子坐下”**，或者改为**“先拄着拐走到椅子边，把拐靠在顺手处再坐下”**，❌ 写“把拐靠回门边……又走回椅子坐下”。
- 放拐后需要取回、替代或换乘时交代结果；不必每次完整展示取放四步。
- 跨场后状态必须一致，不能上一段放下、下一段无动作回到手中。

### 3.6 占手账

| 类型与状态 | 移动时 | 停稳后 |
|---|---|---|
| 单侧下肢＋双拐 | 摆动阶段双手主要支撑 | 可按支撑腾一手或双手 |
| 假肢无拐 | 通常双手可用，稳定按装备 | 同左 |
| 假肢＋单拐 | 一手用拐 | 可调整拐后腾手 |
| 已配置的手动轮椅（限无完整健腿者） | 双手或单手推轮 | 刹车后可操作 |
| 已配置的电动轮椅（同上限制） | 取决于控制器 | 同上 |
| 肩离断 | 健手一只 | 健手＋躯干／工具 |
| 肘腕截肢 | 健手＋残端或工具 | 同左，腕平面旋转按手术 |
| 双侧上肢（两条健腿） | 无真手，可用脚、嘴、残臂或设备；站着仍可用一只脚操作 | 同左，双脚均可解放 |
| 双臂＋单腿 | 移动或站着时脚被占用，只用嘴、肩、残臂或躯干 | 坐下、倚稳或另寻支点解放脚后，脚与脚趾才可操作 |

- 端热饮、抱娃和大件不能仅凭“双手有空”判断，还要看稳定、装备和物品风险。
- 幻想能力是否代替手、支撑和移动按登记及当前代价，不默认只在战斗中有效。

### 3.7 求助门槛（单侧下肢拄拐）

本节是身体移动求助门槛的单一来源。

- 本门槛只在拐在手且能用时适用。拐丢失、损坏或不在手时，只看当场单腿跳或替代移动是否确实困难（见 `基础层/行动库.md#4.3`、`写作层/素材/受限场景库.md#3.2`）。
- 拐在手且能用时，出于身体移动原因请人帮忙，须同时满足：双手被占到完全握不住、也压不住拐柄（抱大件或易碎物、两手都在做事、手受伤）；当场单腿跳也确实困难（湿滑、陡梯、负重、力竭、落点差）。
- 随身背负的包袋与挂腕、勾指小件（见 3.2）不构成双手占满；携行物位置微移时手掌仍可压柄控拐或停步整理，正文无需专门描写整理随身包袋的小动作，更不以此作为求助理由。
- 别人主动帮可以接受、婉拒或接一半，按情境与关系自然回应（见 `写作层/技法/世界观构建.md#四`）；关系上的开口（陪我去、送我）、非移动事务、受伤或生病后、明确的危险情境不受本门槛限制。
- 已配置轮椅者（限无完整健腿者）：遇到真实阻挡（高门槛、没有搭板、窄梯）时请人抬椅或搭板是合理的，平地与合规通道不触发；搭板等环境辅助物为何不在场按 `写作层/素材/受限场景库.md#1.2` 铁律 1。
- 不满足门槛的求助不算受限看点，也不当受限链里的取舍环节，见 `写作层/素材/受众定位.md#六`。

## 四、单手日常通用

### 4.1 总则

- 目标是把事做成，不是反复证明“她什么都能做”或“她做不到”。
- 常用资源包括固定面、工具、残端、腿、嘴、脚、身体和协助，选择由任务与人物决定。
- 合理劳损、疲劳和受伤可以出现，但不把单手生活写成持续受苦。

### 4.2 残端代偿

- 肘腕平面可夹、顶、按、承托和短时支撑，耐受因皮肤与手术而异。
- 肩离断无上臂残端，不写残端夹持；肩带和胸廓活动及假肢控制另算。
- 腕离断的旋前旋后幅度按手术，不默认完整；肘离断无前臂旋转。
- 残端疼痛、神经瘤或皮肤问题时减少直接顶压。

### 4.3 分类速查

- 进食：单手餐具、预切、防滑垫、固定碗盘和适配工具。
- 穿脱：先患后健或先健后患按衣物与残端，磁扣、松紧、拉链辅助可用。
- 书写：健手、压纸器、残端、重物或胶带固定。
- 拧转：防滑固定、工具、腿夹或台面，不把牙咬当所有包装的默认。
- 提携：单手、背包、肩带、推车、滑板或分次。
- 清洁：长柄刷、浴凳、手持花洒和适配瓶罐。
- 双手任务：可用残端和工具完成一部分，不把端盆、开罐、撕膜全部列为绝对不可能。

### 4.4 现代高频

- 手机与键盘：单手布局、语音、触控笔、脚控、口控、读屏和快捷键。
- 支付与包装：扫码、固定包装、剪刀、易开容器和配送。
- 衣物扣件：前扣、磁扣、拉链辅助、先扣后穿。
- 驾车：按当地法规与改装，方向控制、手控、脚控和辅助装置分别设定。手动挡还须拆分离合、刹车、油门、换挡和紧急制动的操作侧与车辆布局；缺左腿或右腿不是同一问题，不能用“单腿”直接推出所有车辆都能开或都不能开。中国现行口径（公安部令第 162 号第十四条）：单独左下肢缺失、右下肢正常，可申请 C2 小型自动挡，用右脚开普通自动挡，不需手控；右下肢或双下肢缺失、能自主坐立且上肢合规，申请 C5 残疾人专用小型自动挡（常配手控）。只作设定依据，正文不讲法规。
- 婴儿护理：稳定台面、固定用品、背带与协助，不能仅用“单手可行”概括全部风险。

### 4.5 幻肢错位

- 幻手运动意图可伴随实际失手，但结果还取决于当前动作和注意，不把每次掉落都归因于幻肢。
- 长期截肢者也可能出现，频率按个体，不用“近期专属／多年绝无”限制。

## 五、高频场景物理

### 5.1 沐浴

- 浴凳、防滑垫、扶手、手持花洒和合适水温是常见配置，按实际环境。
- 单腿站立、弯腰和转移的风险分别处理，不能仅用“截肢所以难”概括。
- 水流、镜面、衣物和瘢痕是否成为镜头由人物与事件决定，不固定为“水路＋收口”。

### 5.2 如厕

- 马桶转移可用扶手、坐便椅和拐杖放置；已配置轮椅者（限无完整健腿者）也可用轮椅转移。空间与隐私影响动作。
- 蹲式便器能否使用与单腿蹲、假脚踝、扶手和持续时间有关，不写“必然起不来”。
- 经期、排泄、失禁与护理分开设定；截肢不自动等于失禁。
- 公共卫生间可找坐厕、无障碍间、协助或改地点，不把尿在身上当默认结局。

### 5.3 就寝与晨起

- 睡姿按舒适、瘢痕和装备，不统一“患侧必须朝上并垫枕”。
- 假肢、拐杖和呼叫设备放在够得到的位置；已配置轮椅者（限无完整健腿者）的轮椅同样如此。除非剧情有意改变。
- 晨起可从动作、事件或对话开始，不必先巡视身体和清点装备。

### 5.4 更衣

- 更衣顺序与衣物结构见第六节。
- 裙子可以裁剪，裤子不必每件都封死；按人物审美和衣物用途。
- 试衣间可有空间、扶手和隐私问题，不把每次镜前凝视都写成身体接纳仪式。

### 5.5 公共空间

- 购物、安检、就医、预约和乘行按真实地点与流程，先查当时当地规则。
- 安检不要求普遍卸假肢或爬行；可提供私密、坐式和替代检查，具体按机构。
- 预约服务可能便利也可能延误，不写“约了也一定等、司机一定不帮”。
- 无障碍设施好坏都可能成为日常事实，好设施不必当稀罕运气。

### 5.6 运动、校园与职场

- 游泳与水上活动按防水装备、浮力、划水、转移和安全，不写“无腿必垂直下沉”。
- 校园住宿、考场、课程和体育活动按实际合理便利与申请流程，不统一“没申请就什么都不能做”。
- 职场可关注过道、久坐、通勤、设备和任务分配，不把歧视当每场必有的冲突。

### 5.7 照护操作

- 翻身减压、清洁、导尿和排泄照护只按实际伤病与护理计划，不由截肢自动附带。
- 具体频率、清洁用品和导管处理按专业方案，不写统一“每日必拔管／必扑粉／必酒精”。
- 照护者与当事人有分工、同意和边界，护理不自动等于情色或幼儿化对待。

## 六、服装穿脱与选择（物理部分）

### 6.1 先判裙裤与裤长

- 分开裤腿与一片下摆只是起点，还要看长短、宽窄、弹性、开口、扣件、鞋子和假肢。
- 短裤可自然露出残端或空口，也可以按审美修改；裙装同样能裁剪，不设“裙装绝不裁剪”。
- 同一人不同衣物可以有不同处理，不把“四大流派”当全书固定身份标签。

### 6.2 长裤与上装袖管的常见处理

- **首选（不穿假肢的膝上与髋离断长裤）**：默认「剪掉缝合（裁短封口或定制）」或「折叠塞进裤腰固定」，两者并列，由角色卡登记一种；常切换假肢者多倾向塞腰保留成衣，长期不用假肢者多倾向剪掉缝合。自然空垂、别针、挽结、原装不改只在另有理由时用：临时状态（康复早期、借来的衣服、刚卸假肢未及处理）、刻意展示或人物审美、古装或特定衣制、剧情需要（衣物被扯乱、匆忙出门）；理由须在设定、章纲或当场可见。
- **边界**：膝下维持下表并列；穿假肢时、裙装与短裤（6.1、6.4）、上肢袖管不适用本首选；双侧叠加按各侧类型分别判断。

| 方式 | 用法与条件 |
|---|---|
| 翻折、塞起、别针或暗扣 | 保留成衣，方便切换假肢，固定程度按布料与动作 |
| 挽结或束起 | 适合宽松裤袖，结的位置和安全性按残肢与活动 |
| 裁短、封口或定制 | 适合稳定审美和专用衣物，之后不能再写同件长空管 |
| 自然空垂 | 人物选择空垂时适用；摆动物理见 6.3 |
| 原装不改 | 衣物足够合身时无需额外处理，不强行“每件必改” |

### 6.3 空裤管与空袖管的物理

- 有骨残肢可主动带动衣物；若空垂，髋、肩离断的空管主要随躯干、风或外力。剪掉缝合后，残端下方（膝上）或裆线（髋）处是平整收口；折叠塞腰的布料贴着胯侧或残肢，不会晃。
- 处理方式只在需要时交代一次：首次被看见、换衣、处理改变、影响动作或亲密、被他人注意并影响情节。同一件衣服之后不复述怎么处理，也不反复描写空管状态；视线回落时直接写视线落回其下肢或腿部即可（❌ 每次必点“空裤管”）。台词里的功能性提及不算。
- 已裁短或固定的同一件衣服不能再无原因变成长空管。
- 状态连续按“这一件衣服”判断，不因角色换衣就当成设定错误。

### 6.4 裙装与外裙里裤

- 先辨衣物结构：独立裤腿按裤装；一片裙摆按裙装；裙裤有独立裤腿仍按裤装；外裙里裤与连衣裙的上身、袖子、裤腿、裙摆分别判断。
- 裙摆不是裤管，不把裤管的翻折塞腰、挽结或残端下封口直接套给裙装。裙装可改裙长、腰身、开衩、里衬与固定；裁短的是裙摆，不是沿残端封一条不存在的裤腿。特殊打结等造型须另有结构与人物目的，不冒充截肢裤装的默认处理。
- 裙装松解或脱下假肢需要隐私、空间、放置和实际扣具，不把桌下暗卸写成通用技巧。
- 裙摆遮蔽与移动是否暴露由裙长、辅具、步态和旁观者位置决定，不设“静止必藏、移动必露”。

### 6.5 视觉信号与遮蔽

- 长裤、短裤、裙装、空管和假肢的外观由当场衣物与动作决定。
- 衣物能否隐藏截肢不是人物义务；想藏、想露或无所谓都可成为人物选择。
- 可以写“没有”“空”等直接表述，也可以只写缝线和动作，不禁止否定式缺失。

### 6.6 袜、鞋与假肢踝角

- 丝袜、长筒袜、连裤袜、短袜帽和定制衣物都可选，固定方式按衣物与身体，不只三种。
- 鞋是否成对购买、保存、交换或捐赠由人物习惯，不写“鞋柜永远成排单只鞋”。
- 假脚与鞋跟需要匹配对线、角度和稳定；可调跟高、专用假脚或换鞋均可。
- 单足高跟加双拐可以是审美选择，但不是稳定性的证明；前掌、拐杖和接触面共同分担受力。

### 6.7 穿脱动作物理

- 窄裤可先给假肢套裤、先穿假肢、使用改装拉链或换宽裤，取决于接受腔与悬吊。
- 坐位穿脱、先后侧顺序、衣物结构和假肢悬吊共同决定动作。
- 上装可先患侧或健侧，按袖管、残端和单手操作，不统一。
- 常规穿脱可简述，首次、换装、状态变化或关系需要时再展开。

### 6.8 贴身层与特定场景衣物

- 肩离断的肩带、领口和文胸是否滑落取决于肩峰、剪裁与衣物，不写成必然“稍动就滑”。
- 内裤、连体衣和丝袜的固定按身体与款式，不把高腰、包臀或某一款式写成唯一物理答案。
- 泳装、旗袍、礼服与运动装按真实结构和活动需求写，不把每种截肢类型固定为同一穿衣风格。

### 6.9 服装写作要点

- 服装细节要影响动作、审美、关系、身份或场景，不是给每个类型贴固定制服。
- 普通鞋、运动鞋和无跟鞋不因截肢失去描写价值，高跟鞋也不是必需看点。
- 服装、袜鞋和假肢维护可以正常出现，不必把磨损当禁词。

## 七、书写纪律

- 先写人物正在完成什么，再让动作物理进入因果，不把日常场景写成器械说明书。
- 常规复现的动作可按 `写作层/素材/受众定位.md#5.4` 简写，首次、方式改变、困难或关系需要时再展开；不把熟练日常动作拔高成核心受限，见 `写作层/素材/受众定位.md#六`。
- 允许多种正确答案，不把“最省事”当成唯一聪明，也不把“最费力”当成最真实。
- 熟练者可以稳定，初学与环境变化可以生疏，双侧与四肢复合者也有自主权与技巧。
- 维修、更换、合理疲劳、过用和伤病可以入戏，避免的是机械重复的买惨，而不是这些生活事实本身。
