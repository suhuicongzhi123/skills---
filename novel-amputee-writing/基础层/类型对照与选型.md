# 类型对照与选型

> 用于设定阶段快速选型与写作时定位文件。这里只做对照，不另立生理定义；具体动作以对应类型文件、`基础层/行动库.md` 和人物实际装备为准。
> **没有跨类型通用的行动答案**：截肢平面决定解剖边界，装备、训练、健康和环境决定实际表现。

> **目录（按需读取，勿整体加载）**：一 核心差异速览｜二 移动能力对照｜三 体位与姿势对照｜四 假肢对照｜五 不可能动作对照｜六 服装对照｜七 受限清单对照｜八 四肢复合与无肢路由表｜九 快速决策树｜十 易混淆点汇总｜十一 占手与移动选择速查｜十二 使用建议

## 一、核心差异速览

| 类型 | 主要保留与缺失 | 残肢动作边界 | 常见移动选择 |
|---|---|---|---|
| 髋离断 | 骨盆通常完整，缺整腿与骨性杠杆 | 软组织可收缩，不能独立抬甩蹬踢 | 双拐、假肢、跳、扶物挪步与载具 |
| 膝上 | 有髋与部分股骨 | 可由髋带动，真膝不存在 | 假肢、拐、跳、扶物挪步与载具 |
| 膝下 | 有髋、真膝与部分小腿 | 真膝可控，假踝非生物踝 | 假肢、拐、跳、膝行与载具 |
| 肩离断 | 有肩胛锁骨轮廓，无上臂 | 无上臂残端抓握或顶按 | 下肢可走跑，平衡与保护因人而异 |
| 肘腕 | 有上臂或前臂残端 | 可夹顶按，腕旋转按手术 | 下肢可走跑，操作方式多样 |
| 双侧叠加 | 逐侧确定 | 不能套用单侧健侧逻辑 | 按关节、装备与训练组合 |

## 二、移动能力对照

### 2.1 辅具与假肢使用

- 髋离断常见双拐、假肢、单腿跳或载具，假肢使用依适配，不能写成“假肢不可日常驱动”；单侧髋离断一律不配置轮椅。
- 膝上常见假肢，也可双拐、单拐、单腿跳或载具；普通机械膝与微处理器膝分别处理，单侧不配置轮椅。
- 膝下常见假肢，真膝可动；不穿假肢时可跳、拐或膝行，单侧不配置轮椅。
- 上肢类型主要解决操作与部分平衡问题，不因截肢本身配轮椅或拐；仅在合并下肢伤病、平衡障碍或其他已登记条件时按实际装备写。有一条完整可站立的健腿即禁轮椅；交叉组合若仍要用轮椅，须明示虚构豁免。
- 双侧类型必须分双膝下、双膝上、双髋及不同平面，不能统一为“轮椅＋爬行＋被抱”。
- 双臂＋单腿仍有一条完整可站立的健腿，移动默认单腿跳，不以拐或轮椅为默认，见 `基础层/类型-双侧叠加.md#4.3` 与 `基础层/行动库.md#3.14`。不要把四肢复合的轮椅方案写给这一组合。

### 2.2 单腿跳与追赶

- 单腿跳是部分单侧角色的选择，熟练者可以稳定连贯，但没有统一跳数和速度。
- 追赶比较双方装备、训练、路线、障碍和目标，不直接由截肢名称决定结果；单腿跳对全力奔跑的健全人默认追不上、甩不掉，基线与例外见 `基础层/行动库.md#4.2`。
- 双侧无健腿不等于无移动能力，轮椅、假肢、膝行、爬行和载具可组合。

## 三、体位与姿势对照

| 动作 | 单侧下肢 | 双侧下肢 | 上肢截肢 |
|---|---|---|---|
| 坐 | 骨盆坐骨保留时可坐实 | 同左，稳定按躯干与座具 | 通常可坐，操作不同 |
| 健腿单腿蹲 | 可尝试，扶持按训练 | 无健腿，按剩余关节与装备 | 可蹲，起身方式按训练 |
| 穿假肢蹲 | 按关节和支撑 | 同左 | 不适用 |
| 跪 | 有真膝与假肢条件分别判断 | 双膝下可真有膝，其他按残肢和装备 | 下肢可跪，起身保护不同 |
| 交叠腿／夹物 | 按残肢长度与姿势 | 同左 | 下肢结构通常保留 |

## 四、假肢对照

| 特征 | 髋离断 | 膝上 | 膝下 |
|---|---|---|---|
| 常见组件 | 髋膝踝足＋骨盆接受腔 | 膝踝足＋大腿接受腔 | 踝足＋小腿接受腔 |
| 主动来源 | 骨盆、躯干、健侧与组件 | 残侧髋部与关节组件 | 真膝与组件 |
| 日常可用性 | 个体差异大，不绝对排除 | 常见，型号分化 | 常见，动作潜力较多 |
| 易错点 | 写成绝不能日常用 | 所有膝都写成被动阻尼 | 假踝写成生物主动踝 |

上肢假肢不能用“肩离断无肌电”概括。残余肩胸信号、索控、压感和 TMR 后增强控制分别设定。

## 五、不可能动作对照

- 真缺失的脚、小腿、膝、手和前臂不能实际完成动作；假肢代偿必须写明是装备。
- 髋、肩离断无骨性残端独立抬甩和顶按，但软组织与躯干可以活动。
- 膝上无真膝屈伸，膝下保留真膝；普通假膝和动力／微处理器膝不能混写。
- 跪、蹲、交叠腿、骑车、游泳和踢击均不能脱离装备与训练做绝对判断。
- 双侧继承各侧解剖限制，但不把较好一侧的能力一并删掉。

## 六、服装对照

- 髋离断空管主要随躯干和外力；膝上、膝下残肢可带动；肩离断无上臂残端顶袖。
- 翻折、挽结、裁短、自然垂落、原装和定制都可选择，同一人不同衣物可以不同。
- 穿假肢配裤的顺序由裤型和接受腔决定，不强制“先套假肢进裤腿”。
- 丝袜、内裤、肩带和鞋履按实际剪裁与身体，不写成某类型只有一种固定方案。
- 裙装可裁剪，但裙摆不是裤管；裙长按衣物结构处理，不套用裤管挽结、塞起或残端下封口。裙裤有独立裤腿仍按裤装，外裙里裤逐层判断。
- 没有完整可站立健腿的设定中，轮椅与假肢足部可以使用脚踏板。有一条完整可站立的健腿即禁配轮椅；交叉组合若仍要用，须明示虚构豁免。

## 七、受限清单对照

- 髋离断：无骨性杠杆、假肢适配与装备选择可能影响任务，可用拐杖、单腿跳、载具和协作，单侧不配置轮椅（双髋离断见 `基础层/类型-双侧叠加.md#九`）。
- 膝上：真膝缺失、普通假膝控制、接受腔与长距任务。
- 膝下：假脚踝足、接受腔、防水与具体地形。
- 上肢：双手协同、抓握、保护与摆臂，不等于移动受限或完全不能平衡。
- 双侧：装备、转移、环境、左右差异和手部占用，不等于完全失能。

## 八、四肢复合与无肢路由表

### 8.1 判定顺序

逐侧列结构 → 确定当前装备 → 分析任务所需支撑与协同 → 选择代偿。

### 8.2 组合路由

| 设定 | 读取重点 |
|---|---|
| 双侧下肢 | 双侧叠加＋对应下肢类型＋行动库双侧节 |
| 双侧上肢 | 双侧叠加＋肩／肘腕＋单手日常 |
| 四肢复合 | 所有涉及类型＋双侧叠加，分别判断移动与操作；轮椅只用于没有完整可站立健腿的复合 |
| 双臂＋单腿 | 读 `基础层/类型-双侧叠加.md#4.3` 与 `基础层/行动库.md#3.14`；移动默认单腿跳，不以拐或轮椅为默认；操作按嘴、肩、残臂或解放后的脚；因仍有一条完整可站立的健腿，禁配轮椅，除非明示虚构豁免 |
| 单臂＋双腿 | 无完整可站立健腿时可配轮椅；移动、轮椅控制、持物和转移分别判断 |

### 8.3 冲突仲裁

- 不用“最弱项决定一切”，而是检查任务必要条件是否满足。
- 较好侧和装备可以形成代偿，不能把单侧或双侧的限制机械叠加成无能力。
- 辅助器具与训练改变的是实际做法，不改变已缺失的解剖结构。

## 九、快速决策树

```
先定每侧截肢平面与保留关节
→ 再定当前装备与控制方式
→ 再定训练、皮肤、健康与熟练度
→ 再定任务、距离、负重、腾手与环境
→ 最后选择动作，并检查缺失肢体是否被误写参与
```

## 十、易混淆点汇总

### 10.1 髋离断与半盆切除

- 髋离断通常骨盆完整，坐位可以稳定。半盆切除不是髋离断，无独立类型文件；须在设定中单独写明坐骨与骨盆变化，禁止套用髋离断的坐位和裤腰规则。
- 不能由“裤腰能否挂住”单独判断术式，外观与软组织因个体而异。

### 10.2 经肱平面与肘、肩离断

- 经肱骨肘上截肢挂在肘腕类型下，不是肘离断，也不是肩离断：有上臂残段，无肘关节。选型与动作按残端长度和保留结构，不套用肘离断或肩离断的残端规则。细节见 `基础层/类型-肘腕.md`。
- 经桡骨（前臂中段）保留真肘，旋转随残端长度减少，挂在肘腕类型下，见 `基础层/类型-肘腕.md#二` 与 `基础层/类型-肘腕.md#五`。

### 10.3 足部、踝离断与缺趾

- 足部／踝离断／缺趾按膝下变体分别设定，不套用标准小腿接受腔。详见 `基础层/类型-膝下.md`。

### 10.4 单侧与双侧取象

- 单侧和双侧都可写空椅面、空裤管与不对称，不必为了形式禁止某个词。
- 重要的是解剖正确和当场状态，不是“双侧无半边”这种文字游戏。

### 10.5 单腿蹲与假肢蹲

- 单腿蹲是一种可能动作，不是正式豁免；扶持和起身按个人。
- 假肢蹲取决于关节和支撑，不按类型一刀切。

### 10.6 假肢关节控制

- 普通机械膝、手动锁膝、微处理器膝和动力膝分别设定。
- 肩离断肌电与压感可存在，TMR 是增强路径而非必需入口。

### 10.7 残肢软硬与动作

- 有骨残肢也不是整根都硬，软组织与骨共同构成。
- 无骨性残肢可收缩和随躯干移动，但不能独立杠杆发力。

## 十一、占手与移动选择速查

- 下肢与装备决定移动时是否需要手，上肢决定剩余抓握与操作资源。双臂＋单腿站着或跳跃时脚被占用，只有解放脚之后才能用脚操作；双侧上肢而两条健腿健全时，站着仍可用一只脚代手。
- 双拐摆步时双手主要支撑，停稳后可腾手；假肢和轮椅（仅限没有完整可站立健腿的设定；交叉有健腿须明示虚构豁免）按控制方式。
- 抱娃、热汤和大件优先考虑安全转移，不推荐跳跃搬运。
- 不设“1–2 米旋移、2–5 米跳、超过 5 米必拿拐”的固定规则。

## 十二、使用建议

- 设定阶段先确定类型和变量，不从类型直接复制一整套动作。
- 写作阶段遇到具体任务再查类型和行动库，未覆盖动作按参与肢体与支撑推导。
- 审查阶段同时查“把不能写成能”和“把能做写成绝不能”，避免两种刻板印象。
