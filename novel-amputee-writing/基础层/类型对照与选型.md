# 类型对照与选型

> 目的：设定阶段快速选型、写作时快速查证、交叉验证生理事实。覆盖全部类型：髋离断／膝上／膝下／肩离断／肘腕／双侧叠加；四肢复合与无臂的路由见 八。
> 本文件只做对照与选型，**不立生理定义**：各类型物理以 基础层/类型-髋离断.md、类型-膝上.md、类型-膝下.md、类型-肩离断.md、类型-肘腕.md、类型-双侧叠加.md 为唯一权威，冲突以类型文件为准；单侧髋离断为全库调优主类型，双侧与四肢复合的叠加细则见 基础层/类型-双侧叠加.md。

> **目录（按需读取，勿整体加载）**：一 核心差异速览｜二 移动能力对照｜三 体位与姿势对照｜四 假肢对照｜五 不可能动作对照｜六 服装对照｜七 受限清单对照｜八 四肢复合与无肢路由表｜九 快速决策树｜十 易混淆点汇总｜十一 使用建议

## 一、核心差异速览

| 类型 | 保留与缺失 | 残肢性质与能否主动移动 | 移动默认 | 裁剪位置（裤装／上装） |
|---|---|---|---|---|
| 髋离断 | 骨盆完整；缺整条腿（无股骨、无髋关节） | 无骨性残肢（只有软组织），❌ 独立抬起甩动，可绷肉 | 双拐（绝对主力） | 大腿根部（裆线） |
| 膝上 | 保留髋关节与部分大腿 | 有股骨残段，✅ 可屈髋带动残肢 | 假肢为主，拐杖为辅 | 残端下缘（或不裁折叠塞起） |
| 膝下 | 保留髋、膝与部分小腿 | 有胫腓骨残段，✅ 可屈髋屈膝 | 假肢为主 | 膝下残端下缘（或不裁折叠塞起） |
| 肩离断 | 保留肩胛锁骨轮廓；缺整臂（经肩关节） | 无残端，❌ 一切残端动作 | 与常人同（下肢健全） | 肩峰下缘／肩缝处（上装） |
| 肘腕 | 保留上臂或前臂；肘／腕处离断 | 有残端，✅ 夹、顶、按、承重（腕离断可旋前旋后） | 与常人同（下肢健全） | 残端下缘（上装） |
| 双侧叠加 | 两侧同缺或上下肢复合 | 按所叠类型 | 轮椅＋爬行＋被抱（下肢双侧）；上肢双侧移动不受限 | 按所叠类型分别处理 |

## 二、移动能力对照

### 2.1 辅具与假肢使用

| 类型 | 日常首选 | 假肢使用率 | 单拐适用性 |
|---|---|---|---|
| 髋离断 | 双拐（绝对主力） | 低（耗力大，主要用于社交／外观） | 仅极短辅助 |
| 膝上 | 假肢为主，拐杖为辅 | 中（可日常穿戴） | 初期康复／长距离辅助 |
| 膝下 | 假肢为主 | 高（接近正常步态） | 不常用 |
| 肩离断／肘腕 | 无需移动辅具（下肢健全） | 上肢假肢以代偿持物为主，细目见 基础层/辅具-假肢.md | 不适用 |
| 双侧叠加 | 轮椅（主载体）＋爬行＋被抱 | 按平面递减：双膝下＞双膝上＞双髋离断 | 不适用（无腿无从摆拐） |

原因：
- 髋离断无股骨杠杆，假肢能耗约为正常步行 2-3 倍，不可日常驱动。
- 膝上有股骨残段，可驱动假肢摆动。
- 膝下保留膝关节，假肢控制最接近自然。
- 上肢类型移动与常人同，差异在平衡与保护（摔倒无法用手撑，单脚站立需依靠物）。
- 双侧下肢无健腿，拐杖体系整体失效；行动方式只由残肢长度决定。

### 2.2 单腿跳与追击

| 类型 | 连跳能力 | 主要限制 |
|---|---|---|
| 髋离断 | 熟练者可连跳几十次 | 无骨性支撑，重心高（❌ 写「重心低」——截断整腿后重心上移偏健侧） |
| 膝上 | 同髋离断 | 无小腿承重 |
| 膝下 | 同上，略稳 | 无踝关节 |
| 双侧下肢 | ❌ 无单腿跳 | 移动三件套：轮椅／爬行／被抱 |
| 上肢 | 跑跳与常人同 | 肩离断跑动残臂摆动、单脚站立需依靠物 |

- 单腿跳适用层（临时无辅具／无辅具设定／辅具空白期／幻想向特殊移动在位）见 基础层/行动库.md#一、移动方式分层总表；单腿＋双拐速度远不及常人——追不上。

## 三、体位与姿势对照

| 动作 | 髋离断 | 膝上 | 膝下 |
|---|---|---|---|
| 坐 | 坐得实，椅面前方没腿 | 坐得实，残肢可屈在椅上 | 坐姿接近正常 |
| 单腿蹲 | ✅ 可（正式豁免，须一手支撑） | ✅ 可（同左） | ✅ 可（同左） |
| 双腿蹲 | ❌ 不可（只有一条腿） | ❌ 不可（只有一条腿） | ❌ 不可（只有一条腿） |
| 穿假肢蹲 | ❌ 极难（假肢无主动控制） | ❌ 极难（膝关节被动／阻尼控制） | ⚠️ 可短时（须慢、须扶物） |
| 单腿久站 | ❌ 难（须找依靠或换姿势） | ❌ 难（同左） | ❌ 难（同左） |

跪／二郎腿／并膝夹物见 五（不可能动作对照），图例同 五。

- 上肢类型：坐跪蹲与常人同；起身不能双手撑地，须借物（桌沿／椅背／他人手臂）。
- 双侧下肢：见 基础层/类型-双侧叠加.md（「跪」＝残端顶地档；双髋离断连残端顶地也没有）。

## 四、假肢对照

| 特征 | 髋离断假肢 | 膝上假肢 | 膝下假肢 |
|---|---|---|---|
| 组件 | 髋关节＋膝关节＋踝足（三组件） | 膝关节＋踝足（两组件） | 踝足（一组件） |
| 接受腔 | 包裹胯与腰腹 | 包大腿残肢（坐骨承重） | 包小腿残肢（髌韧带承重） |
| 重量 | 又长又重 | 较重 | 相对轻 |
| 穿脱时长 | 耗时（套腔／对线／系带） | 中等 | 较快 |
| 步态 | 机械、耗力 | 较自然（有髋推送） | 接近正常 |
| 膝关节控制 | 无法主动驱动 | 被动／阻尼控制（无主动屈膝） | 真膝关节（可主动） |
| 日常使用率 | 低 | 中 | 高 |

- 上肢假肢（含钩子假臂）与双侧假肢（平面递减、双髋离断适配困难）细目见 基础层/辅具-假肢.md 与 基础层/类型-双侧叠加.md，本表只对照下肢三型。

## 五、不可能动作对照（核心禁区）

| 动作 | 髋离断 | 膝上 | 膝下 |
|---|---|---|---|
| 并膝／双膝并拢 | ❌ | ❌ | ⚠️ 短时可（有膝） |
| 患侧踩／蹬／踢 | ❌ | ❌ 不穿；⚠️ 穿假肢摆动式踢 | ❌ 不穿；⚠️ 穿假肢有限踢 |
| 患侧跪 | ❌（无膝） | ❌（无小腿） | ⚠️ 短时可（残端跪） |
| 二郎腿患侧在上 | ❌ | ❌ | ⚠️ 穿假肢时可 |
| 双腿夹物 | ❌ | ❌ | ⚠️ 短时可夹持 |
| 残肢独立抬起／甩动 | ❌（无骨骼杠杆） | ✅（有股骨） | ✅（有骨骼） |
| 患侧屈髋 | ✅（髋完好） | ✅（髋完好） | ✅（髋完好） |
| 患侧屈膝 | ❌（无膝） | ❌（无小腿，假肢膝被动） | ✅（真膝可主动） |

图例：❌＝绝对不可；⚠️＝有条件可（见具体类型文件）；✅＝可以。

上肢速查：
- 肩离断：患侧抓握／提举／推拉／撑地一切违规；❌ 任何残端动作（无残端）；双手协同做不到，须固定物／工具／求助。
- 肘腕：患侧手指的捏握拧拨一切违规；✅ 残端夹物／承重／顶按（腕离断可旋前旋后）；双手协同须健手＋固定物或工具替代。
- 双侧叠加：并集原则——所叠单侧清单全部继承＋双侧禁项，见 基础层/类型-双侧叠加.md#六、不可能动作（并集原则）。

## 六、服装对照

| 类型 | 裤装／上装处理 | 裙装／下摆 | 视觉信号 |
|---|---|---|---|
| 髋离断 | 已裁剪：大腿根部收口；未裁剪：空垂空瘪（❌ 被残肢带动——无骨性残肢） | 不裁剪（一片下摆） | 裤装已裁剪＋双拐＝一眼便知 |
| 膝上 | 假肢常用：折叠塞裤腰（不裁剪）；不穿假肢：可裁剪至残端下缘 | 不裁剪 | 裤装＋假肢不易察觉 |
| 膝下 | 同膝上 | 不裁剪 | 假肢步态接近正常 |
| 肩离断 | 上装裁剪至肩峰下缘／肩缝处；未裁剪：空袖管空瘪 | —— | 空袖管随动作晃，❌ 写被残端带动 |
| 肘腕 | 未处理有空袖管＋残端带动可写 | —— | 空袖管＋残端动作 |
| 双侧叠加 | 按所叠类型分别处理；双髋离断配专用连裤袜／无袜腿 | 裙摆下空空 | 轮椅使用者的推进方式露在手上 |

- 裙裤判定铁则：**分开的两条裤腿 vs 一片下摆**，按形态不按名字判——判定表见 基础层/日常动作.md#六、服装穿脱与选择（物理部分）。

## 七、受限清单对照（类型特有）

- **髋离断**：蹲着只能单手做事；跪不了；跷不了二郎腿；单腿久站难；不能并膝／双腿夹物；拐杖不在手＝只能单腿跳；追不上。
- **膝上**：跪不了（无小腿可跪）；蹲着只能单手做事；假肢穿脱耗时；接受腔问题（久坐压迫／出汗）；长距离吃力（不穿假肢时全靠拐杖）。
- **膝下**：假肢依赖（日常高使用率，故障影响大）；踝关节无感知反馈；残端承重不均（长时间假肢步行）。
- **肩离断／肘腕**：双手任务须固定物／工具／求助（剪纸／绑绳／撕薄膜／剥线）；摔倒无法用手撑护头脸；拧盖系带类改法（按压式／松紧／魔术贴）；肩离断无残端代偿，受限全在「手少」；肘腕残端可部分代偿（夹物／承重）。
- **双侧叠加**：辅具依赖为主轴——轮椅出事＝完全失去行动力（见 基础层/类型-双侧叠加.md#七、受限清单）。

推导方式：不可能动作→放进具体事件；辅具依赖→让辅具不在手。

## 八、四肢复合与无肢路由表

> 适用：quad（四肢缺如）、DHD＋DSD、无臂（双上肢缺、下肢健全）、双臂＋单腿、单臂＋双腿等复合设定。注入组合见 基础层/类型-双侧叠加.md#一、适用范围与叠加路由。

### 8.1 判定顺序

先定下肢（移动主干）→ 再定上肢（剩余手数）→ 再取叠加层。

### 8.2 组合路由

| 设定 | 组成 | 口径 |
|---|---|---|
| quad（四肢缺如） | 双侧叠加（下肢层）＋肩离断或肘腕（上肢层） | 移动按双侧层，操作按上肢类型与剩余能力；不可能动作取并集 |
| DHD＋DSD（无任何残肢） | 双侧叠加＋肩离断 | 无残肢可顶、无手可持：全靠被抱与口、下巴代偿 |
| 无臂（双上肢缺、下肢健全） | 肩离断／肘腕叠加层 | 移动不受限；操作按脚代手／嘴代手；下肢条目全部不适用 |
| 双臂＋单腿／单臂＋双腿 | 上肢看剩余手数，移动看下肢 | 上下肢冲突按最弱项仲裁（见 8.3） |

### 8.3 冲突仲裁

- 下肢决定移动方式；上肢决定操作能力（能腾几只手）。
- 复合时按最弱项：需要双手的事只有一只手就做不了，或须改法（固定物／工具／求助）。
- 辅具适配按实际能力：不能持双拐就改单拐或其他方案（组合类型拄单拐、身体向残侧倾斜——物理见 基础层/行动库.md）。
- 爬行按四肢协同的最弱项定可用支撑点：缺一腿→三点爬（双手＋健膝）；再缺一手→两点爬（单手＋健膝）。单侧下肢类型的爬行门槛见 基础层/行动库.md#一、移动方式分层总表。

### 8.4 复合铁则

复合不是「优点相加」，是「限制相乘」：每个动作须同时满足两侧约束——任何一侧做不到，整体就做不到。

## 九、快速决策树（设定阶段选型用）

问题0：截肢在哪侧？

```
上肢还是下肢？
├─ 下肢单侧 → 髋离断（齐裆线、无骨性残肢）／膝上（有股骨残段）／膝下（有膝与小腿残段）
├─ 下肢双侧 → 类型-双侧叠加
├─ 上肢单侧 → 肩离断（无残端）／肘腕（有残端）
└─ 两侧都有 → 八、四肢复合与无肢路由表
```

问题1：日常主要用什么移动？

```
├─ 髋离断 → 双拐为主，假肢仅社交／外观
├─ 膝上 → 假肢为主，拐杖为辅
├─ 膝下 → 假肢为主
├─ 双侧下肢 → 轮椅＋爬行＋被抱
└─ 上肢 → 与常人同
```

问题2：能跷二郎腿吗？

```
├─ 髋离断／膝上／双侧下肢 → ❌ 不能
├─ 膝下 → 穿假肢短时 ✅，不穿 ❌
└─ 上肢 → ✅ 与常人同
```

问题3：能跪吗？

```
├─ 髋离断／膝上 → ❌ 不能
├─ 膝下 → ⚠️ 短时（残端跪）
├─ 上肢 → ✅（起身不能双手撑地）
└─ 双侧下肢 → 无膝跪；残端顶地按 基础层/类型-双侧叠加.md（双髋离断无跪）
```

问题4：残肢能主动晃动吗？

```
├─ 髋离断 → ❌（无骨骼杠杆，只能绷紧肌肉）
├─ 膝上／膝下 → ✅（有骨骼残段）
├─ 肩离断 → ❌（无残端）
├─ 肘腕 → ✅（残端夹顶按）
└─ 双侧 → 按所叠类型
```

## 十、易混淆点汇总

### 10.1 髋离断 vs 半盆骨切除

| | 髋离断 | 半盆骨切除 |
|---|---|---|
| 骨盆 | **完整**（一根不缺） | 切掉部分髂骨／坐骨 |
| 腰胯 | 腰胯那道棱还在 | 一侧腰胯真塌 |
| 裤腰 | 卡得住、不掉 | 挂不住 |
| 本库 | ✅ 调优主类型 | ❌ 禁止写入 |

### 10.2 「空椅面」——单侧 vs 双侧

| | 单侧髋离断 | 双侧髋离断 |
|---|---|---|
| 能用「空椅面」吗 | ✅ 能（不对称对照：一边有一边没有） | ❌ 不能（无可对照的另一边） |
| 臀部悬空吗 | ❌ 不悬空，坐得实 | ❌ 不悬空，坐得实 |

### 10.3 单腿蹲 vs 双腿蹲

| | 单腿蹲（健腿） | 双腿蹲 |
|---|---|---|
| 可行性 | ✅ 正式豁免（下肢三型通用） | ❌ 不可（只有一条腿） |
| 条件 | 须一手支撑（扶拐／扶墙／撑地）；一手撑地，另一手做简单的事 | 需要两条腿 |
| 起身 | 扶拐撑起／撑膝盖／就手扶物 | —— |

### 10.4 假肢膝关节控制

| 类型 | 膝关节类型 | 控制方式 | 能主动屈膝吗 |
|---|---|---|---|
| 髋离断假肢 | 机械膝 | 无法主动驱动 | ❌ 不能 |
| 膝上假肢 | 机械膝 | 被动／阻尼控制 | ❌ 不能 |
| 膝下假肢 | 真膝关节 | 主动肌肉控制 | ✅ 能 |

### 10.5 残肢的「软」与「硬」

髋离断患侧是软的、随体位变形的软组织（触之无骨感）；膝上／膝下是硬的、有骨撑的残端（可主动带动裤管）；肩离断无残端可写。❌ 把膝上的「柱状残端带动裤管」写进髋离断。

### 10.6 肩离断 vs 肘腕

肩离断无残端；肘腕保留上臂或前臂残端，残端是仅次于健手的第二「工具」（夹物／承重／顶按）。❌ 给肩离断写任何残端动作。

## 十一、使用建议

- 设定阶段：按 九 决策树选类型；复合设定按 八 路由表。写作阶段快速查 五、六；自查阶段用 十 逐条核对。
- 幻肢范围：髋离断＝整条腿（幻腿／幻膝／幻足）；膝上＝小腿及以下；膝下＝脚及以下；上肢＝对应臂／手；双侧两侧均可有。机制与档位全类型统一，见 基础层/身体细节与幻肢.md。
- 完整细节：各 基础层/类型-*.md 为唯一权威；战斗与冲突的战术应用见 写作层/素材/冲突与战斗.md。
