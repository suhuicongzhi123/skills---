# 审查报告模板

> 审查员按此格式落盘 `审查/审查报告-第XXXX章.md`（UTF-8 无 BOM），并全文返回主对话。修订说明由修订执行方追加进「修订记录」节（倒序），保证磁盘上可追溯「原文→修订」。

```markdown
# 审查报告：第XXXX章 《章节标题》

## 评级：PASS / MINOR / REWRITE

## 维度判定
| 维度 | 判定 | 要点（一句话+引文位置） |
|---|---|---|
| 1 生理事实与类型物理 | 通过/问题 | |
| 2 设定与角色卡一致性 | 通过/问题 | |
| 3 连续性 | 通过/问题 | |
| 4 反AI | 通过/问题 | |
| 5 叙事连贯与人物 | 通过/问题 | |
| 6 术语与用名 | 通过/问题 | |
| 7 文体与描写有度 | 通过/问题 | |
| 8 成人内容（仅 B/C 章，否则写「不适用」） | 通过/问题/不适用 | |
| 9 叙事质量（仅 B/C 章，否则写「不适用」） | 通过/弱/缺/不适用 | 章八要素齐缺、阅读承诺、峰值段、故事优先、对话博弈、人物区分各一句证据 |

## 叙事质量（维度 9 明细，证据句）
- 章八要素：（逐项「齐／缺」，缺项附位置）
- 阅读承诺与兑现：
- 峰值段或感官递进：（冲突/推进章填起点与占比；养护/恋物/呼吸章填感官波次递进，或「不可定位」）
- 故事优先与分档镜头：（篇幅第一名、身体镜头预算档〔常规/感官主菜〕与删除测试结果）
- 对话博弈：（抽一段，两人在争什么）
- 人物区分：

## 收尾三问（只记录，不作放行条件）
- 读完是否想翻下一章：
- 哪一句读得最慢：
- 哪个人物最有辨识度：

## 问题清单
- [严重度: 高/中/低] 位置 问题描述
  → 修改建议：

## 亮点（可选，1–2 条值得保留的写法）

## 结论
（一句话：PASS 可定稿 / MINOR 修订要点 / REWRITE 理由）

## 修订记录（倒序追加）
- 修订X：改了什么／为什么（对应问题条目）
```

## 落盘纪律

- 维度判定缺一行＝报告不完整；问题条目缺四要素之一（严重度/位置/描述/改法）＝条目无效。
- 引文实证：问题与亮点均须引用正文原文（标注位置）；❌ 无引文的空泛结论。
- 落盘语气按 `写作层/文风/台词库.md` 第二部分；返回主对话的摘要不用语气词。
