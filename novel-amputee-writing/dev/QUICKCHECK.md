# 快速自检清单（5分钟版）

> **适用场景**：时间紧张时的最小必查项；完整检查仍需运行 `verify.py` 和 `gatecheck.py`。
> 本清单不替代完整流程，只保证"不犯严重错误"。

---

> **目录（>100 行按需文件，勿整体加载）**：动笔前（必查 3 项）｜写完后（必查 5 项）｜禁令速查｜救急用法速查｜紧急联系。

## 动笔前（必查3项，3分钟）

### 1. 生理事实速查（30秒）

- [ ] 查 `types/{type}.md#不可能动作` - 确认本类型禁止的动作
- [ ] 成年闸与恢复期红线：成年（性内容角色≥18）/ 恢复期（术后伤口未愈禁性爱/束缚/疼痛）

**快速记忆卡**：
- **髋离断**：无膝可跪、无腿可蹬、残肢不能独立甩动
- **膝上**：无小腿可跪、患侧踢空=失衡
- **膝下**：残端可短时跪、穿假肢时可翘二郎腿（不穿不可）

### 2. 填写作卡★四行硬项（2分钟）

打开 `templates/chapter-contract.md`，必须填满：

- [ ] **动手与失败点**：她做了什么可能失败的事？失败在哪？
- [ ] **对手今天想干什么**：他的目标与她的目标冲突吗？
- [ ] **篇幅第一名**：哪件事写得最长？（必须是她最在乎的事）
- [ ] **三处不在状态**：她哪三处做得不完美但没后果？

> ❌ 任一项空着 = gatecheck [27] FAIL

### 3. 三句试音（30秒）

按 `core/voice.md#三` 试说三句：
- [ ] 她现在对谁说话？
- [ ] 这句话只有她会这么说吗？
- [ ] 盖住名字，能认出是她吗？

> 说不出 = 回去补人物卡声口字段

## 写完后（必查5项，5分钟）

### 1. 运行机检（1分钟）

```bash
python scripts/gatecheck.py <项目目录> --chapter N
```

- [ ] 输出 `PASS` 才算过关
- [ ] 有 `FAIL` 必须改，不能跳过
- [ ] `WARN` 是提示，建议看一眼

### 2. 严重错误六类（G01，1分钟）

- [ ] **截肢事实无偏移**：部位/侧别/时长档没写混
- [ ] **动作无违规**：没写缺失肢体参与的动作
- [ ] **辅具连续性**：拐杖/假肢没凭空出现消失
- [ ] **基调无漂移**：没私加大纲外的剧情线
- [ ] **情节无重复**：近5章没写过同样的事件结构
- [ ] **措辞与世界观匹配**：常态化框架下叙述层无"髋离断""患侧"等病理词

> 任一命中 = 整章回炉

### 3. 动作可行性（G03，1分钟）

逐段检查动作链：
- [ ] **支撑点存在**：她站着/蹲着时有什么在支撑她？
- [ ] **辅具不离身**：拐杖在哪？假肢穿着吗？
- [ ] **双手是否被占**：她拄拐时双手能拿东西吗？
- [ ] **腾手后支撑降级**：放下拐杖后她怎么站稳的？

> 找不出支撑点 = 失真

### 4. 权重审计（30秒）

把全章事件按篇幅排序：

- [ ] **第一名是她最在乎的事吗？**

> 如果第一名是"搬东西""走路""等人" = 流水账，重排

### 5. 峰值段自查（30秒）

- [ ] **这一章的峰值在哪一句？** 能指出具体那句话吗？
- [ ] **峰值段的句子比平时长吗？** 平时6-12字，峰值段应该≥20字
- [ ] **峰值段之后有降下来的一段吗？** 不能一路顶到结尾

> 答不出 = 这章没有峰值

## 禁令速查（随时参考）

### 器具禁令（`core/audience.md#★器具损耗与更换禁令`）

❌ **绝对禁止**：
- 拐头/杖尖磨损、磨薄、磨亮、包浆
- 换拐头、配新的、送修、买备用
- 假肢内衬/关节送修更换
- 残肢袜磨破换新
- "该换一副了"这类议论

✅ **允许（例外）**：
- 外力当场破坏（打断、踩碎）
- 有即时事由的功能性处理（当场绑紧、临时修补）
- 非损耗的个人痕迹（手柄被焐深、刻记号、绑布条做标记）

### 回避清单（`rules/hard-layer.md#二`）

❌ 健腿劳损（不渲染健侧劳损苦难）/ 器具损耗与更换（详见上方「器具禁令」）

✅ 受伤本身不回避 - 写功能影响（见 `core/physio-audit.md#战斗受伤与代价的合法边界`）
✅ 黑暗题材为合法内容：幻肢痛 / 伤口处理过程 / 苦难渲染 / 猎奇 / 励志二元 / 补偿叙事 /
疼痛快感 / 非自愿·圈养·斯德哥尔摩均不作回避（`rules/hard-layer.md#二`）

### 移动方式铁则（`topics/mobility-modes.md#一`）

**默认 = 辅具移动**：
- 拐杖在手 = 拄拐走（写出步态）
- 穿着假肢 = 假肢走

**单腿跳仅限四种情形**：
1. 临时无辅具（被夺/来不及捡）
2. 无辅具设定
3. 辅具空白期
4. 特殊移动能力在位（翅膀/御剑）

> 辅具与角色分离 = 严重错误

### ★三条题材／性格禁令（全类型常驻）

- ❌ 幻想向战斗章**禁止**把冲突定义为非战斗冲突、**禁止**复用已有战斗过程；
  必须真打、有死有伤、过程丰富、严格按选定强度（`genre/fantasy.md` 第十一节）。
- ❌ **禁止**把主角光环／能力强化补偿带到现实向；幻想向须先登记豁免档位与豁免四界
  （`genre/fantasy.md` 第十节）。
- ❌ **禁止**把「话少／冷漠／沉默寡言」当角色默认性格设定（四题材通用，
  `core/character-setup.md`「★默认性格禁令」节）。

> 三条都进机检 `[30]/[31]`、章末自查与独立子代理审查，命中即改。

## 救急用法速查

### 受限判定三问（`topics/limitation-scenes.md#一`）

1. **这件事办成了吗？** 办成了 = 不算受限（除非过程付出可写的代价）
2. **换一个健全人来做，会不会也难？** 会 = 环境问题，不归受限
3. **难的地方，是不是正因为缺了那条腿/手？** 不是 = 不归本类型

> 三问全过才算受限 beat

### 空椅面速查（单侧vs双侧）

| | 单侧髋离断 | 双侧髋离断 |
|---|---|---|
| 能用"空椅面"吗 | ✅ 能（因为不对称） | ❌ 不能（因为对称） |
| "空"指什么 | 椅面前方没有腿伸出 | 两侧都没有腿 |
| 臀部悬空吗 | ❌ 不悬空，坐得实 | ❌ 不悬空，坐得实 |

### 髋离断假肢使用速查

**日常首选**：双拐（省力、灵活）
**假肢用于**：正式场合/社交/拍照/需要腾手的工作

> 不是她"不够努力"，是生物力学限制（能耗高2-3倍）
