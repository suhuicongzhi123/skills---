# B/C 档亲密戏执行手册

> **定位**：`topics/intimacy.md` 的执行层。`intimacy.md` 管「写到哪、为什么」，本文件管「怎么写、写成什么样」。
> **注入时机**：账本 `角色固定属性.亲密尺度档` = B 情色 或 C 成人 时注入；A 含蓄档不注入、不读、不写。
> **档位分区（硬）**：B 情色档（半程）读 §〇–§七 ＋ §十–§十七（**跳过 §八 高潮 / §九 后戏**；§十中涉及高潮/后戏的条目 B 不取）；C 成人档（全程）读全量。
> （§十七「与剧情编排的接口」B 档**必读**——它规定 B 档可提前做哪个 beat、密度与事后变化；旧版分区漏了这一节。）
> **记号约定（防歧义）**：本文件的「B 档 / C 档」一律指**亲密尺度档**（B 情色 / C 成人）；**截肢时长档位一律写「近期档 / 多年档」**，不用字母。跨文件引用时写全称「B 情色档 / C 成人档」。
> **生理事实**以 `types/{type}.md` 为准；本文件只做「事实 → 动作」的翻译，不新增生理事实。示范句适用三禁一学与四道闸门（`core/audience.md#四道闸门`）。

## 〇、开写前五问（硬闸）

| # | 问 | 不合格怎么办 |
|---|---|---|
| 1 | **成年**：本场所有参与者是否 ≥18 岁？校园题材是否明确大学/成年？ | 年龄未填或 <18 → **本场不成立**（不得降档写 B——B 档同样是性内容，同样要求成年）；补足成年设定后才可写 |
| 2 | **同意**：本场每一次升级是否有可辨认的在场同意？她是否随时可以停？ | 无同意信号 → 补；写不出 → 不写这场 |
| 3 | **疼痛**：是否把疼、伤口、出血、撕裂写成了快感？ | 命中 → 改；残端/瘢痕只能写绷、麻、过电、牵拉，不写伤口 |
| 4 | **档位**：本章声明的是 B 还是 C？B 是否**止于临界前**（三条客观锚见 §9.6）？C 是否已由用户显式声明？ | 未声明 C 写临界/高潮/后戏＝越档；B 写临界/高潮/后戏＝越档 |
| 5 | **生理**：本场每个动作是否过了 `types/{type}.md#不可能动作`？ | 命中 → 换动作或换体位；**失神、酒醉、情绪失控不豁免** |

> **越档判定**：未声明 C 成人档而写**临界、高潮、后戏**中的任一项＝越档；B 情色档可写插入/含纳/抽送，但写高潮/后戏＝越档。越档不是风格问题，是本场不成立。

## 一、B/C 边界四判据（**转写；权威源在 `topics/intimacy.md#二、尺度分档`**）

> 本表只把总纲的四判据执行化，**不另立标准**；两处冲突以 `intimacy.md` 为准。

| 判据 | A 含蓄 | B 情色 | C 成人 |
|---|---|---|---|
| 性部位接触（手、口、残肢、性器） | 无 | 有 | 有 |
| 插入或含纳（手指/口/器物/性器进入） | 无 | **有** | 有，且写过程 |
| 临界与高潮（含临界反应） | 无 | **无** | 有 |
| 后戏（清理、归位、情绪落点） | 无 | 无 | 有 |

**B 情色档的准确边界**：**前戏全开，可进入，止于临界前。**（「临界前」的客观判定见 §9.6——不靠语感）
可以写：亲吻、脱衣、抚摸、揉捏、舔舐、口交含入、手指进入、性器进入、抽送、残肢摩擦、湿润、硬度、呼吸、声音、体液（她的湿/他的前液，**不写射精**）、她的主动引导。
不可以写：**临界（快要到的过程）、高潮、后戏**。

**C 成人档（全程）**：含临界、高潮、后戏。**不得跳切**——不得用「一夜过去」「次日清晨」「后来他们就……」替代场景本身。
C 分两档强度：**C1 直写（较轻）／C2 全露（默认）**——C2 是更密、更完整，不是更粗俗。

> **B 不是关灯**：B 可以进入、可以抽送、可以写口交与体液；它只是**不写到高潮**。
> 把 B 写成「亲了一下就关灯」是描写不充分，不是含蓄；把 B 写成「到了」是越档。

## 二、露骨度下限（防「不够黄」）

### C 成人档：C2 六项（默认）/ C1 五项，缺一即描写不充分

**C1 直写（较轻，用户显式要求）**：
1. **性部位接触**：至少一处明确的接触（手、口、残肢、性器），用日常词直写，不用借代。
2. **进入过程**：至少一处进入/含纳的动作过程（角度、阻力、深度、停顿），不跳切。
3. **临界与高潮**：至少一处临界（快要到）与高潮的生理反应（收缩、痉挛、呼吸、声音、皮肤）。
4. **体液与温度**：至少一处湿润、滑、黏、热、汗的实感；有射精则写去向（体外/套内/体内，按同意与避孕）。
5. **她的主动**：至少一处她发起、引导、校准或喊停。

**C2 全露（默认）**：C1 五项全齐，另加——
6. **完整过程**：进入—抽送—（可换位）—临界—高潮—后戏，至少三段不跳切；每段有具体的身体事实。

### B 情色档：五项最低配置，缺一即不充分

1. 性部位接触（手、口、残肢、性器；口可含入）。
2. 进入过程（手指/口/性器；角度、阻力、深度、停顿，不跳切）。
3. 身体反应（呼吸、湿、硬、颤、绷、声音）。
4. 她的主动或引导。
5. 明确停在临界前（无临界、无高潮、无后戏）。

### 密度与篇幅

- **C1 直写（较轻）**：核心场景 ≥1000 字（短篇 ≥600 字）；**每 300 字至少 1 个具体身体事实**。
- **C2 全露（默认）**：核心场景 ≥1500 字（短篇 ≥1000 字）；**每 200 字至少 1 个具体身体事实**。
- **B 情色**：核心场景 ≥600 字；**每 350 字至少 1 个具体身体事实**。
- 篇幅不含前后剧情；不靠对话水字数。

### 三种「不充分」的形态（命中即重写）

| 形态 | 表现 | 判据 |
|---|---|---|
| **概述式** | 「他们做了爱」「一切发生得很自然」「亲了一下就关灯」 | 删掉这句，读者不知道谁的手在哪、什么进去了、她什么反应 |
| **比喻式** | 潮水、烟花、云端、电流窜遍全身、灵魂出窍 | 删掉所有比喻后，场景还剩什么？剩不下＝不充分 |
| **跳切式** | 解扣子→「一夜过去」→ 天亮 | 过程被省略；C 档不允许，B 档只允许停在临界前 |

**判定问句**：删掉所有比喻与形容词后，读者还知道**谁的手/什么部位/在做什么/她怎么反应**吗？不知道＝不充分。

### 同一拍的三个档位（校准「够黄」而不「过火」）

| 档 | 例（同一进入拍） | 判定 |
|---|---|---|
| **不够（概述）** | 「他们做了很久，她很舒服。」 | 不充分：没有部位、动作、反应 |
| **够（直写）** | 「他进去一半，她吸了口气，手在他腰上收紧。他停住，等她松了才往里。」 | 达标：角度、阻力、停顿、她的反应都有 |
| **过火（网文）** | 「灭顶的快感如潮水般将她淹没，她在他身下化作一滩春水。」 | 套话：比喻替代动作，删掉后什么都不剩 |

> 目标不是「更黄」，是**更具体**。具体到读者能感到阻力、温度、停顿，就已经够黄；再加形容词只会变假。

## 四、身体地图（残肢 / 瘢痕 / 空处）

### 4.1 五个接触面（不是只有残端）

| 接触面 | 写法 | 注意 |
|---|---|---|
| **残肢/残端** | 形状、软硬、温度、绷紧与放松、被按压后的回弹 | 髋离断是软组织，不能独立位移；膝上/膝下/肘腕有骨性残端 |
| **瘢痕** | 色（新深旧淡）、质地（凸/平/薄）、温度、牵拉感 | 感觉可能减退或过敏，因人而异；不写伤口/溃烂 |
| **空处** | 手落空、被面塌陷、没有可抓的东西 | 写"落空"与"带回"，不写"声明缺失"（禁否定式缺失描写） |
| **健侧** | 健腿/健手的代偿与紧张 | 健腿可能抽筋/撑不住；健手是她的锚 |
| **器具痕迹** | 接受腔压痕、拐柄的茧、肩带勒痕、残肢袜的边 | 是身体的一部分历史，不是道具陈列 |

### 4.2 六种手法（力度与反应）

| 手法 | 写法 | 强度 | 常见错误 |
|---|---|---|---|
| **覆** | 手掌整个盖上去，先不动，等她的呼吸 | 轻 | 一上来就揉 |
| **抚** | 顺着形状走，掌根比指尖重 | 轻中 | 只用指尖划 |
| **揉** | 掌根压住，画圈，软组织跟着走 | 中 | 把软组织当面团 |
| **捏** | 拇指与四指夹住一小块，提起再放 | 中重 | 捏到骨头顶着的地方（会痛） |
| **含** | 嘴唇包住，舌面压，不吸 | 中 | 一上来就吸/咬 |
| **舔** | 舌面从下往上，慢，路径清楚 | 轻中 | 乱舔、只写"舔"不写路径 |

**辅助三种**：**磨**（贴住来回）、**顶**（抵住加力）、**夹**（限有骨性残肢的类型：用残肢与身体/床面夹住）。这三种是残肢能"做事"的核心，见 §十一。

### 4.3 残端感觉四型（人物卡授权，默认普通）

| 型 | 表现 | 写法 |
|---|---|---|
| **敏感型** | 残端/瘢痕是性敏感区，触碰即有反应 | 可写战栗、绷紧、湿；仍须她引导，不是开关 |
| **普通型**（默认） | 与普通皮肤差不多，更多是心理与温度感受 | 写触感、温度、被看见的心理，不写"一碰就软" |
| **回避型** | 因身体意象/创伤心回避触碰 | 写她挡开、把他的手带走；不强迫、不"治好心结" |
| **减退型** | 瘢痕区感觉迟钝/发木 | 写"她没什么感觉，但他舔的时候她在看他的脸"——落差本身是戏 |

> **默认普通型**。写敏感型必须由人物卡授权；第一次接触由她引导。❌ 不许「他一碰残端，她就浑身酥软」——那是把残端写成开关，属猎奇化。

### 4.4 主体性三条（C 档最容易破功的地方）

1. **第一次接触由她引导**：她把他的手放上去、拿走、改位置，至少一个动作。
2. **她可以喊停**：停不是扫兴；他停下来的动作要写（手离开、身体退开、问一句）。
3. **她不是被观看的陈列**：至少一处她主动（发起、要求、调整节奏、看他的反应）。

### 4.5 瘢痕写法

- 新瘢痕（近期档）：色深、触感清晰、可能有牵拉感；不要写"刚愈合"的伤口。
- 成熟瘢痕（多年档）：色淡、平、温度与周围皮肤不同。
- 舔舐/亲吻瘢痕：写路径（从哪到哪）、质地（凸/平）、她的反应（绷/痒/没感觉/看他）。
- ❌ 不写伤口、结痂、渗液、溃烂；❌ 不写"他亲吻她的伤，她被治愈了"（补偿叙事＋升华尾）。

### 4.6 空处写法

- **手落空**：他的手往那半边下去，落到床单上；她把它带回胯侧/腰侧。
- **被面塌陷**：空的那边压下去，被子陷一块，塌着。
- **抓空**：她伸手往那半边抓，抓到床单；这个动作可以是一瞬间，不解释。
- ❌ 不写「那里什么都没有」「没有腿」这类声明式句子（否定式缺失描写，见 `core/style.md`）。

### 4.7 幻肢四象限

| 档位 | 场景 | 合法写法 | 禁止 |
|---|---|---|---|
| **近期档** | 前戏/进入 | 她真的想用**缺失的那一截**（幻脚蹬地、幻膝夹住、幻腿缠上去）→ 残肢随动发力 → **动作未完成** → 失衡/落空/被接住 | 写成"缠上去了/夹住了/蹬到了" |
| **近期档** | 高潮 | 残肢随呼吸/收缩抽动，不伴随使用意图 | 把抽动写成"腿在动" |
| **多年档** | 前戏/进入 | 不会真的想用；仅肌肉反应（绷一下/抽一下） | 写"她习惯性抬腿/迈腿/夹腿" |
| **多年档** | 高潮 | 臀肌/断口/残端不自主收缩，可见可触 | 写"她想夹紧那条腿" |

> **一句话**：近期档可以"想"，但做不成；多年档连"想"都不写，只写肉的反应。

## 五、前戏（B/C 共用）

### 5.1 拍 1·许可与接近

- 不是问「可以吗」就完事；写**具体的接近**：他先碰哪里、她怎么回应、谁先靠近。
- 同意的信号可以是：她拉他的手、她解开自己的扣子、她说「过来」、她把拐放倒。
- ❌ 不写「她没有拒绝，于是他……」——不拒绝不是同意。

### 5.2 拍 2·器具与衣物

| 对象 | 写法 | 禁忌 |
|---|---|---|
| **拐杖** | 放倒/靠床头/床边够得到；谁放的、放哪 | 凭空消失；随手扔地上（夜里起身要用） |
| **假肢** | 穿/脱/半脱；接受腔放哪；衬垫的汗 | 为亲密而卸的表演；卸下后身体无变化 |
| **接受腔** | 边缘压痕、闷热、取下后的红印 | 穿着却无压痕/无汗 |
| **衣物（裤装）** | 患侧裁剪收口/折叠塞起；脱的时候有动作 | 一把扯掉；裁剪处被写成"空裤管" |
| **衣物（上装）** | 肩离断：患侧无袖/空袖管；**脱时先健侧后患侧，穿时相反** | 空袖管被残端带动（肩离断无残端） |
| **裙装** | 裙摆、下摆的遮挡与掀开；不裁剪 | 把裙装写成裤装处理 |

> 器具状态在场景内必须连续：前戏在哪、进入前在哪、事后在哪，至少三个点对得上。账本 `当前状态.拐杖/假肢` 同步更新。

### 5.3 拍 3·身体地图

- 顺序不是固定的：可以从残肢开始，也可以从脸/颈/腰开始；**由她的反应决定下一站**。
- 每到一个接触面，写三件事：**他的动作 / 她的身体反应 / 她的指令或选择**。
- 残肢不是必经站；她不让他碰，就不碰——回避型人物的戏在"挡开"上。

### 5.4 拍 4·体位安置

- 先解决**支撑**：她靠什么、他靠什么、枕头在哪、床沿够不够高。
- 再解决**谁在哪**：她在上/在下/在侧；他在前/在后；她的手在哪。
- 最后才是**进入前的那一刻**：停顿、看一眼、问一句、或者她自己往下坐。

### 5.5 B 情色档截断线

- 可写：手、口交含入、手指进入、性器进入、抽送、残肢摩擦、湿润、硬度、体液、她的声音、她的引导。
- 不可写：临界（快要到的过程）、高潮、后戏。
- **收束**：停在临界前——他停、她推开、她说「等一下」、门响了、电话响了、她笑场；不解释、不升华。

### 5.6 前戏的节奏

- 前戏不是"准备工作"，是主体；B 档以前戏＋进入＋抽送为主（不写高潮/后戏），
  C 档前戏占 40–50%，其余为进入/高潮/后戏。
- 节奏：慢—快—停—再慢；至少一次停顿（说话、换位置、喝水、笑场）。
- ❌ 不写"前戏很长"这种概述；写其中三个具体动作。

## 六、体位矩阵（B/C 共用）

> 读法：**可行**＝直接写；**需改造**＝写清支撑/垫枕/角度；**不可行**＝不写，换位。
> 体位可行性对 B/C 都适用——B 档的前戏/手/口/进入也要安置；§八起才是 C 档的高潮/后戏写法。
> 所有"不可行"均可在 `types/{type}.md#不可能动作` 找到依据。

### 6.1 单侧类型 × 八体位

| 体位 | 髋离断 | 膝上 | 膝下 | 肩离断 | 肘/腕离断 |
|---|---|---|---|---|---|
| **仰卧·面对面** | 可行（患侧臀下垫枕，防骨盆下沉） | 可行（残肢可置于对方髋侧） | 可行 | 可行（单臂，对方自撑） | 可行 |
| **侧卧·面对/背后** | 可行（患侧朝上＋垫枕；朝下压瘢痕须换侧） | 可行 | 可行 | 可行（最优） | 可行 |
| **女上·跨坐** | **不可行**（无膝可跪、无腿可跨）→ 改坐位 | **不可行**（患侧无膝）→ 改坐位/侧卧 | 穿假肢可行（跪在假肢小腿管/脚背，角度浅）；不穿改坐位 | 可行，需单臂支撑或前倾趴伏 | 可行 |
| **跪姿后入** | **不可行** | **不可行** | 穿假肢可行；不穿改侧卧 | **不可行**（需双手撑）→ 侧卧后入 | 可行（单手＋残端支撑） |
| **站姿·俯身** | 可行（手撑床/桌，患侧靠床沿） | 穿假肢可行；不穿短时 | 可行 | **不可行**（需双手撑）→ 背靠墙/坐位 | 可行（单手＋残端） |
| **站姿·背靠墙** | 短时可行（单腿＋墙） | 穿假肢可行；不穿短时 | 可行 | 可行（背靠墙，单臂扶他；双手扶墙式不成立） | 可行（单手＋残端） |
| **坐位（床沿/椅）** | **最优** | **最优** | 最优 | 可行 | 可行 |
| **侧卧·背后进入** | 可行（他托住空侧） | 可行 | 可行 | 可行（最优） | 可行 |

### 6.2 双侧

| 体位 | 可行 | 改造 |
|---|---|---|
| 床沿坐位 | ✅ 最优 | 背靠床头/墙；他在前跪/站 |
| 仰卧 | ✅ | 腰下/残端下垫枕；他托住她的腰 |
| 侧卧 | ✅ | 患侧朝上；背后进入可行 |
| 轮椅坐位 | ✅ | 先刹轮椅；坐垫防压；他在前跪/站 |
| 站立 | 仅双侧膝下穿假肢：短时可行；双侧髋离断/膝上：❌ | 靠墙/他托腰；假肢承重与平衡须先交代 |
| 跪 / 跨坐 | ❌（双侧均不取） | 无健腿支撑；跪/跨需双膝，不成立 |

- **转移**：轮椅→床/椅，先刹、再撑手挪移；每一步有动作，不瞬移。
- **手**：双手既是腿又是手；进入时她需要一只手支撑，另一只手才能给他。
- **抱**：他把她从轮椅抱到床上须经她同意，且不是默认（主体性）。

### 6.3 复合

- **体位可行性取两侧交集**：任一侧不可行即不可行。
- **禁止事项取并集**：两侧的不可能动作都成立。
- 例：髋离断＋肩离断——不能跪、不能跨、不能双手撑、不能抱；可行解只剩「侧卧＋垫枕楔形支撑＋单臂」与「坐位＋靠背」。
- 招牌元素两侧分别取象：空椅面（下）＋空袖管（上）同场，但不堆在同一句。

### 6.4 改造五件套

| 件 | 用法 | 例 |
|---|---|---|
| **垫枕** | 补高度、稳骨盆、隔开瘢痕 | 髋离断患侧臀下；膝下腰下 |
| **床沿/桌沿** | 给她坐/靠/撑的边界 | 坐位进入；站姿俯身 |
| **椅/轮椅** | 坐位、靠背、扶手 | 双侧；肩离断女上 |
| **墙** | 背靠，替代双手支撑 | 肩离断站姿；髋离断短时站 |
| **对方的手** | 托住、固定、替代她缺的支撑 | 托空侧；托腰；扶肩 |

### 6.5 换位的动作链

- 换位不是瞬移：**先分开 → 再移动 → 再重新贴近**（C 档为：先退出来 → 再移动 → 再重新进入）；中间有停顿、有说话、有调整。
- 至少写一个"笨拙"的动作：枕头掉了、拐倒了、腿麻了、两人笑了一下——这是生活感，不是破坏气氛。

## 七、进入方式（B/C 共用）

> B 情色档可写进入与抽送，但**止于临界前**；C 成人档写完整流程（默认 C2 全露；C1 直写较轻）。
> 本节对 B/C 都适用；§八起为 C 专属。

### 7.1 进入前四件事

1. **润滑**：尤其坐位/侧卧/紧张时；写涂抹的动作，不写"很顺利"。
2. **避孕**：套/药/环，按人物与时代；古装/末世按可得性写，不默认现代。
3. **支撑**：她的手在哪、他的手在哪、她的背靠什么；支撑不稳不进入。
4. **她的位置**：她坐/躺/侧；患侧朝上/朝下；空的那边怎么放。

### 7.2 按类型的进入方式

| 类型 | 推荐进入 | 角度与支撑 | 患侧处理 |
|---|---|---|---|
| **髋离断** | 坐位（他跪/站）；侧卧；仰卧 | 坐位：她手撑身后，胯前送；侧卧：他托住空侧，垫枕稳骨盆 | 不压收口处/瘢痕；空侧不悬空太久；不拉残端 |
| **膝上** | 坐位；侧卧；站姿俯身 | 残肢可搭在他髋侧/被他托住；坐位她可自己控制深度 | 不压残端末端；接受腔边缘避开 |
| **膝下** | 全部；穿假肢可跪/跨 | 穿假肢注意膝关节负重稳定；不穿用垫枕 | 残端受力敏感，不压末端 |
| **肩离断** | 侧卧（最优）；坐位靠背；女上前倾 | 他自撑重量，不压在她身上；她单臂扶他肩/床 | 不压患侧肩；空袖管推到一边 |
| **肘/腕离断** | 全部；后入/站姿可用残端撑 | 残端末端可承重（顶住，不长撑）；健手主导 | 不压断口瘢痕；不拉残端 |
| **双侧** | 床沿坐位；仰卧；侧卧；轮椅 | 她双手支撑优先，他托腰；轮椅先刹 | 两侧断口都不压；转移有动作 |
| **复合** | 取两侧交集；侧卧/坐位为主 | 单臂＋靠背/垫枕；他承担主要支撑 | 两侧分别避让；不叠压 |

### 7.3 患侧处理三条

1. **不承重**：患侧不承担体重（髋离断无骨性传导；膝上/膝下不穿假肢时残端不承重；肩离断无臂）。
   穿假肢时按器具承重规则，不把体重压在接受腔边缘或残端末端。
2. **不压瘢痕**：体重/手肘/膝盖不压在瘢痕或断口末端；用垫枕隔开。
3. **不拉残端**：不抓住残端把人拽过来；要拉就拉手臂/腰/健腿。

### 7.4 节奏、深度与停

- **谁控制**：坐位/女上由她控制深度与节奏；仰卧/侧卧由他控制，但她有否决权。
- **信号**：她说「慢」「等」「这里」；或身体信号（吸一口气、手抓紧、腰后退）。
- **停**：任何不舒服都可以停；停下来不是失败，是场景的一部分。
- **深度**：角度比深度重要；髋离断坐位可调角度，侧卧用枕头调骨盆。

### 7.5 五种常见错误（命中即改）

| 错误 | 为什么错 | 改法 |
|---|---|---|
| 双腿缠腰 | 无膝以下/无腿 | 健腿可环；患侧用手/残肢/整边身子贴 |
| 跪姿 | 患侧不能跪 | 坐位/侧卧/站姿俯身 |
| 跨坐 | 需双膝支撑 | 坐位（他坐/她坐） |
| 抬腿环腰 | 患侧不能抬 | 健腿可抬；患侧用垫枕 |
| 抱起抵墙 | 单臂不能抱/无腿不能环 | 背靠墙/坐位；他托腰不抱人 |

## 八、高潮（C 成人档）

### 8.1 生理清单（C2 默认至少五项 / C1 至少三项）

- 呼吸：屏住—急促—断裂；不是"娇喘"。
- 收缩：盆底/臀肌/大腿/残肢，一阵一阵，可见可触。
- 皮肤：潮红、出汗、起栗。
- 手：抓握、掐、撑不住、松开。
- 声音：卡在喉咙里、变调、只剩一口气；不是"啊啊啊"。
- 体位：腰弓起、背落下、支撑手滑、需要立刻换姿势。
- 射精/体液：有则写去向（体外/套内/体内，按同意与避孕）、量感、温度、气味；
  不夸张（不写"喷涌/泛滥"）。

> **C2 全露加项**：至少五项生理反应；进入—抽送—换位—临界—高潮至少三段不跳切；
> 射精/体液去向明确；后戏接得上（见 §九）。

### 8.2 按类型的反应差异

| 类型 | 高潮时最该写的 | 专属细节 |
|---|---|---|
| **髋离断** | 臀侧/收口处可见收缩；整边身子上提；健腿绷紧/脚趾蜷 | 手撑不住，背落到床上；空的那边陷进被子 |
| **膝上** | 残肢绷紧/抽动/夹紧；接受腔在/不在两种身体 | 残肢可能不自主夹住他；卸下后断口贴床 |
| **膝下** | 残端肌肉跳；假肢被蹬动/响；健腿抽筋 | 穿假肢时关节的金属声；脱下后短残肢的轻 |
| **肩离断** | 肩胛/胸侧收紧；空袖管动；单臂抓握 | 肩头疤绷白；手从他背上滑下来 |
| **肘/腕** | 残端顶住/绷紧；健手抓握 | 残端"做事"到最后一刻；断口贴着他不放 |
| **双侧** | 两侧断口/臀肌收缩；躯干绷紧；手抓握 | 需要支撑，不能双手同时自由；轮椅/床沿的边界 |
| **复合** | 两侧分别取象；能动的那部分更明显 | 单臂/整边身子/声音成为唯一的主动通道 |

### 8.3 禁套话（出现即改）

潮水、烟花、白光、云端、电流窜遍全身、灵魂出窍、灭顶、绝顶、失控尖叫、哭出来（除非人物卡授权）、"她终于完整了"。

### 8.4 幻肢四象限

见 §4.7。高潮是违规高发位，尤其两句：
- ❌「她忘了自己没有腿，那条腿缠了上去」——失神不豁免。
- ❌「她想夹紧，可那里什么都没有」——多年档不写"想夹"；近期档可写"想夹→没夹住→落空"。

### 8.5 失神不豁免（硬规则）

意识状态（高潮、酒醉、疲惫、情绪失控、半梦半醒）**不改变身体结构**。不得以"她忘了"为由写缺失肢体做成动作。判定问句：**这个动作最终做成了吗？做成＝违规，没做成＝幻肢。**

### 8.6 高潮后的三十秒

- 敏感：碰一下都过头；她会推开、缩、笑、喘。
- 体位：支撑手松开，身体可能滑/歪；他接住或她自己调整。
- 话：短句、断句、不说话；不写长篇告白。
- 不立刻睡着：至少一个动作（拉被子、喝水、看天花板、笑）。

## 九、后戏（C 成人档）

> C2（默认）：三拍写足，加夜间起身与次日具体动作；C1：余波 / 清理 / 情绪落点各一拍。
> B 情色档不写后戏（B 停在临界前）；若剧情需要，B 只可写「停下之后的第一个动作」，不展开清理场景。

### 9.1 余波三拍

1. **身体**：颤抖、敏感、汗、腿麻、断口或收口处被压出的印。
2. **位置**：换姿势、垫枕、把患侧放好、把假肢/拐够到。
3. **话**：一句短的、具体的、不解释的。

### 9.2 清理与归位（现实细节）

| 项 | 写法 | 禁忌 |
|---|---|---|
| 水 | 谁去倒、杯子放哪、她先喝还是先擦 | 省略 |
| 纸巾/毛巾 | 擦拭的动作、扔哪、床单湿了一块 | 医学化描述 |
| 体液 | 擦哪、谁擦、床单/身上/套内；按同意与避孕 | 夸张/回避 |
| 避孕 | 套的处理、药、环；按时代/可得性 | 默认现代/默认无 |
| 残端皮肤 | 压痕、汗、红印；她揉一揉/擦干 | 伤口/溃烂 |
| 接受腔 | 放哪、衬垫要不要晾、第二天要不要穿 | 凭空消失 |
| 拐杖 | 床边够得到；夜里起身要用 | 扔地上/找不到 |

### 9.3 情绪落点（不升华）

- 可以是：笑、沉默、尴尬、困、饿、想洗澡、想他留下/想他走。
- ❌ 不写「她终于接受了自己的身体」「原来残缺也可以被爱」「她觉得自己完整了」——补偿叙事＋升华尾，双重违规。
- ✅ 停在一个具体动作：她把拐靠在床头、他把被子往她那边拉、她说明天要早起。

### 9.4 夜间起身

- 拐在床边够得到；假肢脱了/穿着；灯在哪；她要不要人扶。
- 这是「器具连续性」的最后一环，不能省。

### 9.5 次日

- 关系变化用一个具体动作落地：他先看她的脸再看拐、她把备用拐递给他拿、他改了床的高度。
- 不写总结、不写感悟、不写"从那以后"。

---

### 9.6 B 档停手的三条客观锚（判越档，不靠语感）

> 旧口径「止于高潮前」是语感判据——示范句写到自己都分不清。改用三条**可数**的锚：
> **命中任一条＝越档**（本场不成立，删段重写，不是润色）。

| # | 锚 | 怎么判 | 为什么能判 |
|---|---|---|---|
| **1** | **无自主收缩的节律描写** | 是否写了不随意志控制的收缩/痉挛/一股一股/收紧又松开？ | 自主收缩是临界的生理标志，写出来就是临界 |
| **2** | **无「只剩一口气」式失神** | 是否出现"脑子里一片白/听不见了/只剩那一点/整个人被抽空"？ | 失神＝临界以上的主观标志；B 档只写"呼吸乱了/手抓紧了" |
| **3** | **无事后清理与相拥收尾** | 是否写了擦拭/倒水/盖被子/把头埋在他颈窝里不动了？ | 清理与相拥是后戏的固定开场，出现即进入 C |

- **合法的停点**：停在"她说了句什么""他停了""外面有声音""她的腿抽了一下（残肢，不是高潮）"——
  **停在动作还在进行、但叙述收住的地方**。
- **"差一点"可以写，"到了"不可以**：写她快要、写他停手、写两个人都知道差一点——这是 B 档最好的收尾；
  写"她到了"就是 C。
- **越档的处理**：整段重写，不删一句补一句（越档是结构问题，不是措辞问题）。

## 十、按类型配方

### 10.1 髋离断

- **残肢**：软组织残端，无骨性杠杆。可被抓揉、按压、含舔；**不能自己抬起/夹住/甩动**。
- **她的主动**：整边身子前送/上提/侧倾（L1），臀肌与髋侧肌肉收缩（L2）；不是残端自己动。
- **可行**：坐位（最优）、仰卧（患侧臀下垫枕）、侧卧（患侧朝上＋垫枕）、站姿俯身（手撑）、站姿靠墙（短时）、侧卧后入。
- **不可行**：跪姿、跨坐、双腿缠/夹、抬腿环腰、并膝、患侧蹬床。
- **进入**：坐位（他跪/站，她手撑身后）；侧卧（他托空侧）；仰卧（垫高患侧臀）。
- **高潮**：臀侧/收口处可见收缩，整边子上提，健腿绷紧；手可能撑不住。
- **禁忌**：残端自己抬起/夹住/甩动；跪/跨；双腿夹紧。
- **专属**：空的那边"没有可抓的东西"；他的手会落到空处，她带回胯侧；坐位时床沿的空。

### 10.2 膝上

- **残肢**：有髋、有部分大腿；可屈伸、可夹、可顶；不能跪（无小腿）。
- **可行**：坐位、仰卧、侧卧、站姿俯身、侧卧后入、女上坐位（不跨跪）。
- **不可行**：跪姿、跨坐（患侧无膝）、患侧跪、双腿并膝。
- **进入**：坐位（她坐他腿上/床沿）；侧卧（残肢搭在他髋侧或被他托住）；站姿俯身（手撑）。
- **高潮**：残肢绷紧/抽动/夹紧；接受腔在/不在两种身体。
- **专属**：残肢可主动"夹/磨"，是她能给出的信号；接受腔边缘硬，注意压痕。
- **禁忌**：把残肢写成能变出小腿/缠住腰。

### 10.3 膝下

- **残肢**：有膝、有大腿；残端短、受力敏感；穿假肢可跪（假肢小腿管/脚背触地），不穿则残端跪地不写。
- **可行**：几乎全部；穿假肢可跪姿/跨坐/后入；不穿则坐位/侧卧/仰卧。
- **不可行**：患侧脚掌踩/蹬/踢（无脚掌）；不穿假肢跑跳。
- **进入**：穿假肢注意膝关节负重稳定；不穿用垫枕/坐位。
- **高潮**：残端肌肉跳/绷；假肢被蹬动/响；健腿抽筋。
- **专属**：假肢的冷/硬/接受腔边缘与皮肤的对比；脱下后的短残肢。

### 10.4 肩离断

- **无残端**；接触面：肩峰、锁骨、肩胸瘢痕、腋下、空袖管。
- **只有一只手**：不能双手撑、不能双臂环抱、不能托举对方、不能被双手按住。
- **可行**：侧卧（最优）、仰卧（他自撑）、坐位（靠背）、女上（前倾/单臂撑）。
- **不可行**：双手撑床后入、站立双手扶墙、抱起、双臂环抱。
- **进入**：侧卧（患侧朝上，他托肩背）；坐位（她背靠床头/墙，单臂扶他肩）；女上（前倾趴在他身上，单臂撑）。
- **高潮**：肩胛/胸侧收紧，空袖管动，单臂抓握；肩头疤绷白。
- **专属**：空袖管在两人之间；他的手指停在肩峰/锁骨；她不能抱紧，只能用一只手。

### 10.5 肘离断 / 腕离断

- **肘离断**：上臂残端，无前臂/手；可屈伸、夹（残端与身体/台面之间）、末端承重；不能抓/握/旋前旋后。
- **腕离断**：前臂残端，无手；可旋前旋后、夹、压、顶、末端承重；不能抓/握。
- **可行**：几乎全部；单手＋残端可支撑（后入、站姿扶墙）。
- **不可行**：双手抓握、双手撑、手指动作。
- **进入**：残端垫/撑/顶；健手主导；腕离断可用残端"转/揉"。
- **高潮**：残端绷紧/顶住；健手抓握。
- **专属**：残端能做事——夹、撑、顶、转、按；不是缺席的手。
- **肘上/肘下（经肱骨/经前臂）未登记时**：按 `SKILL.md` 第五节注入索引「类型未登记兜底」先确认截断平面与残端长度，
  再套用本节「残端能做事」原则；❌ 不得默认套用肘离断的「无前臂」或腕离断的「旋前旋后」。

### 10.6 双侧

- **无健腿**；轮椅/床沿/椅；双手是腿也是手。
- **可行**：床沿坐位、仰卧（垫枕）、侧卧、轮椅坐位（刹住）；双侧膝下穿假肢可短时站立。
- **不可行**：双侧髋离断/膝上站立；双侧跪、跨坐；任何需要双腿支撑的体位。
- **转移**：先刹轮椅，再撑手挪移；床边转移有动作链。
- **高潮**：两侧断口/臀肌收缩，躯干绷紧，手抓握；需支撑，不能双手同时自由。
- **专属**：轮椅的刹车/扶手/坐垫；抱她须经同意，且不是默认。

### 10.7 复合

- **可行性取交集**：任一侧不可行即不可行。
- **禁止取并集**：两侧的不可能动作都成立。
- **例**：髋离断＋肩离断——不能跪/跨/双手撑/抱；可行＝侧卧（垫枕楔形）＋坐位（靠背）＋单臂。
- **高潮**：两侧分别取象；空椅面＋空袖管同场，不堆一句。
- **专属**：她的"能动"只剩整边身子、单臂、声音；主动通过引导他的手/说/腰。

## 十一、截肢侧运动专题（「你踢我一下」）

> 这类要求可以是玩闹、情话、权力游戏或好奇；须在场同意。不写命令式羞辱（除非双方明确约定），不把"做不到"写成羞辱点。她的反应可以是笑、恼、自嘲、反而兴奋——由人物卡定。

| 要求 | 她实际能做的 | 肌肉反应 | 做不到的 | 写法 |
|---|---|---|---|---|
| **「踢我一下」·髋离断** | 整边身子前送/上提 | 臀肌、髋侧肌群收缩；收口那儿绷紧/隆起 | 无腿可踢，无位移 | 写「意图→肌肉先动→没有然后」；C 成人档场景内按人物时长档位：多年档只写肌肉反应，近期档写「想而未成」 |
| **「蹬我/蹬床」·髋离断** | 整边身子压/送；手推 | 同侧臀肌收紧；收口那儿抽动 | 无脚可蹬 | 写「她那半边一紧，床单被压出褶，腿的位置空着」 |
| **「夹住我」·髋离断** | 手、口、整边身子贴 | 臀肌/内收肌残部收缩 | 双腿夹 | 写「她夹不了，用手；或把他往那半边按」 |
| **「踢我」·膝上** | 残肢前送/屈伸 | 残端肌肉收缩、绷紧 | 无小腿/脚 | 写「断口往前一送，到一半停住」 |
| **「夹住」·膝上** | 残肢与身体/对方之间夹 | 残端收紧、可见隆起 | 双腿夹 | 写「她收了一下，夹住；断口贴着他」 |
| **「踢我」·膝下** | 屈膝/送；穿假肢可踢（假脚） | 大腿/残端肌肉收缩 | 无踝足（不穿时） | 写「膝盖抬起来，末端停在半空」 |
| **「抱紧我」·肩离断** | 单臂抱 | 肩胛/胸肌收缩；空袖管动 | 双臂环抱 | 写「她只有一只手，另一边的袖管动了一下」 |
| **「抓住我」·肘离断** | 残端夹/顶 | 上臂残端收紧 | 抓/握 | 写「断口顶住，握不住」 |
| **「抓住我」·腕离断** | 残端压/转/夹 | 前臂残端收紧；旋前旋后 | 握/手指 | 写「断口压下去，转半圈」 |

**档位差异（两条轴，别混）**：
- **时长档位决定「想不想用」**：近期档可以写「她真的想用**缺失的那一截**（下肢：踢/夹；上肢：抱/抓）」→ 残肢随动发力 → **未完成** → 失衡/落空/被接住；多年档只写肌肉反应，不写「真的想用」。
- **亲密尺度决定「写到哪」**：B 情色档可以写上述「想而未成」的全部张力，止于临界前；C 成人档可以把它放进完整场景，但仍受时长档位约束。
- **两档共同**：不得写成「做成了」——做成＝违规。
- **失神不豁免**：即使高潮/情绪失控，也不得让缺失肢体做成动作。

## 十二、用词与露骨度

### 12.1 总原则

**直写不借代，日常不临床。**

- 直写：说「下面」「里面」「最前面那一点」「硬起来」，不用「花穴」「幽谷」「玉茎」。
- 日常：用身体部位与动作词，不用解剖名（阴道/阴茎/阴蒂）——除非角色是医护且在其专业内心独白里。
- 不借代：不用比喻链替代动作；比喻只做调味，一道菜最多一勺。

### 12.2 三栏词表

| 层级 | 例 | 用法 |
|---|---|---|
| **推荐（日常直写）** | 胸、乳、腰、臀、腿根、腿间、下面、里面、湿、滑、硬、抵、磨、含、含住、进、退、抽、送、顶、撞、蹭、吸、吞、绞、绞紧、绷、缩、射、流、滴、湿透、套、体液 | 叙述层默认 |
| **慎用（限人物声口/视角）** | 私处、下体、甬道、花心 | 角色自己的说法可用，旁白不用 |
| **禁用（叙述层）** | 阴道/阴茎/阴蒂；残端/患侧（常态化框架）；花穴/蜜穴/肉棒/爱液/玉茎；灭顶/绝顶/潮水/烟花 | 临床 / 日式 / 网文腔，三类污染源 |

> **「残端/患侧」例外**：病因学框架的医疗场景、角色是医护的专业独白可破例；常态化框架的叙述层零容忍（见 `core/worldbuilding.md#框架→叙述措辞`）。
> **C2 全露**：允许更直接的动词与体液描写（射/流/滴/撞/顶到/含住/吞），但仍禁临床词、日式借词、网文套词；
> 每 200 字至少 1 个身体事实。

### 12.3 器官命名策略

- **她的说法**：偏日常、偏短（「下面」「那儿」「里面」）；人物卡声口决定粗/细。
- **他的说法**：可以更直，但不粗俗；不写侮辱词（除非双方约定）。
- **旁白**：日常词、具体动作；不临床、不网文、不日式。

### 12.4 声音 / 体液 / 气味

- **声音**：呼吸、断句、气音、短促的"嗯"；少拟声，不写"啊啊啊"。
- **体液**：湿、滑、黏、温度、量感（「手心一层」）；不夸张（不写"泛滥/喷涌"）。
- **气味**：少量、具体（汗、皮肤、皂、雨）；不写"靡靡之气"这类套词。

### 12.5 视角限制

- **第一人称**：只写她能感到/看到/听到的；不写她背后的表情、他心里的想法。
- **第三人称限知**：同；镜头贴在她身上。
- **第三人称全知**：可以写双方，但不变成医学镜头/色情片镜头；仍以她的体验为主。

### 12.6 三种「黄」都要避免

| 类型 | 特征 | 改法 |
|---|---|---|
| **临床黄** | 器官名+流程说明 | 换日常词，写感觉不写结构 |
| **网文黄** | 比喻链+夸张+「灭顶」 | 删比喻，写具体动作与反应 |
| **日式黄** | 借词+拟声+「绝顶」 | 换中文日常词，声音写呼吸不写拟声 |

> **真正"黄"的来源**：具体、克制、身体事实、她的反应。不是形容词堆，也不是器官名堆。

## 十三、同意与边界

### 13.1 在场同意

- 每一次升级（接触→脱衣→手→口→进入）都要有一个可辨认的信号：她拉他的手、她说「可以」、她自己解开、她往下坐。
- ❌ 不写「她没有拒绝」「她半推半就」「他当她默认了」。
- 同意可以撤回；撤回后他停下，场景继续写停下来的动作。
- **体液/射精**：体内/体外、套内/身上，须事先说清；不写「偷偷射在里面」；
  不写「用怀孕留住他」。避孕按人物与时代，不默认无。

### 13.2 喊停

- 她可以随时停；停不是扫兴、不是失败、不是"她不爱他"。
- 他停下来的动作要写：手离开、身体退开、拉被子、问一句「要不要喝水」。
- 停之后可以继续（换方式），也可以结束；不强迫"停了一定要扫兴"。

### 13.3 权力关系

- 照顾者/被照顾者、devotee/被看、年龄差、身份差、经济差——权力差越大，同意越要明确。
- ❌ 不写「她用身体换照顾」「他以辅具/住所/工作为筹码」——这是胁迫，不是情色。
- ✅ 可以写权力差带来的张力，但张力落在"她要不要""她怎么拿回主动权"上。

### 13.4 四不写

1. 未成年人（全角色 ≥18；校园须大学/成年）。
2. 胁迫/下药/趁睡/无法同意。
3. 疼痛＝快感（残端/瘢痕的疼不写成爽）。
4. 失禁/排泄（回避清单）。

### 13.5 devotee 凝视的自反

- 他看她的残肢太久，她注意到了——这是好戏，不要替她消解。
- 性不解决「他是爱我还是爱我的残肢」；C 档可以加深这个疑虑（他在床上更兴奋的是哪一部分），不可闭环。
- 她的主体性：她可以享受被渴望，也可以反感被消费；两种都成立。

| C06 | 高潮 | C2（默认）至少五项；C1 至少三项；无禁套话 |
| C07 | 幻肢 | 按 §4.7 四象限；近期档想而未成；多年档仅肌肉 |
| C08 | 失神不豁免 | 无「忘了→做成」 |
| C09 | 器具连续 | 拐/假肢/接受腔五时序对得上 |
| C10 | 后戏 | ≥10% 篇幅；清理/归位/情绪落点齐 |
| C11 | 露骨度下限 | C2（默认）六项 / 每 200 字 ≥1 个；C1 五项 / 每 300 字 ≥1 个 |
| C12 | 用词/视角/不物化 | 三栏词表；视角不越界；她至少一次主动 |

## 十六、露骨示范

> 三禁一学：不整句抄、不近 5 章复用同载体、不改标点；只学「公式＋变量」，换情境/载体/感官通道重新生成。
> 以下示范均为**成年角色、在场同意**；示范中的破折号/引号如写入正文，按 `core/style.md` 破折号总闸计配额。

### 16.1 残肢接触（髋离断）

- 平庸：「他摸着她的残肢，她很舒服。」
- 直写：「他的手掌覆上来，落在胯侧那块肉上。她没躲，呼吸慢了半拍。他往下按，肉陷下去，松手又慢慢弹回来。她伸手把他的手腕往回收了半寸：『轻点。』他轻了。她自己又把他的手按回去，按到刚才那个位置。」
- 公式：**他者接触 + 软组织受力变形 + 她的校准**。
- 变量：接触点∈{胯侧、臀下缘、收口那一圈}；变形∈{按下去陷、松手回弹、绷紧}；校准∈{往回收半寸、自己按回去、说轻点}。

### 16.1-b 抓揉与舔舐（髋离断）

- 直写：「他一只手扣住胯侧那块肉，往掌心里收，收出一把，再松开。她看着他的手，呼吸变浅。他低头，舌尖落在收口上沿，咸的。她的整边身子往上一提，又落回去。『那儿轻。』她说。他轻了，改用嘴唇贴，贴着不动。她自己动了动胯，把他往下带了带。」
- 公式：**抓揉的收放 + 舔舐的位置与味觉 + 整边身子的反应 + 她的校准**。
- 变量：抓∈{扣住收一把、拇指压、掌心揉}；舔∈{收口上沿、疤的一侧、胯侧}；校准∈{那儿轻、往下带、别停}。
- 注意：髋离断的动来自整边身子，不写那块肉自己抬起或夹住。

### 16.2 舔舐瘢痕（膝上）

- 平庸：「他亲吻她的伤疤，她很感动。」
- 直写：「灯下那道疤泛着浅白，斜着绕过断口。他低头，舌尖从疤的一头慢慢过去。她的腿根绷了一下，手抓住床单。『痒。』她说，没让他停。他舔到中间那块发木的地方，她没什么反应，只把腿根往他嘴里送了送。他换了个地方，她的呼吸才乱起来。」
- 公式：**瘢痕的视觉 + 舌的路径 + 感觉不均 + 她的指令**。
- 变量：路径∈{从下往上、从一头到另一头、绕开最敏感处}；感觉∈{痒、发木、过电、没感觉}；指令∈{没让他停、往他嘴里送、换一边}。

### 16.3 残肢摩擦（腕离断）

- 平庸：「她用残肢挑逗他，他受不了。」
- 直写：「她用手臂断口那圈压着他，慢慢地转。那圈皮肉贴着他硬起来的地方，转一下，停一下。他吸气，腰腹绷紧。她看着他：『别动。』断口又转过去，这回重了点，疤的边缘刮过去，他闷哼了一声。她笑了一下，没停。」
- 公式：**残端的能力（转/压/顶）+ 对方的反应 + 她的控制**。
- 变量：能力∈{转、压、顶、夹}；反应∈{吸气、腰腹绷紧、闷哼}；控制∈{别动、笑一下、没停}。

### 16.3-b 被要求踢（髋离断）

- 直写：「『踢我一下。』他说。她笑了一声，还是试了。那半边先动——臀侧的肉绷起来，胯往上提了提，床单被压出一道褶。然后就没有然后了。她低头看了一眼，又笑：『踢不着。』他伸手把她拉过去：『那就别踢。』」
- 公式：**要求 + 意图 + 肌肉先动 + 无位移 + 她的反应（笑/自嘲）+ 转向**。
- 变量：要求∈{踢我一下、蹬我、夹住我}；反应∈{笑、恼、自嘲、反而兴奋}；转向∈{那就别踢、你过来、换我来}。
- 档位：近期档可写「真的想踢→未完成→失衡/落空」；多年档只写肌肉先动，不写「真的想」；两档都不写「踢到了」。

### 16.3-c 残肢夹磨（膝上）

- 直写：「她让他把腿根夹住。膝上的残肢能屈能伸，她自己收了一下，把那根东西夹在大腿根和断口之间，慢慢磨。他吸了口气，手扶住她的胯。她停了一下，换了角度，又夹紧。『这样行吗？』她问。他说行。她就按自己的节奏来，磨一下，停一下，断口的肉跟着收。」
- 公式：**残肢的能力（夹/磨）+ 她的节奏 + 他的反应 + 一句确认**。
- 变量：能力∈{夹、磨、顶}；节奏∈{磨一下停一下、换角度、夹紧}；确认∈{这样行吗、别动、我慢点}。

### 16.3-d 残肢磨蹭（髋离断）

- 直写：「她把那半边压上去，胯往前送。软的那块贴着他硬起来的地方，慢慢地磨。那块肉自己动不了，她只能动整边身子；送一下，停一下，收口那儿跟着绷。他扶着她的腰，跟她的节奏。她低头看了一眼，又送过去一点：『这样。』」
- 公式：**用整边身子代替残端位移 + 软组织的贴压 + 她的校准**。
- 变量：动作∈{胯前送、整边身子压、侧倾}；接触∈{软的那块、收口上沿、胯侧}；校准∈{这样、再慢点、别顶}。
- 注意：❌ 不写那块肉自己抬起/夹住/晃动；动的是整边身子。

### 16.3-e 残端摩擦（膝下 / 肘离断）

- 膝下：「她把小腿残端抵在他腿间，膝盖带着它往前送。末端短而硬，隔着皮肤磨过去。他吸了口气，她停了一下，换了个角度，又抵上去。『这样？』她问。他说行，她就按自己的节奏来，送一下，停一下。」
- 肘离断：「她用上臂断口压着他，往下顶。她只能用这一截；顶一下，停一下，断口那圈皮肉贴着他发烫的地方。他腰腹绷紧，她看着他的脸，又顶了一次。」
- 公式：**残端的能力（抵/顶/磨）+ 角度调整 + 一句确认 + 她的节奏**。
- 变量：能力∈{抵、顶、磨}；角度∈{换个角度、往下压、往前送}；确认∈{这样、行吗、别动}。

### 16.4 前戏（B 情色档）

- 平庸：「他用手让她很舒服，她忍不住叫出声。」
- 直写：「他的手从她腰侧下去，隔着内裤按了按。她湿了，布料贴上去，形状都出来了。他把手伸进布料里，指腹沿着那道缝往上，停在最前面那一点，画了个圈。她膝盖一软，健腿先屈起来，胯侧那边跟着一抽。她抓住他的手腕，不是推开，是带着他往下。『就这儿。』她说。他的手指压着那一点，慢慢地磨。她喘得不成句，收口那儿绷紧又松开，手在他背上抓了一把。」
- 公式：**手的路径 + 湿润/形状 + 她的引导 + 身体反应 + 停在前戏范围内**（B 可继续进入，见 16.4-b）。
- 变量：路径∈{从腰侧下去、隔着布料、伸进布料里}；反应∈{膝盖软、胯侧抽、抓背}；引导∈{带着往下、就这儿、慢点}。
- **B 档红线**：不写临界/高潮/后戏；本段只写外部刺激与反应，B 可继续进入（见 16.4-b）。

### 16.4-b 进入（B 情色档上限）

- 直写：「她坐在床沿，他扶着她的腰进去。她没让他一口气到底，手在他胸口按了一下：『慢。』他停住，等她松了才往里。她把手撑在身后，胯往前送，整边身子跟着动；空的那边在床沿外空着一截，她把重心压到健腿和手上。抽送是慢的，一下一下，收口那儿跟着绷。她喘起来，他加快，她突然抓住他的手腕：『停。』他停了，额头抵着她的肩，两个人都没说话。」
- 公式：**谁支撑 + 进入的角度/阻力/停顿 + 抽送节奏 + 她的叫停**。
- 变量：支撑∈{手撑身后、背靠床头、靠在他肩上}；停顿∈{换角度、等一下、退出来一点}；叫停∈{停、等一下、别动}。
- **B 档红线**：可以进入、可以抽送，**止于临界前**；不写「快要到」、不写高潮、不写后戏。

### 16.4-c 口交（B/C 共用）

- 直写：「她让他躺下，自己俯过去。她先用嘴唇碰了碰，再含进去一点，舌头贴着下面那圈慢慢地转。他吸了口气，手放在她头上，没按。她退出来，看他一眼：『别按。』他说好。她又含进去，这次深一点，手握着根部，跟着嘴唇的节奏动。他腰绷起来，她停住，抬头：『要到了就说。』」
- 公式：**口腔的接触 + 舌的路径 + 她的节奏 + 边界（不按头/要到了就说）**。
- 变量：接触∈{嘴唇碰、含进去一点、深一点}；路径∈{贴着转、从上往下、绕着}；边界∈{别按、要到了就说、停}。
- **档位**：B 可写含入与节奏，止于对方临界前；C 可写射精与吞/吐的选择（按同意）。

### 16.5 进入（C 成人档·髋离断坐位）

- 平庸：「他们换了几个姿势，最后她坐在他身上。」
- 直写：「她坐在床沿，他在她前面跪着——他跪，她不用。她把手撑在身后，胯往前送了送，那半边跟着抬起来一点，床沿外空着一截。他扶着她腰进去，进到一半她停住，眉头皱了一下，换了个角度，才又往里。『慢点。』她说。他就慢。她的手在身后撑着，指节压进床单，健腿的脚踩在他腿上借力。整边身子随着动作往前送，送一次，她就往他这边贴一次。」
- 公式：**谁支撑 + 进入的角度/阻力/停顿 + 患侧处理 + 她的控制**。
- 变量：支撑∈{手撑身后、背靠床头、靠在他肩上}；停顿∈{换角度、等一下、退出来一点}；控制∈{慢点、我自己来、别动}。

### 16.6 进入（C 成人档·肩离断侧卧）

- 平庸：「他把她压在身下，她只能用一只手抱着他。」
- 直写：「她侧躺着，患侧朝上。他用一只手固定她的腰，另一只手撑着自己，不敢把重量压下来——她只有一只手，撑不住他。她的手抓着他的肩，指尖陷进去。空袖管被推到一边，肩头那道疤露在外面，他的嘴唇贴上去，她吸了一口气，腰往他手里送。」
- 公式：**单臂的限制 + 他的自我支撑 + 空袖管/肩疤的接触 + 她的回应**。
- 变量：支撑∈{他撑床、她背靠墙、枕头垫腰}；接触∈{肩峰、锁骨、肩疤、空袖管}；回应∈{吸气、腰往前送、手抓紧}。

### 16.7 高潮（C 成人档·髋离断）

- 平庸：「她达到了顶峰，眼前白光一闪。」
- 直写：「她先绷的是那半边。臀侧的肉一阵一阵地收，收得看得见，收口那儿跟着抽，抽一下，整边身子就往上一提。她手撑不住了，背落到床上，空的那边陷进被子里，另一条腿的膝盖弯起来，脚趾蜷紧。声音卡在喉咙里，出来的时候只剩一口气。他还在动，她推了他一下：『等……等一下。』」
- 公式：**可见的收缩 + 整边身子/健腿 + 支撑失效 + 声音 + 喊停**。
- 变量：收缩∈{臀侧、收口那儿、小腹}；支撑失效∈{手滑、背落下、腰塌}；声音∈{卡住、只剩一口气、变调}。

### 16.8 后戏（C 成人档）

- 平庸：「事后，她靠在他怀里，觉得自己是世界上最幸福的人。」
- 直写：「她先要的是水。他起来的时候她拉住他：『拐。』他把拐递到她手边，她才松开。水喝了两口，她低头看收口那一圈，被压出一道红印，她用手掌揉了揉。床单湿了一块，她把它往旁边推了推。『下次垫条毛巾。』她说。他说好。她笑了一下，把拐靠在床头够得到的地方，才躺回去。」
- 公式：**一个具体需求 + 器具归位 + 身体检查（非医学） + 一句日常话 + 不升华**。
- 变量：需求∈{水、拐、毛巾、灯}；归位∈{拐靠床头、假肢放床边、接受腔放椅面}；话∈{下次垫毛巾、明天要早起、你别压那边}。

### 16.8-b 全露（C2·髋离断侧卧）

- 直写：「她侧躺着，患侧朝上，收口那边垫了枕。他从后面进来，手从腰下绕过去，把她固定住。进到一半她吸了口气，里面绞了一下，他停住，等她松了才往里。抽送快起来，床板响，她手抓不住床单，指甲刮过去。他伸手到前面，指腹压着那一点，她整个人弓起来，里面一阵一阵地收，收口那儿跟着抽。他问：『里面？』她说：『别。』他就退出来，射在她腿根上，热的，顺着往下流。她抖了一下，笑：『擦。』」
- 公式：**体位支撑 + 进入的阻力/停顿 + 抽送的节奏 + 高潮的收缩 + 射精去向（同意）**。
- 变量：支撑∈{垫枕、他从后面固定、她手抓床沿}；节奏∈{慢进、快抽、停一下}；去向∈{体外、腿根、套内}（按同意与避孕）。
- **C2 要点**：进入—抽送—临界—高潮至少三段不跳切；体液写去向与温度，不夸张。

### 16.8-c 后戏（C2·清理与体液）

- 直写：「她去擦的时候先摸到的是腿根上那一片，热的已经凉了，黏。他拿纸巾过来，她接过去自己擦，擦完把纸团了扔进床边的袋子里。『套呢？』她问。他指给她看，打了结，放在袋子里。她嗯了一声，拉过被子盖到腰，露出一截收口。『下次垫毛巾。』她说。他说好。」
- 公式：**体液的触感 + 谁清理 + 避孕物的处理 + 一句日常话 + 不升华**。
- 变量：触感∈{热的凉了、黏、滑}；清理∈{她自己擦、他递纸、一起换床单}；日常话∈{下次垫毛巾、套呢、灯关一下}。

## 十七、与剧情编排的接口

- **密度与位置**：按 `core/chapter-planning.md#六、亲密戏的编排（B/C 档）` 的题材基准执行；不在本章临时加戏。
- **每场 B/C 档须有剧情功能**：关系确认 / 权力变化 / 信息交换 / 误解加深 / 和解 / **受众供给**
  （身体接纳/器具卸下/受限处置——本类型读者的核心期待，属合约内容，不得以「与主线无关」删）；
  并在账本 `亲密戏登记` 填「事后变化」。**删场测试**见 `core/chapter-planning.md#6.1`（唯一删除判据）。
- **首次 C 档前须有「被看见」beat**（招牌元素⑥）：她让他看见，才让他碰；B 档可提前做这个 beat。
- **devotee 疑虑不由性解决**：C 档可以加深（他在看哪里、她注意到了），不可闭环。
- **短篇/单章**：短篇 1–2 场；单章可一场，但仍须 turn、钩子；核心受限按配额（短篇 ≥1 条）。
- **节奏**：B/C 档章张力级通常 3–4；首次 C 或危机章可 5，之后 1–2 章内安排 ≤2 呼吸章。
