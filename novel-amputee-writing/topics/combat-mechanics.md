# 截肢型战力学

> **本文件是「截肢事实如何改变战斗」的唯一权威源**——敌方怎么针对她、她能怎么打、
> 什么地形帮谁、什么武器她拿不了、赢和输各要付什么代价。
> 与相邻文件的分工：
> - 对抗节拍 / 口角升级 / 霸凌 / 反向题材边界 → `topics/conflict-scenes.md`
> - 位移分层 / 体力节奏 / 无辅具位移学 → `topics/mobility-modes.md`
> - 动作可行性兜底（不可能动作）→ `core/physio-audit.md` 与 `types/{type}.md#不可能动作`
> - 战斗中的受限如何登记 → `topics/limitation-scenes.md`（战斗本身不等于受限 beat）
>
> **本文件不豁免任何生理事实**：§四 的武器表、§二 的强项，都不能让缺失肢体做出
> `types/{type}.md#不可能动作` 里的动作。
> 注入时机：写战斗 / 追逐 / 围堵 / 擂台 / 群战 / 守城 / 末世遭遇时注入，不常驻。

## 零、四条读法

1. **先定类型，再定战场，最后定招**——顺序反了就会写出「她很强」的空话。
2. **她的胜负不取决于谁更强，也不取决于占住哪个点**——取决于她能否制造一个 1–2 拍的空档，
   并在空档里完成一次输出。战斗设计的第一步是**找制造点**，不是选阵地。
3. **每一场都要能回答：她的手在哪、她的支撑在哪、她倒了怎么办**。三问答不出＝没设计。
4. **战斗是受限的放大器，不是军事推演**——读者看的是她在限制里怎么选（弃什么、保什么），
   不是看阵法图；每场至少一次「她想要但做不到」的选择（与 `topics/limitation-scenes.md` 四-补3 同源）。
5. **每场至少一次「身体被看见」**——敌方/队友/围观者的目光落在她的残端、拐、接受腔、空袖管上那一下，
   ＋她一个几乎看不出的回应（收拐半寸/握柄收紧/没躲）。战斗是受众「被看见」偏好的高压舞台，不是纯战术手册；
   目光分层与写法见 `core/audience.md#★平庸 vs 心动对照范例` 的「★目光的分层」表，服从招牌⑥限频。示范：「他扑过来前先扫了一眼她空着的裤管——就那半秒，她把拐尖往他脚背前一寸挪了挪。」

## 一、四条底层事实（下肢/阵地型）

> **上肢截肢不走这四条**（见本节末「上肢分岔」）——她们的底盘与常人无异，
> 真正的底层事实是**无第二手**，不是「换位成本」。

| 事实 | 物理内容 | 写作后果 |
|---|---|---|
| **支撑面** | 站定后她能用的承重面＝一只脚（或两侧假肢脚底）＋器具 / 墙 / 车体补的第二支点 | 所有「能不能发力」的问题先问支撑面，**不问力气**（力量性归因＝违规，见 `topics/limitation-scenes.md` 四-补） |
| **无冗余** | 健全人两条腿是双份；她只有一份。健腿被控 / 被陷 / 被绊＝全部移动能力同时失效；唯一的手被控＝不能夺回、不能撑地、不能起身 | 针对她的控制技（抱腿、踩拐、抓手）收益远高于常人；她必须优先保护这三样 |
| **倒地即失能** | 起身不是一撑就起，是**五步动作链**（①拐杖拿到身旁够得着处 → ②翻身侧卧/仰卧 → ③**健腿屈曲蹬地**、双手撑地坐起 → ④摸到拐杖、双拐撑地、健腿蹬起站直 → ⑤站稳后调整拐杖位置；权威链见 `topics/crutch-usage.md#三、摔倒与起身`，K04 按此五步判），战斗中要十几秒且需对方不补刀。**这是单腿＋双拐口径**；膝下假肢/上肢截肢起身较快，但同样不是「一撑就起」；**双侧分档（权威 `types/bilateral.md`）：双髋不能自行站起；双膝上可起但须双手撑物、慢、不能久站；双膝下可起须扶物、慢** | **她的第一战术目标不是杀伤，是不倒。** 倒地章写「怎么抓到一个支点」，不写「鲤鱼打挺」 |
| **换位成本** | 每移动一步都要重建支撑；她的「换一个点」成本远高于「守住一个点」 | 她是**位置战**不是移动战：赢在「过不来」，输在「被拖走」 |

> **推论**：她是**短回合**打法——**单个回合** 3 拍内解决或脱离，缠斗＝输。
> ⚠ **回合 ≠ 场**（v9 修正）：一场战斗由 **3–6 个回合**组成，下面那条三拍链里的「脱离或重置」，
> **「重置」就是下一回合的开始**，不是战斗的结束。拖长指的是**单回合内缠斗**，不是整场不能多回合。
> 回合数基准、四拍写法与动作密度（每 100 字 ≥2 个可辨识动作）见 `core/intensity.md#三、战斗回合制`。
> 战术围绕「制造一个空档 → 原地输出 → 脱离或重置」展开，**不围绕「守住某个位置」**。
>
> **为什么不能守**：守＝等对方来；她的支撑面只有一份，等得越久，对方越有时间针对（夺拐/拆地形/远程）。
> 「一夫当关守窄路」那种写法本书**禁用**——赢的不是她的能力，是地形替她打的（见 §八 禁用清单、K13）。

### 上肢分岔：无第二手

> 肩/肘/腕离断的机动与站姿不受影响，四条事实里只有「无冗余」成立——
> 而且不是「腿没有备份」，是**手没有备份**。

- **无第二手**：不能双手长兵/弓/大盾；不能双手攀爬/拉绳；不能双手夺回。
- **患侧不能撑地**：摔倒时无第二手缓冲，倒地比常人更重；起身靠单手＋腿。
- **被近身抱住即失杠杆**：单手无法同时控制与打击；她的第一反应是**退出抱距**，不是摔。
- **被夺兵器＝空手**：没有第二只手夺回，所以她的武器要有备用/退路。
- **战场选择多**：她不怕换点，怕的是被贴住；敌方阶梯按 §二 上肢三行取。

### 战斗中的幻肢（仅近期档；下肢为主，上肢同理）

> 战斗是幻肢的高压触发场景：她想迈步 / 撑地 / 踢，残肢发力但**动作未完成** →
> 真失衡 / 真摔倒。**这是「倒地」的一条合法来路，也是敌人可乘的瞬间**。
> 频率服从 `topics/timeline.md` 档位上限，不得每场都用；**多年档只写肌肉一抽，不写真用**
> （`core/physio-audit.md#幻肢感豁免`）。
> 上肢同理：想用患手去挡 / 抓 → 落空 → 门户大开；同样只用一次，不每场。

## 二、类型分型总表（十一型）

> 读法：先找她的类型 → 看「敌方针对阶梯」→ 再看 §三 她的手够不够用。
> 同一角色若为双侧或上下肢复合：**弱点取并集（两侧的弱点都成立）、强项取交集**
> （只有两侧共有的才还能算强项）。

| 类型 | 结构性强项 | 结构性弱点 | 敌方针对阶梯（成本低→高） |
|---|---|---|---|
| **髋离断·无辅具** | 站定后比移动时稳得多——靠**单脚＋墙/车补第二支点构成三角支撑**（单足支撑面更小、重心上移偏健侧，❌ 不写「重心低」）；**可健腿单腿蹲**（蹲低腾手——正式豁免，见 `core/physio-audit.md#下肢截肢违规类别`）；一个身位内她最稳（仅指站定输出，❌ 不据此卡窄口，K13） | 转向慢、不能追、**跨障受限（低障可跃、高障须绕）**；**倒地起不来**；**蹲下后起身须一手支撑**（扶拐/扶墙/扶健侧膝/撑地；无扶手深蹲＝蹲得下起不来）；只有一支「腿」，被绊即倒 | ① 长兵器在身位外消耗 → ② 绊/推/撞使她失位 → ③ 分两路逼她选边 → ④ 拆地形 → ⑤ 佯退诱她移动 |
| **髋离断·双拐** | 两条支撑线，可短距腾挪；拐本身可攻防；**放拐后可健腿单腿蹲**（蹲低腾手；起身仍须扶拐或就手扶物） | **双手被占＝不能持武器**；拐离手即降为无辅具；怕湿滑/台阶/窄门 | ① 夺拐/打飞 → ② 攻她必须用手的地方（逼她放拐）→ ③ 湿滑/台阶/窄门设伏 → ④ 逼她跨/追 |
| **髋离断·假肢** | 穿长裤外观接近常人，可短时站立 | 无髋不能主动驱动，步态机械、耗力；日常多弃用；**格斗中基本不可用** | ① 逼她走/站久 → ② 撞患侧 → ③ 卸下即回无辅具（战斗方式降级） |
| **膝上·假肢** | 双手自由，站定可持双手武器；可较长距离行走 | 步态可识破；假肢怕扭转与侧向力；**不能跪**；跑动耗能；卸下回原始受限 | ① 看步态定患侧 → ② 侧向撞/别腿 → ③ 逼跑 → ④ 破坏假肢 → ⑤ 逼跪/低姿 |
| **膝下·假肢** | 步态近常人；**可跪**（低姿/掩体）；可短距跑；双手自由 | 假肢怕扭转；湿滑打滑；长时摩擦；卸下回原始受限 | ① 逼长跑 → ② 侧向/扭转 → ③ 湿滑地面 → ④ 破坏假肢 |
| **膝上/膝下·无辅具（单腿跳）** | 双手全自由；可蹲低；启动突然；**可连跳**（熟练者十几步以上没问题） | **慢且费劲**（连跳可行但慢于常人奔跑）；不能追/**跨障受限（低障可跃、高障须绕）**；起身需支撑；被撞即倒 | ① 拖时间/退着打 → ② 逼她连续移动 → ③ 绊/推 → ④ 占高差 |
| **肩离断** | 下肢健全，机动不受限；单手兵器都能用 | 无第二手：不能双手长兵/弓/大盾；被近身抱住失杠杆；**患侧不能撑地**（摔倒更重）；不能双手攀爬/拉绳 | ① 近身缠抱/夺兵器 → ② 逼双手任务 → ③ 攻患侧 → ④ 逼她失衡（无第二手撑） |
| **肘离断** | 上臂在，可肩撞/上臂挡；残端可夹/顶；单手兵器可用 | 无前臂/手；不能旋前旋后；不能双手；**肘弯不存在**（不能挂、不能撑肘起身） | ① 近身抱摔 → ② 攻患侧 → ③ 逼双手 |
| **腕离断** | 前臂/肘在；残端可夹/撑/顶/压；肘弯可挂；可「抵住」辅助 | 无手不能抓握；不能双手协同；患侧不能抓/夺 | ① 打掉她的兵器（无第二手夺回）→ ② 逼抓握 → ③ 攻患侧 |
| **双侧（双髋／双膝上／双膝下）** | **双髋**：地面/轮椅平台，重心最低，撞与卡位最稳；**双膝上**：可短时站立（**须双手撑物，不能久站**）；**双膝下**：**可站立短距行走、双手自由**（能耗 2–3 倍） | **双髋**：不能站、不能自行起身；**双膝上**：不能久站、倒地不能自行站起、双手撑物＝不能持兵器；**双膝下**：能耗高、平衡差、不能跑、起身须扶物且慢；**三者共用（轮椅态时）**：轮椅双手推轮＝不能持武器、被掀翻即失能、台阶门槛＝死路 | **双髋/双膝上**：① 逼她站起/掀翻轮椅 → ② 台阶门槛 → ③ 远程 → ④ 火/烟（撤离慢）；**双膝下**：① 逼跑/逼久站 → ② 侧向撞（平衡差） → ③ 堵路 → ④ 远程 |
| ↳ **双侧·双膝下口径澄清** | 强项的「可站立短距行走」与弱点的「轮椅推轮不能持武器」**不是矛盾，是两种场景**：短距/室内可站立行走（双手自由），**长距离/现实向以轮椅为主**（`types/bilateral.md#移动样态`）。战斗按当前场景取态——站立行走态用「双膝下」敌方阶梯，轮椅态用「三者共用」弱点。❌ 不得在同一场既写她站立持械又写她双手推轮 | — | — |
| **上下肢复合** | 只剩「选位置」和「借外力」；轻组合（膝下＋腕离断）仍可走 | **按两侧最重项叠加**；极端组合（髋离断＋肩离断）＝不能拄拐（无手）＋不能走（无腿），轮椅单手推＝打转、起身需人 | ① 断器具/断路 → ② 远程 → ③ 等她耗尽 → ④ 直接俘获 |

- **膝上/膝下·无辅具合并为一行**：不穿假肢时两者都是单腿跳，打法相同；
  差异在残端承重与幻肢感，按 `types/{type}.md` 取。
- **髋离断·假肢**单列，是因为它在格斗里几乎不成立：无髋无法主动驱动假肢关节，
  站定可以，移动与受击都不行。写它参战，须先交代「为什么今天穿了」。
- **双侧不是「一个更重的单侧」，三档必须分开取**（`types/bilateral.md`）：
  双髋＝**不能站**（战斗只有地面/轮椅两态）；双膝上＝**能站不能久站，且须双手撑物**
  （站着＝没有手，持兵器＝站不住，这是它独有的战术矛盾）；双膝下＝**能走能跑短距**，
  但能耗高、平衡差。❌ **不得把双膝上直接写成轮椅**，也不得把双髋写成「扶着东西能站一会」。
- **复合**的最强写法是「固定炮台」（极端组合）：她动不了，但她守住的那个点别人进不来。

## 三、手的经济（移动、武器、操作的三选几）

> 截肢战斗的第一资源不是体力，是**手**。每一场先写清「她的手在哪」，
> 手不够时**必须做取舍**——弃武器 / 弃移动 / 弃操作，取舍本身就是戏。

| 类型 | 移动占手 | 可持武器 | 关键限制 |
|---|---|---|---|
| **双拐** | 2 手 | 0；**拐即武器** | 不能一手拐一手刀；极短时间可单拐＋短兵（一两步），之后必须回到双拐或弃拐 |
| **单拐＋假肢** | 1 手 | 1 手（单手兵器/小圆盾） | 单拐支撑弱于双拐，重击会打偏；不能双手长兵 |
| **假肢（无拐）** | 0 手 | 2 手（双手兵器 / 盾＋兵器） | 站定可，连续步法不行；侧向力怕 |
| **无辅具单腿跳** | 0 手 | 2 手 | **可连跳十几步以上**，但每一跳都是单脚落地＝没有稳定的射击/输出平台（❌ 不写「一步一停」，也不写边跳边精准打击）；蹲下后起身要空出一只手 |
| **轮椅** | 2 手推 | 0（停轮后可双手用弓/弩，但失去移动） | 1 手推＋1 手兵器＝速度减半、转向困难；0 手＝停下挨打 |
| **上肢单手** | 下肢不占手 | 1 手总 | 兵器 / 盾 / 操作三选一，不能同时；被夺兵器＝无第二手夺回 |
| **上肢双侧（双侧上肢截肢）** | 下肢不占手 | **0 手** | 不能持兵器、不能撑地、不能自行起身；只剩残端夹/顶、肩撞与借外力，战术只剩位置、借物与借助他人（见 `types/bilateral.md`） |
| **飞行态（翅膀/御剑）** | 0 手（翅膀由身体承担）；御剑视设定 0–1 手 | 2 手（御剑占手时 1 手） | **空中不占手 ≠ 不受限**：空中受限与落地回落见 `topics/combat-magic.md` 15.0；❌ 不得因飞行抹平地面段 |

- **双拐者持刀＝手不够**：这是最常见的战斗出戏点。要用刀，先解决拐（放拐/藏拐/弃拐）。
- **轮椅者射箭**同理：双手都在轮上，移动中射不了；要射，先停轮，射完再重新起步（停轮期间不能躲）。
- **单手角色一手刀一手盾**：做不到——盾要绑在残端/前臂上才可以（须世界观或日常铺垫）。
- **上肢双侧＝0 手**，不是「一只手不方便」：她既不能持兵器也不能撑地、不能自行起身，
  战斗的落点只能是**位置、借物、借助他人**；把她写成「用双臂残端夹住兵器作战」＝违规。
- **飞行态的手是自由的，但自由不是豁免**：翅膀不占手，所以空中她能持兵器——
  代价是被看见、被射翼、被锁空，且**落地那一段仍按辅具四类走**（`topics/combat-magic.md` 15.0）。
- 取舍写法：她放掉哪一样、放在哪、还能不能拿回来——三句写完，比写她「身手矫健」有用。

## 四、武器与器具的可用性

> 判据只有一条：**这件武器需要几只手、什么姿势、什么步法**。
> 需要她做不到的那一项，就是不能用——不是「用得吃力」。

| 武器/器具 | 谁能用 | 谁不能用 | 备注 |
|---|---|---|---|
| 单手刀/剑/短矛/棍 | 单侧下肢（假肢或无辅具，手空时）、上肢单手 | 双拐者/轮椅者**移动中**（手在移动上；停拐/停轮后可，但失去移动） | 双拐者要用，先放拐 |
| 小圆盾 | 肘/腕离断（**绑残端或前臂支架**）、肩离断（**肩带/躯干支架**）；健手仍可持兵器，须前文铺垫 | 双拐/轮椅（手在移动上）；双手兵器者；无支架可固定的场合 | 不绑而用手举＝占掉唯一的手，等于弃兵器 |
| 弓 | 双手健全者（**轮椅坐姿可行**：停轮后双手拉弦） | **上肢截肢一律不可**（拉弦需双手）；双拐者不可（除非放拐并以墙/车支撑，须写清） | 不写「用牙咬弦」的奇观 |
| 弩 | 轻弩可单手（需脚踏/辅助上弦）；轮椅可停轮单手射 | 重弩；双拐者（须先放拐） | 上弦慢＝只够一箭 |
| 长枪/双手剑/长柄斧/大盾 | 双手健全者；假肢者**站定**可持长枪；单腿跳可**原地**持枪（不能步法配合） | 上肢截肢；双拐；轮椅 | 长兵可抵地/抵墙做一次性支撑，不能双手操持 |
| 投掷（飞刀/石/标枪） | 单手可；双手自由者 | 双拐/双手推轮椅时（要先腾手） | 投掷后有一段空手期，须写 |
| 徒手（拳/肘/膝/腿） | 上肢截肢（单手拳/肘、单手抓，腿完好可踢）；膝上/膝下假肢或拄拐（**有第二支撑点时**健腿可离地踢，踢空即失衡） | 髋离断无辅具（**无腿可踢**＝唯一的健腿是支撑腿，离地踢即失去支撑/摔倒，只能拳/肘/抓）；双拐（手被占）；轮椅（腿无） | **分档**：① 有辅具/假肢分担支撑时，最可靠的徒手武器是**健腿膝/脚**＋**单手肘**；② **无辅具单腿跳时健腿不能离地**，只能拳/肘/抓（见 §一 倒地即失能，用支撑腿踢＝自倒）。❌ 不写患侧踢/蹬；单手抓握无法形成摔法（无第二手控制） |
| 陷阱/绊索/火/水 | 所有人 | — | **她的首选**：不需要手持，不需要追 |
| 拐杖 | 双拐/单拐者 | 无辅具角色（没有拐） | 戳膝/胫、扫踝、横挡、勾颈/勾腿；**不是长枪**：长度、握法、无刃，不能刺穿、不能挥砍如刀 |
| 假肢 | 膝上/膝下（可挡、可踹） | **髋离断不可**（无髋驱动；幻想向动力义肢已在 `题材豁免` 登记的除外，仍须写能耗/故障/卸下后受限）；上肢假肢不可抓握 | 膝下踹优于膝上；踢空＝失衡；不写「假肢踢断刀」 |
| 轮椅 | 双侧 | 单侧（轮椅不是常用辅具） | 可撞/卡/横挡；**不是盾**，会被掀 |
| 残端（肘/腕） | 肘离断/腕离断 | 肩离断（无臂） | 可夹/顶/压/挡；不能抓握、不能发力如手 |

**改装边界**：
- ✅ 拐杖加固、缠布防滑、加箍、换粗握柄——**同一辅具的改装**，合法，但须有日常铺垫
  （她平时就是这么缠、这么握的，战中才不会像变出来的）。
  ⚠ 铺垫**不得**写成"因为磨坏了才改"——那是损耗叙事，见
  `core/audience.md#★器具损耗与更换禁令`；改装的由来只能是**用途**（防滑/静音/加力）。
- ⚠ **不得把橡胶拐头换成金属尖**：拐头的功能是防滑缓冲静音（`topics/crutch-spec.yaml`），
  换尖＝丧失防滑、声响暴露、刮地出声，须在世界观与正文写出取舍；现实向不写。
- ❌ 拐杖改成机关/长刃/多用途兵器——超出辅具四类与物理，不写。
- ❌ 假肢加刃/加钩：现实向不写；幻想向/科幻须在世界观 `题材特有设定` 登记，
  且**不得因此获得抓握或踢蹬能力**（`core/physio-audit.md#题材豁免`）。

## 五、四个重点类型的打法（接战 / 相持 / 破点 / 倒地）

> 选这四型是因为它们的位移/支撑最受限；**上肢三型（肩/肘/腕）的打法短**——
> 核心是「手」不是「位置」，见 §一 上肢分岔、§二 上肢三行、§四 武器表。

### 5.1 髋离断·无辅具

- **接战前·三问**（答不出＝这场不该打）：
  ① 我的支撑在哪（脚＋器具＋背靠的实体）；② 这一拍我要他**多做一个什么动作**（制造点）；
  ③ 我脱离/重置的路线在哪。
  ❌ 不把「一个身位的窄口」当选点——那是等对方排队，本书禁用（K13）。
  **背靠墙只用于防绕后**（她转身要把整个身子带过去），**不用于取胜**。
- **三拍链（**每个回合**跑通一次；一场 3–6 个回合，见 `core/intensity.md#三`）**：
  1. **制造**（四选一，见 §八）：换时间 / 换高度 / 换接触 / 借他者——让对方多做一个动作；
  2. **原地输出**：站定不动完成一次打击或控制（拐/短兵/投掷）。**她的杀伤力来自"不需要位移"**；
     　⚠ **输出必须留下可观察的后果**——对方受伤／失去某物／改变打法，三选一。
     　打中了却无伤无代价地走回来＝输出空转，力量感全失（第 4 章实测事故：七丈龙的尾扫
     　把对方扫出门外，二十行后他拍雪走回，读者读到的是一场空打）。
  3. **脱离/重置**：退回支撑位、换点（须掩护）、或交给队友。**重置后进入下一回合**。
- **相持**：不追；**不退**（退＝丢支撑）；每 3 拍必须有一次"制造"。没有制造的相持＝等输。
- **破点**（对方拆地形/两路/佯退）：三选一——换点（最贵，须掩护）、借人（队友/敌方的敌人）、
  借火/障碍（同归于尽式）。写她**选了哪一个**，不写她「灵机一动」。
- **倒地**：唯一目标＝抓到一个支点（对方腿/桌腿/墙）或滚到墙边；
  起身 3–5 步，须对方不补刀。❌ 不写「一撑就起」「鲤鱼打挺」。
- **一句话**：她的强不是「过不来」，是「**她站定的时候，你总要多做一个动作**」。

### 5.2 髋离断·双拐

- **手的经济**：拐＝移动＋武器，二合一；**不能持刀**。
- **夺拐三解法**：先手废对方夺拐的手（戳腕/扫踝）；藏拐（把一支拐放到对方够不着处，
  自己单拐短时）；第二副拐（提前布置在另一处，**只作场景切换用**，须前文铺垫）。
  ⚠ 第二副拐的理由只能是**位置**（车里/门口各一副），❌ 不得写"怕磨坏所以备一副"，
  ❌ 不得由此引出送修/换拐头（见 `core/audience.md#★器具损耗与更换禁令`）。
- **拐的四种用法**：戳膝/胫、扫踝、横挡、勾颈/勾腿。
  ❌ 不能刺穿、不能挥砍如刀、不能当长枪。
- **拐离手后 30 秒**：单腿跳＋短兵，或退到墙边；不能追。
- **拐被对方拿走**：对方会用拐的长度打她——她比谁都清楚那根拐能打多远。
  应对是**贴上去**（贴住则长物失效；但抱摔距离须有短兵/队友），或用自己那支拐别住对方手腕。
  ❌ 不写「退进窄处让他挥不开」（K13）——那是地形替她挡，不是她挡。
- **台阶**：**占上端**（高度差＝合法的"换高度"）；❌ 不守门内门外——她上楼慢、下楼更慢，
  把自己堵在门口＝把退路也堵了。

### 5.3 膝上·假肢

- **站立战**：可双手武器，但不换位；靠墙/靠人补平衡（**不靠门框卡位**）。
- **侧向力**：被撞患侧＝打软；所以站时患侧靠墙/靠人。
- **不能跪**：不能低姿、不能借掩体下半部、不能跪压——这是与膝下最大的战术差。
- **假肢损坏**：卸下＝回到无辅具（单腿跳），战斗结束；损坏前给征兆（异响/松动/打软）。
- **假肢可踹**（摆动），但踢空＝失衡；不写「假肢踢断刀」。

### 5.4 双侧·轮椅

- **轮椅战**：撞（正面）/ 卡（门洞）/ 横挡；轮椅是平台，不是盾。
- **被掀翻**：地面战＝手撑挪移＋抓对方脚踝/裤腿；**不能站起**，须有人/物支撑。
- **门槛/台阶**：提前解决（坡道/人抬/绕路）；战斗中遇台阶＝死路。
- **单手推轮＋单手兵器**：速度减半、转向困难；停下手推＝挨打。
- ❌ 不写「她从轮椅上跳起来」（幻想向特殊移动已登记除外）。

## 六、地形矩阵

> 地形对她不是背景，是算术。同一块地形，对不同类型的价值相反——先查类型，再查地形。
> 下表默认按**下肢/阵地型**写；**上肢截肢与膝下假肢机动接近常人**，开阔地未必是减成——
> 故增「机动型读法」一列：**该列才是上肢/膝下/飞行型的取值**，阵地型列不得直接套用。
> 飞行型（翅膀/御剑）另见 `topics/combat-magic.md` 15.0 的代偿上限与回落规则。

| 地形 | 对她（阵地型） | 写法落点 | 谁受益 | 机动型读法（上肢/膝下/飞行） |
|---|---|---|---|---|
| **窄道/门框** | **双刃（她进得去出不来）**——❌ 不构成她的加成 | 宽度、肩、拐的横竖；被火/烟/远程封住出口的那一下；她怎么把自己退出来 | **对方**（封口/放火/远程） | 不构成减成（转身不难）；❌ 仍不得作为取胜手段（K13） |
| **开阔地** | 减成（够不着＝打不到）；但她**不需要位移就能输出**，等对方进身位即可 | 距离、对方的接近路线、她退到哪 | 看谁先动（她先动＝输） | **不构成减成**——这是与阵地型的分岔点；飞行型反而加成（空中不受地面约束） |
| **楼梯/台阶** | 双刃：守上端强，守下端弱；上楼慢、下楼更慢；**轮椅/髋离断上下都难**（须人抬/绕） | 阶数、拐尖落点、假肢打软的那一阶 | 看谁占上端 | 上肢/膝下可正常上下（膝下假肢仍怕打软那一阶）；飞行型：台阶不构成障碍，但**落点仍要选** |
| **上下坡** | 下坡难（拐/假肢打滑），上坡耗力 | 坡度、落脚、膝盖打软 | 对方（逼她下坡） | 上肢不受影响；膝下**打滑仍成立**（坡是摩擦源，不是距离源） |
| **门槛/沟/车辕** | **低矮障碍可单腿一跃而过**（门槛/浅沟/倒卧物，代价：每跳重新蹬地、落地收不住重心）；**膝盖以上高度或落点须精准者不可跨 → 必须绕**（车辕/深沟） | 绕行的时间成本、跃过后收势的那一拍 | 对方 | 可跨；膝下假肢跨沟须选落点。❌ 不写「她也跨不过去」，也 ❌ 不写无辅具者「凡需抬腿越过的都过不去」（口径源见 `topics/mobility-modes.md#四、无辅具角色的位移学`） |
| **湿滑/泥/雪/冰** | 致命（拐打滑、假肢打滑、轮椅打滑） | 打滑的瞬间、她怎么恢复支撑 | 对方 | **同样致命**——打滑与手/支撑面无关，是地面摩擦问题；膝下假肢尤甚 |
| **水面/船甲板** | 晃动＋窄；无辅具极危；轮椅须固定或不上船 | 船身倾斜、她抓的那根缆/舷 | 对方 | 上肢可上船，但**无第二手扶＝平衡差**，仍是减成；飞行型须写落点与负重 |
| **马背/车斗** | **下肢高位/无腿者**不能骑马（双腿夹马腹）；上肢截肢/膝下假肢可骑（控缰需改单缰或训练）；可驾车/坐车斗/砍马腿 | 上下车、车斗的宽度 | 看谁有车 | 飞行型：马背不是必选项，**须写为何不飞**（升空代价/负重/怕被射翼） |
| **夜间** | 拐声是定位源；听觉代偿 | 拐尖点地的声音、她停下的那一下 | 对方（若先发现她） | 无拐声＝定位源消失，**是她的加成**；飞行型：空中剪影反而是新的定位源 |
| **室内/桌凳** | 可借家具（推桌/翻凳），但转身难 | 桌子被推出去多远、椅子倒下的方向 | 她（若先占位） | 转身不难，借家具仍可用；上肢推桌须写用什么部位发力 |
| **人群/市集** | 可借人（挡/扶/掩护），也会被撞倒 | 人流方向、她被挤到哪 | 不稳定 | 可挤出，但仍怕被撞倒——**上肢倒地更重**（无第二手撑） |
| **城墙/高处** | 窄梯/女墙：**能上的人**守上端是强项；轮椅上不去、髋离断上下是死穴 | 梯宽、她的上行节奏、下不来的那一刻 | 她（守）/对方（断梯） | 飞行型**可直达**，但直达须付代价并留破绽（15.0）；❌ 不写「飞上去就不用下来了」 |

- **接战三问**：支撑在哪？这一拍让他多做什么动作？脱离路线在哪？三问有一问答不出，这场就不该打。
- **地形只用于「防」与「换高度」，不得用于「收窄通道取胜」**（K13）。
- ❌ 把窄处写成开阔（她突然有很多闪避空间）；❌ 把开阔写成窄处（敌人突然只能一个一个上）；
  ❌ 把「守窄处」写成取胜手段。

## 七、对手矩阵

> 默认按**下肢/阵地型**写；**上肢/膝下假肢可机动**，但仍怕被贴住、被夺兵器、被逼双手任务——
> 按 §二 该类型行调整，不要把「只能守一面」套给所有人。
> 增「机动型差异」一列：**上肢/膝下/飞行型按该列取值**，阵地型列不得直接套用。

| 对手 | 威胁点 | 她的可行应对 | 不可写 | 机动型差异（上肢/膝下/飞行） |
|---|---|---|---|---|
| **单兵同级** | 正面压上、试探 | 制造空档 / 先手 / 借地形（只用于防） | 零成本胜、一招制敌 | 可换位、可绕行；❌ 不写「绕着他转三圈还毫发无伤」 |
| **2–3 人** | 只能守一面 | 背靠实体挡住**一侧**（只挡 1 拍，不是长期卡口）；用障碍制造**单侧接触**，打完立刻重置 | 转身连打三人（**阵地型**）；靠窄口让他们排队 | 「转身连打三人」**对机动型不适用**——她可以转身；但仍怕被夹住患侧与背后 |
| **5 人以上** | 消耗、包围 | 拖 / 借火 / 借人 / 谈 / 降 | 全灭、杀出重围 | 可突围式撤离（不是歼灭）；❌ 仍不写杀出重围 |
| **远程（弓弩/火器）** | 她不能快速接近 | 借掩体/烟/人质/谈判/等援 | 她冲过去 | **可以接近**——这是与阵地型最大的差；须写接近的代价（暴露/时间/掩体） |
| **重甲** | 短兵无效 | 绊 / 火 / 水 / 高处 / 打关节 | 硬拼、一刀破甲 | 同阵地型（短兵无效），但可绕到关节侧；上肢仍不能双手破甲 |
| **骑乘** | 冲撞＋高度；**下肢高位者不能以骑马对冲** | 砍马腿 / 绊索 / 以车阵·桩阵挡（借物）/ 诱导其撞障碍 | 正面挡、徒手拽马；退进窄处 | 上肢/膝下**可骑马对冲**；飞行型须付升空代价且留破绽（15.0） |
| **兽/无智群** | 不会针对拐，但会扑倒 | 火 / 长兵 / 高台 / 门；**绝不倒地** | 倒地后还能反杀 | 同样**绝不倒地**；上肢倒地比阵地型更重（无第二手撑） |
| **火/烟/水攻** | 撤离慢 | 提前备出口 / 湿布 / 低姿 / 弃点 | 她冲出去、毫发无伤 | 撤离快＝减成变小；❌ 仍不写毫发无伤 |
| **陷阱/伏击** | 她**不能应急垫步闪避/连续变向躲**（❌ 不是「不能跳」——熟练者可连跳十几步以上，口径见 `topics/mobility-modes.md#二`；此处指落地后收不住重心，做不出急停急转的规避） | 先手侦查 / 拐探路 / 诱敌触发 | 她一眼看穿 | 膝下可跳但假肢怕扭转；上肢可跨；❌ 不写「她轻松避开所有陷阱」 |
| **暴民/无武器人群** | 推挤＝倒地 | 靠墙 / 退出 / 借权威 / 让开 | 她打翻一片 | 可挤出人群；仍怕被推倒（上肢倒地更重） |

- **敌人也会犯错**：轻敌、抢功、内讧、怕死——但错要有动机，不是为让她赢。
- **敌人不跳阶**：见 §九。同一敌人第二次交手必须比第一次更针对，否则按「敌人降智」报。
- **规则战（擂台/决斗）**：规则先于武力——出界算输、不许退、兵器不限。
  「不许退」对阵地型是加成，「绕场三圈/连胜三场」对她是判决。写规则，不写「她硬撑」（场景库见
  `genre/fantasy.md#九、战斗题材场景库（行会 / 擂台 / 攻城 / 群战 / 赶路）`）。

## 八、她的解法谱（战术目标与招法）

> **先分清两层，查重才不会误杀人物风格**：
> - **战术目标**＝换时间 / 换高度 / 换接触 / 借他者 / 拖时间 / 让对方付接近成本。
>   可以反复出现，是她的打法性格，**不计查重**。
>   ❌ 「守点」「逼对方进窄处」**已废止**——它们把胜负交给了地形（K13）。
> - **招法**＝达成目标的具体手段（卡门框、推车堵道、泼油、火、绳绊、借台阶……）。
>   这是查重的最小单位，**同一招法同一场景域近 5 章 ≥2 次＝复用**。

**招法库（按目标取，不按类型取）**：

| 目标 | 招法 | 判据（他多做的那个动作） |
|---|---|---|
| **换时间** | 扬沙/泼水泼油（湿滑）、熄灯/遮光、断绳/落物、关门落闩（**隔断，不是守门**）、假动作/惊呼、割断对方带子 | 他眨眼/抬手挡/脚下一滑/扭头看 |
| **换高度** | 上台阶、上桌面、上车斗、占坎沿；**让他改变高度**（绊倒/拽倒/逼他跳下） | 他抬腿/弯腰/跳下的那一下 |
| **换接触** | 贴身抱距、抓腕/衣领/发、拐别腿、肘/头击、倒地时带倒对方 | 他收臂/后退半步/弃长兵 |
| **借他者** | 队友、敌方的敌人、围观者、规则（擂台/城门例禁）、火/水/坍塌、兽 | 第三方介入或环境改变 |
| **拖时间** | 谈判、示弱、抛财物、制造声响、等援 | 他停手/转头/迟疑 |
| **让对方付接近成本** | 投掷、绊索、翻桌挡道、湿滑地面（**不用窄口**） | 他绕路/减速/换姿势 |

**升级的三种写法**（都不算复用）：
1. **同目标换手段**：上次推车堵门，这次泼油点火。
2. **学对方的招反用**：对手拆过她的地形，下一次她先拆对方的。
3. **换场景域**：同一个制造点从街口换到船头/桥面/城门洞——须在账本 `解法台账.备注` 注明「升级·换域」。

**登记**：账本 `解法台账` 记「目标 / 招法 / 场景域 / 结果 / 备注」。

**★禁用清单（K13，任何题材、任何章节不得作为取胜手段）**：

| 禁用 | 为什么禁 |
|---|---|
| 卡门框/门内侧 | 把胜负交给宽度，不是她的能力 |
| 退进窄巷/窄道等对方排队 | 一夫当关是地形赢，读者看三次就腻，且与"她只有一份支撑"的物理矛盾 |
| 诱敌进窄口/巷口 | 同上，且敌方降智（理性敌人不会排队送） |
| 以窄道宽度限制敌方人数 | 同上 |
| 「守点＝不换位等对方来」作为整套打法 | 守得越久，越给对方时间针对（夺拐/拆地形/远程） |

- **允许**：背靠实体**防绕后**、台阶上端**换高度**、车阵/桩阵**借物挡骑**、门板/桌面**当盾**——
  这些是"用位置防"或"用高度差进攻"，不是"用通道宽度取胜"。
- ❌ 把「换时间」当招法登记（太粗）；❌ 把「她很聪明」当解法。

## 九、敌方升级曲线（四阶，不跳阶）

> 战斗线的自然升级不是「换个更强的敌人」，是**敌人变聪明**。
> 这条曲线同时是她的解法升级曲线：敌人每升一阶，她必须换一次招。

| 阶 | 敌方认知 | 敌方动作 | 她的可行应对 | 写作落点 |
|---|---|---|---|---|
| **1 轻敌** | 按常人打法 | 正面压上、抢攻、想一招拿下 | 制造空档 / 先手 / 借地形（防） | 她赢，但**赢得有代价**（拐损/体力/暴露） |
| **2 识别** | 发现她「不换点」 | 佯退、远程、分两路 | 不追 / 换点 / 借人 | 写敌方**改变打法**，不写她「识破」 |
| **3 针对** | 找到她的支撑（拐/假肢/地形） | 夺拐、拆地形、侧向撞、泼水/撒沙 | 护拐 / 换招 / 弃点 | 写支撑被动摇的那一下（木头的响、车偏出去多少、缝从几指开到几指） |
| **4 学习** | 学会她的招 | **预判她的空档**（假动作被识破、光源被控、地面先被泼湿）、夜袭、消耗 | 换制造点 / 借外力 / 撤 | 写她**发现自己被算**，不写她「早有预料」 |

- **跳阶须有依据**：情报（见过她打）、强者（不需要针对）、命令（必须速胜）、
  或她已受伤/失拐。无依据的跳阶＝敌人降智。
- **同一敌人第二次交手**：必须比第一次更针对（至少用上一阶的招）；否则敌人降智。
- **敌方学习要有载体**：逃走的敌人、被俘的同伴、见过的伤势（她哪只手不能用了）、买来的情报——
  不能「他们突然就知道了」。

## 十、失败、代价与撤离

**五种失败形态**（都可写，都要付代价）：

| 形态 | 写法 | 后续 | 账本 |
|---|---|---|---|
| **失位** | 被逼离开选好的点 | 下一场她得重新选点/借人 | 位置暴露（`open_setups`） |
| **倒地** | 写她抓到哪个支点、谁没补刀 | 起身（单腿＋双拐 3–5 步）/ 被俘 | 姿态/位置 |
| **辅具损毁/被夺** | 写拐的裂纹、假肢的异响 | 降级战斗/辅具空白期 | `拐杖.状态`/`假肢.状态`/`辅具空白期` |
| **受伤** | 写「哪件事做不成了」，不写疼 | 恢复占时间、改计划 | `当前状态.伤势`（部位/功能影响/起章/预计恢复章） |
| **被俘** | 写她放下了什么（武器/尊严/同伴） | 谈判/交换/逃脱 | 关系与信息状态 |

- **赢也要付代价**：拐损 / 体力透支 / 暴露位置 / 结下新仇 / 受伤——至少一项。
- **输可以输**：败是剧情事件，写后果与处置，不写伤口与疼痛处理。
- **撤离**：她不能跑，只能「退到下一个点」。撤离需要条件——掩护、障碍、对方不追、
  队友接应、弃物。❌ 不写「她且战且退，很快消失在巷子里」（她退不快）。
- ❌ 无伤连胜；❌ 输了还全身而退（除非付出别的代价：弃拐、弃点、弃人）。

## 十一、群战与队形

> 默认按**下肢/阵地型**写；**上肢/膝下假肢可担任机动位、远程位、护卫位**，
> 不硬塞定点岗——她们的换位成本低，队伍的分工也该不同。

- **她的位**：定点输出 / 断后 / 看守 / 远程支援（弩、投掷、示警）（❌ 不"卡口"——卡窄口取胜属 K13 禁用）。
  ❌ 不站中间（挡路、被撞）；❌ 不站最后（追不上）；❌ 不做机动预备队。
- **换位成本**：队伍里必须有人负责「把她换到下一个点」——这是队友存在的意义
  （功能位见 `core/scene.md#配角功能位`：腿/眼/嘴/手/账/心）。
- **队形**：背靠实体的一侧、台阶上端、车斗/高处——位置用于**防与高度**，不用于收窄通道。
  三处任选，别让她「跟着队伍跑」。
- **指标**：她的击杀数不该最高；写「她那道防线没被绕过／她换到了下一个点」，不写「她杀了十个」，也不写「她守的那道门没破」（守门卡口属 K13 禁用）。
- ❌ 群战里她突然机动救全场（幻想向特殊移动已登记除外）。

## 十二、战后与跨章

- **拐**：损坏只写**外力当场破坏**——被踩断、被劈裂、被夺走、锁扣被人拧松、腋托被扯脱；
  战后降级（双拐→单拐→单腿跳），下一场必须体现。
  ⚠ **维修要时间/钱/工匠、备用拐、磨损/裂纹一类自然损耗与更换写法禁用**
  （`core/audience.md#★器具损耗与更换禁令`）；战后要写代价就写**打法降级与身体代价**，
  不写"拿去修"。
- **假肢**：接受腔压痕、出汗、松动；卸下回原始受限；
  **穿脱耗时（髋离断尤其）——战中卸下不可逆**，下一场只能按无辅具打。
  ⚠ 「关节损坏送修/内衬磨破更换/维修更换」同属禁用范围，写受力与失效的**当场后果**。
- **伤**：账本 `当前状态.伤势`，痊愈须有事件（不得无声消失）；
  写功能影响，不写疼痛（`core/physio-audit.md#战斗受伤与代价的合法边界`）。
- **敌方学习**：逃走的敌人带走针对打法——这是下一场升级的依据，不是「巧合」。
- **声望**：她守住的点名、她杀的人名——会带来敌人针对，也会带来盟友求助。
- **体力**：连续急行/连战之后，下一章须有恢复代价（`topics/mobility-modes.md#二、体力节奏`）。

## 十三、禁忌清单（与 §十四 K 表同源，去重留指针）

> 本节禁忌与 §十四 K01–K13 自查表同源——超人化/敌人降智/零成本反杀/假肢当腿手/拐杖当长枪/单手双手精细协同/
> 瞬间起身/疼痛奇观/励志翻转/无视手的经济/窄路依赖等逐条判据**见 §十四 K 表**（机检/自查以 K 表为准），此处不复述。
> 仅留两条 K 表未单列的原则：
> - ❌ **轮椅＝束缚**：轮椅是她的移动平台，不是囚笼；写她用得好、改得顺手。
> - ❌ **把战斗写成「她证明自己」**：每场战斗都要有利益、位置或关系的变化，否则删。

## 十四、战斗章自查表（K01–K13）

> 用法：战斗/追逐/围堵章章末逐条过，格式同 `topics/intimacy-explicit.md` 自查表——
> 「编号｜项名｜判定｜证据」。任一条不过＝回炉，不是润色。
> **高武/高魔/神话章另过 `topics/combat-magic.md` 的 M01–M08，与 K01–K13 并过**；现实向章不填 M 表。

| 编号 | 项 | 判定 |
|---|---|---|
| K01 | **类型打法匹配** | 本篇打法与 §二 该类型的强项/弱点/阶梯对得上；没有把上肢写成阵地型、把髋离断写成机动型 |
| K02 | **手的经济** | 写明移动/武器/操作各占几只手；手不够时有取舍；**须排除**：❌ 双拐持刀、❌ 双手推轮椅同时射箭（这两项是禁止项，缺否定符会被误读成许可） |
| K03 | **支撑面** | 每个发力动作有支撑（脚/墙/拐/车），归因走结构不走力气 |
| K04 | **倒地与起身** | 倒地后有处置（抓支点/滚墙/等人），无「一撑就起」；双髋不自行站起；双膝上起身须写明双手撑物、慢；双膝下须扶物慢起（分档见 `types/bilateral.md`） |
| K05 | **敌方针对性** | 敌方至少一次针对她的结构弱点（不排队送、不无视拐） |
| K06 | **敌方不跳阶** | 升级有依据（情报/强者/命令/她已受伤）；同一敌人第二次更针对；账本 `敌方阶` 只升不降 |
| K07 | **地形** | 加成/减成写对；窄处不写成开阔、开阔不写成窄处；**地形只用于防与换高度，不用于收窄通道取胜** |
| K08 | **武器可用性** | 无弓/长枪/双手剑/大盾（单手角色）；长兵只可抵地/抵墙做一次性支撑 |
| K09 | **器具武器化边界** | 拐不是长枪；假肢不抓握；轮椅不是盾；改装是同一辅具的加固，不是新兵器 |
| K10 | **代价与取舍** | 赢有代价、输有后果；**至少一次「她想要但做不到」的选择**；代价落进账本（伤势/拐状态/空白期/暴露） |
| K11 | **无疼痛奇观/无励志翻转/无超人化** | 三条禁令逐条过 |
| K12 | **解法未复用** | 对照账本 `解法台账`；招法是具体手段不是战术目标；近 5 章同招同域 ≤1 次 |
| K13 | **无窄路依赖** | 本章不得以卡门框/退进窄处/诱敌进窄口/逼敌方排队取胜；且**每回合**跑通三拍链（制造→原地输出→脱离/重置）；**输出须有可观察后果**（受伤／失物／改打法），无后果＝输出空转 |

## 十五、高武/高魔/神话战斗豁免（题材层，可选）

> 本节已拆为独立条件文件 **`topics/combat-magic.md`**（约占原文件 36%，只有高武/高魔/神话题材用得上）。
> 触发条件、档位 E1–E3、三件套（能力/代价/失效）、六条红线、M01–M08 自查表全部在该文件。
> 现实向、古装低武、无超自然能力的末世战斗章**不读**，仍按 K01–K13 过表。
> **v9.6**：六条红线的 A 组（生理）全书有效，B 组（零豁免题材战斗）在幻想向按 R-032 解禁；
> 幻想向真打规格与两条禁令另见 `genre/fantasy.md` 第十一节。

- 高魔章登记：`本章登记.能力受限` 不计入受限配额（`是否顶替` 恒「否」），
  截肢受限与能力受限**分两本账**，不得互相顶替（**幻想向按 R-032 豁免配额强制**）
- 未登记档位就写超自然战斗＝违规；敌人未针对性打法（禁魔/锁空/破领域/夺法器至少一项）＝违规
