# 亲密关系

> 截肢者在亲密关系中的样态。**保持尊严与真实，不猎奇。**
> 注入时机：写到情感 / 亲密戏时注入（与 `topics/limitation-scenes.md` 同级，**不常驻**）。
> 承载招牌元素⑦「亲密中的身体」，频率服从 `core/audience.md` 密度规则。
> 复合截肢（上下肢均有）的取象见 `SKILL.md#★上下肢复合（并行注入 · 按域分工）`。

## 一、情感

- 截肢者的情感需求与常人无异：爱、被爱、安全感、吸引力
- 可能的自卑 / 敏感：身体意象、被凝视的不安
- 慕残者视角：对方被截肢状态吸引，是**肯定而非怜悯**
- 写作：写情感的真实流动，不把截肢当情感障碍或奇观
- **对方是 devotee 时的特殊张力**：她可能顾虑"他是被我吸引，还是在消费我的身体"——
  这条顾虑本身是好戏，❌ 不要替她消解掉
- **与时长档位联动**（见 `topics/timeline.md`）：多年档＝身体已是平常事实；
  近期档＝仍在重建身体意象，亲密中的不安更重
- 截肢不等于无性能力（多数保留）；髋离断本身通常不损伤性神经——**默认写无影响**；仅当前史涉及盆腔/骶丛伤病才谈影响，且只写生活不便，不写医学过程

## 二、尺度分档

> **记号约定**：本节的 A/B/C 指**亲密尺度档**；截肢时长档位的「近期/多年」不写成 B 档/C 档（防混）。

| 档 | 写到哪 | 适用 |
|---|---|---|
| **A 含蓄** | 情感、身体意象、触碰、拥抱、卸器具的仪式感；**不写性行为** | 全年龄向、言情主线 |
| **B 情色（半程）** | 亲吻、脱衣、抚摸、揉捏、舔舐、口交含入、手指/性器进入、抽送、残肢摩擦；**止于临界前（不写临界/高潮/后戏）** | 需用户显式确认（含进入/抽送） |
| **C 成人（全程）** | **含临界/高潮/后戏**；**C1 直写（较轻）/ C2 全露（默认）**；体位与身体受限的具体处置 | 明确成人向 |

**四判据（边界不再靠语感）**：

| 判据 | A 含蓄 | B 情色 | C 成人 |
|---|---|---|---|
| 性部位接触（手/口/残肢/性器） | 无 | 有 | 有 |
| 插入或含纳（含手指/器物/口腔含入） | 无 | **有** | 有 |
| 高潮（含临界反应） | 无 | **无** | 有 |
| 后戏（清理/归位/情绪落点） | 无 | 无 | 有 |

> **B 与 C 的分界线**：B 可进入、可抽送，但**不写临界/高潮/后戏**；C 写完整流程。
> C 再分两档强度：**C1 直写（较轻）／C2 全露（默认）**——差别在密度与细节，不在底线。

> **本包尺度上限＝ C（成人档）**：允许写完整成人场景（临界/高潮/后戏），C2 可进一步加密度；仍受第七节边界约束。
> **允许 ≠ 必须**——判定问句：**「这段感情戏的目标读者是谁？这段亲密推进了什么？」**
> **未声明时按 A 处理**（默认 A，不默认 B/C）；B 含进入/抽送，**须用户显式确认**；C 须显式声明。
> 理由：默认值是最容易被无意识写出的档位——把默认设成含插入的 B，等于让每一本书都先越一次档。
> **B 是半程**：可进入、可抽送，但不写临界/高潮/后戏；把 B 写成关灯是描写不充分，不是含蓄。
> **执行层**：B/C 的具体写法（前戏四拍/体位矩阵/进入/高潮/后戏/残肢玩法/用词/出戏点/自查）见
> `topics/intimacy-explicit.md`；B 情色档读该文件 §〇–§七＋§十–§十七（跳过 §八/§九），C 成人档读全量。
> **本节四判据是本库唯一权威**；`intimacy-explicit.md` §〇 只做执行化转写，冲突以本节为准。

## 二-补、A 档五拍（含蓄档的执行层）

> A 档是言情主线的默认档，但旧版只有一行定义，实际写起来只能"关灯"或"越档"。
> 五拍是 A 档的最小结构——**不含性行为，但含欲望**。

| 拍 | 写什么 | 判据 | 忌 |
|---|---|---|---|
| **1 看见** | 她注意到对方在看（或她在看对方），**部位具体**：手、锁骨、拐杖靠在门边的样子 | 须有一个具体部位/动作，不写"他看着她" | ❌ 抽象心动（"心里一动"） |
| **2 触碰** | 有意的、可撤回的接触：递东西时指尖擦过、扶她时手停在肘上多一秒 | 接触须**可撤回**（不是被抓住）；她须有反应（不退/退半寸） | ❌ 借"意外"逃避意图 |
| **3 收** | 有人先收手（她/他/第三人在场），收得**有理由** | 收的理由须是外部或性格，不是"作者不让" | ❌ 无理由突然转场 |
| **4 停** | 停在一个**未解决的状态**：手还在原处、话没说完、灯没关 | 停的瞬间须能被下一章接住 | ❌ 停在抒情总结上 |
| **5 次日** | 第二天的一个具体动作变了：多带了一副拐、换了件衣服、绕路走、没绕路 | 变化须可被他人看见 | ❌ 只写"关系不一样了" |

- **A 档的欲望可以明写**：她想要、她主动、她提要求——只是不落到性行为。
  「她想让他再碰一下，没说」是 A 档的正写，不是禁写。
- **A 档也可以失败**：被拒绝、自己退了、时机不对——比"两情相悦"更有后劲。

## 三、按类型的身体样态

| 类型 | 亲密中的身体样态 |
|---|---|
| **髋离断** | 不对称最重；**「空」的接触**（臀部压住承托面、患侧**往前**没有腿）；残端不能独立动；**体位受限最大** |
| **膝上** | 残肢**可主动带动**、可夹物；接受腔是边界（穿 / 不穿是两种身体） |
| **膝下** | 最接近常人；穿假肢时差异小，脱下后是短残肢；残端受力敏感 |
| **肩离断** | 单手；**空袖管**的接触（**未处理上装时**）；肩带 / 索控假肢在肩胸留下痕迹 |
| **肘离断 / 腕离断** | **残端能做事**——夹、撑、顶、按；这是它们与肩离断最大的差别，也是亲密中的特点（**「转」＝前臂旋前/旋后仅腕离断可，肘离断无前臂做不到**，分型以 `types/elbow-wrist.md#运动能力` 为准） |
| **双侧** | 无健腿；轮椅 / 床沿为承托面；双手既是腿又是手；**体位受限最大**（双侧髋离断/膝上：站立/跪/跨均不成立；双侧膝下穿假肢可短时站立） |

> 体位与动态的细节见 `types/{type}.md#体位与动态`；亲密中的体位受限**照该节写**，
> 不另立一套"亲密专用"的生理规则。
> **复合（上下肢均有）**：体位可行性取两侧交集（任一侧不可行即不可行），禁止事项取并集；
> 取象两侧分别写，不堆一句。详见 `topics/intimacy-explicit.md#六、体位矩阵`。

## 四、器具与身体的边界

- **器具放哪**：床边够得到的地方（夜里起身要用）；❌ 不随手扔在地上
- **什么时候卸**：卸假肢是**日常仪式**，不是亲密专属——❌ 不写成"为亲密而卸"的表演
- **卸下后的身体**：不对称显现；残端 / 空的样态按类型取象（见 `types/{type}.md#身体细节`）
- **器具在不在场**：穿假肢的接触 vs 不穿的接触，是**两种不同的身体**，可分别写
- **拐杖的放置**：靠墙 / 放倒 / 夹腋——亲密场景同样受 `topics/hands-occupied.md` 约束
- **状态时序**：前戏前 / 前戏中 / 进入前 / 事后 / 夜间五个点，拐与假肢的位置须连续
  （见 `topics/intimacy-explicit.md#九、后戏`）；账本 `当前状态` 同步
- ❌ 不写残端溃烂、伤口处理、医学化操作（回避清单）

## 五、亲密场景库（6 个可拍节拍）

> 用法同 `topics/limitation-scenes.md`：写亲密戏时取 1 个，不要堆。
> 本库是**节拍素材**，不是写法；B 情色档 / C 成人档的具体动作、体位与露骨度下限见 `topics/intimacy-explicit.md`。

1. **卸假肢的时刻**——日常仪式被对方看见 / 参与；可对接招牌元素⑥「被看见」
2. **器具的放置**——床边、够得到、夜里起身要用
3. **对方第一次看见**——不对称与「空」的初次呈现（她的反应是主体性的，不是窘迫）
4. **亲密中的体位受限**——按 `types/{type}.md#体位与动态` 写**她的调整**，不写窘迫
5. **幻肢感介入**——亲密中下意识要使唤那条不存在的腿（**仅近期档**，见下）
6. **事后的日常**——晨起够拐、穿假肢、回到日常样态（反套路，见 `core/opening.md`）

## 六、幻肢感在亲密中的介入

> 严格服从 `topics/timeline.md` 档位总表——**亲密不是加戏的借口**。

- 幻肢介入规则见 `topics/timeline.md#幻肢档位总表（频率 × 触发 × 意图 × 残肢 × 后果）`——**仅近期档**，多年档不硬加；出现须有剧情触发，频率仍受该档位上限约束

## 七、边界与禁忌

- ❌ 不渲染性功能障碍为苦难
- ❌ 不把亲密当奇观
- ❌ 不写「被怜悯的亲密」——对方是**被吸引**而非同情
- ❌ 不把卸器具写成「展示残缺」的奇观
- ❌ 不写伤口 / 残端溃烂 / 医学化处理
- ✅ **尊重截肢者的主体性与欲望**——亲密里她也是主体，不是被观看的对象
- ✅ **正面欲望条款（她可以要）**：本库通篇是防守型"不许这个/那个"，容易写成"她被动接受"。
  以下三条是**正写**，不是可选项：
  1. **她可以想要**——写她的欲望（想看、想碰、想被碰），不写"她不知道为什么就……"的失主体句式
  2. **她可以说要**——她开口提要求（"别停""你过来""这样不行，换一下"），说得出口本身是人物力量
  3. **她可以为自己的快感提要求**——包含纠正对方的动作、说出哪里不舒服、要求换体位/停/慢
  —— 与 B04 / C12「她的主动」同源；**"她要"与"她喊停"是同一枚硬币**，两条必须同时成立
- ✅ 尺度分档由受众（devotee / wannabe）与题材定，上限见第二节
- ✅ **三条硬闸（不可关闭）**：
  1. **成年**：本场所有参与者 ≥18 岁；年龄未填或 <18 → **本场不成立**
     （B 情色档同样是性内容，同样要求成年，不得以降档规避）。
  2. **在场同意**：每次升级有可辨认的同意信号；她有喊停权，停不被写成扫兴。
  3. **疼痛不作快感**：残端 / 瘢痕的疼不写成爽；只写绷、麻、过电、牵拉。
- ❌ **越档**：未声明 C 成人档写临界 / 高潮 / 后戏，或 B 情色档写高潮 / 后戏——本场不成立（不是风格问题，是档位违规）；B 写插入/抽送不算越档。

## 八、体位与接触：按类型素材

> 按类型补的体位受限速查——尺度分档内取用（B 情色档 / C 成人档）。
> 类型专属细则仍以 `types/{type}.md#体位与动态` 为准。
> **力学与进入方式**（支撑/角度/患侧处理/换位）见 `topics/intimacy-explicit.md#六、体位矩阵` 与 `#七、进入方式`；本节只给取象与类型差异。
> 素材导向：写**她怎么调整、她主动引导**，不写尴尬渲染。

### 髋离断

- **单侧无腿＝重心面窄**：侧卧与后仰都不稳，**靠墙/床沿借力**的姿势逻辑——她先把自己安置好，再安置对方
- **患侧软组织在对方掌下会绷紧**（用力/情绪触发颤动的既有口径）——联动招牌元素②颤动，是亲密与身体细节的天然交叉点
- **「臀部压住承托面、患侧往前没有腿」的接触边界**——对方的手放在哪、往哪放会**落空**：写手落上臀侧那一下的分量，写再往前是空的
- **收口缝合处在亲密中的触感与她的敏感**：新瘢痕色深触感清晰（近期档）、成熟瘢痕色淡（多年档，见 `topics/timeline.md`）
- **她的主动引导**：用手带着对方的手绕开、落到对的地方——主体性写法

### 膝上 / 膝下（各 2 条）

- 膝上：残肢**可主动带动**，接触中残端的动静是她能给出的信号；接受腔在不在场是**两种身体**（穿/不穿分别写）
- 膝上：卸下假肢后患侧的短与轻——拥抱的不对称靠她调整站位/坐位补齐
- 膝下：残端受力敏感——轻触与避开都写她的直接反应，她说了算
- 膝下：最接近常人，体位受限最小——受限写「脱下假肢后的短残肢会碰到的位置」

### 肩离断（2 条）

- **拥抱的单臂性**：她的单臂环抱与对方的双手——写对方的手落在患侧肩峰/空袖管上的接触差异（未处理上装时空袖管在两人之间）
- **袖管/肩部的处理**：无残端，肩胸是敏感带转移处（肩带/索控假肢留下的痕迹）；触碰由她自己引导

### 肘离断 / 腕离断（2 条）

- **残端能做事的优势面**：夹、撑、顶、按（见第三节）——亲密中她的残端是**主动的手**，不是缺席（**「转」仅腕离断**，肘离断无前臂做不到，勿套用）
- 对称性几乎无损，体位受限最小；写她用残端完成的那些小动作——细节即差异

### 双侧（2 条）

- **无健腿**：坐位 / 床沿 / 轮椅为主；双侧髋离断/膝上站立、跪、跨坐不成立，双侧膝下穿假肢可短时站立——写支撑与转移，不写"努力一下"
- **双手是腿也是手**：她需要一只手支撑，另一只手才能给他；双手同时自由＝不成立

### 复合（上下肢均有，2 条）

- **可行性取交集**：任一侧不可行即不可行（如髋离断＋肩离断：不能跪 / 跨 / 双手撑 / 抱）
- **取象两侧分别写**：空椅面（下）＋空袖管（上）同场，不堆一句；能动的那部分（整边身子 / 单臂 / 声音）成为主动通道

> 类型差异示范（勿照抄）：「关灯不用手。残端顶上去，灯灭了。」
> 类型差异化即差异——肘/腕离断的残端能做事（夹撑顶转按），亲密中的主动由残端完成

> ⚠ **示范句使用规则（三禁一学）**：
> ❌ 禁止整句抄录（含仅换一两个词）
> ❌ 禁止在同一次创作的近 5 章内复用同一载体
> ❌ 禁止把示范句直接写进正文后只改标点
> ✅ 只能学**结构与手法**——提取其「公式+变量」后，换情境、换载体、换感官通道重新生成
> 自检：我写的这句与示范句对照，**载体/动作/落点意象**三项中相同 ≤1 项；≥2 项相同即判复写，重写
> 闸门：写入正文前过**四道闸门**（见 core/audience.md#四道闸门）

## 九、照顾与被照顾的拉锯（devotee 言情的第一爽点）

> 「被爱但不被怜悯」是圈内名场面的共同配方——他伸手想帮，她偏不要；
> 最后她要了，但用她自己的方式。三到四拍节奏：

- 第一拍·拒绝：他伸手，她侧身避开——动作轻，但明确（「我自己来」说得平静，不带刺）
- 第二拍·各退半步：他不再伸手，但把东西挪到她够得着的位置——不说话的照顾
- 第三拍·她的方式：她做成了，用她的方式——比他预想的慢，但漂亮
- 第四拍·他的领会：他下次不再伸手了，只是提前把路让开——被驯化的体贴才是终点
  （终点是**他改习惯**，不是**她锁选项**——她的应对仍可波动，见 `core/audience.md` ★目光的分层）
- 写法铁则：拉锯的每拍都要有具体动作，不写内心独白解释「她为什么不要帮」——
  拒绝的理由读者自己懂，说出来就矮了

## 十、devotee 疑虑暗线（全书级金钩子）

> 「他是被我吸引，还是消费我的身体」——这个疑虑能撑一整本书的暗线，
  4–5 个节拍，不急着给答案：
- 节拍1·察觉：他第一次露出那种目光时她读到了什么（欣赏？她太熟悉这个光谱了）
- 节拍2·试探：她「不小心」露出残端看他的反应——比语言诚实的测试
- 节拍3·摇摆：他做了一件与身体无关的好事——疑虑松动半格，但只半格
- 节拍4·对照：出现另一个「只看身体」的角色（路人/前任/网友）——
  有对照她才看清他看的是什么
- 节拍5·确定：不是宣言，是一个瞬间——他替她把拐放到她一伸手就够到的位置，
  放完自己都没注意。他看见的是「她走路」，不是「她少一条腿」
