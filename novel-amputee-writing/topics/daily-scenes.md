# 高频日常场景样态

> `topics/daily-actions.md` 只覆盖主干动作。本文件补齐**高频私密与公共场景**——
> 这些场景既是出戏高发区，也是受众关注区（如厕、沐浴、更衣、公共交通）。
> **注入时机：写到该场景时注入本文件，不常驻。**
> 跨类型通用；类型差异叠加 `types/{type}.md#日常动作差异`；古装变体见 `genre/historical.md`。

## 一、如厕

- 马桶：移到马桶前 → 拐靠墙/并到一手 → 转身背对 → 健腿屈膝坐 → 手撑扶手或水箱稳住
- 起身：手撑膝或扶手 → 健腿蹬起 → 够拐
- **蹲厕**：单腿蹲撑不久（蹲姿全靠一条腿），须坐便器或加坐便椅；
  膝下穿假肢者可短时蹲，仍费力（处置细目见下文「十-补、蹲坑」）
- 狭小空间：转身难，拐杖常须先递出或立在门外
- 写作：写"门要开着还是关着"这类真实取舍，扶手与水箱瓷面的凉是现成触感锚点；❌ 不写失禁、排泄、清洁窘态（属猎奇）

## 二、床上起卧与床边转移

- 床高：过低起不来、过高坐不上；常见做法是与常坐的椅面等高的床
- 起卧动作链：侧身 → 手撑床面抬上身 → 健腿下床落地 → 坐稳 → 够拐站起
- 睡姿：患侧朝上垫枕；翻身要带动**整边身子**（髋离断）
- 床边转移（床↔坐处）：坐于床沿 → 手撑 → 站起够拐 / 挪移到坐处
- 写作：晨起/睡前是日常样态好素材，光脚落地那一下的凉、床垫只塌半边的陷都是现成锚点；但❌ 不写"醒来—巡视身体—起身"套路（见 `core/opening.md`）

## 三、公共交通

| 场景 | 样态与写法 |
|---|---|
| 地铁 | 直梯优先（找直梯要绕路）；扶梯需侧身双拐并拢站；安检要人帮忙递包；车厢拥挤无处扶靠 |
| 公交 | 上下两级台阶是难点；车厢内单腿站需抓扶手；让座是被看见场景 |
| 网约车/出租 | 上下车同 `topics/daily-actions.md#上下车`；后备箱放拐/取拐 |
| 长途（火车/飞机） | 座位选过道、提前申请协助、如厕是最大障碍、久坐患侧受压 |
| 步行与绕路 | 无障碍水平决定绕路距离，见 `core/worldbuilding.md` |

- ❌ 不写因无障碍缺失而"无法通行"；写绕路、耗时、挑路线
- 但「无障碍被占→等/绕/开口请让」是合法受限素材（见 `topics/limitation-scenes.md` 衍生类 5「环境与他者」）

## 四、长距离行走

- 体力衰减：腋下与手掌先吃不消，其次健腿；中途必须找坐处
- 节奏：走一段歇一段，歇时把拐靠好；出汗与器具摩擦（腋下、掌心）
- 按 `训练程度` 取值：初学＝百米级即需歇；熟练＝可连续走一段但仍挑路面；
  长期适应＝挑路线后能走较长
- 写作：长距离是**弱受限与真实感**的好素材——体力代价归弱受限层（不当核心受限 beat、
  不登记账本，见 `topics/limitation-scenes.md` 四-补2），写停顿、换手、找支撑物——拐头橡胶的闷响数着节奏

## 五、负重与楼梯

- **负重上楼**：物先放下搬到平台上再回头取拐，或单手并拢持双拐、另一手提轻物（须有扶手；无扶手则分次）；双肩包肩带与腋托冲突（压腋）
- **背包优于提袋**：双手要留给拐
- **楼梯跌倒**（与平地摔倒不同）：台阶卡拐、失重心向下滚落；
  起身须先稳住不继续滑，再按平地起身链处理（见 `topics/crutch-usage.md#三、摔倒与起身`）
- ❌ 不写摔倒后的伤势处理

## 六、厨房与家务

| 场景 | 变通 |
|---|---|
| 端热锅/热汤 | 不端走——用托盘放灶台旁分次，或坐下后再取 |
| 洗碗 | 坐矮凳；❌ 不写久站 |
| 切菜 | 坐高凳操作台面；单手固定食材用叉或压板 |
| 开罐头/拧瓶盖 | 台面固定+单手拧、开瓶器夹台边、求助 |
| 扫地拖地 | 长柄工具；湿拖地面对拐头是打滑源 |
| 晾收衣服 | 见 `topics/hands-occupied.md`（坐矮凳、分次） |
| 倒垃圾 | 分次提、或用背包 |

## 七、照护与亲密日常

- **静态照护小孩**：换尿布在地面/矮台进行（坐位操作）、久站哄抱不可行→改为坐姿抱、
  携娃出行＝推婴儿车+单拐或让娃跟着走
- **更衣全过程**：内衣（坐位穿，先从健侧脚套入）、裙子侧拉链（单手够背难）、
  外套（先患侧后健侧）、试衣间（空间窄、转身难、无扶手）
- **经期与卫生用品**：坐位更换；久坐与器具压迫叠加的不便；❌ 不写血污细节

## 八、其他高频

| 场景 | 样态 |
|---|---|
| 楼梯/电梯困住 | 停电困电梯＝密闭+无处坐；楼梯间被困＝坐台阶等待，用手机求助 |
| 雨雪结冰 | 路面打滑，拐头防滑失效；改走有遮挡路线、缩短行程 |
| 运动/游泳 | 膝下穿假肢者可游泳（防水套/专用肢）；髋离断水中靠浮力活动，更衣与进出泳池是难点 |
| 门诊/取型/调腔 | 只写**流程与不便**（排队、反复试穿、尺寸不合），❌ 不写伤口、残端检视、医学术语堆砌（见 `core/audience.md` 回避清单） |
| 职场 | 工位过道宽度、会议久坐、通勤、出差、团建活动的地形 |
| 校园 | 宿舍上下铺（爬梯不可行→换下铺）、教学楼台阶、体育课见习、集体活动地点 |

## 九、用法

- 本文件按场景查，**不全文注入**（见 SKILL.md 注入索引）。
- 写法通则：写**受限与她的处置顺序**，主角是处置者；不写求助为常态、不写窘态为看点。
- 与 `topics/hands-occupied.md` 联动：凡"双手+移动"先问拐杖在哪。

## 十、沐浴与更衣（裸露场景专项）

> 受众偏好高位场景：残肢与剩余部分细节的自然舞台。写身体，不写苦难。

- **浴凳上的水路**：水顺着患侧滑下去的路径与健全侧不同——髋离断的水沿收口缝合线分岔；膝上的水在残端上缘改道。这是把「裸露细节」与「身体事实」焊在一起的黄金细节
- **单腿平衡脱裤的序列**：坐姿→健腿先出→（收口/空管/假肢的）视觉一瞬——更衣过程的「空」是动态的，比静态更抓人
- **更衣室镜前**：镜子里的不对称全景——「被看见」的自愿版，她自己看自己
- **睡前卸具仪式（3-4 拍）**：解悬吊的声音→假肢拿在手里的沉→放床边哪个位置→患侧翻身时那半边格外轻
- **睡姿的「轻」**：患侧在上时，身子朝床面那侧沉；「半边身子轻得像不是自己的」是体感写法方向
- 浴室积水+单腿+无处扶=事情办不成，成立受限 beat（区别于防滑/水汽的点缀）

**裸露场景的心理底色轮转**（同一素材在不同底色下是不同的戏）：

> 身体素材需要情绪乘数——第 8 次沐浴场景若还是「水路+收口+不对称」的排列组合，
> 就该换底色了。底色决定她怎么看自己的身体，同一动作是任务、是仪式、是回避、还是面对。

| 底色 | 同一条「水路」怎么变 |
|---|---|
| 例行（平常日） | 水从健侧流到患侧，她顺手擦完——身体是身体，不是话题 |
| 疲惫日 | 热水多冲了半分钟——那半分钟不是洗，是站着的许可 |
| 有约（期待日） | 擦到收口处她停了一下——今晚有人会看到这里 |
| 低落日 | 跳过了镜子；毛巾裹得比平时高 |
| 与自己和解日 | 多看了一眼镜子里不对称的轮廓——不是检查，就是看 |
| 亲密余温日 | 昨晚他碰过的地方，今天水流过时她会想起来 |

（本表示范句内破折号如写入正文，按 core/style.md 破折号总闸计配额——示范自身破折号占配额）

- **「自我目光」素材组**（更衣室镜前的「被看见的自愿版」——devotee 深层享受
  是想象中的注视张力）：她看自己的眼光，就是她此刻与世界的关系——
  例行日不细看，期待日挑角度，和解日敢看正面的全貌
- 写法：底色用一两处行为差异侧写（跳过镜子/毛巾裹高/多冲半分钟），不写「她今天心情不好」这类直陈

## 十-补、蹲坑（中国公厕——公共场所隐形考点）

- 髋离断/膝上：蹲坑**几乎不可行**（患侧无支撑、悬臀深蹲难以维持——区别于
  扶物单腿蹲豁免：蹲坑无扶手且需时长）——
  处置三选：扶隔板单腿浅蹲（短时可忍）/找无障碍位/换地方（真实高频决策，
  出门前先查目的地有没有坐厕是本能）
- 膝下：可行但形态特别——假脚踝背屈有限，蹲姿是健腿深蹲+患侧脚跟翘起的半蹲
  （与 transtibial 蹲形态条同口径）
- 写法：这不是苦难叙事是日常决策——「这家的厕所她来过，知道有坐位」
  是熟练生活者的知识质感；「又是一个蹲坑」的叹气+出门找第二家，
  是受阻→处置→结果的最小完整链
