# 拐杖使用方法

> 类型特有差异见 `types/{type}.md#拐杖使用差异`。本文件为跨类型通用方法与写作要点。
> **注入时机**：写到任何"拄拐移动/上下楼/摔倒起身/拐在手里"的场景时注入本文件，不常驻；
> 辅具类型＝无（单腿跳）或上肢截肢时**不注入**（见 SKILL.md 注入索引的无辅具分支与上肢截肢分支）。

## 一、步态

单腿截肢者（无假肢或假肢未穿）用**双拐**行走，负重落在拐杖与健腿。

- **摆至步**：双拐先出→健腿摆至拐杖水平。省力慢，台阶、拥挤、湿滑处常用。
- **摆过步**：双拐先出→健腿摆过拐杖前方。快，步幅大，平地常用。
- **三点步态**：本技能**不写此步态**。三点步态指患侧可部分负重时的步态，
  单腿截肢且患侧不承重时无第三点可言（见 `topics/crutch-spec.yaml`）。
  单腿截肢只写**摆至步**与**摆过步**两种。

**写作要点**：写出"双拐先落地、咯噔两声、健腿跟过去"的节奏感；拐头落地有橡胶闷响；摆过步时身体前倾、健腿甩过拐杖。

## 二、上下楼

口诀**"健上拐下"**：上楼健腿先上、拐杖跟上；下楼拐杖先下、健腿跟下。

- 有扶手时：一手扶栏，双拐并拢另一手同持，逐级挪。
- 无扶手：双拐同上同下。
- 拐杖在台阶上要竖直，拐头别悬空。

**写作要点**：**上下楼本身只是场景点缀**（费劲、要试探、拐头磕台阶边），
不算受限 beat——只有当台阶导致**事情办不成**（进不去、赶不上、拿不下来）才构成受限，
见 `topics/limitation-scenes.md`。

## 三、摔倒与起身

单腿+双拐重心高，湿滑、绊坎、拐头打滑易摔。

**摔**：常向前或侧倒，拐杖脱手飞出或压身下；本能用健腿和手撑地。

**起身**（关键动作链，可写实写慢）：
1. 拐杖拿到身旁够得着处
2. 翻身侧卧或仰卧
3. 健腿屈曲蹬地，双手撑地坐起
4. 摸到拐杖，双拐撑地，健腿蹬起站直
5. 站稳后调整拐杖位置

**写作要点**：起身是体现受限与**动作智慧**的好场景，可写喘息、试几次、磨蹭、地面凉硬、
判断先摸哪只拐；可有一句口语化的即时反应（疼/气/骂），**但不延伸为疼痛描写或诉苦**。

## 四、日常场景

| 场景 | 样态 |
|------|------|
| **开门** | 拐杖夹腋下或靠墙，单手开门；或先开门用拐杖撑住门 |
| **拿物** | 拐杖单手夹持，另一手取物；或靠墙放拐取物再回来拿 |
| **坐** | 走到椅前→拐杖移到患侧或前→健腿屈膝坐→拐杖靠椅边或放倒 |
| **起** | 拐杖先到位→健腿蹬地→双手撑拐站起 |
| **过门槛** | 抬腿跨或侧身挪，拐杖先过 |
| **湿滑地** | 小步、拐头防滑、慢，重心压低（**场景点缀**，不单独成立为受限 beat，见 `topics/limitation-scenes.md`） |
| **提物** | 背包为主，单手提物则另一手持双拐并拢 |

## 五、双拐与单拐

- **双拐**：单腿截肢（尤其髋离断）主流，稳定。
- **单拐**：持于**健侧手**，出拐与**患侧（假肢侧）同出、健腿迈步**——教学口诀「拐跟患腿走」；单腿截肢者的单拐用途＝假肢穿戴初期平衡辅助与长距离省力（患侧不承重，不存在「部分负重」语境——三点步态禁写口径见 `topics/crutch-spec.yaml`）。
- 髋离断者日常**双拐**为主（见 `types/hip-disarticulation.md#拐杖使用差异`）。

## 六、拐杖与假肢并用

穿假肢时仍可能用单拐辅助（平衡、起步、长距离省力）——步态同上单拐口径：**拐跟患腿走**（拐与假肢同出、健腿迈步）。

## 七、写作总则

- 拐杖是主角身体延伸，写它的声音、触感、贴合感、位置感
  （⚠ **不写磨损/磨薄/包浆/换新/送修**，见 `core/audience.md#★器具损耗与更换禁令`）
- 不渲染苦难，但受限与不便要真实（够不着、打滑、卡住）
- 代入感：让读者感到拐杖落地的踏实与失重
