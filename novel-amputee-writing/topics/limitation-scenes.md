# 受限场景库

> **受限＝肢体缺失让某件事变难或无法完成。**
> ❌ **不是**：拐杖卡住、拐头打滑、上楼梯费劲——这类**有**，但只作场景点缀，
> 不单独成立为受限 beat（那是辅具的小故障，不是"事情做不了"）。
> 层级判定（核心受限 / 弱受限 / 点缀）见「四-补2」。
> 注入时机：章级规划时从本章剧情**识别**天然受限时刻；写到冲突 / 追赶 / 双手占用 / 对立戏时按类取用。
> 类型特有受限见 `types/{type}.md#受限清单`。

## 一、两条生成轴（受限从哪来）

受限不是靠枚举，是**可推导**的——任意受限都能从这两条轴推出来：

| 生成轴 | 机制 | 推导方式 |
|---|---|---|
| **不可能动作**（功能丧失，主轴） | 该功能生理上不可用 → 这件事变难或做不了 | 查 `types/{type}.md#不可能动作`，把任一"不可能"放进具体事件里 |
| **辅具依赖**（衍生轴） | 功能由辅具代偿 → 辅具不可用或被双手占用时代偿失效 | 让辅具**不在手**或**必须用双手**，能力立刻掉回 `types/{type}.md` 的原始受限 |

> 主轴是根，衍生轴是情境——先有功能丧失，才谈得上辅具代偿与剥夺。
> **无辅具类型**（单腿跳为主 / 幻想替代移动）衍生轴整体静默。
> 这也说明了"拐杖卡住"为什么不算受限：辅具还在手，事情仍做得成。

## 一-补、受限强度分档（随 timeline 档位变化）

> 受限来源＝身体结构（timeline：只有一条腿、重心窄、不能踮脚、无法单腿久站），
> 不是技能生疏——但生疏会叠加在结构上。前后期受限强度须分档：

- **B 近期档**＝结构型＋生疏型：摔倒、误判距离、慌乱的处置顺序（先伸手后发现够不着）
- **C 多年档**＝仅结构型：她熟练利落，但一步台阶就是上不去——**熟练不消解结构**，
  写「她做得又快又好，就是做不了那一件」
- **训练程度**只影响弱受限的呈现（见四-补2 受限层级判定）：初学＝更早歇、更短程；长期适应＝完成但代价高
- 弧线升级（物理→身份→自选受限）见四-补3

## 二、受限类型（一主五衍）

> **主源＝功能丧失**：肢体缺失直接导致的功能不可用——受限的根，
> 也是**受众核心关注**（缺失的直接后果，受限写作的首选主源）。
> 其余五类都是功能丧失在特定情境下的**衍生形态**——
> 规划受限 beat 时先定主源（她丧失的功能是什么），
> 再选衍生情境（辅具 / 双手 / 速度 / 他人 / 环境怎么把它放大成事件）。

### 主类：功能丧失（不可能动作轴）——重点供给

> **受众核心关注，可重点描写**（占比可高于其他类）。素材服务于剧情内生的受限时刻，
> **样例级不复用**：同一具体功能丧失＋同一场景域不得复用
> （上次写「探窄井支点不够」，这次不能再写探别的窄井——换功能对象或换场景域）。

某件事因肢体缺失**直接做不了**。

- 丧尸题材：有车，但是手动挡，只有一条腿 → **开不了**
- 东西掉地上：单腿蹲下去捡——一只手撑地、另一只手捡；
  起身＝扶拐撑起 / 撑扶健侧膝盖 / **就手扶旁边的东西**（顺手，不是必须）
- 单腿久站站不住：排队、等车、站着说话 → 须找依靠或换姿势
- **冗余备份丧失**（高阶角度）：健全人的腿是双份冗余——一条被困还有另一条；
  她的腿是单份——**健腿被控 / 陷进深泥＝全部移动能力同时被困**。
  被困的不只是一条腿，是她的全部。处置走手部代偿 / 爬 / 等待救援
  （与归因判据「支点」条目天然联动）

### 衍生类 1：辅助器具剥夺（辅具依赖轴）

> 衍生自：功能丧失由辅具代偿 → 辅具不可用时代偿失效，掉回原始受限。
> **前置条件：角色设定含移动辅具**（查 `core/character-setup.md` 辅具类型 /
> 账本固定属性）。**无辅具类型**（单腿跳为主 / 幻想替代移动）本类不触发——
> 不得给无辅具角色硬写「拐杖被打飞」类桥段。

拐杖/假肢**被打飞、被拿走、来不及捡、掉了够不着**。

- 冲突中拐杖被打飞 → 单腿跳着去捡
- 被人拿走 → **追不上**
- 来不及捡 → 单腿跳着继续战斗或周旋

**处置链**：够到 → 跳过去 → 捡回 → 重新撑起（或就地放弃，单腿跳着周旋）
（**单腿跳的体力节奏与分层口径**见 `topics/crutch-usage.md#四-补、移动方式分层与无辅具时的单腿跳`）

**★辅具空白期（剥夺后的跨章状态）**：

> 剥夺不必当章恢复——可延续数章无辅具状态。**空白期＝移动辅具全部不可用**
> 的时期（假肢损坏转用拐杖是**辅具切换**，不算空白期；拐杖与假肢均不可用才是）。
> 三个出口，按实际剧情判断：

- **取回**：原辅具找回（在对方手里/掉落处）——须有取回事件（查账本 `open_setups`
  兑现，不得无因恢复）
- **重获**：获得新辅具（搜刮/赠予/购置/工匠重制）——须有获得事件，可有适配磨合期
- **转入无辅具**：自此进入无辅具状态——账本 `辅具类型` 改登记「无(单腿跳/替代移动)」，
  属**永久状态改变**（改变故事永久状态，符合 `core/structure.md` 弧线原则）

空白期执行口径：

- 期间移动与受限全部按**无辅具类型**口径执行：单腿跳为主（体力节奏见
  `topics/crutch-usage.md#四-补`），辅具依赖轴两类（辅助器具剥夺/双手占用）持续静默，
  受限主源回到功能丧失
- 空白期是「无辅具生活」的体验窗口——写她的适应与样态（借靠/扶墙动线/坐姿作业/
  独门技巧迁移），**不渲染苦难与落魄**
- 长度按剧情判断：取回/重获的 setup 在途则等 payoff；**连续 5 章以上空白须明确出口**
  （安排重获事件，或正式转入无辅具），不得无限悬置
- 账本跟踪：`当前状态.拐杖.状态: 不在场`（或 `假肢.状态: 不在场`）+ 登记空白期起章

**拐杖损坏＝渐进危机的铺陈素材**：拐头磨损打滑、杆弯/断、调节锁扣失灵、腋托脱落——
写异响、打滑、骤失支撑的瞬间；损坏本身是场景点缀/器具特写，
只有导致事情办不成才成立受限 beat（与「拐头打滑只作点缀」同口径）

### 衍生类 2：双手占用（辅具依赖轴）

> 衍生自：移动功能由辅具承担 → 辅具占用双手，与任务争手。
> **前置条件：角色设定含移动辅具**（同衍生类 1）。无辅具类型（单腿跳为主 /
> 幻想替代移动）时双手本就自由、无「放拐」环节，本类不触发。
> **处置按 `topics/hands-occupied.md` 腾手策略阶梯选层**——挂肘/夹持等腾手方案
> 可行时放拐即非理性（轻微占手放拐＝拐杖分离的同族错误）；
> 合法放拐＝末端解条件（双手完全占用+物品不可分离+须移动）或**十步以内豁免**。

双手要做事 → 拐杖腾不出手 → 按阶梯选处置（挂肘 / 携带重整 / 坐姿作业 /
协助 / 十步内放拐单腿跳）。

- 端餐盘 / 端大碗 / 撑伞 / 牵孩子 / 提重物

**豁免/末端解的处置链（闭环，缺一即出戏）**：放拐 → 单腿跳去做 → 做完 → **跳回去拿拐** → 重新撑起
细则见 `topics/hands-occupied.md`

### 衍生类 3：速度劣势（两轴皆可）

> 衍生自：功能丧失降低移动/操作速度 → 时间窗口内追不上、来不及。

追不上、来不及、绕路耗时。

- 小孩拿走拐杖就跑 → 喊不听、追不上 → 单腿跳着追
- 时间窗口内到不了、跟不上队伍、赶不上关门的瞬间

### 衍生类 4：对立挑衅（不可能动作轴）

> 衍生自：他人展示她丧失的功能——**受限的镜像展示**（对方做得成的，
> 正是她功能丧失做不成的；严格按「事情办不成」判据它不满足，故作镜像注记）。

对立角色用**身体完整性**做心理嘲讽——素材按类取用：
嘲讽的杀伤力来自：**那些正是她生理上做不到的动作**（见 `types/{type}.md#不可能动作`）。

- **动作类**：走模特步、四方步、跷二郎腿、当面踮脚够高处
- **语言类**：「走两步我看看」「你跑一个试试」
- **场景类**：游泳池台阶（对方一步下去、回头等她）、需站着系鞋带的场合（对方当她的面弯腰系好鞋带）
- **关系类**：亲戚让全家人等她一个人上车、集体合影被安排到「不用站着」的位置

- **前置条件**：发生在「被看见」之后（先被看见才被嘲讽）
- **归属**：属受限，**不归入** `core/audience.md` 招牌元素清单里的「被看见」——
  正常的被看见不引发冲突，挑衅是冲突行为
- **主角回应**：只有两种——**嘴硬**（嘴上不认，受伤藏在话里）或**无视**（不接招）
  - ❌ 不写"有力反击 / 反杀"——那会让主角开挂，把冲突廉价化
  - ❌ 不写"默默承受 / 低头忍着"——那会让主角沦为被凝视的客体

### 衍生类 5：环境与他者（主轴的社会投影）

> 衍生自：环境按健全者标准建造 / 他人围绕她的功能丧失作出反应——
> 功能丧失的社会投影（归主轴延伸）。她被如何对待，是受众最深的部分。

- 无障碍厕位被堆杂物/直梯检修/无障碍座位被占：受阻→她的处置（等/绕/开口请让）→结果
- **被过度帮助 beat**（高频）：对方越过她直接挪她的拐杖；双手抢着帮她推门
  反而挡了她的动线；「我帮你吧」打断她刚起手的动作链
- 她的应对三选项：接住并道谢 / 婉拒并演示（「这样就好，谢谢」）/ 沉默地
  重新开始——性格定**默认倾向**、非一次性锁定（同一人不同心境选法可波动，
  波动才是亲近感来源——进阶写法见 `core/audience.md` ★目光的分层）

| 冲突 / 战斗 / 悬疑 | 辅助器具剥夺 / 速度劣势 / 对立挑衅 |

## 四、写法模板与边界

**模板**：`受阻 → 她的处置 → 结果（完成 / 未成 / 妥协）`
——只有呈现没有处置的受限，是"为受限而受限"，砍掉。

**处置探索深度（放弃前至少两轮）**：处置链至少尝试两轮**不同策略**
（变通器具 / 他人协作 / 换路径 / 求助各考虑一遍）才允许落到「放弃」；
放弃的归因落在工具、结构或深度的极限，**不落在身体力量的极限**（归因判据见下方四-补）；
同一次放弃不在内心独白中反复点题（最多一次），重复渲染即滑向无助叙事。

**处置性格化**：同一套动作链，不同性格不同写法——生理事实长在性格上，角色才活：
急性子＝一气呵成偶尔第四步失手重来；慢性子＝每步稳但费时；
要强的人＝拒绝扶膝盖，偏用双拐硬撑。

**边界（仍属回避清单）**：
- ❌ 疼痛、残肢劳损、伤口处理
- ❌ 诉苦、被同情、窘态当看点
- 主语是**她的处置顺序**（先够哪只拐、要不要先坐下、换哪条路），不是"她的窘迫"

**地面受限有门槛**（轻微地面影响不算受限）：

| 判定 | 地面情况 |
|---|---|
| ✅ 成立（可作受限） | 摩擦力极低（结冰、油面、湿滑到站不住）、极度不平、陡坡、吸力强且深度大的泥浆 |
| ❌ 不成立（只作点缀） | 小石子、细沙、略有起伏、一般湿滑——这些不影响事情办成 |

> 判据同总定义：**事情办不办得成**。踩到几颗石子照样走，就不是受限。

**与招牌元素「辅助器具特写」的区分**（两者都围着器具转，别混）：

| | 辅助器具特写（招牌元素，受上限管） | 本文件的受限（受下限管） |
|---|---|---|
| 性质 | **展示性**——让读者看见器具本身 | **功能性**——让某件事做不了 |
| 问句 | 这段是在"看"器具吗？ | 这段是在"事没办成"吗？ |
| 例 | 拐头磨亮了、她把拐杖改装了一下 | 拐杖被拿走 → 追不上 |

> 同一场景可以同时命中两者（拐杖被打飞：辅助器具剥夺 + 器具损毁特写），
> **此时分别计入两套账**，不互相抵扣。

**密度（识别优先 + 窗口式软下限）**：每章先从剧情**识别**天然受限时刻写足，
无天然受限**不强造**（为凑数新建高受限场景＝为受限而受限）；软下限＝
**任意连续 3 章内 ≥2 个核心受限 beat**（弱受限不计入下限统计）；
**不连续两章用同一类**（账本记类型，见 `templates/state-ledger.yaml` 的 `本章登记.受限beat`）

**载体轮转**：同类受限复用须换场景域（上次的双手占用在厨房，这次在雨天街头）

## 四-补2、受限层级判定（核心受限 / 弱受限 / 点缀）

> 受众爱看的是「**能不能**」（方式受限 / 做不到 / 无解），不是「累不累」。
> 层级由剧情天然决定，不由写作密度决定。

**快速判定问句：在截肢事实的基础上，排除体力问题后，不改变行为方式能否完成？**

| 层级 | 判定 | 例 | 地位 |
|---|---|---|---|
| **核心受限** | 原行为方式**做不到** → 须**改变行为方式**（代偿）或**无解** | 单腿截肢：走/跑→做不到→单腿跳/拐杖；健腿被控/需欠身→另一条腿提供支点→做不到→手部代偿/爬；开手动挡→做不到→无解 | 受限 beat，登记账本，受众核心看点，可重点描写 |
| **弱受限** | 行为方式**不变**仍可完成，但有附加代价 | 走累了→休息一会→还是走；走得慢→时间延长→还是走 | 写（不写不真实），但不占核心戏、不登记受限 beat（整块留空）；训练程度只影响本层呈现 |
| **点缀** | 纯体力感受与恢复 | 喘息、出汗、停下歇脚的描写 | 场景真实感配件，一笔带过 |

- **弱受限撞上时间窗口**（限时内没完成）→ 升格为**速度劣势类**核心受限（时间窗口内到不了）
- 核心受限的成因归因仍走「四-补、受限归因判据」（力量性 ❌ / 结构性 ✅）；
  弱受限可写体力代价（累了/慢了），但**不得把弱受限写成核心受限的成因**
  （「因为累所以做不到」＝力量性归因违规）

## 四-补3、受限的心动条件（把流程变体验）

> ⚠ **示范句使用规则（三禁一学）**：
> ❌ 禁止整句抄录（含仅换一两个词）
> ❌ 禁止在同一次创作的近 5 章内复用同一载体
> ❌ 禁止把示范句直接写进正文后只改标点
> ✅ 只能学**结构与手法**——提取其「公式+变量」后，换情境、换载体、换感官通道重新生成
> 自检：我写的这句与示范句对照，**载体/动作/落点意象**三项中相同 ≤1 项；≥2 项相同即判复写，重写
> 闸门：写入正文前过**四道闸门**（见 core/audience.md#四道闸门）

> 受限成立为**戏剧**的条件＝她在乎结果。没有在乎的受阻-处置-结果是流程演示；
> 有了在乎，读者才跟着她使劲。头部作品的受限爽点是「她在着急」，不是「她在解题」。
> （着急是情绪层的在乎，与力量性归因无关——过程中的用力描写与情绪张力
> 不触发归因判据，判据只管**成因**，见四-补。）

**在乎的三种来源**（章级受限 beat 选其一说定）：
- **时间压力**：这一班地铁、关门前的药店、还没写完的卷子
- **尊严**：不给某人看笑话、第一次独自完成、面试/见家长
- **为他人**：他在楼下等着、孩子在看、答应过的事

**平庸 vs 心动对照（受限专属——受众第一偏好此前唯一无示范的板块）**：

> **「够罐」受限示范见 `core/style.md#★三阶示范`**（全库同一示范只立一处）——
> 本文件不再复写该例；受限专属的「在乎的三种来源」分析见上（时间压力 / 尊严 / 为他人）。
> （去"指节有点白"一类套话手势：把'用力'落在与物件的具体接触上，而非"指节/拳头"这类通用紧张手势。）

- 平庸：「拐杖被同学藏起来了，她单腿跳着找。」
  心动：「第四节课代表要提前去抱作业本。拐不在桌腿边——赵鹏们又在玩这个。
  她跳向第一排的时候，走廊里有人经过，她把跳的节奏放得很平常，像只是走快了点。
  找到拐的那一秒，上课铃正好响。」
  → 优化候选（主用）〔白〕〔留〕〔破〕：「交卷前十分钟，笔袋掉在地上。她没举手，单腿踮下去扶住桌沿，一点一点蹲低。前桌回头看了一眼，她已经坐直了，笔袋在桌上。」
- 平庸：「下雨天她拄拐走得慢，赶不上公交。」
  心动：「末班车九点四十。雨把拐头打滑了半分，她换了个握法，把节奏压回自己的
  ——九点三十八，她在站台撑住拐，车门开了，司机看了她一眼，没催。」
  → 优化候选（主用）〔白〕〔留〕〔破〕：「末班船十点一刻。码头到跳板七级台阶，她一级一级下，拐尖点在青苔边上。十点十三，她踏上跳板，船身晃了一下。缆绳那头的船员看着她，手停在半空，没有伸过来。」

**受限的弧线升级**（防 20 章后模板感——受限随主线升性质）：
- 早期：物理受限（做不到→代偿→完成/妥协）
- 中期：身份受限（被如何对待——无障碍被占/被过度帮助/被审视，见衍生类5与目光四层）
- 后期：**她选择不用代偿**——明明可以叫人帮，她偏要自己来；明明有更省力的
  方式，她选了更难的。物理上她早就熟练了，这时候的受限是她自己挑的——
  「选择受限」是人物弧线的终点站

> 正交声明：弧线阶段（早/中/后期）是**剧情推进**维度，时长档位（B/C）是
> **设定属性**维度——熟练度随截肢时长走、受限性质随剧情走，两者独立判定
> （B 档角色剧情后期的熟练度是否足以「自选受限」，随剧情时间流逝的档位
> 演进判，见 `topics/timeline.md`；「自选受限」与「安全败退」的区分见
> `core/audience.md` ★安全败退阀）。

## 四-补、受限归因判据（力量性 ❌ / 结构性 ✅）

> 受限的真实来源是身体结构，不是肌肉力量——健腿经日常代偿不低于常人单腿
> （常人做不到的健腿单腿全蹲，她能做）。把受限写成「力气不够」＝把角色写弱，
> 滑向残弱叙事（受众反感被同情的客体）。

| ❌ 力量性归因（禁） | ✅ 结构性归因（写这个） |
|---|---|
| 「力气不够」「力气用完了」 | **支撑面**：重心出了单脚支撑区（一脚掌大，过了脚尖就稳不住） |
| 「腿没劲」「蹬不动」 | **支点**：无对侧可借力（躯干前倾，没有第二支点把她压住） |
| 「一条腿的力气，不够」 | **合力**：爆发动作靠双腿蹬伸+摆臂的合力，单腿给不出 |
| | **力矩**：进得去、收不回（探入窄处后，无锚点把上身拽回来） |
| | **长度**：臂+器具的几何极限，够着了抓不住 |

> 快速自检：写成因时问「两条健全的腿在这里用的是力量吗？」——
> 用的是支点数量/支撑面积/合力/长度 → 写结构；体力代价（长距离/久站/负重的累与慢）
> 归**弱受限层**（见四-补2），可写但不当成因、不占核心戏。
> 稽查入口：`core/physio-audit.md#反向违规：力量弱化`。
