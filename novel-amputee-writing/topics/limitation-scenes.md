# 受限场景库

> **受限＝肢体缺失让某件事变难或无法完成。**
> ❌ **不是**：拐杖卡住、拐头打滑、上楼梯费劲——这类**有**，但只作场景点缀，
> 不单独成立为受限 beat（那是辅具的小故障，不是"事情做不了"）。
> 注入时机：章级规划时先选 1 个受限场景；写到冲突 / 追赶 / 双手占用 / 对立戏时按类取用。
> 类型特有受限见 `types/{type}.md#受限清单`。

## 一、两条生成轴（受限从哪来）

受限不是靠枚举，是**可推导**的——任意受限都能从这两条轴推出来：

| 生成轴 | 机制 | 推导方式 |
|---|---|---|
| **不可能动作** | 该动作生理上不可完成 → 这件事变难或做不了 | 查 `types/{type}.md#不可能动作`，把任一"不可能"放进具体事件里 |
| **辅具依赖** | 行动力依赖辅具 → 辅具不可用或被双手占用时能力骤降 | 让辅具**不在手**或**必须用双手**，能力立刻掉回 `types/{type}.md` 的原始受限 |

> 这也说明了"拐杖卡住"为什么不算受限：辅具还在手，事情仍做得成。

## 一-补、受限强度分档（随 timeline 档位变化）

> 受限来源＝身体结构（timeline：只有一条腿、重心窄、不能踮脚、无法单腿久站），
> 不是技能生疏——但生疏会叠加在结构上。前后期受限强度须分档：

- **B 近期档**＝结构型＋生疏型：摔倒、误判距离、慌乱的处置顺序（先伸手后发现够不着）
- **C 多年档**＝仅结构型：她熟练利落，但一步台阶就是上不去——**熟练不消解结构**，
  写「她做得又快又好，就是做不了那一件」
- **训练程度**只影响体力型 beat 呈现：初学＝中途放弃；长期适应＝完成但代价高

## 二、五类受限

### 能力丧失（不可能动作轴）

某件事因肢体缺失**直接做不了**。

- 丧尸题材：有车，但是手动挡，只有一条腿 → **开不了**
- 东西掉地上：单腿蹲下去捡——一只手撑地、另一只手捡；
  起身＝扶拐撑起 / 撑扶健侧膝盖 / **就手扶旁边的东西**（顺手，不是必须）
- 单腿久站站不住：排队、等车、站着说话 → 须找依靠或换姿势

### 器具剥夺（辅具依赖轴）

拐杖/假肢**被打飞、被拿走、来不及捡、掉了够不着**。

- 冲突中拐杖被打飞 → 单腿跳着去捡
- 被人拿走 → **追不上**
- 来不及捡 → 单腿跳着继续战斗或周旋

**处置链**：够到 → 跳过去 → 捡回 → 重新撑起（或就地放弃，单腿跳着周旋）
（**单腿跳的体力节奏与默认地位**见 `topics/crutch-usage.md#四-补、无辅具时：单腿跳（默认移动方式）`）

**拐杖损坏＝渐进危机的铺陈素材**：拐头磨损打滑、杆弯/断、调节锁扣失灵、腋托脱落——
写异响、打滑、骤失支撑的瞬间；损坏本身是场景点缀/器具特写，
只有导致事情办不成才成立受限 beat（与「拐头打滑只作点缀」同口径）

### 双手占用（辅具依赖轴）

双手要做事 → 拐杖必须放下 → 单腿跳着做完 → **再跳回去拿拐**。

- 端餐盘 / 端大碗 / 撑伞 / 牵孩子 / 提重物

**处置链（闭环，缺一即出戏）**：放拐 → 单腿跳去做 → 做完 → **跳回去拿拐** → 重新撑起
细则见 `topics/hands-occupied.md`

### 速度劣势（两轴皆可）

追不上、来不及、绕路耗时。

- 小孩拿走拐杖就跑 → 喊不听、追不上 → 单腿跳着追
- 时间窗口内到不了、跟不上队伍、赶不上关门的瞬间

### 对立挑衅（不可能动作轴）

对立角色用**身体完整性**做心理嘲讽——素材按类取用：
嘲讽的杀伤力来自：**那些正是她生理上做不到的动作**（见 `types/{type}.md#不可能动作`）。

- **动作类**：走模特步、四方步、跷二郎腿、当面踮脚够高处
- **语言类**：「走两步我看看」「你跑一个试试」
- **场景类**：游泳池台阶（对方一步下去、回头等她）、需站着系鞋带的场合（对方当她的面弯腰系好鞋带）
- **关系类**：亲戚让全家人等她一个人上车、集体合影被安排到「不用站着」的位置

- **前置条件**：发生在「被看见」之后（先被看见才被嘲讽）
- **归属**：属受限，**不归入** `core/audience.md` 招牌元素清单里的「被看见」——
  正常的被看见不引发冲突，挑衅是冲突行为
- **主角回应**：只有两种——**嘴硬**（嘴上不认，受伤藏在话里）或**无视**（不接招）
  - ❌ 不写"有力反击 / 反杀"——那会让主角开挂，把冲突廉价化
  - ❌ 不写"默默承受 / 低头忍着"——那会让主角沦为被凝视的客体

### 环境与他者（社会性受限）

> 无障碍被占/被挡/被抢先帮/被特殊对待——她被如何对待，是受众最深的部分。

- 无障碍厕位被堆杂物/直梯检修/无障碍座位被占：受阻→她的处置（等/绕/开口请让）→结果
- **被过度帮助 beat**（高频）：对方越过她直接挪她的拐杖；双手抢着帮她推门
  反而挡了她的动线；「我帮你吧」打断她刚起手的动作链
- 她的应对三选项：接住并道谢 / 婉拒并演示（「这样就好，谢谢」）/ 沉默地
  重新开始——三种性格三种选法

## 三、题材适配

| 题材 | 主打受限类型 |
|---|---|
| 末世 / 丧尸 / 废土 | 能力丧失 / 器具剥夺 / 速度劣势 |
| 冲突 / 战斗 / 悬疑 | 器具剥夺 / 速度劣势 / 对立挑衅 |
| 都市日常 | 双手占用 / 速度劣势 |
| 言情 / 家庭伦理 | 对立挑衅 / 双手占用 |
| 职场 / 校园 | 双手占用 / 对立挑衅 |
| 古装 | 能力丧失 / 对立挑衅 |

## 四、写法模板与边界

**模板**：`受阻 → 她的处置 → 结果（完成 / 未成 / 妥协）`
——只有呈现没有处置的受限，是"为受限而受限"，砍掉。

**处置性格化**：同一套动作链，不同性格不同写法——生理事实长在性格上，角色才活：
急性子＝一气呵成偶尔第四步失手重来；慢性子＝每步稳但费时；
要强的人＝拒绝扶膝盖，偏用双拐硬撑。

**边界（仍属回避清单）**：
- ❌ 疼痛、残肢劳损、伤口处理
- ❌ 诉苦、被同情、窘态当看点
- 主语是**她的处置顺序**（先够哪只拐、要不要先坐下、换哪条路），不是"她的窘迫"

**地面受限有门槛**（轻微地面影响不算受限）：

| 判定 | 地面情况 |
|---|---|
| ✅ 成立（可作受限） | 摩擦力极低（结冰、油面、湿滑到站不住）、极度不平、陡坡、吸力强且深度大的泥浆 |
| ❌ 不成立（只作点缀） | 小石子、细沙、略有起伏、一般湿滑——这些不影响事情办成 |

> 判据同总定义：**事情办不办得成**。踩到几颗石子照样走，就不是受限。

**与招牌元素「辅助器具特写」的区分**（两者都围着器具转，别混）：

| | 辅助器具特写（招牌元素，受上限管） | 本文件的受限（受下限管） |
|---|---|---|
| 性质 | **展示性**——让读者看见器具本身 | **功能性**——让某件事做不了 |
| 问句 | 这段是在"看"器具吗？ | 这段是在"事没办成"吗？ |
| 例 | 拐头磨亮了、她把拐杖改装了一下 | 拐杖被拿走 → 追不上 |

> 同一场景可以同时命中两者（拐杖被打飞：器具剥夺 + 器具损毁特写），
> **此时分别计入两套账**，不互相抵扣。

**密度**：每章 ≥1 个受限 beat；**不连续两章用同一类**（账本记类型，见 `templates/state-ledger.yaml` 的 `本章登记.受限beat`）

**载体轮转**：同类受限复用须换场景域（上次的双手占用在厨房，这次在雨天街头）
