# 移动方式分层（辅具 / 单腿跳 / 空白期）

> 本文件是**移动方式判定的唯一权威源**；`topics/crutch-usage.md` 只留拐杖本身的方法与步态。
> 无辅具角色、辅具空白期、临时无辅具三种情形均按本文件执行。

## 一、移动方式分层（全局默认）

> **全局默认＝辅具移动（通用铁则）**：角色设定含移动辅具时，日常移动默认用辅具——
> 拐杖在手＝拄拐走（步态见 `topics/crutch-usage.md#一、步态`），穿着假肢＝假肢走。

❌ **不得写辅具与角色分离**：正文移动方式必须与账本辅具状态一致——
拄拐走 ⇒ 拐杖在手且写出步态动作（摆至/摆过/点地）；
单腿跳 ⇒ 拐杖不在手且未穿假肢（且辅具不在场有原因：放下 / 被夺 / 空白期）。
**无原因的单腿跳出场＝辅具分离错误**（开篇与出场段落高发——出场先交代辅具在场与状态）。

**单腿跳的适用层**（仅以下情形；有辅具的角色不以此为日常方式）：

1. **临时无辅具**：拐杖不在手（被夺 / 来不及捡）或未穿假肢——过渡方式。
   自主的「放下去做事」须过 `topics/hands-occupied.md` 放拐门槛三问
   （腾手可行即禁放拐——轻微占手放拐＝辅具弃用非理性），或落在**十步以内豁免**内；
   合法的自主放拐主要是**空间受限类**事务（如厕隔间 / 淋浴间 / 窄处作业——拐进不去那空间）
2. **无辅具设定**：辅具类型＝无(单腿跳)——此时单腿跳是该角色的默认移动方式
3. **辅具空白期**：移动辅具全部不可用的跨章状态（见 `topics/limitation-scenes.md` 衍生类 1）
4. **幻想向特殊移动在位**：翅膀 / 御剑 / 超级跳等身体部位与特殊能力承担当前移动时
   （非辅具，见 `genre/fantasy.md#八、特殊移动体系`）——空中 / 能力段按特殊移动写，
   落地后的地面移动仍回本分层铁则；特殊移动失效或被剥夺时同样回落本层

- 单腿跳**不限于短距离**，长距离也靠它（只是体力节奏不同，见下节）
- 临时 / 空白期的单腿跳不是「落魄」——写得利落熟练，是她的备用步法；
  但**有辅具时不用辅具反而失真**（双拐在手还蹦着走＝失真）

## 二、体力节奏（负面描写适度，不写崩）

- 跳一段歇一下，**不是跳几下就垮**
- 随距离与时间增加，**歇的频次与时长相应增加**
- **前期**：停下站一会儿，接着跳
- **后期**：扶物或坐下歇，或者咬牙硬扛
- **歇过之后回不到最佳状态**——只是能继续，不是满血
- **扶物 / 扶墙是顺手**：有就扶，没有也能跳，**不是必须**
- **连跳能力（口径）**：熟练者可**连续跳十几步以上**——起跳、落地、起跳是一条连着的链，
  只在需要转向、选落脚点、让过障碍时略顿；写法上保留**每一跳落地的下沉感**（单脚承重），
  ❌ 不写「三步一停」「一，二，停」一类机械节拍（旧口径**已废止**——
  那等于把她练出来的熟练度写没了）
- **长距离＝分段推进**：能连跳很远，但不是一口气跳到地方——分段来自**距离、路况与她自己的取舍**，
  ❌ 不写「体力只够跳五步」一类定额。**跨章追踪**：连续急行 / 追赶之后，下一章须有恢复代价
  （见 `core/physio-audit.md#战斗受伤与代价的合法边界`，代价走恢复时长，不走疼痛）

## 三、爬行的门槛

**爬行只在特殊情况下**：健腿受伤，或地面极度受限（摩擦力极低、吸力很强的深泥浆）。
❌ 不作为「累了就爬」的常规降级方式——那是把角色写弱。

## 四、无辅具角色的位移学（阵地型战斗的基础）

> 无辅具下肢角色（髋离断 / 膝上 / 膝下，辅具类型＝无）的位移特征与「拄拐者」不同：
> 拐杖可分走两侧支撑，单腿跳**没有第二支点可分**。写作与战斗设计按下列四条执行。

| 特征 | 物理事实 | 写作后果 |
|---|---|---|
| **转向慢** | 转身须把整个身子带过去，不能原地换脚 | 被绕后即失位；两侧受敌时只能朝一边（见 `topics/combat-mechanics.md#二、类型分型总表（十一型）`） |
| **不能追** | 能连跳十几步以上，但**慢**：每一跳都要重新蹬地，比常人奔跑慢得多 | 追击＝放弃；速度劣势类受限的高发源 |
| **跨障受限（不是全不能跨）** | **膝盖以上高度、或落点须精准的障碍不可跨，只能绕**（车辕 / 深沟）；**低矮障碍可单腿一跃而过**（门槛 / 浅沟 / 倒卧物），代价是每一跳重新蹬地、落地收不住重心 | 绕行＝时间成本；地形对她不是背景，是算术。❌ 不写「凡需抬腿越过的都过不去」——那既与 `topics/crutch-usage.md` 拄拐者「过门槛」冲突，也抹掉了熟练单腿跳者跃过低障的能力（口径同步见 `topics/combat-mechanics.md#六、地形矩阵`） |
| **站定稳·位移弱** | 站定后稳，靠的是**单脚＋剑/墙/车补第二支点构成三角支撑**（不是「双脚」）——单足支撑面比双足更小、截断整条腿后重心反而**上移并偏健侧**，❌ 不写「重心低」；移动中极弱 | 「**站定输出**」是她的强项，「换一个点」是她的弱项；**敌人针对＝逼她移动、逼她倒地**（❌ 不是「逼她离开窄口」——窄路取胜已禁用，K13）。「一个身位内最稳」只指**站定输出的稳定**，❌ 不得据此把她摆进窄道卡口（K13） |

- **反制写法**：她能做的不是「更快」，是「**让对方多做一个动作**」——制造 1–2 拍空档（扬沙/泼油/
  熄灯/断绳/绊倒/贴抱），在空档里原地输出。❌ 不是「选窄处、卡门口、把战场压在一个身位以内」
  （K13 禁用）；反复用同一种制造手段（扬沙/泼油）才是套路（见
  `topics/combat-mechanics.md#八、她的解法谱（战术目标与招法）`）
- **敌方针对清单**、**她能不能打/拿什么打/倒了怎么办**：见
  `topics/combat-mechanics.md#二、类型分型总表（十一型）`——本文件不重复列，避免两处口径。
- ❌ 不写「她跳得比跑还快」「一步三尺」这类超人化描写（幻想向特殊移动除外，见第四层）

## 五、与账本的对齐

- 账本 `当前状态.拐杖.状态` / `假肢.状态` / `辅具空白期` 三处是本文的比对源；
  正文每次移动方式变化，账本须有对应动作（放下 / 拿起 / 被夺 / 取回）
- 无辅具角色：`拐杖.数量: 无`、`假肢.状态: 不适用`，**留空即视为未登记**（机检不查，冷读会查）
