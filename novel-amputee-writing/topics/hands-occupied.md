# 双手占用与移动矛盾（AI 写作高发错误区）

> 单腿截肢者（尤其髋离断、膝上高位）高度依赖双拐，**双拐占用双手**。
> 大量日常场景需"双手+移动"，产生矛盾。AI 写作有两类高发错误：
> ①忽略矛盾直接写（立即出戏）；②**反向出戏**——有零成本腾手方案却设计放换单腿跳
> （辅具弃用非理性，实测曾致开篇拐杖与角色分离：为一杯水放拐蹦跳）。
> 处置须按下方「一-补、腾手策略阶梯」选层，**不是默认放拐**。
> 适用类型：hip-disarticulation、transfemoral(高位) 强适用；transtibial 基本不适用（假肢为主）。
>
> **本文件是受限「双手占用」类的完整处置体系**（定义见 `topics/limitation-scenes.md#衍生类 2：双手占用（辅具依赖轴）`）。

## 一、核心矛盾
- 行走需双拐 → 双手被占
- 常人无感的"边走边用手"场景，截肢者无法直接做到
- **必须写出变通，否则出戏**——读者（尤其慕残者）一眼看穿；
  但变通≠放拐——有拐不用（腾手方案存在时）同样是出戏

## 一-补、腾手策略阶梯（处置选层，按优先级）

> "双手+移动"矛盾的处置**从阶梯顶层往下选**，放拐是**末端解**。

**★近距离豁免（优先于阶梯）**：目标在**十步以内**，可优先考虑放拐单腿跳——
短距离内重新撑拐的仪式成本高于跳本身，这是合理日常而非辅具弃用。
（豁免的是"非理性"判定，**不是"交代"义务**——放拐动作与跳的过程仍须写出，
拐杖放置逻辑见第三节）

1. **腾手优先（拐不离身）——按辅具类型分两支，不可混套**：
   - **①A 前臂拐（肘拐）**：cuff 挂前臂是**天然优势**，可较久保持；
   - **①B 腋拐（本技能默认辅具，见 `topics/crutch-spec.yaml`、髋离断默认腋拐）**：**不能挂肘**，
     只能「单拐夹腋」「单手持双拐并拢」「短时挂肘弯」——注意 `types/hip-disarticulation.md` 默认腋拐，
     髋离断角色的腾手一律走 ①B，❌ 不得写 cuff 挂肘（那是前臂拐的物理前提）。
   杯子、手机、书本等**单手可持物一律走本层**。**注意支撑降级**：挂肘/夹腋/并拢后该拐不撑地不承重，
   支撑点减半——原地站立作业优先；须移动则单拐支撑缓行或扶物挪步，不写健步如常
2. **改变携带**：背包、推车、分次搬运、雨衣替代伞——物品重整后正常拄拐走
3. **坐姿作业**：把"边移动边做"改成"移动到位坐下做"（移动段拄拐，做事段腾手）
4. **他人协助**：接、递、代拿
5. **放拐单腿跳（末端解）**：仅当**双手完全占用＋物品不可分离＋必须保持移动**
   （端滚烫汤移动、抱婴儿转移、双手持重物过窄处级别）

**放拐门槛三问**（设计放拐场景前必过；十步豁免情形除外）：
- **腾手可行吗**——存在挂肘/夹持/背包等任一解即**禁放拐**
  （为一杯水/一部手机放拐＝拐杖分离的同族错误）
- **公共空间吗**——他人目光成本（联动招牌⑥"被看见"与角色自尊人设；
  嘴硬要强者不会在人群里主动蹦跳供人观看）
- **距离多远**——超过十步，体力与仪态成本陡增；长距离放拐移动＝失真

## 二、高发错误场景清单

> 多解并存时**优先靠阶梯上层**（一-补）；标注「十步内」的放拐解法仅在近距离豁免范围内合法。

## 三、拐杖放置逻辑（不能凭空消失）

拐杖不是道具可凭空出现/消失，必须有**放置动作链**：
- **靠墙立**：到目的地先把拐杖靠墙立稳
- **放倒**：坐时拐杖放倒在地或靠椅边
- **夹腋**：临时腾一手时单拐夹腋下
- **挂肘 / 挂肘弯**：前臂拐松手后 cuff 挂前臂＝**挂肘**（拐不撑地不承重、支撑减半）；腋拐松手后拐身挂肘弯＝**挂肘弯**（短时）
- **交给他人/靠物体**
- **起身**：先够到拐杖再撑起
- **取回**：事情做完后**回到放置处把拐杖拿回来**（单腿跳回去），再重新撑起

> 账本登记用同一套枚举（见 `templates/state-ledger.yaml` 的 `拐杖.状态`）：
> 在手 / 靠墙 / 放倒 / 夹腋 / 挂肘 / 挂肘弯 / 交他人 / 不在场

> 错误典型：写主角"放下拐杖"后下一秒又"拄着拐杖走"，却没写拿起动作。
> **另一类半成品**：做完直接走人、缺了闭环末两步——处置链定义见本文件开头
> 与 `topics/limitation-scenes.md#衍生类 2：双手占用（辅具依赖轴）`。

## 四、写作总则
1. 凡"双手+移动"场景，先问：**拐杖在哪？双手怎么腾出来？**
2. 写出变通（挂肘/停/放/夹/背/车/分次/跳），矛盾本身就是真实细节
3. 拐杖放置/拿起的动作链要写全，不凭空
4. **处置按一-补阶梯选层**：腾手方案可行时不设计放拐（轻微占手放拐＝
   辅具弃用非理性）；放拐走「末端解」条件或落在**十步豁免**内；
   豁免内处置链同样闭合：放拐 → 单腿跳去做 → 做完 → **跳回去拿拐** → 重新撑起，
   四步缺一不可（见 `topics/limitation-scenes.md#衍生类 2：双手占用（辅具依赖轴）`）
5. 受限是生活样态非苦难，写好反增代入感（慕残者专看这些）
6. 仅高度依赖拐杖的类型适用；膝下截肢假肢为主少此矛盾

## 五、适用类型
- `hip-disarticulation`：强适用（双拐绝对主力）
- `transfemoral`(高位)：强适用（假肢非优先时）
- `transfemoral`(低位/假肢优)：弱适用
- `transtibial`：基本不适用
