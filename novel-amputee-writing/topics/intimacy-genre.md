# 成人内容的题材分册（四题材 × 六栏）

> **定位**：`topics/intimacy-explicit.md` 是"怎么写"的通用执行层，本文件是"这个题材里能有什么、怕什么"的**可得性层**。
> 两者分工：explicit 管动作与露骨度，本文件管**物件、风险、目击者、衣物、事后、禁忌**。
> **不读本文件的后果**：古装写成现代都市——有润滑液、有避孕套、有独立卧室、没人听见；
> 末世写成无菌棚；幻想写成"魔法自动解决一切"。
>
> **注入时机**：亲密尺度档 = B 或 C 时，与 `intimacy-explicit.md` 同时注入；
> A 档只读「衣物」「目击者」两栏（A 档也需要"这个时代的人怎么穿、怕谁看见"）。

## 用法

1. 先定题材 → 读对应一块。
2. 六栏逐栏过：**可得物**（有什么）/ **风险**（怕什么）/ **目击者**（谁能看见）/ **衣物**（怎么脱、脱到哪）/ **事后**（怎么收）/ **禁忌**（这个题材特有的出戏点）。
3. 每场亲密戏至少用到**两栏**（例：末世用"可得物：没有润滑，用食用油"+ "目击者：帐篷不隔音"）。
4. 六栏都空＝这场戏可以搬去任何题材，那它就是"通用色情"，不是这个题材的戏。

## 一、现实向（都市/校园/职场/家庭）

| 栏 | 内容 |
|---|---|
| **可得物** | 润滑液（便利店/网购）、避孕套（药店/自动贩卖机/抽屉里翻出来的过期一只）、毛巾、纸巾、湿巾、手机（关静音/放歌盖声音）、空调遥控器 |
| **风险** | 被室友/父母/孩子听见；合租隔断墙；手机消息弹窗；避孕失败；月经期；职场关系暴露；年龄差被人议论；前任纠缠 |
| **目击者** | 室友（隔一堵墙）、邻居（老楼隔音差）、家人（突然回来/有钥匙）、同事（酒店走廊）、孩子（单亲家庭必写一次"门没锁"） |
| **衣物** | 现代衣物层数少但**脱起来有声音**（拉链/皮带扣/纽扣）；假肢要脱、拐要放倒；内衣是"脱到什么程度"的节奏器；鞋是最后脱的（很多人不脱） |
| **事后** | 洗澡（谁先去）、扔套（扔哪、被谁看见）、床单（湿了一块、翻面）、点外卖、各自看手机、谁先睡 |
| **禁忌** | ❌ 无菌感（刚做完就干净整洁）；❌ 无后果（永远不避孕、永远不被听见）；❌ 无障碍公寓（老楼没电梯、卫生间窄、床太软起不来） |

- **现实向最好用的是"隔音"与"门锁"**：它们把残疾的现实（她起身慢、拐在地上、假肢在床边）变成紧张源。

## 二、古装（礼法/门第/权力）

| 栏 | 内容 |
|---|---|
| **可得物** | **无润滑**（用脂膏/花油/唾液，且须有铺垫：梳妆台上的口脂、厨房的猪油）；**无避孕**（体外/事后冲洗/藏红花/麝香，且都不可靠）；布巾（白绫/汗巾，**落红是证据**）；水盆、香炉、烛火、帐钩、汤婆子 |
| **风险** | **名分**（未婚先孕＝沉塘/逐出/为妾）；**礼法**（男女七岁不同席、叔嫂不通问）；**门第**（高门纳妾 vs 寒门私通）；**生育**（嫡庶、无子、难产）；**奴仆的嘴**（丫鬟/小厮是活证据）；**身体隐秘暴露**（截肢在古装是"天罚/不祥"的读法，见 `genre/historical.md`） |
| **目击者** | 丫鬟/婆子（守夜、送水、隔窗）、更夫、同院住的妾、族中长辈（突然来人）、庙里的尼姑（借宿） |
| **衣物** | **层数多**：中衣/亵衣/外衫/裙/披帛/袜/履；**脱衣是时间**（一层一层），也是**声音**（系带、玉扣、裙裾）；束胸/抹胸/肚兜；发髻散了就是"失仪"的视觉证据；**截肢侧的袖子/裤管怎么处理**（见 `topics/clothing.md` 古装部分） |
| **事后** | 打水（谁去打、被谁撞见）、烧水、换褥子、梳头（重新盘髻＝掩盖证据）、**避子汤**（谁煎、谁送、苦不苦）、天不亮就走（赶在请安前） |
| **禁忌** | ❌ 现代性脚本（事前洗澡、事后抽烟、说"我爱你"）；❌ 润滑液/避孕套/酒店；❌ 无仆人的大宅；❌ 烛火通明（应是"只留一盏"）；❌ 女方主动被写成现代平等谈判（古装里的主动是**用规矩内的手段**：递茶、留灯、遣开丫鬟） |

- **古装的核心张力不是"能不能做"，是"做完之后怎么收场"**：落红、避子汤、丫鬟的嘴、第二天的请安。
- **截肢 + 古装**：她的身体是"不祥"的证据，亲密里第一次被看见的那一下，风险比现代高一个量级（见 `genre/historical.md#★题材结构包（故事引擎，不只是场景库）` 的「身体隐秘」条）。

## 三、末世（废土/丧尸/灾变）

| 栏 | 内容 |
|---|---|
| **可得物** | **无润滑**（食用油/凡士林/护手霜，都是稀缺物资）；**无避孕**（安全期/体外/根本没有）；**无水**（清洁是奢侈）；布条代替纸巾；帐篷/睡袋/车厢/地下室；**味道**（汗、血腥、消毒水） |
| **风险** | **声音**（隔墙有耳不算，隔墙有尸；床架响/她忍不住的声音＝团灭）；**感染**（伤口、不洁、残端皮肤破损）；**怀孕**（末世生育＝两条命）；**资源**（一支药、一瓶水都是账）；**群体道德**（谁有资格配对、强者占有、被排挤） |
| **目击者** | 同帐篷的人、守夜的人、放哨位、孩子（末世里的孩子什么都懂）、被俘者、**丧尸不是目击者是威胁** |
| **衣物** | 层数少但**不脱完**（冷/随时要跑）；绑带、护具、假肢不卸（卸了就跑不了）；外套铺地上；**她身上可能还带着武器** |
| **事后** | 擦（干布/雪/酒精）、喝水、检查伤口、听外面的动静、谁守上半夜；**没有"温存时间"，只有"下一个威胁"** |
| **禁忌** | ❌ 无菌棚式洁净（刚做完就干净、有热水、有床单）；❌ 忽视卫生（不写清洁与感染风险）；❌ 无视声音（末世做爱是战术问题）；❌ 把怀孕当甜点（末世怀孕是灾难） |

- **末世最好的写法是"压低声音"**：整场戏的音量、动作幅度、什么时候停，都由"外面有没有东西"决定。
- **残疾在末世的加成**：她不能跑，所以"做完之后能不能立刻起身"是真问题（`topics/combat-mechanics.md` 倒地/起身链）。

## 四、幻想（高魔/高武/神话）

| 栏 | 内容 |
|---|---|
| **可得物** | 魔法润滑（炼金/药膏/精油，须有来源与代价）、避孕（避孕药水/符文/法术，**须写明失效条件**）、结界（隔音/遮蔽，须有维持消耗）、契约（血契/灵魂契）、法器（会亮/会响/会认主） |
| **风险** | **魔力反噬**（情绪高涨时法术失控）；**契约代价**（血契的条款、灵魂契的抵押）；**身份暴露**（她是魔族/神裔/通缉者）；**感知共享**（神识/共感＝无法隐藏欲望）；**生育**（半血后代的诅咒/预言） |
| **目击者** | 使魔/契约兽（会说话的最危险）、同门/同修（神识扫过）、神明（誓言被听见）、结界外的人（看不见但听得见） |
| **衣物** | 法袍/道袍/软甲/披风；**法术着装**（幻化衣、法器化衣）；脱衣＝卸防（法袍是防御的一部分）；**残端/假肢的魔法义肢怎么卸**（见 `topics/combat-mechanics.md#十五` 定性） |
| **事后** | 结界撤除（魔力见底）；契约的即时反馈（印记发烫/誓言生效）；**治愈术的边界**（可止血，不可治截肢）；双修/共鸣的后续（修为变化） |
| **禁忌** | ❌ **用魔法"修好"截肢**（硬底线，见 `core/physio-audit.md#题材豁免`）；❌ 无代价的结界/避孕/治愈；❌ 双修写成升级外挂（爽点可以，但不能替代关系推进）；❌ 神力/领域让身体受限消失（`topics/combat-mechanics.md#15.2-bis`） |

- **幻想的核心增量是"代价可见"**：结界要维持、避孕符会过期、治愈术只止血——每一样都要在事后付账。
- **高魔 + 截肢的红线**：能力可以替她飞、替她挡、替她出手，**不能替她长出一条腿**；
  亲密里也一样——魔法义肢是辅具，不是真手（`core/physio-audit.md#上肢截肢违规类别` 三档判定）。

## 五、跨题材通用三条（任何题材都成立）

1. **身体事实先于情欲**：她怎么躺、患侧放哪、器具在哪、起来要多久——先解决这些，再谈情欲。
   （体位矩阵见 `topics/intimacy-explicit.md#六`）
2. **目击者是燃料，不是背景**：每个题材都有"谁能看见"的答案；写出来，紧张就有了。
3. **事后决定这一场是不是真的**：清理、归位、谁先走、明天怎么见——事后写得实，前面才不虚。

## 六、与剧情编排的接口

- **外部后果必选一项**（首次 C 之后 3 章内，见 `core/chapter-planning.md#6.2`）：
  现实＝被听见/避孕失败/名声；古装＝落红/避子汤/丫鬟的嘴/名分；末世＝怀孕/感染/资源账/群体排挤；
  幻想＝契约生效/身份暴露/反噬/预言。
- 本文件的"风险"栏就是外部后果的**选项库**——不要另造，直接用。
