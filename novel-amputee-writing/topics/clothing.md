# 服装与视觉信号

> 截肢者的服装处理及对他人传递的截肢事实视觉信号。
> 跨类型通用，类型差异见 `types/{type}.md#服装`。

## 一、裤装处理

患侧裤腿**按类型处理**：髋离断＝裤子在裆线/大腿根部收口，裆线以下**无裤管**；
膝上/膝下＝残端下缘以下空。写实际处理方式：

| 处理方式 | 裁剪位置 | 做法 | 适用 |
|---------|---------|------|------|
| 折叠塞裤腰 | 不裁剪 | 患侧裤腿折叠后塞进裤腰/口袋 | **假肢为常用辅具时默认**；公用服装不便裁剪时 |
| 裁剪缝合 | **髋离断→大腿根部（裆线/腹股沟）；膝上→残端下缘；膝下→残端下缘** | 患侧裤腿裁短至该位置，缝合封口 | 假肢非常用辅具（如日常用拐杖）；日常常服、长期 |
| 打结 | 不裁剪 | 患侧裤腿打结束起 | 刚截肢初期，尚未掌握塞裤腰技巧时 |

> **假肢为常用辅具时默认折叠塞裤腰，不裁剪**：裁剪后裤腿封死，假肢无法穿进。故需穿假肢者保留裤腿完整，不穿时折叠塞裤腰。
> 打结：刚截肢初期未掌握折叠塞裤腰技巧的临时做法。

**空裤管的写法（★按"是否已处理"判定，易写错）**

> **判据：空裤管只在「未处理」时存在。**
> 一旦**裁剪缝合**（封口）或**折叠塞裤腰 / 打结**（裤管不再垂下），就没有空裤管了，不得再写。

| 情形 | 有无空裤管 | 写法 |
|---|---|---|
| **髋离断** · 常服已裁剪（裆线收口） | **无**——裤子在裆线处就结束 | ❌ 不写空裤管；视觉信号是「裆线以下无裤管」 |
| **髋离断** · 未裁剪公用服装 | 有垂下的一截，但**空瘪** | ✅ 可写空瘪、空垂、**随动作晃动、被风吹起**；❌ 不写"被残肢带动"（无残端） |
| **膝上/膝下** · **未处理**（不折叠、不裁剪） | **有**——残端下缘以下垂着一截空管 | ✅ 可写**变瘪、飘荡**，属明显视觉信号 |
| **膝上/膝下** · 已裁剪缝合 | 无（已封口） | ❌ 不写空裤管 |
| **膝上/膝下** · 折叠塞裤腰 / 打结 | 无垂下的空管 | ❌ 不写空裤管 |
| **肩离断**（上装） · **已裁剪**（肩峰下缘/肩缝处） | **无**——袖子在肩缝处就结束 | ❌ 不写空袖管、不写飘荡 |
| **肩离断**（上装） · **未裁剪**公用上装 | **有**垂下的一截，空瘪 | ✅ 可写空瘪、空垂、**随动作晃动、被风吹起**；❌ 不写"被残端带动"（无残端） |

**空管的晃动（★各类通用，易写错）**

> 空管（空裤管 / 空袖管）**会动**——**随身体动作晃**、**被风吹起飘荡**，
> 这两样**任何类型都有**，不是残肢的专利。
> **唯一不会的：被残端主动带动。**

- ✅ 可写：空垂、空瘪、随动作晃动、被风吹起、飘荡
- ❌ 不写「被残肢 / 残端**带动**而摆动」——髋离断、肩离断**无残端**，这样写是错的
- ❌ 不写「像里面有条腿 / 有只手臂那样有规律的摆动」
- ✅ 膝上/膝下、肘离断/腕离断**有残端**，可写「残肢带动裤管 / 袖管」

> 旧表述「走路时完全不晃」**已废止**——那把"无残肢带动"错等同于"不动"。

## 二、裙装处理

- **裙摆不处理**：裙装自然遮盖患侧，**裙摆自然垂落，无需收口或裁剪**
- 遮盖效果**按裙长分档**，见下节「视觉信号」表的穿着列

## 三、视觉信号（他人如何感知截肢事实）

> **总前提**：失去部分肢体在**未用假肢**时，是**极其明显的视觉信号**——
> 不是"仔细看才发现"，是**一眼便知**。
> **核心规律：静止可藏，移动必露。**

| 穿着 | 器具 | 静止 | 移动 |
|---|---|---|---|
| 裤装（已裁剪/收口） | 无 / 拐杖 | **一眼便知**（髋离断＝裆线以下无裤管；膝上/膝下＝残端以下空） | 一眼便知 |
| 裤装（未折叠/未裁剪，**即"未处理"**） | 无 / 拐杖 | **一眼便知**：空裤管变瘪（各类型皆空瘪） | 一眼便知：空裤管飘荡（随动作或风吹，**各类型皆可**；仅膝上/膝下可写"残肢带动"） |
| 短裙 | 无 / 拐杖 | **一眼便知**：裙摆遮盖范围小，裙摆下只有一条腿 | 一眼便知 |
| 长裙·及小腿 | 无 | 未看到小腿/残端时**难以分辨** | **暴露**：单腿跳，无交替步态 |
| 长裙·及小腿 | 拐杖 | **易误判**：受伤 / 骨折 / 崴脚 | **暴露**：摆至/摆过步同样非交替步态 |
| 长裙·及踝 | 无 | **难以分辨** | **暴露** |
| 长裙·及踝 | 拐杖 | **易误判**（误判概率更高） | **暴露** |
| 长裙 | 假肢 | 不易察觉（假肢撑起下摆） | 不易察觉（假肢恢复交替步态） |
| 裤装 | 假肢 | 不易察觉（假肢撑起裤管） | 不易察觉 |

> **为什么移动必露**：单腿跳 / 摆至步 / 摆过步**都没有交替步态**，
> 与两条腿的走路方式差别极大——他人很快就会察觉异常。
> 唯一例外是**假肢**（恢复了步态形态），所以**长裙+假肢是唯一真正藏得住的组合**。

## 四、写作要点

- 裤装写处理方式（裁剪/折叠/打结）；**空裤管只在"未处理"时写**——
  已裁剪缝合或折叠塞起就不写空裤管；髋离断常服任何情况都不写
- 打结限刚截肢不久 + 公用服装
- 裙装**不处理裙摆**（自然垂落），但**裙长决定遮盖效果**
- **长裙+拐杖的"误判"是戏剧素材**——他人以为受伤/骨折/崴脚，真相是截肢
- **移动即暴露**是更强的素材：她藏得住衣服，藏不住步态
- 视觉信号影响社交：被一眼看穿 vs 被误判 vs 不被察觉 vs 移动后露馅，各有戏
- 慕残者关注：截肢事实如何被他人感知，是代入与张力的来源

## 五、类型差异：裁剪位置（★易写错）

| 类型 | 患侧有无内容物 | **裁剪基准位置** | 常见错误 |
|------|--------------|----------------|---------|
| `hip-disarticulation` 髋离断 | 裆线**以上有**（那儿的肉撑起）；裆线以下无 | **大腿根部（裆线 / 腹股沟处）**，自裆线以下缝合封口 | ❌ 写"裁剪到胯骨那儿"；❌ 写患侧"空裤管" |
| `transfemoral` 膝上截肢 | 有（残肢撑起） | **残端下缘**，略放长 1–2cm 容纳残肢袜/接受腔上缘 | ❌ 写成完全空；❌ 裁剪位置写成裆线（膝上有残肢，裤管要留到残端）；❌ **已裁剪缝合后仍写空裤管飘荡** |
| `transtibial` 膝下截肢 | 穿假肢时有（假肢撑起）；不穿时残端以下空 | 穿假肢时基本不处理（略微调短）；不穿时**残端下缘** | ❌ 不穿假肢时仍写裤管如常；❌ **已裁剪缝合后仍写空裤管飘荡** |
| `shoulder-disarticulation` 肩离断（上装） | 无（无上臂、无袖） | 上装**肩峰下缘（肩缝处）** | ❌ 写"裁剪至锁骨"；❌ **已裁剪后仍写空袖管飘荡**（未裁剪公用上装可写空瘪/晃动） |

### 补充细节
- **髋离断**：患侧常服**没有裤管**，裤子在裆线处结束；正面看裆线封口、侧面看患侧臀下空。
  裆线以上由**那儿的肉**撑起，外观接近一段很短的大腿根
- **肩离断**：患侧常服**没有袖子**；宽松上衣易向患侧滑落，需合肩
- **膝上/膝下**：患侧裤管短而有内容物，残肢可主动带动裤管；髋离断的软组织只能随体位变形，
  区别在**能否主动带动**
- **髋离断**穿未裁剪的公用服装（病号服、临时外裤）：患侧裤管空垂空瘪，
  会随动作晃动、被风吹起，**但不会被残肢带动**（无残端）
- 裙装无需裁剪处理，**裙摆自然垂落**

## 六、隐藏截肢事实

> 隐藏是「视觉信号」的**反向操作**：想办法不让别人看出来。

- **触发条件**（剧情驱动，缺一不写）：
  - 末世 / 废土 / 丧尸：**截肢者＝弱者**，暴露会大幅增加被抢夺、被抛弃、被针对的风险
  - 剧情需要角色隐瞒（身份、求职、初入某环境、不想被特殊对待等）
- **可用手段**：长裙 / 长袍 / 宽大下摆；避免短裙、避免露出空裤管；坐着时把患侧收好
- **天花板（隐藏的真正难点）**：**衣服能藏，步态藏不住**。
  单腿跳没有交替步态，一动就露——所以真正有效的隐藏是**尽量少动**：
  坐着不起身、借故不走动、让别人过来她这边、提前到位再等人
- **❌ 剧情约束（硬）**：隐藏**根据剧情判断是否需要触发，不能为了写而写**。
  判定问句：**这段剧情里，她有必须隐藏的理由吗？** 没有就不写隐藏
- **隐藏失败的后果**：被识别 → 按题材升级风险（末世＝抢夺/抛弃；日常＝被凝视/被议论），
  可作 stakes 变化或危机素材
