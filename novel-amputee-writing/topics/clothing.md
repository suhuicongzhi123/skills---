# 服装与视觉信号

> 截肢者的服装处理及对他人传递的截肢事实视觉信号。
> 跨类型通用，类型差异见 `types/{type}.md#服装`。

## 零、★先判裙裤（写服装前必做）

> 裙装与裤装**处理方式完全不同**。开写前**先判定：这是裙装还是裤装？**

**判定问句**：它是**分开的两条裤腿**（裤装），还是**一片下摆**（裙装）？

**按形态判，❌ 不按名字判**——名字会骗人：

| 名字 | 实际 | 判定 |
|---|---|---|
| 战裙（一片下摆） | 一片式下摆 | **裙装** |
| 战裙（分开的裤腿） | 战斗服 / 裙裤 | **裤装** |
| 裙裤 | 分开的两条腿 | **裤装**（不是裙装） |
| 罩裙 / 一片式战袍 / 长袍 | 一片下摆 | **裙装** |
| 裤裙（两腿分开） | 分开的腿 | **裤装** |
| **里裤外裙**（两件叠穿） | 内层裤 + 外层裙 | **两层分别判定**，见「二-补」 |
| 衬裤 / 安全裤（裙下） | 内层是分开的裤腿 | **裤装**（内层） |

| 判定结果 | 处理方式 |
|---|---|
| **裤装** | 按第一节（裁剪 / 折叠 / 打结 + 裁剪位置） |
| **裙装** | 按第二节（**不裁剪、不收口**，裙摆自然垂落） |
| **组合（里裤外裙）** | 两层分别处理：内层按第一节、外层按第二节，见「二-补、组合搭配：外裙里裤」 |

> ⚠ **判错则全错**：裙装上**不存在"裆线收口""缝合封口"**这些概念——
> 收口是**裤腿末端**的处理，裙装没有裤腿。把裤装的"裆线收口"套到裙装上，是最常见也最出戏的错误。

## 一、裤装处理

患侧裤腿**按类型处理**：髋离断＝裤子在裆线/大腿根部收口，裆线以下**无裤管**；
膝上/膝下＝残端下缘以下空。写实际处理方式：

| 处理方式 | 裁剪位置 | 做法 | 适用 |
|---------|---------|------|------|
| 折叠塞裤腰 | 不裁剪 | 患侧裤腿折叠后塞进裤腰/口袋 | **假肢为常用辅具时默认**；公用服装不便裁剪时 |
| 裁剪缝合 | **髋离断→大腿根部（裆线/腹股沟）；膝上→残端下缘；膝下→残端下缘** | 患侧裤腿裁短至该位置，缝合封口 | 假肢非常用辅具（如日常用拐杖）；日常常服、长期 |
| 打结 | 不裁剪 | 患侧裤腿打结束起 | 刚截肢初期，尚未掌握塞裤腰技巧时 |

> **假肢为常用辅具时默认折叠塞裤腰，不裁剪**：裁剪后裤腿封死，假肢无法穿进。故需穿假肢者保留裤腿完整，不穿时折叠塞裤腰。
> 打结：刚截肢初期未掌握折叠塞裤腰技巧的临时做法。

**空裤管的写法（★按"是否已处理"判定，易写错）**

> **判据：空裤管只在「未处理」时存在。**
> 一旦**裁剪缝合**（封口）或**折叠塞裤腰 / 打结**（裤管不再垂下），就没有空裤管了，不得再写。

| 情形 | 有无空裤管 | 写法 |
|---|---|---|
| **髋离断** · 常服已裁剪（裆线收口） | **无**——裤子在裆线处就结束 | ❌ 不写空裤管；视觉信号是「裆线以下无裤管」 |
| **髋离断** · 未裁剪公用服装 | 有垂下的一截，但**空瘪** | ✅ 可写空瘪、空垂、**随动作晃动、被风吹起**；❌ 不写"被残肢带动"（无骨性残肢；有软组织残端但撑不动裤管） |
| **膝上/膝下** · **未处理**（不折叠、不裁剪） | **有**——残端下缘以下垂着一截空管 | ✅ 可写**变瘪、飘荡**，属明显视觉信号 |
| **膝上/膝下** · 已裁剪缝合 | 无（已封口） | ❌ 不写空裤管 |
| **膝上/膝下** · 折叠塞裤腰 / 打结 | 无垂下的空管 | ❌ 不写空裤管 |
| **肩离断**（上装） · **已裁剪**（肩峰下缘/肩缝处） | **无**——袖子在肩缝处就结束 | ❌ 不写空袖管、不写飘荡 |
| **肩离断**（上装） · **未裁剪**公用上装 | **有**垂下的一截，空瘪 | ✅ 可写空瘪、空垂、**随动作晃动、被风吹起**；❌ 不写"被残端带动"（无残端） |

**空管的晃动（★各类通用，易写错）**

> 空管（空裤管 / 空袖管）**会动**——**随身体动作晃**、**被风吹起飘荡**，
> 这两样**任何类型都有**，不是残肢的专利。
> **唯一不会的：被残端主动带动。**

- ✅ 可写：空垂、空瘪、随动作晃动、被风吹起、飘荡
- ❌ 不写「被残肢 / 残端**带动**而摆动」——髋离断无骨性残肢、肩离断无残端，这样写是错的
- ❌ 不写「像里面有条腿 / 有只手臂那样有规律的摆动」
- ✅ 膝上/膝下、肘离断/腕离断**有残端**，可写「残肢带动裤管 / 袖管」

> 空管**会动**——随身体动作晃动、被风吹起飘荡，**各类皆有**；"无残肢带动"≠"不动"。唯一不写的是「被残端主动带动」——当残端不存在时（髋离断无骨性残肢、肩离断无残端）。

## 二、裙装处理

- **不裁剪、不收口、不封边**：裙装自然遮盖患侧，**裙摆自然垂落，无需收口或裁剪**
- ❌ **不写**「在裆线收口」「缝合封口」「残端下缘收边」——那是**裤装**的做法，
  套到裙装上即错（裙装没有裤腿，也就没有"收口"这一说）
- 裙装的视觉信号由**裙长**决定，见下节「视觉信号」表的穿着列：
  - **短裙**：裙摆下只有一条腿 → 一眼便知
  - **长裙（及小腿 / 及踝）**：静止时难分辨或被误判，移动即暴露

> 判定方法见本节前面的「★先判裙裤」——**先判再写**，不要凭名字想当然。

## 二-补、组合搭配：外裙里裤

> 外裙 + 内裤（或衬裤 / 安全裤）是常见叠穿——**两层分别判定、分别处理**。

| 层 | 判定 | 处理 |
|---|---|---|
| **内层（裤）** | 裤装 | **仍按裤装规则处理**——髋离断在裆线收口、膝上/膝下在残端下缘收口；或折叠塞裤腰 |
| **外层（裙）** | 裙装 | **不处理**——自然垂落，不裁剪、不收口 |

**❌ 常见错误**：以为"外面套了裙子，里面的裤子就不用管了"。
内层的裤腿**仍然在身上**，该收口的照样收口、该折叠的照样折叠——
它只是**被外裙遮住了**，不是"不存在"。

**"看不见" ≠ "不用写"**：

- 内层的处理**照样要写**——它有穿着体感：收口处的缝线、折叠塞起的厚度、坐下时的压感、
  裙摆下露出一截的收边
- 它只是**不向他人传递视觉信号**（被外层挡住了）
- 区分两层：**视觉信号看外层，穿着体验看内层**

**视觉信号由外层裙长决定**：

| 外层裙长 | 视觉信号 |
|---|---|
| 短裙（遮不住内层裤管） | 内层若露出 → 按**裤装**信号（一眼便知） |
| 长裙（及小腿 / 及踝，遮住内层） | 按**裙装**信号：静止难分辨或被误判，**移动即暴露** |

> ⚠ 特殊情形：**裙摆被掀起 / 坐下时裙摆上移 / 风吹起裙摆**——
> 内层裤装的收口会短暂露出，这是天然的戏剧瞬间（可对接招牌元素⑥「被看见」），
> 但❌ 不要写成刻意展示。

## 三、视觉信号（他人如何感知截肢事实）

> **总前提**：失去部分肢体在**未用假肢**时，是**极其明显的视觉信号**——
> 不是"仔细看才发现"，是**一眼便知**。
> **例外**：**长裙（及小腿 / 及踝）+ 静止**时可遮蔽或被误判——**移动即暴露**（见下）。
> **核心规律：静止可藏，移动必露。**

| 穿着 | 器具 | 静止 | 移动 |
|---|---|---|---|
| 裤装（已裁剪/收口） | 无 / 拐杖 | **一眼便知**（髋离断＝裆线以下无裤管；膝上/膝下＝残端以下空） | 一眼便知 |
| 裤装（未折叠/未裁剪，**即"未处理"**） | 无 / 拐杖 | **一眼便知**：空裤管变瘪（各类型皆空瘪） | 一眼便知：空裤管飘荡（随动作或风吹，**各类型皆可**；仅膝上/膝下可写"残肢带动"） |
| 短裙 | 无 / 拐杖 | **一眼便知**：裙摆遮盖范围小，裙摆下只有一条腿 | 一眼便知 |
| 长裙·及小腿 | 无 | 未看到小腿/残端时**难以分辨** | **暴露**：单腿跳，无交替步态 |
| 长裙·及小腿 | 拐杖 | **易误判**：受伤 / 骨折 / 崴脚 | **暴露**：摆至/摆过步同样非交替步态 |
| 长裙·及踝 | 无 | **难以分辨** | **暴露** |
| 长裙·及踝 | 拐杖 | **易误判**（误判概率更高） | **暴露** |
| 长裙 | 假肢 | 不易察觉（假肢撑起下摆） | 不易察觉（假肢恢复交替步态） |
| 裤装 | 假肢 | 不易察觉（假肢撑起裤管） | 不易察觉 |

> **为什么移动必露**：单腿跳 / 摆至步 / 摆过步**都没有交替步态**，
> 与两条腿的走路方式差别极大——他人很快就会察觉异常。
>
> **穿戴假肢时不用"藏"**：假肢撑起裤管/裙摆且恢复了交替步态，
> 所以**裤装+假肢、长裙+假肢都不易察觉**（上表最后两行）。
> **未用假肢时**，唯一能短暂遮蔽的只有**长裙 + 静止**——一动就露。

## 四、写作要点

- 裤装写处理方式（裁剪/折叠/打结）；**空裤管只在"未处理"时写**——
  已裁剪缝合或折叠塞起就不写空裤管；髋离断常服任何情况都不写
- ❌ **禁止否定式缺失描写**：写了「在 X 处收口」后**不再追加**「没有裤管 / 没有袖管 /
  下面什么都没有 / 空空的」——**写了收口就等于说了那里没有**，追加即此地无银三百两
  （见 `core/style.md#★禁止注释式纠错与注释式解释`）
- 打结限刚截肢不久 + 公用服装
- 裙装**不处理裙摆**（自然垂落），但**裙长决定遮盖效果**
- **长裙+拐杖的"误判"是戏剧素材**——他人以为受伤/骨折/崴脚，真相是截肢
- **移动即暴露**是更强的素材：她藏得住衣服，藏不住步态
- 视觉信号影响社交：被一眼看穿 vs 被误判 vs 不被察觉 vs 移动后露馅，各有戏
- 慕残者关注：截肢事实如何被他人感知，是代入与张力的来源

## 四-补、标签锁定（旁人印象中的她）

- **不使用假肢的截肢者：截肢事实是最明显的标签**——比疤、比任何其他身体标签都
  更有力度、更直接、更容易锁定。旁人印象里她直接被定型：
  「那个独腿的女孩」「那个一条腿的」「那个拄拐的女孩」「那个受伤的女孩」
  「那个瘸子」「这个人只有一条腿」；上肢截肢同理：「那个只有一只手的女孩」。
- **藏不住，丢不掉**：长裙+静止可短时遮蔽、可被误判（受伤/崴脚，见上方误判表）；
  但**移动即暴露**——藏得住衣服，藏不住步态。即便一时藏住，一次突发动作、
  一趟上下楼、相处日久，最终都会暴露。标签一旦贴上就丢不掉——它先于她的名字被记住。
- **使用假肢的下肢截肢者**：截肢事实被遮蔽，旁人标签降级为**步态标签**——
  「走路不方便」「走路一瘸一拐」；细看、被告知或假肢暴露后才升级为截肢事实。
- **写作口径**：旁人反应按辅具分档——无假肢＝一眼定型（标签先于了解）；
  假肢＝先看步态（标签含糊），暴露后标签才换代。称呼强度落差
  （「那个女孩」→「那个拄拐的」→「那个瘸子」）本身就是素材。
- ❌ 标签是**旁人口语称呼**（印象/对话层素材）；正文叙述层仍守否定式缺失描写禁令
  （见 `core/style.md`）——可写「旁人管她叫'那个拄拐的女孩'」，不写叙述句「她没有腿」。

## 五、类型差异：裁剪位置（★易写错）

| 类型 | 患侧有无内容物 | **裁剪基准位置** | 常见错误 |
|------|--------------|----------------|---------|
| `hip-disarticulation` 髋离断 | 裆线**以上有**（那儿的肉撑起）；裆线以下无 | **大腿根部（裆线 / 腹股沟处）**，自裆线以下缝合封口 | ❌ 写"裁剪到胯骨那儿"；❌ 写患侧"空裤管" |
| `transfemoral` 膝上截肢 | 有（残肢撑起） | **残端下缘**，略放长 1–2cm 容纳残肢袜/接受腔上缘 | ❌ 写成完全空；❌ 裁剪位置写成裆线（膝上有残肢，裤管要留到残端）；❌ **已裁剪缝合后仍写空裤管飘荡** |
| `transtibial` 膝下截肢 | 穿假肢时有（假肢撑起）；不穿时残端以下空 | 穿假肢时基本不处理（略微调短）；不穿时**残端下缘** | ❌ 不穿假肢时仍写裤管如常；❌ **已裁剪缝合后仍写空裤管飘荡** |
| `shoulder-disarticulation` 肩离断（上装） | 无（无上臂、无袖） | 上装**肩峰下缘（肩缝处）** | ❌ 写"裁剪至锁骨"；❌ **已裁剪后仍写空袖管飘荡**（未裁剪公用上装可写空瘪/晃动） |

### 补充细节
- **髋离断**：患侧常服的裤子**在裆线处收口结束**（自裆线以下缝合封口）；
  正面看裆线封口、侧面看患侧臀下空。（规则说明**不写**"没有裤管"这类句子，见写作要点）
  裆线以上由**那儿的肉**撑起，外观接近一段很短的大腿根
- **肩离断**：患侧常服**没有袖子**；宽松上衣易向患侧滑落，需合肩
- **膝上/膝下**：患侧裤管短而有内容物，残肢可主动带动裤管；髋离断的软组织只能随体位变形，
  区别在**能否主动带动**
- **髋离断**穿未裁剪的公用服装（病号服、临时外裤）：患侧裤管空垂空瘪，
  会随动作晃动、被风吹起，**但不会被残肢带动**（无骨性残肢）
- 裙装无需裁剪处理，**裙摆自然垂落**

详见 `types/{type}.md#服装`

## 六、隐藏截肢事实

> 隐藏是「视觉信号」的**反向操作**：想办法不让别人看出来。

- **触发条件**（剧情驱动，缺一不写）：
  - 末世 / 废土 / 丧尸：**截肢者＝弱者**，暴露会大幅增加被抢夺、被抛弃、被针对的风险
  - 剧情需要角色隐瞒（身份、求职、初入某环境、不想被特殊对待等）
- **可用手段**：长裙 / 长袍 / 宽大下摆；避免短裙、避免露出空裤管；坐着时把患侧收好
- **天花板（隐藏的真正难点）**：**衣服能藏，步态藏不住**。
  单腿跳没有交替步态，一动就露——所以真正有效的隐藏是**尽量少动**：
  坐着不起身、借故不走动、让别人过来她这边、提前到位再等人
- **❌ 剧情约束（硬）**：隐藏**根据剧情判断是否需要触发，不能为了写而写**。
  判定问句：**这段剧情里，她有必须隐藏的理由吗？** 没有就不写隐藏
- **隐藏失败的后果**：被识别 → 按题材升级风险（末世＝抢夺/抛弃；日常＝被凝视/被议论），
  可作 stakes 变化或危机素材
